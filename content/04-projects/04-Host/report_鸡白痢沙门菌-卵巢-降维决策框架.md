# 鸡白痢沙门菌(SP)-鸡卵巢:从"器官"到"细胞"的降维研究决策框架

> **本文档定位**:这不是一份从零启动的项目方案,而是一份**针对你当前研究节点的方法论决策框架** — 把"从组织降维到细胞"这件事讲清楚、讲透,并基于你已有的实验进度(已完成成鸡+幼雏感染期/持续期 scRNA-seq)给出**承上启下的下一步行动建议**。
>
> 写作参照: Reyes et al. 2025 *Cryptococcus* — 微胶质细胞延迟激活 (Spp1/IFN-γ 轴) 研究 — 提供了一个结构上完全同构的"宿主-病原-组织微环境-细胞降维"实验链。

## 0. 总览(给课题组讨论用的一页摘要)

**你的研究锚点**
- 系统: 鸡白痢沙门菌(*Salmonella* Pullorum, SP)感染鸡卵巢
- 已完成: 器官层面表型(卵泡病变、定植量) + scRNA-seq(成鸡 & 幼雏,感染期 & 持续期)
- 核心机制问题: **靶细胞身份 + 胞内命运**
- 现有资源: 荧光标记 SP 菌株 ✓ / 鸡卵巢解离经验 ✓ / 测序+空间组学预算 ✓

**核心论断(本文档的中心思想)**
> 从器官到细胞的"降维",不是一个技术堆叠问题,而是一个**信息纯度问题**:每一步降维都在剔除掉"非靶细胞的信号背景",让你能听清楚真正回答机制问题的那一小群细胞的"声音"。

**降维必要性的三层逻辑**
1. **组织层面无法分辨"被感染细胞" vs "旁邻细胞"** — CFU 是混合信号,IHC 只能看少数标记物,无法量化"谁被入侵了"。
2. **不同细胞类型的胞内命运可能截然相反** — Salmonella 在巨噬细胞里"安家",在上皮里被清除;两者混在一起的 bulk 数据会互相抵消。
3. **垂直传播的"特洛伊木马"必然是少数细胞** — 罕见关键细胞群体在器官 bulk 信号中会被稀释 100-1000 倍,只有降维到细胞分辨率才能看到。

**你目前所处的位置**
```
[器官层面表型] → [IHC/CFU定位] → [scRNA-seq图谱✓你在这里] → [???下一步缺什么]
                                          ↑
                                你已经"降维"到了细胞图谱,
                                但缺乏 "感染状态" 这一维度的标注
```

**最关键的判断 — 你 scRNA-seq 数据的"盲区"**
- 当前 scRNA-seq 让你看到了**所有卵巢细胞类型在感染时的转录变化**
- 但**没有直接区分"细胞内含 SP" vs "邻近被旁观影响的细胞"**(因为细菌 mRNA 在标准 10x 文库里不可靠捕获,且未做 GFP+/- 分选预富集)
- 这导致目前的图谱**只能回答"哪些细胞类型在感染时被扰动"**,**还回答不了"哪些细胞实际包含 SP 且 SP 在里面活/死/复制"**

**下一步降维的核心任务**
不是再做一次 scRNA-seq,而是用 **3 种相互正交的技术补齐 3 个缺失维度**:
- 空间维度: 空间转录组 → 病灶在哪、邻居是谁
- 感染态维度: SP-GFP FACS 分选 + dual RNA-seq → 谁真的包含菌、菌在里面什么状态
- 因果维度: 体外原代细胞 + RNAscope/IF 共定位 → 验证降维结论

## 1. 必要性论证 — 为什么不能停在器官层面

### 1.1 鸡卵巢的特殊性放大了"降维"的紧迫性

鸡卵巢不是均匀组织,而是**多发育阶段卵泡构成的等级结构**(产蛋期母鸡尤其明显):
- **F1–F5 大黄卵泡**:数量少但体积大,被颗粒细胞-膜细胞-基质层包裹
- **小黄卵泡 (SYF, 6–8 mm)**:数十个
- **白色卵泡 (WF, <6 mm)**:数百个
- **皮质卵巢区**:原始卵泡储备 + 间质 + 血管 + 神经
- **髓质**:富含血管、淋巴、巨噬细胞

每个区域的**细胞构成、激素背景、免疫细胞密度、SP 易感性**都不同。器官 bulk 数据(CFU、IHC、bulk RNA-seq)把这些区域的信号**平均成一锅粥**,你看到的是"卵巢被感染了",但完全不知道:
- 是哪个区域的哪种细胞被感染
- 感染信号在不同卵泡阶段的差异
- 旁观细胞与真正感染细胞的应答差异

### 1.2 降维要回答的 4 个具体机制问题(对应你的"靶细胞身份+胞内命运")

| 机制问题 | 器官层面能回答吗 | 降维到细胞后能回答什么 |
|---|---|---|
| **Q1: SP 主要被卵巢内哪种细胞类型摄取?** | ❌ CFU 总量看不出细胞分布 | 颗粒/膜/巨噬/上皮等谁的胞内荷量最高 |
| **Q2: SP 在不同细胞中存活/复制 vs 被清除的差异?** | ❌ 总菌量混合信号 | 胞内菌量 + 菌转录态 (dual RNA-seq) |
| **Q3: 哪些细胞是"持续期库藏"细胞 — 解释垂直传播?** | ❌ 罕见库藏细胞被稀释 | scRNA-seq 检出罕见持续期细胞群体 |
| **Q4: 被感染细胞 vs 旁邻细胞的应答区别?** | ❌ Bulk 转录全是混合 | GFP+/GFP-分选 → 真正胞内菌驱动的应答 |

### 1.3 Reyes 2025 的镜面验证

Reyes 团队在 *Cryptococcus* 脑感染研究中做了一个**几乎和你一样**的降维链条 — 但他们走完了从 CFU → IHC → FACS+bulk → scRNA-seq → CellChat → 基因敲除的全链条。最关键的洞察是:

> 如果他们停在器官层面,他们会得出 "脑里有炎症" 这种空洞结论 —— **必须降维到"微胶质细胞 vs 浸润髓系"才发现微胶质细胞反应迟钝**,才进一步推断出 T 细胞→微胶质细胞的 IFN-γ 轴,才能用基因敲除验证因果。

你的 SP-卵巢研究面临完全相同的逻辑陷阱:**只看器官,你能写出"产蛋下降+卵泡病变+CFU 升高"这种描述性论文,但永远写不出机制论文**。

## 2. 系统性技术对比 — 在鸡卵巢现实条件下逐一评估

> 每一项技术都从**4 个维度**评估:**它能回答什么问题** / **鸡卵巢的特殊挑战** / **优势** / **致命缺陷或风险**

### 2.1 文献挖掘 + 公共数据再利用 [Step 0 — 性价比最高]

**回答的问题**: 不浪费已有人类知识的捷径 — 先确认你要做的事别人是不是已经做了,以及"颗粒细胞被沙门菌侵补"等具体假设的文献证据强度。

**关键检索方向**:
- 鸡卵巢/卵泡 scRNA-seq:Estermann et al. 2020 (*Cell Reports*) 鸡胚卵巢细胞图谱;近年若干鸡产蛋期卵巢/输卵管 atlas
- *Salmonella* 感染组织 scRNA-seq:小鼠肠道 Paneth/M cell / 脾脏 / 骨髓 / 输卵管文献
- *Salmonella* 在 macrophage vs epithelial 胞内命运分歧机制(STM 文献丰富)
- 鸡白痢与肠炎沙门菌(Enteritidis, Gallinarum)在卵巢中的细胞嗜性差异

**鸡卵巢的特殊点**: 鸡参考基因组(GRCg7b)注释完整度低于小鼠/人,免疫细胞标记基因尤其需要交叉验证 — 例如鸡"巨噬细胞"标记 MRC1L-B、CSF1R、TIMD4 在不同公共数据集里命名不一致。

**优势**: 0 实验成本 / 2 周内可完成 / 直接服务你的 scRNA-seq 注释复用 / 帮你写文献综述

**风险**: 鸡卵巢相关 scRNA-seq 资源相对小鼠匮乏,部分细胞类型可能没有参考图谱可借鉴 → 需要部分细胞类型靠 marker 推断和形态学验证。

---

### 2.2 免疫组化/免疫荧光(IHC/IF) [Step 1 — 必做的"组织地图"]

**回答的问题**: SP 在卵巢里的**空间分布** — 集中在哪种卵泡阶段、哪个组织层、是否形成 granuloma 样结构。这一步在 Reyes 论文里对应他们用 GXM/MBP/Iba-1/GFAP 多色 IF 描绘"病灶外环-中心"梯度。

**鸡卵巢的特殊挑战**:
- **自发荧光严重**: 卵泡颗粒含大量脂质(尤其黄色卵泡),卵黄甚至直接发绿光 → 必须做 Sudan Black B 处理或选用远红荧光通道(Cy5、AF647)
- **组织异质性高**: 一张切片可能含多个发育阶段,需要明确取材标准(例:每只鸡固定取 F1 + 小黄卵泡 + 皮质区 + 髓质,4 个区域分别处理)
- **鸡抗体匮乏**: 多数小鼠/人抗体在鸡上需重新验证;关键标记物的 IHC 验证抗体(鸡 CD45 / CSF1R / Iba-1 类似 / 颗粒细胞 STAR、CYP17A1 / 膜细胞 INHA)需要预先逐一测试

**优势**: 成本低 / 直接给你"病灶在哪、谁挨着 SP"的直观图像 / 是后续所有降维的"地图基础"

**风险**: 单张切片只能看 3-5 个标记物 → 无法做高维细胞类型分辨;只能看蛋白,不知道转录态

**强烈建议**: 用 **SP-GFP 菌株 + 多色 IF (4 色)** 做时空侦察:
- 通道 1: SP-GFP (内置)
- 通道 2: pan-leukocyte (鸡 CD45)
- 通道 3: 颗粒细胞(STAR / FOXL2)
- 通道 4: 巨噬细胞(MRC1L-B 或 CSF1R)
- DAPI

这一步**必须先做**,因为它会告诉你 scRNA-seq 数据里看到的"应答细胞"在空间上是不是真的挨着 SP。

### 2.3 流式细胞术(单细胞悬液) [Step 2/3 — 量化+富集的关键中转]

**回答的问题**: 不同细胞类型中**含 SP 比例 (GFP+%)、胞内菌强度 (GFP MFI)**、激活状态变化(MHC-II、CD86)。这是你"靶细胞身份"问题最直接的定量答案。

**鸡卵巢与肠道解离的核心差异(这是你的具体疑惑)**:

| 维度 | 鸡肠道(参照) | 鸡卵巢 |
|---|---|---|
| **组织密度** | 中等,黏膜易剥离 | 致密,基底膜/血管丰富,大卵泡需先机械剥离 |
| **关键易损细胞** | 上皮细胞 | 卵泡颗粒细胞(剪切力敏感)、卵母细胞(直径毫米级,无法走 10x) |
| **脂质含量** | 低 | 极高(尤其黄色卵泡含大量卵黄前体) → 影响乳化、堵塞微流控芯片 |
| **酶解配方** | EDTA + 胶原酶 IV | **建议**: 分两步 — 先机械剥离大卵泡(避开 F1-F5 的卵黄),再用胶原酶 II/IV + DNase I + 透明质酸酶联合;**避免** 胰蛋白酶(损伤颗粒细胞膜抗原) |
| **温度** | 37°C 短时 | 37°C 不超过 30-45 min,期间晃动温和;长时间会启动细胞应激转录(IL1B、HSP70 假阳性) |
| **细胞活率** | 80–90% 较易达到 | 65-80% 是现实区间,死细胞导致 ambient RNA 污染(对 scRNA-seq 是大问题) |
| **批次效应** | 卵泡数量稳定 | 不同鸡个体卵巢阶段不同 → **必须按发育阶段配对取样** |

**关键的"被感染 vs 旁邻"区分方案**:

| 方案 | 怎么做 | 信息内容 | 注意 |
|---|---|---|---|
| **A. SP-GFP 内置法 (最干净)** | 用 GFP 标记的 SP 菌株感染 → 流式直接读 GFP 信号 | 真实胞内菌(活菌信号) | 需注意 GFP 在死菌中也保留 → 配合 propidium iodide 区分活菌-死菌 |
| **B. SP 表面抗体染色法 (后处理)** | 解离后用抗 SP 血清 + 二抗 染色 | 包含表面附着的菌(可能高估真"胞内") | 适合没有 GFP 株的备份方案 |
| **C. GFP + gentamicin 处理 (金标)** | 解离时用 gentamicin (50–100 μg/mL) 杀死胞外菌,只留胞内菌 → GFP 阳性即真胞内 | 真正区分胞内 vs 表面附着 | 多一步,但最严谨 |

**优势**: 量化能力强 / 可分选 (FACS) 用于下游测序 / 抗体 panel 可达 8-10 色

**风险**:
- 解离损失大卵泡里的卵母细胞和大颗粒细胞 (>40 μm) → 这部分细胞 scRNA-seq 也漏
- 鸡流式抗体 panel 不如小鼠丰富 — 需要提前用 SouthernBiotech、BioRad、和国内中农大试剂确认抗体可用性

### 2.4 激光捕获显微切割(LCM) [Step 2.5 — 可选,病灶特异性提取]

**回答的问题**: 从切片上**精确抠出 SP 阳性病灶 vs 远端正常组织**,做空间分辨的 bulk RNA-seq 或者 dual RNA-seq。

**在 SP-卵巢系统中的真正用途**: 不是和 scRNA-seq 二选一,而是**互补**:
- scRNA-seq 失去了空间信息,LCM 保留空间信息
- scRNA-seq 测不到细菌 mRNA,LCM 富集的病灶可以做 dual RNA-seq(因为局部细菌密度高)
- LCM 能抠出**罕见但形态特异的病灶**(例如卵泡内部的微菌落),这些细胞在解离-scRNA-seq 中会被稀释丢失

**鸡卵巢的特殊挑战**:
- **冰冻切片 vs FFPE 选择**: 强烈推荐 **冰冻切片(OCT)** 用于 LCM-RNA — 鸡卵巢脂质含量高,FFPE 固定+脱蜡过程 RNA 降解严重,RIN 常 <4。冰冻切片 RIN 可保持 7+。
- **形态识别**: SP-GFP 在冰冻切片中保留荧光信号良好 → 可做 GFP 指导的 LCM (光镜下直接抠 GFP+ 区域)
- **量需求**: 每个 LCM 样本需 ~5000-10000 细胞起 (bulk RNA-seq);现代低输入测序方案 (Smart-seq3、SMART-Seq Total RNA) 可降到 200-500 细胞

**优势**: 唯一能在保留空间信息前提下做 dual RNA-seq 的方案 / 罕见病灶富集 / 配合冰冻切片是金标准

**风险**: 通量低 / 操作员经验依赖性极高 / 鸡卵巢冰冻切片做厚切+染色后形态保留比小鼠脑差(脂质)

**适合你的场景**: **如果你的 scRNA-seq 在持续期看到的"罕见库藏细胞"频率 <0.5%,LCM 是抢救它们的最后手段。**

### 2.5 单细胞转录组 scRNA-seq / CITE-seq [Step 3 — 你已在这里]

**回答的问题**: 全卵巢细胞类型谱 + 感染时的转录状态变化 + 罕见细胞群发现。

**你已完成**: 成鸡 + 幼雏,感染期 + 持续期 scRNA-seq

**你的数据缺什么 — 这是这份方案的核心诊断点**:

| scRNA-seq 数据能/不能回答的 | 你目前的状态 |
|---|---|
| ✓ 卵巢有哪些细胞类型 | 已有(假设你完成了注释) |
| ✓ 感染期 vs 持续期各细胞类型频率变化 | 已有(假设你做了对比) |
| ✓ 各细胞类型的应答基因 (DEG) | 已有 |
| ✓ 推断的 cell-cell communication (CellChat) | **建议补做** — Reyes 论文的关键工具 |
| ✓ 罕见细胞群 (e.g. 持续期库藏细胞) 鉴定 | 数据里应该有,但需要专门搜索 |
| ❌ "这个细胞含 SP 吗" | **未解决** — 10x 不可靠捕获细菌 mRNA |
| ❌ "SP 在这个细胞里是死的还是活的、转录什么" | **未解决** — 需要 dual RNA-seq |
| ❌ "这个细胞在卵巢哪个位置" | **未解决** — 单细胞数据丢失空间信息 |
| ❌ "这个 DEG 是被感染导致 vs 旁观应答" | **未解决** — 因为没做 GFP+/GFP- 预分选 |

**CITE-seq vs 普通 scRNA-seq 的取舍**:
- CITE-seq 的优势是同时拿到蛋白和 RNA 信号 — 适合解决鸡转录本注释不全、抗体识别能补充蛋白层信息的问题
- 但鸡专用 CITE-seq 抗体几乎没有商品化,需要 conjugate 自己做 → 工作量大
- **建议**: 如果要补做一次,做 **CITE-seq 必要性中等**,优先级低于"SP-GFP 预分选 + scRNA-seq"

### 2.6 空间转录组(Visium / Stereo-seq / MERFISH) [Step 4 — 你需要补的关键技术]

**回答的问题**: **在原位**告诉你 — SP 阳性区域 (用 IHC/GFP 标定的) 周围细胞是谁、转录什么、形成什么微环境。这是你目前 scRNA-seq 的**最大盲区互补**。

**3 种平台的鸡卵巢适配性比较**:

| 平台 | 分辨率 | 鸡卵巢适用性 | 成本/样本 | 优势 | 风险 |
|---|---|---|---|---|---|
| **10x Visium** | 55 μm spot (多细胞) | 较好,组织 6.5×6.5 mm 适合卵巢小区域 | $4-6k | 操作成熟、生信工具完善 | 分辨率不到单细胞;大卵泡装不下 |
| **10x Visium HD** | 2 μm (subcellular) | 好 | $6-8k | 接近单细胞分辨率 | 鸡参考库需自建 |
| **Stereo-seq (华大)** | 纳米级 spot,可重构单细胞 | **国内最有优势** | $5-10k 看面积 | 大视野,可一次覆盖整个卵巢横切面 | 数据量大、生信门槛高 |
| **MERFISH / Xenome** | 真单细胞,靶向 panel | 鸡 panel 需自定义 | $10-15k+ | 真单细胞分辨,蛋白+RNA可结合 | 鸡 panel 没有商品化,需 500 基因自定义 |

**强烈推荐**: **Stereo-seq** (如果国内合作可行) 或 **Visium HD** — 因为:
1. 你已有 scRNA-seq → 空间转录组的分析范式是 **空间数据上反卷积 scRNA-seq 细胞类型注释 + 定位 SP-GFP 病灶**
2. 你不需要再发现新细胞类型,只需要把已知细胞类型映射回空间
3. 大视野覆盖能力对鸡卵巢异质性是刚需

**鸡卵巢空间组学的特殊挑战**:
- 切片厚度: 10-16 μm 是 Visium 标准,但鸡卵巢需要确认黄色卵泡是否会脱片(高脂质)
- 取材: 建议每只鸡同时取 1 张冰冻切片 (空间转录组) + 邻近切片做 IHC/IF (做 SP-GFP 定位匹配)
- 参考基因组: 用 GRCg7b + Ensembl 注释,部分免疫基因可能需要手动添加 (鸡 IFNG、IL10、CSF1R 注释经常不全)

## 4. 针对鸡卵巢的技术贴士(实操级)

### 4.1 解离方案 — 鸡卵巢专属酶解配方

```
推荐流程(成鸡产蛋期卵巢):
1. 取卵巢 → 立即冰浴 HBSS (Ca²⁺/Mg²⁺-free)
2. 机械剥离大卵泡 (F1-F5):
   - 镊子剥离卵泡膜,小心保留颗粒细胞-膜细胞层
   - 卵母细胞不进入解离 (太大,无法走 10x)
3. 剩余皮质+髓质 + 小黄/白卵泡 → 切 1-2 mm 碎片
4. 酶解液(每 mL):
   - 胶原酶 II:  0.5-1 mg/mL
   - 胶原酶 IV: 0.5-1 mg/mL
   - DNase I:   100 U/mL (打散死细胞 DNA,极重要 — 防止 ambient RNA)
   - 透明质酸酶: 0.1 mg/mL (松解基质)
   - HBSS + 2% BSA + 10 mM HEPES
5. 37°C 摇床 (60-80 rpm), 30-45 min, 每 15 min 用 5 mL 移液管轻吹松
6. 70 μm 过滤 → 40 μm 过滤
7. 红细胞裂解 (ACK buffer, 鸡 RBC 有核,务必用鸡专用 lysis)
8. Dead cell removal (Miltenyi 试剂盒) — 强烈推荐,鸡卵巢解离后死细胞往往 20-30%
9. 立即用于流式或 10x,不要冻存
```

**避免的陷阱**:
- ❌ 不要用胰蛋白酶 — 损伤颗粒细胞膜表面抗原,影响后续流式
- ❌ 不要 >45 min 酶解 — 启动 IEG (Immediate Early Genes, e.g. FOS、JUN、HSP70) 假阳性
- ❌ 不要冻存 scRNA-seq 样本 — 鸡卵巢解离细胞冻存活率极低
- ❌ 不要省去 Dead cell removal — ambient RNA 污染会让 scRNA-seq 的细菌污染信号也增加,SP 假阳性

### 4.2 确定取样区域 — 时空侦察实验设计

**预实验(2-3 周)**:
1. 用 SP-GFP 株感染 5-8 只产蛋期母鸡 + 同样数量幼雏 + 阴性对照
2. 在 12 h, 24 h, 48 h, 72 h, 7 dpi, 14 dpi (6 个时间点) 各取 2 只鸡
3. 卵巢取材分 4 区域:F1-F5 大卵泡膜层 / 小黄卵泡 / 皮质 + 原始卵泡区 / 髓质
4. 每个区域: 一半冰冻切片 (LCM/空间组学预留) + 一半 OCT 包埋 IF
5. IF 通道: SP-GFP (内置) + CD45 + 颗粒标记 (STAR) + 巨噬标记 (MRC1L-B)

**预实验输出**(决定后续 Steps 取样区域和时间窗):
- 哪个区域的 SP 阳性强度最高
- 急性期 (24-72 h) vs 持续期 (14 dpi+) 的细胞分布差异
- 是否存在"病灶聚集区" → 决定是否需要 LCM

### 4.3 冰冻切片 vs FFPE — 鸡卵巢的特殊抉择

| 维度 | 冰冻切片 (OCT) | FFPE |
|---|---|---|
| **RNA 完整性(RIN)** | 7-9 (优) | 3-5 (差,鸡卵巢脂质加速 RNA 降解) |
| **形态保留** | 中等(脂质易裂) | 好 |
| **GFP 荧光保留** | 优(直接读) | 几乎丢失(需要抗 GFP 抗体) |
| **LCM 适用** | ✓ 推荐 | △ 可,但 RNA 质量差 |
| **空间转录组** | ✓ Visium/Stereo-seq 都支持 | △ Visium-FFPE 可,但鸡卵巢上验证少 |
| **IHC** | 中等 | 优 |

**结论**: **冰冻切片 (OCT) 为主**,用于 LCM / 空间转录组 / GFP 直接读;**FFPE 仅为存档** 和高分辨率形态学补充。

### 4.4 流式中区分"被感染" vs "旁邻" — 最关键的设计

**金标准方案**:

```
1. SP-GFP 株感染 (GFP 在 SP 内组成性表达)
2. 解离后 + gentamicin 50-100 μg/mL on ice 处理 30 min
   (杀死所有胞外/表面附着菌)
3. 流式 panel (推荐 8 色):
   - GFP (内置): SP-GFP+ vs GFP-
   - LIVE/DEAD: 死细胞排除
   - CD45 (免疫细胞总标记)
   - CSF1R/MRC1L-B (巨噬细胞)
   - MHC-II (激活态)
   - STAR/CYP17A1 (颗粒细胞,胞内染色)
   - DNA (Hoechst,排除双联体)
4. 关键分选门:
   - GFP^high CD45+: "被感染免疫细胞"(主要是巨噬)
   - GFP^high CD45-: "被感染非免疫细胞"(颗粒、膜、上皮)
   - GFP^low CD45+: "可能旁邻或正经过的免疫细胞"
   - GFP- 同型细胞: 旁邻对照
5. 各群分选 5000-10000 细胞 → smart-seq3 或 10x 测序
```

**避免的陷阱**:
- ❌ 单纯靠 GFP 阴/阳性二分 — GFP 信号有强度梯度,需用 GFP 阴性对照鸡定门
- ❌ 不做 gentamicin 处理 — 高估"胞内菌"(表面附着的菌也算阳性)
- ❌ 不做活/死染色 — 死细胞会吸附胞外 GFP 信号
