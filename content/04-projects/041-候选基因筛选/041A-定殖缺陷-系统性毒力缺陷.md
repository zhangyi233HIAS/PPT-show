## 在鸡卵巢模型中区分"定殖缺陷"与"系统性毒力缺陷"的实验设计框架

这是沙门氏菌组织嗜性研究中一个核心但常被忽略的方法学问题。当你发现某个突变体在卵巢中丢失时，至少有三种可能解释：

| 缺陷类型             | 含义                            | 机制本质            |
| ---------------- | ----------------------------- | --------------- |
| **A. 卵巢特异性定殖缺陷** | 细菌能到达卵巢，但无法在卵巢微环境中定殖/存活       | 细菌-卵巢组织特异性互作失败  |
| **B. 系统性毒力缺陷**   | 细菌在到达卵巢前已在脾/肝等系统性位点被清除，从未到达卵巢 | 胞内存活/免疫逃逸的一般性缺陷 |
| **C. 混合型**       | 细菌既无法有效到达卵巢，到达后也无法存活          | 两个层次的缺陷叠加       |

### 核心逻辑：**多器官平行取样 + 差异衰减分析**

如果某个基因是系统性毒力因子，突变体应在**所有系统性器官**（脾、肝、卵巢）中一致衰减；如果某个基因是卵巢特异性定殖因子，突变体应在脾/肝正常但在**卵巢选择性衰减**。

---

### 第一层：多器官竞争指数（CI）比较实验

**设计原则**：Shah et al. (2012, _Infect Immun_) 的 qPCR-CI 方案 + 多器官扩展

```
感染途径：口服 (PO) 或腹腔注射 (IP)
              │
              ├── Day 3-7 采集器官
              │     ├── 脾脏 (系统性对照)
              │     ├── 肝脏 (系统性对照)
              │     ├── 盲肠 (肠道定殖对照)
              │     ├── 卵巢 (目标器官)
              │     └── 输卵管膨大部 (生殖道对照)
              │
              └── 计算每个器官的 CI = (突变体/WT)器官 / (突变体/WT)输入
```

**判读矩阵**：

| 卵巢 CI | 脾/肝 CI | 盲肠 CI | 结论                                    |
| ----- | ------ | ----- | ------------------------------------- |
| ↓↓    | ↓↓     | ↓↓    | **系统性毒力缺陷**（如 _ssaV_, _phoP_, _sifA_） |
| ↓↓    | ≈1     | ≈1    | **卵巢特异性定殖缺陷**                         |
| ↓↓    | ↓↓     | ≈1    | **系统性胞内存活缺陷**（SPI-2 类，盲肠腔内不依赖胞内存活）    |
| ↓↓    | ↓      | ≈1    | **偏向系统性但卵巢更敏感**                       |
|       |        |       |                                       |
|       |        |       |                                       |

### 第二层：感染途径控制——绕过系统性屏障

**关键设计**：比较口服 vs 静脉注射（IV）/腹腔注射（IP）感染

```
口服感染 (PO)                    IV/IP 感染
   │                                │
   细菌须经肠道侵入 →               细菌直接进入血流
   系统性播散 → 到达卵巢            → 直达卵巢
   │                                │
   受系统性毒力影响大              受系统性毒力影响小
```

**判读逻辑**：

- 若突变体在口服感染中卵巢丢失，但在 IV 感染中卵巢正常 → **系统性播散/到达缺陷**（基因参与肠道侵入或早期全身性存活）
- 若突变体在两种途径中卵巢均丢失 → **卵巢微环境定殖缺陷**（基因直接参与卵巢内生存）
- 若突变体在 IV 感染中卵巢 CI 部分恢复但仍低于 WT → **混合型**：系统性缺陷为主，叠加部分定殖缺陷

### 第三层：体外卵巢细胞感染模型

**设计**：使用原代鸡卵巢表面上皮细胞（OSE）或输卵管膨大部腺体细胞的庆大霉素保护实验

```
体外感染实验
   ├── 原代卵巢表面上皮细胞 (OSE)
   ├── 原代输卵管膨大部腺体细胞
   ├── HD-11 鸡巨噬细胞 (系统性胞内存活对照)
   └── LMH 鸡肝细胞 (系统性对照)
```

**判读逻辑**：

- 突变体在 OSE 中缺陷但在 HD-11 中正常 → **卵巢细胞特异性侵入/存活缺陷**
- 突变体在 OSE 和 HD-11 中均缺陷 → **一般性胞内存活缺陷**（系统性毒力因子）
- 这一层直接排除了"到达"的问题，因为细菌与细胞直接接触

### 第四层：Tn-seq 多器官比较 + 差异适合度分析

**设计**：基于 Chaudhuri et al. (2024, _Nat Genet_) 的 Rb-Tn-seq 方法学 + 多器官扩展

```
Tn-seq 多器官文库
   │
   ├── 体外条件模拟 (25+ 压力条件)
   │     ├── InSPI2 (胞内模拟)
   │     ├── 低铁 / 低镁
   │     ├── 氧化应激 (H₂O₂, NO)
   │     ├── 抗菌肽 (多粘菌素B, 鱼精蛋白)
   │     └── 胆汁 (输卵管/消化道)
   │
   ├── 体内多器官 Tn-seq
   │     ├── 卵巢 (目标)
   │     ├── 脾脏 (系统性对照)
   │     ├── 肝脏 (系统性对照)
   │     └── 盲肠 (肠道对照)
   │
   └── 差异分析
         ├── 卵巢特异性衰减基因 = 在卵巢中|t|>4 但在脾/肝中无显著衰减
         ├── 系统性衰减基因 = 在所有器官中一致衰减
         └── 聚类分析验证功能分群
```

**关键统计策略**（借鉴 Chaudhuri et al.）：

1. 用 moderated _t_-like 统计量（|t| > 4）筛选每个器官中的显著衰减基因
2. 定义**器官特异性**：某基因在卵巢 |t| > 4，但在脾/肝 |t| < 2
3. 定义**系统性**：某基因在所有系统性器官（卵巢+脾+肝）中 |t| > 4
4. 对差异基因进行共适应网络聚类（Pearson R > 0.75），验证功能模块的器官特异性

### 第五层：时空动力学与组织学验证

```
时间序列实验
   ├── Day 1: 检测到达（是否有细菌到达卵巢？）
   ├── Day 3: 检测定殖（细菌是否开始增殖？）
   ├── Day 7: 检测持续（细菌是否维持？）
   └── Day 14-21: 检测长期持久性

组织学验证
   ├── 免疫组化 (IHC) 标记 Salmonella LPS
   │     → 定位细菌在卵巢中的具体位置（表面上皮 vs 间质 vs 卵泡）
   ├── FISH (荧光原位杂交) 标记 Salmonella 16S rRNA
   │     → 单细胞水平定位
   └── 共聚焦显微镜
         → 鉴别胞内 vs 胞外细菌
```

**判读逻辑**：

- Day 1 卵巢即无细菌 → **到达缺陷**（系统性毒力问题）
- Day 1 有细菌，Day 3 衰减 → **早期定殖/存活缺陷**
- Day 7 正常，Day 14 衰减 → **持久性/免疫逃逸缺陷**（免疫清除延迟型）

### 第六层：条件性基因表达与互补实验

**设计**：解决"基因是否在卵巢环境中被激活"的因果性问题

```
1. 组织特异性启动子驱动互补
   ├── 突变体 + 空载体 → 确认表型
   ├── 突变体 + 组成型启动子互补 → 全身性互补
   └── 突变体 + 卵巢特异性启动子互补
         → 仅在卵巢中互补 → 确认定殖特异性功能

2. 荧光报告系统 (GFP/Lux)
   ├── 目标基因启动子-GFP 融合
   │     → 检测基因在卵巢 vs 脾脏中的表达差异
   └── IVIS 活体成像
         → 实时追踪细菌在体内的分布和丰度

3. 条件性基因敲除 (Cre-lox 或 CRISPRi 诱导系统)
   ├── 先让 WT 建立卵巢定殖
   └── 诱导目标基因沉默 → 观察是否特异在卵巢丢失
```

### 综合判定流程图

```
突变体卵巢丢失
     │
     ├── [Step 1] 多器官 CI 比较
     │     ├── 脾/肝/盲肠均丢失 → 系统性毒力缺陷 (A类)
     │     └── 仅卵巢丢失 → 继续判断 (B类)
     │
     ├── [Step 2] IV 感染途径对照
     │     ├── IV后卵巢恢复 → 系统性到达缺陷
     │     └── IV后卵巢仍丢失 → 卵巢内定殖缺陷
     │
     ├── [Step 3] 体外卵巢细胞感染
     │     ├── 卵巢细胞正常+巨噬细胞缺陷 → 系统性胞内存活缺陷
     │     └── 卵巢细胞缺陷+巨噬细胞正常 → 卵巢特异性互作缺陷
     │
     ├── [Step 4] Tn-seq 多器官差异分析
     │     └── 统计学确认器官特异性衰减
     │
     ├── [Step 5] 时空动力学
     │     ├── Day 1 无细菌 → 到达缺陷
     │     ├── Day 1-3 有→衰减 → 早期存活缺陷
     │     └── Day 7+ 衰减 → 持久性/免疫逃逸缺陷
     │
     └── [Step 6] 组织特异性互补 + 启动子报告
           → 因果性确认
```

### 已知基因的分类示例

根据现有文献，可以初步将沙门氏菌卵巢定殖相关基因分为以下类型：

**A. 系统性毒力因子（误判风险高）**：

- `ssaV/sseC`（SPI-2 T 3 SS）：在所有系统性器官中一致衰减，卵巢丢失是"从未到达"而非"无法定殖"
- `phoP/phoQ`：一般性胞内存活调控因子
- `sifA`：SCV 膜完整性，所有胞内环境都需要
- `mgtC`：一般性巨噬细胞内存活

**B. 可能的卵巢/生殖道特异性定殖因子**：

- 特定菌毛基因（如 SEF 14 `sefA`、YPE fimbriae）：介导生殖道上皮黏附
- `spvB`（毒力质粒）：在鸡生殖道中有特异性功能，但同时也是系统性毒力因子
- 卵清蛋白/溶菌酶抗性基因（`ivy`, `mliC`）：应对蛋清/输卵管特有抗菌环境的基因，可能是生殖道特异的

**C. 需要多层次验证的灰色地带基因**：

- `invA`（SPI-1 T 3 SS）：涉及肠道侵入，但在卵巢上皮侵入中也可能有直接作用
- `sopE/sopB`：既是系统性毒力因子，也可能参与生殖道上皮的特异性信号劫持

---

### 总结

区分定殖缺陷与系统性毒力缺陷的**核心策略**是**多维度正交验证**：

1. **空间维度**：多器官平行 CI（脾/肝 vs 卵巢）
2. **途径维度**：口服 vs IV/IP 感染比较
3. **细胞维度**：体外卵巢细胞 vs 巨噬细胞感染
4. **时间维度**：感染动力学时间序列
5. **因果维度**：组织特异性互补和启动子报告

任何单一实验都无法给出确定性结论，但多维度收敛验证可以将假阳性率（把系统性毒力基因误判为定殖基因）降到最低。在实际操作中，**Step 1（多器官 CI）+ Step 2（IV 途径对照）** 是性价比最高的初步筛选策略，Step 3-6 则针对候选基因做深入验证。
