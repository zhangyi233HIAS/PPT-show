第一部分：概念与定义重述

Prompt 1: “核心概念反向定义”重述法

"请你采用‘反向定义’（Negative Definition）的策略，重写以下关于核心概念[输入核心概念，如“制度逻辑”]的定义。原句是：[粘贴原文定义]。你的任务是，通过阐述这个概念‘不是什么’以及它与哪些易混淆概念的区别，来重新界定其内涵和外延，最后再总结其核心特征。目标是创造一个全新的、但意义等价的定义性段落。"

Prompt 2: “隐喻驱动”的概念阐释

"我正在描述一个抽象的理论概念[输入概念名称，如“路径依赖”]。原文描述是：[粘贴原文描述]。请你扮演一位善于使用比喻的学术导师，为这个概念寻找一个或两个贴切的科学或生活中的隐喻（Metaphor），并基于这个隐喻来重构整个段落。要求：隐喻需有助于理解概念的核心机制，且整个段落的学术基调保持不变。"

Prompt 3: “操作化过程”重述定义

"针对以下定义：[粘贴原文对某个变量或概念的定义]。请将其从一个静态的、描述性的定义，改写为一个动态的、基于‘操作化过程’（Operationalization Process）的定义。即，通过详细描述‘我们如何识别、测量或在研究中应用这个概念’的过程，来反向阐明其定义。这需要你将抽象定义转化为一系列具体的步骤或标准。"

Prompt 4: “词源学追溯”的定义重构

"对于核心术语[输入一个有拉丁或希腊词源的术语，如“Hegemony”]，我当前的定义是：[粘贴原文定义]。请你引入该术语的词源学（Etymology）背景，从其原始含义的演变过程入手，重新组织和阐述其在当代学术语境下的精确含义。目标是构建一个更具历史深度和学术底蕴的定义段落。"

Prompt 5: “功能对等”重述法

"请分析以下段落中的核心概念[输入概念名称]。原文是：[粘贴原文]。请识别这个概念在段落的论证中所扮演的‘功能’（例如，作为原因、结果、中介变量、调节变量等）。然后，请你围绕这个核心‘功能’，而不是概念本身，来重新组织和叙述整个段落，实现功能对等但表述迥异的效果。"

第二部分：文献综述与引述改写

Prompt 6: “学者观点整合”的综合性重述

"以下是我对几位学者（学者A, B, C）关于同一主题[输入主题]的观点综述：[粘贴原文]。目前是‘学者A说...学者B说...’的罗列模式。请你将其重构为一个‘议题中心’（Issue-centered）的段落。你需要：1) 提炼出这些学者共同探讨的核心议题或辩论焦点。2) 将他们的观点打散，并围绕这些议题重新组织，形成一个综合性的、带有批判性评论的论述。3) 在适当的地方，以(Author, Year)的形式保留引用。"

Prompt 7: “批判性引述”转换

"我引用了一位权威学者的观点：[粘贴原文引述]。目前我的表述比较中立。请你将其转换为一段‘批判性引述’（Critical Citation）。这意味着，你需要在引述其观点前后，加入我自己的立场，例如，指出该观点是在何种前提下成立、其潜在的局限性是什么、或者我的研究将如何挑战或补充这一观点。"

Prompt 8: “研究发现”的转述练习

"请将以下对某篇参考文献研究发现的直接描述：[粘贴原文，如“张三（2023）的研究发现，X对Y有显著的正向影响...”]，进行深度改写。请尝试用以下至少两种方式重述：1) 从结果到启示：直接从该研究的理论或实践启示入手，再回溯其具体发现。2) 从方法到结论：先简要提及该研究采用了何种独特方法或数据，然后引出其结论。确保保留(Zhang, 2023)的引用格式。"

Prompt 9: “理论脉络”的重新梳理

"这段文献综述描述了一个理论[输入理论名称]的演进过程：[粘贴原文]。请你打破原文按时间顺序的线性叙事，尝试从以下一个新的逻辑脉络来重写：1) 从核心假设出发：先阐明该理论最根本的几个核心假设。2) 逻辑推演：然后展示基于这些假设，理论是如何推导出其主要命题和预测的。3) 修正与发展：最后再论述后来的学者是如何挑战或修正其核心假设，从而推动了理论的发展。"

Prompt 10: “引述动词”多样化与精确化

"请审查以下文献综述段落：[粘贴原文]。请识别其中所有用于引述的动词（如 'argues', 'suggests', 'finds', 'points out'），并生成一个‘引述动词替换建议表’。该表格应包含：1) 原动词。2) 至少3个意义相近但更精确或更多样化的替换词。3) 简要说明每个替换词的细微差别（例如，'posit' 强调假设性，'contend' 强调争议性，'demonstrate' 强调强证据）。然后，请提供一个使用这些多样化动词重写后的段落版本。"

第三部分：研究方法与过程重述

Prompt 11: “被动语态与主动语态”的策略性互换

"我的研究方法章节大量使用了被动语态，显得客观但呆板。原文：[粘贴一段以被动语态为主的方法描述，如‘The data was collected...’]。请你将其策略性地改写为以主动语态为主的段落。当需要强调研究者的决策和操作时，使用‘We’或‘The author’作为主语。当需要强调客观流程或工具时，保留被动语态。目标是在客观性与可读性之间取得更好的平衡。"

Prompt 12: “决策理由”的嵌入式重写

"以下是我对研究步骤的描述：[粘贴原文，如‘我们首先进行了A，然后进行了B’]。这种流水账式的描述缺乏学术深度。请你通过嵌入‘决策理由’（Justification）的方式来重写。对于每一步操作，都要简要阐明‘为什么’要这么做，以及这个选择相对于其他替代方案的优势是什么。例如，‘为了解决...问题，我们首先采用了A方法，因为它能有效地...。在此基础上，我们继而进行B分析，旨在...’。"

Prompt t 13: “数据处理流程”的可视化文本重述

"请将这段关于数据清洗和预处理的文字描述：[粘贴原文]，转换成一个更清晰、更结构化的‘步骤式’描述。请使用编号列表或项目符号，将整个流程分解为独立的、按逻辑顺序排列的步骤。在每个步骤中，明确指出‘输入’是什么，‘执行的操作’是什么，以及‘输出’是什么。"

Prompt 14: “质性分析过程”的具象化叙事

"我对质性数据（如访谈稿）的分析过程描述得比较抽象：[粘贴原文，如‘我们对访谈数据进行了主题分析’]。请你通过一个具体的‘编码示例’（Coding Example）来使这段描述更具象、更可信。你需要：1) 虚构一个简短但典型的原始引文（Raw Quote）。2) 展示如何从这个引文中提炼出初始编码（Initial Code）。3) 说明这个初始编码是如何归入一个更高级别的主题（Theme）的。将这个示例自然地融入到对整个分析过程的描述中。"

Prompt 15: “局限性声明”的积极重构

"在承认研究局限性时，我的措辞可能过于消极：[粘贴原文，如‘本研究的一个缺点是样本量较小’]。请你将其重构为一种更具建设性和前瞻性的表述。你需要：1) 承认局限性：清晰、坦诚地指出问题。2) 解释原因：简要说明造成此局限性的客观原因（如资源、时间限制）。3) 评估影响：论证该局限性在多大程度上不影响核心结论的有效性。4) 展望未来：将其转化为对未来研究的具体建议。例如，‘尽管本研究的样本规模受限于...，为初步探索提供了有效洞见。未来的研究可以通过...来进一步验证本研究的发现。’"

第四部分：结果与发现的多元呈现

Prompt 16: “数据到故事”的叙事性转换

"以下是对我的量化研究结果的客观陈述：[粘贴一段充满数据和统计术语的结果描述]。请你将其转换为一段更具‘叙事性’的段落，即‘让数据讲故事’。你需要：1) 提炼出这些数据背后最重要的发现或趋势。2) 以这个核心发现作为故事的‘主角’。3) 用更平实但精确的语言，围绕这个主角展开叙述，将统计关系转化为逻辑关系和现实意义。4) 在段落结尾处，用括号附上关键的统计数据作为支撑。"

Prompt 17: “表格/图表信息”的文本化重写

"请看我的表格/图表[简要描述图表内容，或直接粘贴图表生成的文本]。请你为这个图表撰写一段描述性文本，但要避免简单地重复图表中的数字。你的任务是：1) 点明总体趋势：首先总结图表所揭示的最显著的模式、趋势或异常点。2) 进行关键对比：选择几个最有意义的数据点进行两两比较或分组比较，突出其差异。3) 引导读者注意：提醒读者注意图表中某个不那么明显但同样重要的细节。4) 引出结论：简要说明这个图表支持了哪个研究假设或引出了什么初步结论。"

Prompt 18: “统计显著性”的审慎解读

"我这样描述我的统计结果：[粘贴原文，如‘结果表明X对Y有显著影响（p < 0.05）’]。为了避免对p值的过度解读，请你提供几种更审慎、更全面的重写方式。例如：1) 强调效应量：‘除了统计上的显著性，X对Y的效应量（Effect Size）为...，表明其在实际中具有...意义。’ 2) 结合置信区间：‘X对Y的影响在95%置信区间内为[...]，排除了零值，表明该效应的稳健性。’ 3) 避免因果暗示：将‘影响’改为‘关联’或‘预测’等更中性的词语。"

Prompt 19: “非显著结果”的意义挖掘

"我的研究发现某个假设未得到支持（即p > 0.05）。原文可能简单带过：[粘贴原文]。请你帮助我更有深度地阐述这个‘非显著结果’（Null Result）的意义。你需要：1) 排除方法论解释：首先论证这个结果并非源于研究设计的缺陷（如统计功效不足）。2) 提出理论解释：探讨为什么理论上预期的关系在现实中并未出现，这可能挑战了原有理论的哪些边界条件？3) 引出新的问题：这个出人意料的结果为我们打开了哪些新的研究问题？"

Prompt 20: “质性发现”的主题句重塑

"以下是我对一个质性研究主题的描述：[粘贴原文]。请为这个段落重写一个更具分析性和概括性的主题句（Topic Sentence）。好的主题句应该：1) 不仅仅是描述主题内容，而是提出一个关于该主题的‘论点’（Argument）或‘断言’（Claim）。2) 能够统领整个段落的内容。3) 体现出该发现在理论或实践层面的重要性。请提供3个不同角度的主题句供我选择。"

第五部分：句法与结构层面的高级变换

Prompt 21: “长短句交错”的节奏重塑

"请分析以下段落：[粘贴一个由连续长句或连续短句构成的段落]。该段落的句子结构单一，读起来很单调。请你通过‘长短句交错’的原则对其进行重写。你需要：1) 将一些过长的复合句拆分为几个有力的短句，以强调核心信息。2) 将一些关系紧密的短句合并为一个逻辑清晰的复合句，以展示复杂关系。目标是创造一种更有节奏感、更具表现力的学术散文风格。"

Prompt 22: “信息焦点后置”的句式改写

"请使用‘信息焦点后置’（End-Focus）或‘倒装’（Inversion）等语法结构，重写以下句子：[粘贴一个普通陈述句]。目标是将句子中最新、最重要的信息移到句末，以达到强调或制造悬念的效果。例如，将‘The most important finding is the discovery of X.’ 改写为 ‘What is most significant is the discovery of X.’ 或 ‘Crucial to our understanding is the discovery of X.’。请提供至少两种改写方案。"

Prompt 23: “并列结构”的逻辑升级

"以下句子使用了一系列并列成分：[粘贴原文，如‘This theory includes concepts A, B, and C.’]。请将其从简单的罗列，升级为更具逻辑层次的结构。你可以：1) 分类组织：如果A, B, C可以被归入不同类别，先提出类别再分别阐述。2) 递进关系：如果它们之间存在重要性或逻辑上的递进关系，请用‘not only... but also...’, ‘more importantly...’等词语来体现。3) 因果链条：如果它们构成因果链，请用相应的逻辑连接词重构。"

Prompt 24: “抽象名词具体化”

"我的段落中使用了过多的抽象名词（Nominalization），如 ‘utilization’, ‘investigation’, ‘confirmation’，导致语言晦涩。原文：[粘贴原文]。请你将这些抽象名词尽可能地还原为动词形式，并相应地调整句子结构，使用更直接、更有力的主谓宾结构。例如，将‘The confirmation of the hypothesis was achieved through...’ 改为 ‘We confirmed the hypothesis by...’。"

Prompt 25: “逻辑连接词”的精准替换

"请审查以下段落中的逻辑连接词（如 ‘however’, ‘therefore’, ‘and’, ‘also’）：[粘贴原文]。请判断这些连接词是否最准确地反映了前后文的逻辑关系。如果不是，请提供一个‘替换建议表’，并说明理由。例如，原文用‘and’连接两个观点，但如果第二个观点是对第一个的补充和强调，用‘furthermore’或‘moreover’可能更佳。"

第六部分：语篇与语气的整体调控

Prompt 26: “作者立场”的显化与隐化

"根据我的要求，调整以下段落中‘作者立场’的明确程度。原文：[粘贴原文]。

选项A (立场显化)：请加入更多明确表达作者观点和判断的短语，如‘I argue that...’, ‘My analysis reveals...’, ‘This clearly demonstrates...’，以增强论证的主观力量。

选项B (立场隐化)：请移除或弱化上述主观性强的短语，采用更客观、更中立的第三人称叙述，让事实和数据本身说话，使论证显得更加克制和公允。"

Prompt 27: “学科方言”转换

"这段文字是用社会科学的通用语言写的：[粘贴原文]。请你将其改写，使其带上更鲜明的[输入具体学科，如‘经济学’、‘人类学’或‘计算机科学’]的“学科方言”（Disciplinary Dialect）。这意味着你需要：1) 使用该学科更偏好的特定术语。2) 模仿该学科论文中典型的句法结构和论证风格。3) 调整段落的叙事节奏以符合该学科的惯例。"

Prompt 28: “引导性设问”的植入

"为了增强段落的引导性和读者参与感，请在以下段落[粘贴原文]的开头或关键转折处，植入一个或两个具有启发性的“引导性设问”（Rhetorical Question）。这个问题应该能够预示本段即将探讨的核心内容，并激发读者的思考。例如，在分析一个矛盾现象前，可以加入‘So, how can we reconcile these seemingly contradictory findings?’"

Prompt 29: “段落间过渡”的平滑化

"这是两个相邻的段落：段落A：[粘贴段落A]；段落B：[粘贴段落B]。目前它们之间的过渡比较生硬。请你在段落A的结尾增加一个‘过渡句’（Transition Sentence），并在段落B的开头增加一个‘承接句’（Hook Sentence），以建立起更平滑、更具逻辑性的连接。"

Prompt 30: “自信而谦逊”的语气平衡

"在我的‘讨论’或‘结论’章节，我希望在强调研究贡献的同时，保持学术谦逊。原文：[粘贴原文]。请你润色这段文字，使其达到‘自信而谦逊’（Confident yet Humble）的平衡。这意味着：在阐述贡献时，使用肯定、有力的语言（如‘This study provides compelling evidence for...’）；在提及推论或局限性时，使用更审慎的限定词（如‘This may suggest...’, ‘Within the scope of this study...’）。"

第七部分：特殊场景与综合应用

Prompt 31: “摘要”的极致压缩与重写

"这是我的论文摘要初稿（约400词）：[粘贴摘要]。请你将其压缩并重写为一个信息密度极高的版本（目标250词）。你需要对每一句话进行重构，去除所有冗余信息，只保留最核心的‘问题-方法-发现-贡献’四要素，并确保逻辑流畅，语言精炼。"

Prompt 32: “跨章节内容”的呼应与整合

"我的‘引言’章节提出了一个研究问题，而‘讨论’章节回应了这个问题。引言中的表述是：[粘贴引言中的句子]。讨论中的表述是：[粘贴讨论中的句子]。请你重写这两处的句子，让它们在用词和句法上形成更明确的‘前后呼应’（Echoing），以增强整篇论文的结构完整性。"

Prompt 33: “图表标题”的信息化重写

"我当前的图表标题只是描述性的，如‘Figure 1: GDP Growth Rate’。请将其重写为一个‘结论性’或‘陈述性’的标题（Declarative Title），即标题本身就概括了该图表所揭示的核心发现。例如，‘Figure 1. GDP Growth Rate Significantly Slowed Down After the 2008 Financial Crisis’。"

Prompt 34: “致谢”部分的非模板化重写

"我的致谢部分听起来像模板：[粘贴致谢草稿]。请你帮助我注入更多真诚和个性化的细节。对于每一位感谢对象（如导师、家人），请引导我思考并加入一个具体的、能体现其独特帮助的小事例，然后将这些细节自然地融入到感谢的言辞中。"

Prompt 35: “同一思想”的三种表达法

"我有一个核心观点需要在我论文的不同部分（如引言、正文、结论）反复强调。这个观点是：[陈述核心观点]。为了避免简单的重复，请你为这个观点提供三种不同的表达方式：1) 引言中的版本：应更具启发性和悬念。2) 正文中的版本：应更具分析性和论证性。3) 结论中的版本：应更具总结性和升华性。"

Prompt 36: “消除模糊性”的精确化重写
