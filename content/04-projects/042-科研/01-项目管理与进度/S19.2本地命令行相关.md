行，你如果经常做 **md ↔ pdf / docx / pptx** 转换，Pandoc 常用命令基本就一套流程：**检查 → 转换 → 调样式 → 批量自动化**。我给你按“从启动到结束”整理一份常用命令清单（Windows 也适用）。

---

## 0）确认 pandoc 是否安装成功（启动第一步）

```bash
pandoc --version
```

如果能输出版本号，就 OK。

---

## 1）Markdown → Word（最常用）

```bash
pandoc input.md -o output.docx
```

指定参考模板（推荐，控制字体/标题样式）：

```bash
pandoc input.md -o output.docx --reference-doc=template.docx
```

---

## 2）Markdown → PDF

### 方法A：用 LaTeX 引擎（最标准）

```bash
pandoc input.md -o output.pdf
```

如果你装了 TeX Live / MikTeX，它会自动走 LaTeX。

指定引擎（XeLaTeX 中文更友好）：

```bash
pandoc input.md -o output.pdf --pdf-engine=xelatex
```

指定字体（中文常用）：

```bash
pandoc input.md -o output.pdf --pdf-engine=xelatex -V mainfont="SimSun"
```

---

## 3）Markdown → PPT（PowerPoint）

```bash
pandoc input.md -o output.pptx
```

使用 pptx 模板（强烈推荐，控制主题）：

```bash
pandoc input.md -o output.pptx --reference-doc=template.pptx
```

---

## 4）Word → Markdown（docx 转 md）

```bash
pandoc input.docx -o output.md
```

如果想尽量保留图片（导出到文件夹）：

```bash
pandoc input.docx -o output.md --extract-media=media
```

---

## 5）PDF → Markdown（注意：效果不稳定）

PDF 转 md 依赖 PDF 内部结构，效果经常一般，但命令是：

```bash
pandoc input.pdf -o output.md
```

如果是扫描版 PDF（图片），Pandoc 基本无能为力，需要 OCR（如 tesseract、abbyy、acrobat）。

---

## 6）Markdown ↔ HTML

md → html：

```bash
pandoc input.md -o output.html
```

html → md：

```bash
pandoc input.html -o output.md
```

pandoc input.md -o output.tex

# 9）通用高频参数（你会反复用）

## 指定输入格式（避免识别错误）

```bash
pandoc -f markdown input.md -o output.docx
```

## 指定输出格式

```bash
pandoc input.md -t docx -o output.docx
```

## 指定目录资源路径（图片引用找不到时）

```bash
pandoc input.md -o output.docx --resource-path=.
```

## 提取图片（docx/pdf → md 常用）

```bash
pandoc input.docx -o output.md --extract-media=assets
```

# 10）Markdown → PPTX 的正确写法（按 slide 分页）

Pandoc pptx 分页靠标题分级：

```markdown
# 第一页标题
内容

# 第二页标题
内容
```

然后：

```bash
pandoc slides.md -o slides.pptx
```

# 11）Markdown → PDF 最常见“最终版”命令（推荐你直接收藏）

```bash
pandoc input.md -o output.pdf ^
  --pdf-engine=xelatex ^
  -V mainfont="SimSun" ^
  -V geometry:margin=2cm ^
  --toc --toc-depth=2
```

（Windows 下换行符 `^` 是续行，Linux/mac 用 `\`）

# 12）批量转换（结束阶段：一次性处理文件夹）

## 批量 md → docx（Windows CMD）

```cmd
for %f in (*.md) do pandoc "%f" -o "%~nf.docx"
```

## 批量 md → pdf

```cmd
for %f in (*.md) do pandoc "%f" -o "%~nf.pdf" --pdf-engine=xelatex
```

# 13）你最该记的“工作流”（从开始到结束）

### A. 写 md → 输出 Word（投稿/交稿）

```bash
pandoc paper.md -o paper.docx --reference-doc=template.docx
```

### B. 写 md → 输出 PDF（打印/投稿）

```bash
pandoc paper.md -o paper.pdf --pdf-engine=xelatex
```

### C. 写 md → 输出 PPT（汇报）

```bash
pandoc talk.md -o talk.pptx --reference-doc=template.pptx
```

### D. Word / PDF 收到别人的 → 转 md 做整理

```bash
pandoc input.docx -o note.md --extract-media=media
```
