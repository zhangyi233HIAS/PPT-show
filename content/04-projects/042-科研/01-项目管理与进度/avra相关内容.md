一、 AvrA   的基本功能与结构概览（为后文做铺垫）

YopJ   家族去泛素化 / 乙酰转移酶

AvrA   属于  YopJ   家族效应蛋白，具有去泛素化酶  +  乙酰转移酶双重活性，可直接作用于  I κ B α、β - catenin  等底物，抑制  NF- κ B，稳定  β- catenin。

其全酶活性依赖宿主细胞的  IP₆（inositol  hexakisphosphate ）   作为别构激活因子，结构研究表明  IP₆  结合后诱导酶构象重排，形成乙酰辅酶  A  结合口袋，从而激活乙酰转移酶活性。

近期对  YopJ   家族结构的解析（ HopZ 1 a、AvrA  等）进一步明确了其催化三联体  +  底物识别螺旋的构象基础，为后续设计抑制剂或功能缺失突变提供了结构依据。

核心信号通路靶点

主要靶向： NF- κ B、JNK-MAPK、 β- catenin/Wnt、p 53、自噬相关  Beclin-1  以及  STAT 3  通路。

这些通路与炎症、细胞凋亡 / 存活、屏障功能、干细胞更新以及肿瘤发生高度相关，为我们推测其在卵巢组织长期感染中的作用提供了关键逻辑基础。

## 二、 AvrA   现有研究进展与具体结果 { #slide-53 }

2.1  抗炎与免疫调控： NF- κ B / JNK  轴

早期发现：抑制  NF- κ B  并调控凋亡

在人肠上皮细胞中， AvrA   可抑制  I κ B α  的降解，从而抑制  NF- κ B  激活，同时促进上皮细胞凋亡，被认为是"限制过度炎症"的一个效应因子。

去泛素化机制

小鼠结肠和上皮细胞实验显示， AvrA   可直接去泛素化  I κ B α  和  β- catenin ：

去泛素化  I κ B α →  阻断其降解 → 抑制  NF- κ B  通路 → 下调  IL-6  等炎症因子；

去泛素化  β- catenin →  稳定  β- catenin →  上调  c-Myc、Cyclin  D 1  等增殖相关基因。

选择性抑制  JNK，不抑制  ERK/p 38

精细机制研究表明， AvrA   通过乙酰化  MAPKK（ 如  MKK 7） 选择性抑制  JNK  通路，显著减弱  JNK  依赖的炎症与凋亡，但对  ERK、p 38  影响较小。

在鸡白痢相关血清型中的差异

S. Pullorum  的  AvrA（SP-AvrA） C   端缺失  10  个氨基酸，与  S. Enteritidis  AvrA   相比，在异源表达体系中对  TNF- α  诱导的  NF- κ B  抑制能力较弱；

但将  SP- AvrA   放回原生  Pullorum  背景后，由于表达量较高，整体仍能有效抑制  NF- κ B，通过下调  p-JNK  和  Beclin-1  参与抗炎。

👉  启示： 在鸡白痢沙门菌中， AvrA   应当仍然是重要的抗炎"刹车"因子，但其活性与结构存在血清型特异性差异，这可能会影响它在不同组织（包括卵巢）的具体功能强度。

2.2  屏障功能与上皮稳态：紧密连接与干细胞

稳定肠上皮紧密连接（ TJ）

AvrA   缺失菌株在体外感染上皮细胞时， ZO-1、claudin-1  水平下降、 TJ  结构紊乱，通透性增加；表达  AvrA   的菌株则维持  TJ  结构和屏障功能。

进一步研究（ Tissue Barriers + JBC） 证实： AvrA   通过抑制  JNK/c-Jun   通路，阻止  TJ  蛋白  ZO-1  的解聚和降解； JNK  抑制剂可模仿  AvrA   的保护效应。

调控肠干细胞与  Wnt / β- catenin

在小鼠结肠炎模型中，表达  AvrA   的菌株持续激活  β- catenin  信号，提高  Wnt   靶基因水平、增加干细胞和增殖细胞数量，促进肠上皮更新。

AvrA   还能上调  Wnt 2、Wnt 11，抑制细菌侵袭、凋亡及  IL-8  分泌，从而增强上皮抗感染与修复能力。

👉  对卵巢的启示：卵巢 / 输卵管上皮也具有屏障与自我更新特性，若  AvrA   能在该组织中类似地调节紧密连接与  Wnt / β- catenin ，有助于形成  "功能完整但带菌"的慢性隐性感染上皮层。

2.3  细胞凋亡、自噬与胞内生存

抑制上皮和巨噬细胞凋亡，支持菌体胞内存活

在小鼠感染模型中， AvrA   缺失菌株诱导更强的肠炎反应和上皮 / 巨噬细胞凋亡，反而导致更高的组织细菌负荷和更严重的全身感染，提示  AvrA   通过抑制  JNK  保护受感染细胞避免"过早死亡"，为稳定胞内微环境提供条件。

调控  p 53  乙酰化和细胞周期

AvrA   具有乙酰转移酶活性，可乙酰化  p 53，增强其转录活性和细胞周期阻滞能力，从而影响炎症环境中的上皮细胞命运； AvrA   缺失菌株感染导致  p 53  乙酰化下降。

抑制自噬（ Autophagy） 促进细菌存活

在  S. Enteritidis  研究中， AvrA   通过  JNK-AP-1  轴下调  Beclin-1 ，抑制  LC 3-I  向  LC 3-II  转化和溶酶体富集，从而抑制抗菌自噬，增加菌体在上皮细胞 / 类器官中的存活。 Frontiers+2 X-MOL+2

抑制  Perforin-2  表达，逃避免疫清除

在成纤维细胞和肠上皮细胞中， AvrA   联合  LPS  修饰系统共同抑制  Perforin-2（MPEG 1）   的表达，该分子是宿主清除胞内细菌的重要孔形成蛋白。缺失  AvrA   时， Perforin-2  上调，有利于杀菌。

👉  对卵巢持续感染的启示：卵巢滤泡细胞、间质细胞、驻留巨噬细胞如果受到这些机制影响（凋亡↓、自噬↓、 Perforin-2↓），非常有利于形成长期胞内生存"隐蔽库" 。

2.4  AvrA   与慢性感染及肿瘤发生

慢性结肠感染与炎症

小鼠长期（ 27  周）感染  AvrA   阳性  S. Typhimurium  时，动物表现为持续轻度炎症、细菌在肝、脾、胆囊等器官长期存在， AvrA   抑制  IL-12、IFN- γ、 TNF- α  分泌，同时增强细菌侵袭能力和胆囊转位。

β- catenin  持续激活与肠癌

慢性  AvrA   阳性菌株感染下， β- catenin  持续被稳定和乙酰化，核转位增强，配合  Akt/ Tcf   等上游信号，促进肿瘤相关基因表达与肿瘤发生。

AOM/DSS  诱导的结肠癌模型中， AvrA   阳性感染组肿瘤发生率可达  100% ，显著高于未感染或  AvrA -  菌株组，并伴随  β- catenin  靶基因（如  Bmi 1、MMP-7、Cyclin D 1） 上调。

STAT 3  通路与感染相关肿瘤

AvrA   还能激活  STAT 3   信号，提高其靶基因表达，进一步促进增殖与肿瘤形成；在炎症相关癌症中， STAT 3  与  β- catenin  形成交互网络。

人群相关性

在临床结直肠癌样本和前驱病变中可检出  AvrA   蛋白  /  抗体，提示与人类结直肠癌风险存在潜在联系。

👉  虽然这些研究集中在肠道和结直肠癌，但  "慢性、低度炎症  +  细胞增殖 / 存活信号增强"  的模式，很有可能在卵巢组织中以类似方式帮助  S. Pullorum  长期定植。

2.5  AvrA   表达调控与血清型差异

表达谱：四类血清型

不同  S. enterica  血清型中  avrA   基因广泛存在，但蛋白表达有四种类型：

Class 1： 构成性表达；

Class 2： 酸诱导表达；

Class 3： 有基因但几乎不表达；

Class 0： 完全缺失。

表达受  Salmonella  特异性调控系统控制，在大肠杆菌背景中即使带有  avrA   也不表达。

CsrA / CsrB   介导转录后调控

AvrA   的翻译受  CsrA / CsrB   系统调控：当  avrA   拷贝数升高时翻译增强，但过量  CsrA / CsrB   又可抑制其表达，呈"跷跷板"式调节，保证适量产生。

S. Pullorum  中的  AvrA   特性

基因组分析显示  S. Pullorum  中基因大量假基因化或截短，其中  AvrA   缺失  C  端  10  aa。

体外实验表明，在相同表达水平下， SP- AvrA   对  NF- κ B  的抑制、自噬相关  Beclin-1  的下调等功能略弱于   S. Enteritidis  AvrA ，但在  Pullorum  自身背景中因高表达量总效应仍然明显。 MDPI+2 梅斯医学 +2

最新禽用  Pullorum  研究

2025  年对  S. Pullorum  中  avrA、gtgA、pipA、sseL   等抗炎效应蛋白的联合缺失研究发现：

单独或联合缺失这些基因对  Pullorum  在鸡体内的长期持留总体影响不大；

但缺失  avrA   和  gtgA   明显加重肝脾等组织炎性损伤，提示这些蛋白主要调节病变程度而非是否持留。

👉  对你们的课题，这提示： AvrA   可能不是"是否能持久存在"的开关，而是" 如何在组织中低损伤地长期存在"的重要调节器 ------ 这在卵巢这种功能关键又免疫相对"温和"的组织尤为重要。

2.6  家禽模型与肠道外组织（尤其是生殖道）的相关证据

Pullorum  持续感染与卵巢定植

经典动物实验证实： S. Pullorum  在成鸡中可形成持续感染，主要持留于脾脏巨噬细胞，在性成熟后细菌数量上升并扩散至生殖道（卵巢、输卵管） ，导致垂直传播。 ASM Journals+2 Taylor & Francis Online+2

感染母鸡可有  6%  左右产蛋带菌，卵巢多灶性肉芽肿性卵巢炎 / 卵巢炎常见。 Merckvetmanual. Com+1

Pullorum  在不同年龄鸡体内的播散

BMC Vet Res  的新研究显示， S. Pullorum  在不同日龄鸡中的肝、心、脾等器官定植模式存在显著差异，提示宿主年龄和免疫状态对于持久感染至关重要。 BioMed Central

AvrA   在鸡盲肠免疫反应中的作用

在鸡  S. Typhimurium  感染模型中，缺失  AvrA   的菌株在鸡体内感染导致体重下降更明显、菌体持留时间更长、肠道病变更重，盲肠黏膜信号通路激活谱整体类似，但具体炎症中介子和迁移信号存在差异； WT  AvrA   组  14  d  时  IL-10  上调更明显。

虽非  Pullorum，但说明在鸡肠道环境中  AvrA   同样发挥"减炎、慢性化"作用。

禽生殖道免疫环境特点

导读性综述指出，禽类生殖道（尤其是母鸡卵巢 / 输卵管）是多种病原（包括  Salmonella） 定植与垂直传播的关键部位，其黏膜免疫既要防御病原，又要避免对精子 / 胚胎造成过强炎症，是一个天然偏"免疫耐受"的黏膜环境。科学直通车

👉  综合来看： Pullorum  具有明确的卵巢定植和垂直传播能力，但目前几乎没有直接解析  AvrA   在卵巢 / 输卵管水平作用的研究 ------ 这是你们项目最直接的知识缺口。

2.7  AvrA   的工程化与治疗潜力（对机制理解也有帮助）

AvrA   作为抗炎蛋白的工程化利用

通过蛋白纳米颗粒将  AvrA   递送至肠黏膜，可抑制炎症信号，在  DSS  结肠炎小鼠中显著降低临床和组织学炎症评分。

进一步通过  AvrA -NPs +  海藻酸钠 / 壳聚糖微粒口服递送，可以保护蛋白跨越胃酸并在小肠释放，同样缓解  DSS  结肠炎。

IP₆/IT₆  作为  AvrA   调节因子

新近工作表明，用硫代磷酸酯改造的  IP₆  类似物（ IT₆）   能更稳定且更高亲和力地结合  AvrA ，延长结合驻留时间，可作为研究  AvrA   结构与活性的工具分子，具有潜在药物化学价值。 MDPI

👉  虽然这些更偏向治疗应用，但侧面证明： AvrA   的结构和信号调控已经非常清楚，也可以通过小分子 / 蛋白工程精细调节，为你们做功能突变、结构域互换等提供很好的参考。

## 三、与"鸡白痢沙门菌在卵巢细胞持续感染"直接相关的证据提取 { #slide-60 }

3.1  抗炎  +  抑制细胞死亡  =  有利于卵巢"隐性感染"

Pullorum  自身被证明可在成鸡卵巢和输卵管中长期存在，并通过卵感染后代。 ASM Journals+2 Taylor & Francis Online+2

AvrA   在多种模型中表现为抑制  NF- κ B / JNK，降低  IL-6、TNF- α  等炎性因子、抑制凋亡、自噬和  Perforin-2  介导的杀菌，帮助细菌在上皮细胞和巨噬细胞内稳定存活。

在鸡  S. Typhimurium  模型中，缺失  AvrA   导致炎症加重、体重下降加重，提示  AvrA   在鸡体内确有"减炎、缓病程"的作用。 Abstract- AvrATitleA -set

推理性整合： 卵巢内主要驻留细胞包括卵泡颗粒细胞、卵泡膜细胞、间质细胞及组织巨噬细胞。若  Pullorum  在这些细胞中表达并转运  AvrA ，则：

NF- κ B/JNK  被抑制 → 炎症因子低水平 →  卵巢局部炎症不典型，不易被机体清除；

凋亡、自噬、 Perforin-2  被抑制 → 受感染细胞不易死亡或清除 →  形成长期胞内细菌库；

这与  Pullorum  感染临床症状轻、长期带菌但卵巢病变可较重的特点高度吻合。 Merckvetmanual. Com+1

3.2  上皮屏障与生殖道定植

AvrA   能通过  JNK  抑制稳定紧密连接蛋白  ZO-1、claudin-1 ，在肠上皮中维持屏障完整性。欧洲生物医学文献库 +2 JBC+2

生殖道上皮同样依赖紧密连接维持屏障和选择性通透。如果在卵巢 / 输卵管上皮中， AvrA   同样稳定  TJ：

一方面可减少急性渗出性炎症，保持组织结构；

另一方面细菌可更多转向胞内定植而非急性破坏性感染。

3.3  干细胞 / 增殖信号与卵巢组织重构

AvrA   持续激活  β- catenin/ Wnt   与  STAT 3   信号，促进肠干细胞增殖和肿瘤形成。

卵巢本身是高度动态重构的器官（排卵周期、卵泡发育与闭锁）。若  Pullorum  感染状态下， AvrA   在卵巢上皮或基质细胞中激活这些通路，可能：

改变卵泡成熟 / 闭锁节奏；

帮助被感染的细胞在组织重构过程中"保留下来"，维持细菌库；

甚至在长期感染下诱导局灶性增生或肿瘤样改变（目前尚无直接证据，这本身就是潜在研究方向）。

3.4  S. Pullorum  AvrA   的血清型特异性：适应禽类宿主

SP- AvrA  C  端缺失导致其在异源体系中对  NF- κ B  的抑制、自噬调控略弱于  SE- AvrA ，但在  Pullorum  背景下凭借较高表达量，仍可显著抑制  p-JNK  和  Beclin-1。 MDPI+2 梅斯医学 +2

2025  年联合缺失  Pullorum  中多个抗炎效应因子（包括  avrA ） 发现： 缺失并不显著减少长期持留，但显著加重组织炎性损伤，降低组织内细菌生存能力。

这说明： AvrA   更像是  Pullorum  维持  " 低炎症、高持留"平衡的调节器，而不是获得持久感染的唯一条件。因此在卵巢持续感染中，它很可能主要决定病变轻重和组织损伤模式，这与"持续卵巢炎但母鸡依然能产蛋"的现实情况高度吻合。

## 四、潜在研究方向与知识缺口（结合你们的课题） { #slide-61 }

Gap 1： 几乎没有  AvrA   在鸡卵巢 / 输卵管中表达与转运的直接证据

可行方向：组织 / 细胞水平定位与动态

建立成鸡和青年鸡  Pullorum  感染模型，在不同时间点采集卵巢 / 输卵管：

## 假设  1 ： AvrA   通过抑制  NF- κ B / JNK  介导的炎症和凋亡，促进卵巢上皮细胞、颗粒细胞和基质细胞"带菌不死"，从而建立和维持  S. Pullorum  的长期胞内储库。 { #slide-65 }

理论依据

AvrA   可抑制  I κ B α  降解、阻断  NF- κ B  激活，抑制  JNK  通路，从而下调炎症因子并调控凋亡。 Cell+2 MDPI+2

- 在  S. Enteritidis/ Typhimurium  模型中， AvrA   能在不显著诱导凋亡的前提下抑制先天免疫反应，使细菌更容易建立慢性感染。 Cell+1
- S. Pullorum  在成鸡可形成持续感染，并在性成熟后定植卵巢和输卵管，与垂直传播和卵带菌率升高密切相关。 Eprints. Nottingham. Ac. Uk+3 ASM Journals+3 Taylor & Francis Online+3

## 假设  2 AvrA   通过抑制  JNK--Beclin-1  介导的自噬通路，阻断卵巢细胞的抗菌自噬，从而提高  S. Pullorum  在卵巢上皮、颗粒细胞和基质细胞中的胞内存活与长期定植能力。 { #slide-66 }

理论依据

SE- AvrA   通过抑制  JNK  活性，下调  Beclin-1，抑制  LC 3-II  形成和自噬流，从而增强细胞内细菌存活。 C 186 A  失活突变丧失调控  Beclin-1  的能力。欧洲生物医学文献库 +1

AvrA   还参与抑制宿主孔形成蛋白  Perforin-2  的表达，这是清除胞内细菌的重要效应分子。科学直通车

在鸡  Pullorum  模型中，删除  avrA   可增强炎症和宿主杀菌反应，说明其在禽类宿主中保守发挥抗炎和"保护细菌"的作用。 MDPI+1

## 假设  3 AvrA   激活  Wnt / β- catenin  与  STAT 3  信号，促进被感染的颗粒细胞和基质细胞在卵泡发育与重构过程中的存活和增殖，从而在卵巢内维持稳定细菌"宿主细胞群"。 { #slide-67 }

S. Pullorum  在成鸡卵巢形成持续感染时并不一定导致明显生殖废用，而是长期"低度炎症 + 持续带菌"。 ASM Journals+2 Taylor & Francis Online+2

## 假设  4 AvrA   维持卵巢和输卵管上皮屏障的结构完整和"温和炎症"状态，从而在不严重破坏组织功能的前提下，提高  S. Pullorum  向卵和后代垂直传播的机会。 { #slide-68 }
