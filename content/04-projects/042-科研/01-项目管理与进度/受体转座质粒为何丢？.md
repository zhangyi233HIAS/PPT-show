在**接合型转座子（conjugative transposon / transposon delivery plasmid）构建转座文库**时，需要区分两个元件：

1. **转座子（transposon）**：真正插入染色体的片段（含抗性标记、Tn两端IR序列等）
    
2. **转座载体质粒（delivery plasmid）**：携带
    
    - 转座子
        
    - **转座酶（transposase）基因**
        
    - 复制起点（ori）
        
    - 可能的抗性标记
        

核心问题是：**质粒是否会保留在受体菌中**。

---

## 一、标准设计：质粒一般会“自动丢失”

大多数**转座文库构建系统**都会设计为 **suicide plasmid（自杀质粒）** 或 **conditional plasmid**。

常见机制：

### 1️⃣ 自杀质粒（最常见）

质粒的复制起点只在**供体菌**中能复制，例如：

- **R6K ori**
    
- 需要 **π protein（pir基因）**
    

供体菌：

```
E. coli λpir
```

受体菌（例如沙门菌）：

```
没有 pir → 质粒无法复制
```

结果：

1. 接合进入受体菌
    
2. **转座子发生一次转座**
    
3. 质粒**不能复制 → 被稀释丢失**
    

最后得到：

```
染色体：Tn插入
质粒：丢失
```

所以**一般不需要特地消除质粒**。

---

### 2️⃣ 温敏复制质粒（ts plasmid）

例如：

```
pSC101ts
```

在：

```
30°C → 可以复制
37°C或42°C → 无法复制
```

流程：
1. 接合
2. 转座发生
3. 提高温度培养
4. 质粒逐渐丢失
    

---

## 二、什么时候需要“特意去除质粒”

如果使用的是**普通复制质粒**（非suicide），就必须消除，否则会有问题：

### 问题

1. **持续表达转座酶 → 二次转座**
    
2. **多次插入**
    
3. 文库不稳定
    

### 常见处理

|方法|原理|
|---|---|
|**无抗培养多代**|质粒自然丢失|
|**温敏质粒升温**|强制丢失|
|**counter selection（sacB）**|蔗糖筛选|
|**CRISPR curing**|实验室高级操作|

---

## 三、转座文库的筛选逻辑（很关键）

典型抗性设计：

|元件|抗性|
|---|---|
|转座子|KanR|
|质粒|AmpR|

筛选方式：

1️⃣ 接合后

```
Kan plate
```

只保留：

```
Tn插入菌
```

2️⃣ 检测质粒是否丢失

复制到：

```
Amp plate
```

结果理想情况：

```
KanR
AmpS
```

说明：

```
染色体有Tn
质粒没了
```

---

## 四、Tn-seq文库的标准状态

最终文库应该是：

```
染色体：Tn插入
转座酶：不存在
质粒：不存在
```

原因：

否则会发生：

```
转座再发生 → 插入位点变化
```

导致：

```
Tn-seq数据失真
```
