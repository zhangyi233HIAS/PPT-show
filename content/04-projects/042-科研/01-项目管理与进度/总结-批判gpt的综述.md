### Prompt 1：论文快速筛选与价值评估

**任务描述：**请基于我提供的论文标题、摘要和关键词，快速评估其与我研究方向的契合度，并判断其阅读价值。你需要提供一个结构化的评估报告。

- **核心论点与贡献分析：** 根据摘要，用一句话总结该论文的核心论点（Main Argument）和声称的主要贡献（Claimed Contribution）。
    
- **方法论初步判断：** 识别论文所采用的关键研究方法（例如，实验、模拟、理论推导、综述等），并判断该方法是否为我关注的主流或创新方法。
    
- **相关性评分与理由：** 结合我的研究方向，为该论文与我研究的相关性打分（1-5分，5分为最高），并提供至少两点具体的评分理由。
    
- **阅读优先级建议：** 基于以上分析，明确建议我对该论文的阅读优先级（例如：建议精读/建议泛读/暂不阅读），并简述原因。
    

**请处理以下论文信息：**

- **我的研究方向：** [例如：利用图神经网络进行药物分子属性预测]
    
- **论文标题：** [粘贴论文标题]
    
- **论文摘要：** [粘贴论文摘要]
    
- **论文关键词：** [粘贴论文关键词]
    

### Prompt 2：单篇论文深度解析与批判性分析

**任务描述：**请对我提供的论文全文进行一次深度、批判性的结构化解析。你需要扮演一个严谨的审稿人角色，深入挖掘其内在逻辑、贡献与潜在局限。

- **研究问题与假设重构：** 从引言和背景部分，明确识别并重构出该研究试图解决的核心科学问题（Research Question）以及其背后的研究假设（Hypothesis）。
    
- **论证逻辑链（Argumentative Chain）梳理：** 梳理从引言、方法、结果到讨论的完整论证逻辑链。请以“因为A（背景/问题），所以采用B（方法），得到了C（结果），这说明了D（结论），其意义在于E”的结构，清晰地呈现其逻辑流程。
    
- **方法论的严谨性评估：** 详细评估其研究方法（Methodology）的严谨性。包括但不限于：实验设计是否合理？数据集/样本是否具有代表性？评估指标是否全面？是否存在潜在的混淆变量未被控制？
    
- **结论的可靠性与泛化性批判：** 评估其结论（Conclusion）是否被实验结果充分支持。是否存在过度解读或过度泛化（Over-generalization）的情况？该结论的适用边界（Boundary Conditions）可能是什么？
    
- **潜在创新点与启发：** 指出该论文对我个人研究可能产生的最大启发或可以借鉴的关键创新点（无论是理论、方法还是实验设计层面）。
    

**请处理以下论文内容：**[此处粘贴论文全文，或提供论文的详细文本内容]

### Prompt 3：研究方法论的复现性与细节探查

**任务描述：**请专注于分析我提供的论文中的“研究方法”章节，探查其技术细节、潜在假设和复现（Reproducibility）的可行性。

- **关键步骤拆解：** 将其核心方法或算法，按执行顺序拆解为一系列关键的技术步骤。
    
- **隐含假设识别：** 识别在其方法描述中可能存在的、但未被明确指出的隐含假设（Implicit Assumptions）。例如，对数据分布的假设、对模型线性的假设等。
    
- **复现所需关键参数列表：** 列出一个清单，包含要成功复现（Reproduce）该研究结果，所必须知道的所有关键参数、超参数、软件库版本或硬件配置。
    
- **模糊性与缺失信息定位：** 指出方法描述中任何模糊不清、定义不明确或缺失的关键信息，这些信息可能会成为复现该研究的主要障碍。
    

**请处理以下“研究方法”章节内容：**[粘贴论文的研究方法（Methodology/Methods）章节全文]

### Prompt 4：识别论文的理论框架与学派归属

**任务描述：**请分析我提供的论文，识别其所依赖的核心理论框架（Theoretical Framework）或所属的学术流派（School of Thought），并分析其理论贡献。

- **核心理论识别：** 从引言和文献综述部分，识别并明确指出该研究建立在一个或多个什么样的核心理论基础之上。
    
- **理论应用方式分析：** 分析论文是如何运用这些理论的。它是在验证（Test）、扩展（Extend）、修正（Modify）还是挑战（Challenge）现有理论？
    
- **学派归属判断：** 根据其引用的关键文献、使用的术语和分析视角，判断该研究最可能归属于哪个学术流派或研究范式。
    
- **理论贡献凝练：** 总结该论文在理论层面做出的具体贡献。是提出了新概念？建立了新模型？还是为旧理论找到了新的应用场景？
    

**请处理以下论文内容：**[粘贴论文的引言、文献综述和讨论部分]

### Prompt 5：多篇论文的观点合成与对比分析

**任务描述：**请基于我提供的多篇关于同一主题的论文摘要或结论，进行一次综合性的对比分析，梳理出它们之间的共识、分歧和演进关系。

- **共识点（Consensus）总结：** 总结这几篇论文共同承认或得出的核心观点、发现或方法。
    
- **分歧点（Debate）与矛盾分析：** 明确指出它们之间在结论、方法或理论解释上存在的主要分歧、争议或直接矛盾之处。
    
- **研究视角与切入点对比：** 对比分析每篇论文研究该问题的独特视角或切入点有何不同。
    
- **知识演进脉络（可选）：** 如果论文有明确的发表时间顺序，请尝试梳理出一个简要的知识演进脉络，即后续研究是如何在前人研究的基础上进行发展的。

### Prompt 6：构建特定主题的文献知识图谱

**任务描述：**我正在研究[特定研究主题]，请基于我提供的一批核心文献列表，帮助我构建一个该主题的迷你知识图谱（Mini Knowledge Graph）。

- **核心概念识别：** 从文献列表中识别出该领域最重要的3-5个核心概念（Key Concepts）。
    
- **关键关系挖掘：** 挖掘并定义这些核心概念之间的主要关系，例如“是...的子类”、“影响”、“解决...问题”、“与...相对立”等。
    
- **代表性文献关联：** 将我提供的每一篇（或关键几篇）文献，关联到这个知识图谱中的一个或多个概念/关系上，作为该节点的支撑证据。
    
- **可视化结构建议：** 以文本形式（如JSON或Markdown列表）输出这个知识图谱的结构，并建议一个最适合展示该结构的可视化图形（如思维导图、概念图、流程图）。

### Prompt 7：挖掘论文的未来研究方向（Future Work）

**任务描述：**请深入分析我提供的论文，特别是其“讨论”和“结论”部分，系统性地挖掘并整理出其中明确提及或暗示的未来研究方向。

- **直接提及的方向：** 直接摘录并列出作者在“Future Work”或类似部分明确提出的未来研究建议。
    
- **基于局限性的推导：** 分析作者承认的研究局限性（Limitations），并基于每一条局限性，推导出一个可以着手改进的具体研究课题。
    
- **未解问题的延伸：** 识别论文中提到但未能完全解决、或新引发出的开放性问题（Open Questions），并将其转化为具体的研究方向。
    
- **方向优先级建议：** 综合考虑可行性、创新性和与我研究方向的关联度，对整理出的所有未来研究方向给出一个优先级的建议（高/中/低）。
    

**请处理以下论文内容：**[粘贴论文的讨论、结论和未来研究方向部分]

### Prompt 8：对比分析论文的实验设计方案

**任务描述：**请对我提供的两篇采用了不同实验设计来研究相似问题的论文，进行一次深入的对比分析，评估各自设计的优劣。

- **核心变量对比：** 对比两项研究的自变量（Independent Variables）、因变量（Dependent Variables）和控制变量（Control Variables）有何异同。
    
- **数据集/样本对比：** 分析它们所使用的数据集或被试样本的差异，并评估这些差异可能对研究结果带来的影响。
    
- **实验流程（Procedure）对比：** 梳理并对比两者从数据准备到结果分析的完整实验流程，找出关键步骤上的差异。
    
- **优劣势评估：** 总结两种实验设计的相对优势和劣势（例如，一个内部效度更高，另一个外部效度/泛化能力更强），并说明在何种研究目标下应优先选择哪种设计。

### Prompt 9：学术术语与定义的精确溯源

### Prompt 10：生成结构化文献阅读笔记（Zettelkasten方法）

**任务描述：**请将我提供的论文内容，转换成一张结构化的、遵循Zettelkasten（卡片盒笔记法）原则的阅读笔记。这张笔记应包含三个核心部分。

- **文献笔记（Bibliographical Note）：** 自动生成该论文完整的引文信息（[请指定一种引文格式，如APA, MLA, BibTeX]）。
    
- **闪念笔记（Fleeting Note）：** 总结论文的核心论点、关键证据和主要结论。这部分应完全使用你自己的语言进行转述（Paraphrasing），避免直接摘抄，并记录下我在阅读时可能产生的初步想法或问题。
    
- **永久笔记（Permanent Note）：** 提炼出一个独立、原子化、可被永久引用的核心知识点或洞见（Insight）。这个知识点应足够凝练，可以脱离原文语境而被理解，并思考它如何与我现有的知识体系（例如，与[我已有的某个研究想法或知识点]）产生连接。
    
- **关键词与链接：** 为这张笔记提供3-5个核心关键词，并建议它可以链接到哪些已有的笔记主题。
    

**请处理以下论文内容：**

- **引文格式要求：** [例如：APA 7th]
    
- **我已有的研究想法/知识点（用于连接）：** [简述一个你自己的想法，用于AI思考如何建立连接]
    
- **论文全文/摘要/核心章节：** [粘贴你希望做笔记的论文内容]
