### 第一步：理解你的“武器库”（每个组学能告诉你什么）
每个数据的“使命”是什么。

1. **转座子插入测序 (Tn-seq):**
    
    - **核心问题：** 在特定条件下（例如，在鸡卵巢中），SP（鸡白痢沙门菌）的哪些基因是“必需”的？
        
    - **能得到什么：** 一个“必需基因”列表。如果在培养基（_in vitro_）中某个基因是“非必需”的，但在卵巢（_in vivo_）中是“必需”的，那么这个基因就是**宿主内适应性关键基因**。这是你寻找SP存活必需基因的**最直接答案**。
        
2. **转录组 (Bulk RNA-seq):**
    
    - **核心问题：** 感染后，宿主组织（如卵巢）的**整体**基因表达发生了什么变化？SP本身的基因表达又有什么变化？
        
    - **能得到什么：** 宿主和SP的差异表达基因（DEGs）。可以知道哪些宿主**信号通路**（如免疫、代谢、凋亡）被激活或抑制了。这是看“战场”全景。
        
3. **单细胞组 (scRNA-seq):**
    
    - **核心问题：** 宿主组织太复杂了。Bulk RNA-seq告诉我们“战场”在打仗，scRNA-seq则告诉我们**“谁”在打“谁”**？
        
    - **能得到什么：** 卵巢组织的细胞图谱（如巨噬细胞、上皮细胞、颗粒细胞等）。你可以精确知道：
        
        - SP主要感染了哪种细胞？
            
        - 每种细胞（特别是被感染的细胞）的基因表达是如何变化的？（例如，巨噬细胞是表现为促炎还是抑炎？）
            
        - 细胞之间是如何“通讯”的？（例如，上皮细胞在呼叫巨噬细胞）
            
    - **这是解析“宿主互作”和“免疫逃逸”的王牌数据。**
        
4. **蛋白组 (Proteomics):**
    
    - **核心问题：** 基因（RNA）表达了，但对应的蛋白质（功能执行者）真的变多了吗？
        
    - **能得到什么：** 差异表达的蛋白质（DAPs）。RNA和蛋白质的相关性有时并不强。蛋白质组是**功能上的“实锤”**。它还可以告诉你蛋白质的**翻译后修饰**（如磷酸化），这直接关系到“信号传递”。
        
5. **代谢组 (Metabolomics):**
    
    - **核心问题：** 宿主和SP在“吃”什么？在释放什么“信号”？
        
    - **能得到什么：** 差异变化的代谢小分子。这能反映：
        
        - **营养竞争：** SP是否在和宿主细胞抢夺某种营养（如葡萄糖、特定氨基酸）？
            
        - **信号通讯：** SP是否在利用宿主的代谢物（如激素）作为信号？宿主是否在用特定代谢物（如ITACONATE，衣康酸）攻击SP？
            
    - **这是连接基因/蛋白与表型的“桥梁”。**

### 第二步：分析路线图（从单兵作战到联合作战）

你应该和你的生信合作者按以下顺序推进分析：

#### 阶段一：质控与单组学分析（先把每张牌看懂）

1. **Tn-seq 分析 (SP)**
    
    - **分析：** 鉴定 _in vivo_（卵巢） vs _in vitro_（培养基）的条件必需基因。
        
    - **产出：** **“SP卵巢存活关键基因列表A”**。
        
2. **scRNA-seq 分析 (Host)**
    
    - **分析：** 细胞聚类、细胞类型鉴定、寻找差异基因。
        
    - **产出：** 1. 卵巢细胞图谱。 2. **“被SP感染的宿主细胞亚群B”**（例如，一群特殊的M2型巨噬细胞）。 3. **“这些细胞特异性高表达的宿主基因C”**。
        
3. **Bulk RNA-seq 分析 (Host + SP)**
    
    - **分析：** 宿主和SP的差异表达基因（DEGs）及通路富集（KEGG/GO）。
        
    - **产出：** 1. **“宿主整体响应通路D”**（如IFN-γ通路被抑制）。 2. **“SP在宿主内上调的基因E”**（如毒力因子、代谢基因）。
        
4. **Proteomics 分析 (Host + SP)**
    
    - **分析：** 差异丰度蛋白质（DAPs）及通路富集。
        
    - **产出：** **“功能上真实变化的蛋白质F”**。
        
5. **Metabolomics 分析 (Host)**
    
    - **分析：** 差异代谢物鉴定及通路分析。
        
    - **产出：** **“宿主微环境中发生剧变的代谢物G”**。
        

#### 阶段二：多组学整合分析（挖掘核心故事）

这是最关键的一步，也是最需要生信专家的地方。整合的目的是**建立因果链**。

**整合策略 1：SP存活机制 (Tn-seq + SP RNA-seq + SP Proteomics)**

- **问题：** SP如何活下来？
    
- **整合：**
    
    1. 从 **Tn-seq** 拿到“必需基因A”。
        
    2. 看这些基因A是否也在 **SP RNA-seq**（来自Bulk RNA-seq）中高表达（基因E）？是否也在 **SP Proteomics** 中高丰度？
        
    3. **交叉点 -> 核心存活因子**。
        

**整合策略 2：宿主免疫逃逸 (scRNA-seq + Host Proteomics)**

- **问题：** SP如何逃避免疫？
    
- **整合：**
    
    1. 从 **scRNA-seq** 锁定“被感染的巨噬细胞B”。
        
    2. 发现这些细胞高表达“免疫抑制基因C”（如 `IL-10`, `PD-L1`）。
        
    3. 去 **Host Proteomics** 中验证“IL-10”或“PD-L1”蛋白（蛋白质F）是否也真的高丰度。
        
    4. **交叉点 -> 宿主被SP操纵的关键免疫逃逸通路**。
        

**整合策略 3：宿主-病原信号互作 (Metabolomics + SP RNA-seq + Host scRNA-seq)**

- **问题：** 宿主信号和SP信号的关系？
    
- **整合：**
    
    1. 从 **Metabolomics** 发现“宿主代谢物G”（例如，某种脂质）显著增加。
        
    2. 从 **Host scRNA-seq** 发现，合成“代谢物G”的酶（基因C）在“上皮细胞”中高表达。
        
    3. 从 **SP RNA-seq** 发现，SP的某个“ABC转运蛋白”或“趋化因子受体”（基因E）高表达。
        
    4. **建立假说：** 宿主上皮细胞释放G -> SP通过E感知G -> 激活SP的毒力（这回答了你的“信号关系”问题）。
        

**整合策略 4：营养竞争 (Metabolomics + Tn-seq + Host Proteomics)**

- **问题：** SP吃什么？
    
- **整合：**
    
    1. 从 **Metabolomics** 发现“代谢物G”（例如，精氨酸）在微环境中耗尽。
        
    2. 从 **Tn-seq** 发现SP的“精氨酸合成酶”（基因A）是 _in vivo_ 必需的。
        
    3. 从 **Host Proteomics** 发现宿主细胞的“精氨酸转运体”（蛋白F）表达下调。
        
    4. **建立假说：** 宿主试图“饿死”SP（下调转运体），但SP通过“自给自足”（激活合成酶）来存活和持续感染。

### 第三步：如何从分析走向实验（验证你的假说）

生信分析的最终产物是**可被验证的科学假说 (Testable Hypothesis)**。

**假说示例 1 (来自 Tn-seq)**

- **假说：** SP的 `geneX`（Tn-seq发现的卵巢必需基因）是其在卵巢定植和垂直传播所必需的。
    
- **实验：**
    
    1. **基因敲除：** 构建 `geneX` 的敲除株 (ΔX) 和回补株 (C-ΔX)。
        
    2. **细胞实验：** 用鸡卵巢颗粒细胞或巨噬细胞感染ΔX，看其胞内生存能力是否下降（Gentamicin protection assay）。
        
    3. **动物实验：** 用成年母鸡感染ΔX，在关键时间点检测卵巢和输卵管的细菌载量，并检测其产下的种蛋阳性率（**垂直传播金标准**）。
        

**假说示例 2 (来自 scRNA-seq 和 Proteomics)**

- **假说：** SP通过诱导巨噬细胞高表达 `ProteinY`（例如PD-L1）来抑制T细胞活化，实现免疫逃逸。
    
- **实验：**
    
    1. **体外验证：** 建立巨噬细胞-T细胞共培养体系。用SP感染巨噬细胞，看T细胞的活化/增殖是否被抑制。
        
    2. **阻断/敲低：** 在上述体系中，加入 `ProteinY` 的中和抗体，或在巨噬细胞中用siRNA/CRISPR敲低 `ProteinY`，看T细胞的抑制是否被逆转。
        
    3. **互作：** SP的哪个效应蛋白（T3SS）导致了 `ProteinY` 的上调？（例如，用效应蛋白突变株去感染巨噬细胞，看 `ProteinY` 是否还上调）。
        

**假说示例 3 (来自 Metabolomics 和 SP RNA-seq)**

- **假说：** SP利用宿主的代谢物 `MetaboliteZ`（例如雌二醇）作为信号，上调其毒力基因（如T3SS）。
    
- **实验：**
    
    1. **体外诱导：** 在培养基中添加不同浓度的 `MetaboliteZ`，用qRT-PCR或Western Blot检测SP的毒力基因/蛋白表达是否上调。
        
    2. **机制：** 寻找感知 `MetaboliteZ` 的SP受体（例如，用EMSA、Pull-down等方法寻找与 `MetaboliteZ` 结合的SP转录因子）。
        

**假说示例 4 (来自你的基因组进化方向)**

- **问题：** 你的“基因退化/获取”如何与这些组学数据结合？
    
- **整合：**
    
    1. **基因退化（假基因）：** 你的比较基因组学发现SP丢失了 `geneW`（一个代谢调控基因）。
        
    2. **组学关联：** 你的**转录组/蛋白组**数据是否显示，`geneW` 曾经调控的下游通路（例如通路P）在SP中处于“持续激活”状态（因为它失去了抑制子`geneW`）？
        
    3. **假说：** SP通过“基因退化”（丢失`geneW`）获得了对通路P的“组成性激活”，这使其更适应卵巢环境。
        
    4. **实验：** 将功能性的 `geneW` “修复”回SP中（基因回补），再进行动物感染，看其垂直传播能力是否**反而下降**了？

### 给“生信小白”的行动总结

1. **立即行动：** 找到一个靠谱的生信合作者，把你的数据和你的核心问题（垂直传播机制）告诉他。
    
2. **明确分工：** 你负责生物学（提供样本、提出问题、验证假说），他负责数据科学（质控、分析、整合、建模）。
    
3. **从简入繁：** 先把每个单组学的故事理顺（尤其是Tn-seq和scRNA-seq，它们的信息量最大）。
    
4. **聚焦交叉点：** 真正的“好故事”一定是在多个组学数据中都得到印证的（例如，Tn-seq的必需基因，同时也在RNA和蛋白水平高表达）。
    
5. **动手实验：** 生信分析跑得再漂亮，也只是“假说”。你的核心竞争力在于用后续的实验去**证实或证伪**这些假说。
