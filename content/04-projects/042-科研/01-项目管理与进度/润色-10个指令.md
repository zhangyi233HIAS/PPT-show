Prompt 1: 优化“讨论”章节的引导性开篇

我需要在“讨论”章节的开头，用一段极具吸引力的文字，将读者从“结果”的客观世界，平稳地引入“讨论”的思辨空间。我将提供[我的研究结果章节的核心发现摘要]。请基于此，为我完成以下任务：

首先，第一个任务是提炼“最惊艳”的发现。请从我的所有发现中，识别出那个最令人惊讶、最反直觉或最具理论冲击力的“亮点发现”，并将其作为开篇的“钩子”。

接下来，第二个任务是构建“悬念式”的开篇结构。请为我设计一个开篇段落的结构，该结构应首先抛出这个“亮点发现”，然后立即提出一个引导性的问题，例如：“这一出人意料的结果，究竟意味着什么？它又将如何挑战我们对... 的传统认知？本章将对此展开深入探讨。”

最后，你需要生成一段“开篇”初稿。请撰写一段约 200 字的、充满悬念和启发性的开篇文字，旨在激发读者的阅读兴趣，并清晰地预告本章的思辨之旅。

Prompt 2: 对核心论点的陈述进行“强度”调节

我需要在讨论中，根据证据的强度，来使用不同层次的、自信而又严谨的语言来陈述我的论点。我将提供[我的一个核心论点]和[支撑该论点的证据的简要描述（例如：证据强度是决定性的、强支持的、还是探索性的）]。请基于此，为我完成以下任务：

第一个任务是建立“论点强度”的语言库。请为我提供一个从弱到强的“论点主张”句式库。例如，从“研究结果似乎暗示了...”（弱）到“本研究有力地证明了...”（强）。

第二个任务是进行“证据-强度”的匹配。请根据我提供的证据强度描述，从你的语言库中，为我的核心论点选择一个强度最匹配的陈述句式。

第三个任务是撰写一段经过“强度”调节的论述。请为我撰写一段完整的论述。该论述需要使用你选择的句式，来陈述我的核心论点，并简要地论证为何基于现有的证据，采用这种强度的论述是最科学、最负责任的。

Prompt 3: 在论证中引入并回应一个“假想的怀疑论者”

为了使我的论证更具说服力，我希望在讨论中，引入一个“假想的怀疑论者”并有力地回应其质疑。我将提供[我的一个核心解释]。请基于此，为我完成以下任务：

第一个任务是构建“怀疑论者”的质疑。请扮演一位最苛刻的“怀疑论者”，针对我的核心解释，提出一个最尖锐、最一针见血的质疑。例如：“你的解释固然有趣，但你如何排除另一种更简洁的可能性，即...？”

第二个任务是进行“先退后进”式的回应。请为我撰写一段回应性的论述。该论述应首先承认这个质疑的合理性（“这是一个非常重要的质疑...”），然后再通过引用更深层次的证据、进行更细致的逻辑辨析，或强调替代性解释的不足，来有力地回应这个质疑。

第三个任务是将回应转化为“贡献”。请在段落的结尾，将这次成功的“自我辩护”，转化为对本文“论证严谨性”的一次凸显，以此来增强读者对结论的信心。

Prompt 4: 将研究局限性的陈述重构为“建设性”的学术对话

我需要将论文的“研究局限性”部分，从一段看似“自我否定”的陈述，重构为一次开启未来对话的、具有建设性的学术贡献。我将提供[我列出的 1-2 条研究局限性]。请基于此，为我完成以下任务：

首先，你需要将“局限”重新定义为“边界”。请为我重写对局限性的陈述，将负面的“缺陷”或“不足”，重新定义为中性的、为了研究的深入而必须做出的“范围界定”或“边界划分”。

其次，你需要将“边界”转化为“新问题”。请将每一个“研究边界”，都转化为一个具体的、有待未来研究深入探索的“新研究问题”。

最后，你需要发起“对话”的邀请。请撰写一段总结性文字，其核心姿态是：“本研究清晰地划定了自身的边界，而正是这些边界，为未来的学者们开辟了激动人心的新研究疆域。我们期待与同行一道，在未来继续探索...”

Prompt 5: 优化讨论章节的“段落间”逻辑流与叙事节奏

我需要确保我的讨论章节，在从一个论点转向另一个论点时，过渡是自然、流畅且富有节奏感的。我将提供[我的讨论章节的几个核心论点要点]。请基于此，为我完成以下任务：

第一个任务是设计“叙事节奏”。请为我的论点要点，设计一个富有节奏感的呈现顺序。例如，可以采用“最强论点先行 -> 补充性论点跟进 -> 意外发现作为转折 -> 总结升华”的结构。

第二个任务是撰写“过渡性”的段落或句子。请为每一个论点之间的转换，都撰写一个起到“承上启下”作用的过渡性段落或引导句，以确保逻辑的无缝衔接。

第三个任务是生成一份“讨论章节”的详细叙事大纲。请生成一份大纲，清晰地展示每个核心论点的呈现顺序、用于支撑论点的核心逻辑，以及用于连接论点的过渡性话语。

Prompt 6: 对一个核心理论贡献进行“多角度”的阐释

为了让读者充分理解我的理论贡献，我需要从多个不同角度，反复、深入地阐释它。我将提供[我的一个核心理论贡献的简短陈述]。请基于此，为我完成以下任务：

第一个任务是进行“正面”阐释。请为我撰写一个段落，用最清晰、最直接的语言，正面阐述我的这个理论贡献“是什么”。

第二个任务是进行“反面”阐释。请撰写另一个段落，通过阐明我的理论贡献“不是什么”，以及它与哪些容易混淆的既有理论有何根本区别，来进一步清晰化它的边界。

第三个任务是进行“案例”阐释。请构思一个简短的虚拟案例或思想实验，并用它来生动、直观地展示，应用了我的理论贡献后，我们对这个案例的理解会发生怎样深刻的改变。

Prompt 7: 撰写一个富有远见的“未来研究展望”

我需要在讨论的结尾，提出一个超越“弥补本文不足”的、更具学科视野和前瞻性的“未来研究展望”。我将提供[我的研究的核心发现]。请基于此，为我完成以下任务：

首先，你需要进行“趋势”的预测。请基于我的研究发现，并结合更宏观的技术、社会或理论发展趋势，预测我所在的研究领域，在未来 5-10 年可能会出现哪些全新的、重大的“研究议程”。

其次，你需要定位“新兴交叉点”。请思考并建议，我的研究领域，在未来最有可能与哪些新兴的、看似不相关的学科领域（例如，脑科学、复杂性科学等）产生交叉，并形成激动人心的新研究方向。

最后，你需要撰写一份“学术路线图”。请撰写一段富有远见和号召力的“未来研究展望”。该展望应能清晰地为本领域的同行，描绘一幅关于未来探索的“学术路线图”。

Prompt 8: 在讨论中增加一段对“研究旅程”的简短反思

我希望在讨论章节中，增加一小段关于“研究旅程”的个人化反思，以增加论文的真诚度和思想性。我将提供[我在研究过程中遇到的一个关键转折点或挑战]。请基于此，为我完成以下任务：

第一个任务是进行“故事化”的叙述。请将我提供的经历，用第一人称的、生动的“故事化”语言，简要地叙述出来。

第二个任务是进行“方法论”的升华。请引导我思考并阐述，这次经历让我对科研工作本身、对理论与现实的关系，或对研究者的角色，产生了哪些更深层次的“方法论反思”。

第三个任务是撰写一段“反思性”陈述。请撰写一段约 200 字的、可以巧妙地插入讨论章节的“研究者反思”段落。该段落旨在向读者展示，本研究不仅产出了知识，更是一次塑造了学者自身的智识旅程。

Prompt 9: 将论文的“核心信息”适配给不同的读者

我需要将我论文最想传达的“核心信息”，以不同的方式，呈现给不同的读者。我将提供[我的博士论文的一个核心结论]。请基于此，为我完成以下任务：

第一个任务是撰写“同行版”核心信息。请为同行专家，撰写一句话版本的核心信息。该版本应使用最精确的专业术语，旨在进行高效的学术交流。

第二个任务是撰写“学生版”核心信息。请为非本专业的学生，撰写一个更长、更具解释性的版本。该版本应包含一个生动的类比，以帮助他们直观地理解。

第三个任务是撰写“公众版”核心信息。请为普通公众，撰写一个极度简化的、旨在引发情感共鸣或现实思考的版本。

Prompt 10: 撰写讨论章节的“点睛之笔”式结尾

我需要为我的讨论章节，乃至整篇论文，撰写一个强有力、令人回味的结尾段落。我将提供[我的论文的核心贡献]。请基于此，为我完成以下任务：

首先，你需要避免“重复总结”。请确保这个结尾段落，不是对前面内容的简单重复，而是要在已有论证的基础上，进行一次最终的“思想拔高”。

其次，你需要回归“宏大图景”。请引导我将我的具体研究贡献，重新放回到引言部分所描绘的那个“宏大问题”或“理论图景”中，并阐明我的研究为这幅图景增添了怎样“新的一笔”。

最后，你需要留下一个“开放性”的思考。请撰写一个富有余味、能够引发读者在读完之后继续长久思考的“开放性问题”或“深刻隐喻”，作为整篇论文的最终收束。
