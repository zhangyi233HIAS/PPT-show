# 结论要点（一句话）

你的 6 列样本**不是生物学重复**（每列是把 3 只鸡的同一部位混合得到的“合样”），且每列代表不同的组织部位（因此彼此并非来自相同“总体”），**不能把它们当成对同一条件的独立生物学重复**。因此**传统基于重复估计 dispersion 的方法（如 DESeq 2/edgeR 在常规设置下）不适合直接应用来给出可靠的 p 值**。但并非没有可做的事——可以做稳健的探索性分析并用保守策略和验证步骤来筛候选基因。

---
### 为什么不能直接把它们当重复？

* 你把三只鸡相同部位“混合”成一个样本 → 每个合样是“已合并的单个观测值”（n=1）;
* 6 列分别是 6 个不同部位（不是相同条件的独立重复），若你把“部位”作为随机重复来对比两类（2 vs 4），那前提是“这 6 个部位在统计上可交换（exchangeable）”，通常不成立（组织学与微环境不同，会引入很大系统差异）；
* 没有生物学重复就无法估计同一条件下的生物学变异（dispersion），这是 DESeq 2/edgeR 能产出可信 p 值的关键。

# 在现有数据下可行的策略（按推荐顺序）


#### 方案 B — 若不能补样：做“严格的探索性/候选基因筛选 + 验证”流程

适合你现在必须利用已有 6 列数据的情形。关键点是把统计检验做得尽可能保守、并强调“探索性（hypothesis-generating）”。具体步骤如下：

1. **使用原始 insertion 数据（推荐）：**

   * 优先用 *unique insertion sites*（No. Of Unique hits / hits per bp）或 *reads per gene*（raw reads）而非直接 RPKM/FPKM。
   * 原因：Tn-seq 的信号来自插入位点与插入读数，其物理机制与转录组不同，RPKM 在转录组合理，但在 Tn-seq 中更直观和常用的是“插入密度 / unique hits / reads”与基因长度或 TA 位点数归一化。

2. **做基础过滤（保守）：**

   * 去掉基因总插入数或总 reads 过少的基因（例如总插入数 < 10 或总 reads < 20），以避免低计数噪声。

3. **计算每基因在 6 个样本的插入密度或 reads（归一化）：**

   * 例如：`density = unique_hits / gene_length` 或 `rpm = reads / (library_size/1e6)`；推荐同时保留 unique_hits 与 reads 两套度量以交叉验证。

4. **用**置换（permutation）**检验得到基于样本分组的经验 p 值（强烈推荐）**。

   * 理由：标准方法需要独立重复估计方差；置换检验只要求样本在原假设下可交换（这是最弱的分布假设）。
   * 在你 6 个样本、将其划分成 2 vs 4 的情形下，**所有可能的分组数只有 C (6,2)=15**，可以枚举全部可能分配，得到精确（exact）经验 p 值 —— 这比单纯求和 Fisher 在没有重复的场景下要稳健得多（假定样本可交换）。
   * 做法：对每个基因，统计观测统计量（例如两组均值差或组间 log 2 FC），然后在所有 15 种分配下计算该统计量分布，p 值 = 极端或更极端次数 / 15。
   * 再对所有基因做 BH 校正得到 FDR（因为你做的是多基因检验）。

5. **并行做基于“汇总计数”的 Fisher 检验（作为参考）**：

   * 对每个基因构造 2×2 列联表：`[插入数_组A, 其余插入数_组A] vs [插入数_组B, 其余插入数_组B]`（即把该基因插入数与组总插入数做对比），做 Fisher 检验并 BH 校正。
   * 这种检验等同 TSAS 的 proportions_insertions 或 Fisher_insertions，可作为比较，但对于不满足独立样本假定的情况要非常小心地解释。

6. **阈值与筛选（保守）**：

   * 只把同时满足：|log 2 FC| ≥ 1（或更严格 2）、最少插入数门槛（如 sum 插入数 ≥ 10）并且置换 FDR < 0.1（或 0.2） 的基因列为候选。
   * 强烈强调后验验证（qPCR/重测/独立样本）。

7. **注：TSAS 的输出可用作输入**：

   * **TSAS 给的 (12) Log-fold Change (Insertions) 与 (16) Adj. Pvalue (proportions_insertions) 可以参考，但当组内样本并非独立重复时（或混合样本导致方差不可估），这些 p 值要被当作“粗略参考**”。
   * 更可靠的方法就是以你自己的置换策略对 TSAS 输出的每个基因统计量做置换检验/校正。

# R 实操模板（两种方法：置换检验 + Fisher 汇总检验）

下面给你可拷贝运行的 R 代码模板。**假设输入是一个 data. Frame `mat`，行是基因，列为 6 个样本，值为 `unique_hits`（插入位点数）或 `reads`**；并且你想把列 1:2 作为组 A（2 列），列 3:6 作为组 B（4 列）。

```r
# 假设 mat 是 rows=genes, cols=6 samples，值为 unique insertion counts
# genes <- rownames(mat)
groupA <- 1:2
groupB <- 3:6

# 基础过滤：至少总插入 >= 10
totals <- rowSums(mat)
keep <- totals >= 10
mat2 <- mat[keep, , drop=FALSE]
genes2 <- rownames(mat2)

# 计算观测统计量：log2 fold-change of mean density
meanA <- rowMeans(mat2[, groupA, drop=FALSE])
meanB <- rowMeans(mat2[, groupB, drop=FALSE])
# 为避免0，可加小常数
log2fc <- log2((meanA + 1e-6) / (meanB + 1e-6))

# 置换检验（枚举所有 C(6,2)=15 种分组）
library(combinat)  # 或 combinat::combn
comb <- combn(6, 2)
ncomb <- ncol(comb)
# 计算 statistic for each gene under each partition
stat_obs <- log2fc  # or meanA-meanB etc.

perm_stats <- matrix(NA, nrow=nrow(mat2), ncol=ncomb)
for(i in 1:ncomb){
  a_idx <- comb[,i]
  b_idx <- setdiff(1:6, a_idx)
  mA <- rowMeans(mat2[, a_idx, drop=FALSE])
  mB <- rowMeans(mat2[, b_idx, drop=FALSE])
  perm_stats[, i] <- log2((mA+1e-6)/(mB+1e-6))
}

# empirical two-sided p-value: proportion of perm absolute >= obs absolute
p_emp <- sapply(1:nrow(mat2), function(r){
  mean(abs(perm_stats[r, ]) >= abs(stat_obs[r]))
})

# BH 校正
p_adj <- p.adjust(p_emp, method="BH")

res <- data.frame(
  gene = genes2,
  log2FC = stat_obs,
  p_emp = p_emp,
  p_adj = p_adj,
  total = totals[keep]
)
head(res[order(res$p_adj), ], 30)
```

并行做 Fisher（汇总计数版）：

```r
# Fisher on summed counts (gene vs genome rest)
library(stats)
total_insertions_groupA <- colSums(mat[, groupA, drop=FALSE])  # per sample -> sum
total_insertions_groupB <- colSums(mat[, groupB, drop=FALSE])

# For each gene:
p_fisher <- sapply(1:nrow(mat2), function(i){
  geneA <- sum(mat2[i, groupA])
  geneB <- sum(mat2[i, groupB])
  restA <- sum(mat2[-i, groupA])
  restB <- sum(mat2[-i, groupB])
  tbl <- matrix(c(geneA, geneB, restA, restB), nrow=2)
  fisher.test(tbl)$p.value
})
p_fisher_adj <- p.adjust(p_fisher, method="BH")
res$fisher_p <- p_fisher
res$fisher_p_adj <- p_fisher_adj
head(res[order(res$fisher_p_adj), ], 30)
```

> 注 1：若使用 reads 而非 unique_hits，把 `mat` 替换为 reads matrix 即可。
> 注 2：上面置换检验枚举了所有分配，p 值是精确的（分母 = 15）。若分组更复杂可用大量随机置换。

# 关于 RPKM / FPKM 在 Tn-seq 的应用

* **RPKM/FPKM 是为转录组（RNA-seq）定义的度量**，它考虑基因长度与测序深度以估计“每基因的转录本丰度”。
* **Tn-seq 的生物学信号是“插入位点数量/插入密度”或“每个插入位点的 reads 数”**，不是转录水平。因此：

  * 你可以用“hits per kb”（unique insertions / gene length）或“reads per million (rpm)”作为归一化度量；
  * 但直接用 RPKM/FPKM 并不直接反映插入概率（插入事件依赖于可插入位点数，如 TA 位点数），更合适的是 **按可插入位点（例如 TA site）或基因长度归一化**。
* 结论：**优先用 unique insertion density 或 normalized reads（比如 reads per million 或 normalized weighted reads），而不是 RPKM/FPKM**，除非你能证明 RPKM 在你的 Tn-seq 实验语义上与 insertion density 是等价且无偏的（通常不会）。
