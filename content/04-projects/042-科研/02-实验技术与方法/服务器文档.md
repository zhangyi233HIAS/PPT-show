#### assembly.sh 适配诺禾测序组装脚本

```Bash
#!/bin/bash
# 基因组组装脚本 自动生成mapping_file和metadata.txt
set -e  # 遇到错误立即退出

# 定义原始数据目录
RAW_DATA=/public/lab/keyefang/linuxnd/CP2018091200195/H101SC25095131/RSMD00304/X101SC25095131-Z01/X101SC25095131-Z01-J011/00.CleanData

# 推导路径
PROJECT_HOME=$(dirname "$RAW_DATA")
MAPPING_FILE="$PROJECT_HOME/mapping_file.txt"
METADATA_FILE="$PROJECT_HOME/metadata.txt"

# 生成正确格式的mapping_file.txt
cd "$RAW_DATA" || { echo "ERROR: 无法进入目录 $RAW_DATA"; exit 1; }

# 清空旧的mapping_file
> "$MAPPING_FILE"

# ========== 核心修复：简洁且准确的路径拼接 ==========
# 遍历样本目录，提取样本名
ls -d */ | awk -F '/' '{print $1}' | sort | uniq | while read sample_name; do
    # 1. 列出样本目录下的所有clean.fq.gz文件（仅文件名）
    file_names=$(ls "${sample_name}/"*.clean.fq.gz 2>/dev/null | xargs -n1 basename)
    
    # 2. 校验文件数量
    file_count=$(echo "$file_names" | wc -l)
    if [ "$file_count" -ne 2 ]; then
        echo "WARNING: 样本${sample_name}的clean.fq.gz文件数量不是2个（当前：${file_count}），跳过"
        continue
    fi
    
    # 3. 拼接成「样本名/文件1,样本名/文件2」格式（核心修复）
    files_formatted=$(echo "$file_names" | awk -v sn="$sample_name" '{print sn"/"$0}' | tr '\n' ',' | sed 's/,$//')
    
    # 4. 写入mapping_file，严格按「样本名        路径1,路径2」格式
    echo -e "${sample_name}\t${files_formatted}" >> "$MAPPING_FILE"
    echo "INFO: 已添加样本${sample_name}，文件列表：${files_formatted}"
done

# 生成metadata.txt
cat > "$METADATA_FILE" << EOF
#metadata
project_home     $PROJECT_HOME
project_id       data_analysis
raw_data         $RAW_DATA
mapping_file     $MAPPING_FILE

#hardware
cpus              60
parallel          8
threads           10

#jellyfish
jellyfish_parameter  -m 31 -s 100M -C -t 8

#memory
memory             300
spades_para        -k 21,33,55,77,99,127
spades_threads     20
EOF

echo -e "\nINFO: mapping_file生成完成，最终内容："
cat "$MAPPING_FILE"

# 执行组装命令
echo -e "\nINFO: 开始执行组装命令..."
bact-typing "$METADATA_FILE" "trimming,spades"
```

## Conda 升级

> 使用 conda 命令，如`conda update conda` 等，已经尝试了各种方法无法升级，于是尝试用手动操作文件的方式来升级，过程如下：
> 
> 下载最新版 miniconda（也可以是最新版 anaconda），先安装到与旧版 conda 不同的目录。
> 
> 从旧版 conda 下面把 envs 里的文件夹全部拷贝到新版 conda 目录下面的 envs 文件夹。
> 
> 不用官方的 conda install anaconda-clean 等命令卸载旧版 conda，而是直接 rm -rf 删除旧版 conda 目录。
> 
> 打开.bashrc 和.bash_profile 文件，把里面的 conda 旧路径替换为新路径。当然也可以把新路径 mv 到旧路径。
> 
> 重开一个 shell 或者 source .bashrc 和.bash_profile，发现 conda 已经成功升级到最新版。
> 
> 注意：如果是 R 环境，需要 conda install -c conda-forge r-base 重装一下 r-base，否则 Rscript 用不了，而且 Rscript 是二进制的，没法修改。

## 在 **Slurm** 作业调度系统中，可以使用以下命令来查看各个节点的使用情况：

  

1. **查看节点的状态（**`**scontrol show nodes**`**）**
    
    ```Bash
    scontrol show nodes
    ```
    
      这个命令会显示所有节点的详细信息，包括节点的状态、可用资源、负载等。例如：
    
    ```Plain
    NodeName=node 01 Arch=x 86_64 CoresPerSocket=8
       CPUAlloc=0 CPUErr=0 CPUTot=16 CPULoad=0.00
       AvailableFeatures=(null) ActiveFeatures=(null)
       Gres=(null) NodeAddr=node 01 NodeHostName=node 01
       RealMemory=64000 AllocMem=0 FreeMem=63000 Sockets=2 Boards=1
       State=IDLE TmpDisk=2000000 Weight=1
       BootTime=2024-11-05 T 02:00:00 SlurmdStartTime=2024-11-05 T 02:00:00
       ...
    ```
    
      在这个输出中，你可以看到每个节点的 **状态（State）**、**分配的 CPU 数量（CPUAlloc）**、**内存情况（RealMemory, FreeMem）** 等信息。
    

  

2. **查看节点状态摘要（**`**sinfo**`**）**
    
    ```Bash
    sinfo
    ```
    
      这个命令会输出简洁的节点状态摘要，包括每个节点的状态（空闲、忙碌、故障等）以及可用资源（CPU 和内存等）。例如：
    
    ```Plain
    PARTITION  AVAIL  TIMELIMIT  NODES  STATE     NODELIST
    debug      up     infinite   2     idle      node 01,node 02
    compute    up     infinite   4     allocated node 03,node 04,node 05,node 06
    ```
    
      通过 `sinfo`，你可以快速了解每个节点的状态（如 `idle` 表示空闲，`allocated` 表示已分配）。
    

  

3. **查看节点使用情况的详细信息（**`**sstat**`**）**
    
    ```Bash
    sstat -a
    ```
    
      如果你需要查看特定作业在各个节点的资源使用情况，可以使用 `sstat` 命令。例如，查看所有作业的资源使用统计信息：
    
    ```Plain
    JOBID      PARTITION  USER    ST    REQ    MEMORY    TIME   NODELIST
    12345      compute    user 1   R     8      4 G        10:00  node 01
    67890      debug      user 2   R     4      2 G        15:00  node 03
    ```
    

  

4. **查看 Slurm 作业的资源使用情况（**`**squeue**`**）**
    
    ```Bash
    squeue
    ```
    
      该命令会列出当前的作业队列和作业的状态。如果需要查看节点的资源分配情况，可以用 `squeue -o` 来定制输出格式：
    
    ```Bash
    squeue -o "%A %T %C %m %D %R"
    ```
    
      输出格式示例：
    
    ```Plain
    JOBID    STATE    CPUS   MEM  NODE  REASON
    12345    RUNNING  8      4 G   node 01  ...
    ```
