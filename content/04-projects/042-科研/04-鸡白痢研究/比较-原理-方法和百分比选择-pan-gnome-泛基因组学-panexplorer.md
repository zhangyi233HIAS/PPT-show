以下是 **PanACoTA、Roary 和 PGGB** 三个泛基因组学工具的核心区别对比表，并针对 **沙门菌属** 分析中的 **Minimum Percentage Identity** 设置给出建议：

### **泛基因组工具对比表**
| 特性       | PanACoTA (v2.0+)       | Roary (v3.13+)       | PGGB (PanGenome Graph Builder) |
| -------- | ---------------------- | -------------------- | ------------------------------ |
| **核心目标** | 快速构建高质量泛基因组（优化流程）      | 经典泛基因组聚类（基于MCL）      | 构建全基因组图（图泛基因组）                 |
| **输入要求** | 基因组序列（FASTA）或注释文件（GFF） | 预注释的GFF文件            | 全基因组序列（FASTA）                  |
| **核心算法** | MMseqs2（快速聚类）+ 过滤策略    | CD-HIT + MCL（马尔可夫聚类） | 基于wfmash的序列比对 + odgi图构建        |
| **速度优化** | ⭐⭐⭐⭐（并行化设计）            | ⭐⭐（大样本较慢）            | ⭐（资源密集型，需GPU加速）                |
| **输出形式** | 核心/泛基因集、系统发育树、矩阵       | 基因存在/缺失矩阵、核心基因列表     | **泛基因组图**（GFA格式）               |
| **独特优势** | 自动过滤低质量基因、整合系统发育分析     | 成熟稳定、社区支持广泛          | **捕获结构变异**（SV）、等位基因多样性         |
| **适用场景** | 大规模细菌泛基因组（>1,000基因组）   | 中小规模泛基因组（<500基因组）    | 研究复杂变异（如病原体进化）                 |

### **沙门菌属的 Minimum Percentage Identity 设置建议**
沙门菌属基因组高度保守（>95% ANI），但存在多个亚种（如 *S. enterica* 亚种）。推荐参数：

| 工具       | 推荐Identity阈值 | 科学依据                                                                 |
|------------|------------------|--------------------------------------------------------------------------|
| **PanACoTA** | **90-95%**       | 沙门菌核心基因保守性高，阈值过低会引入噪声（如移动元件）                 |
| **Roary**    | **80-90%**       | 经典文献常用85%平衡灵敏度与特异性（PMID: 26209429）                     |
| **PGGB**     | **无需设置**     | 基于全基因组比对自动捕获变异（需设置映射参数：`-p 90 -s 5k` 过滤短比对） |

> **关键考虑因素**：
> 1. **研究目标**：
>    - 若关注**核心基因进化**（如系统发育）：提高阈值至 **≥95%**（减少旁系同源基因干扰）。
>    - 若分析**附属基因组**（如毒力基因）：降低至 **80-85%**（捕获更多多样性）。
> 2. **数据异质性**：
>    - 包含不同亚种（如 *S. bongori* 和 *S. enterica*）时，建议 **≤90%**。
> 3. **验证步骤**：
>    - 先运行 **Average Nucleotide Identity (ANI)** 工具（如 FastANI），确认菌株间相似性：
>      - 同亚种菌株：ANI >99% → 可用95%阈值
>      - 跨亚种比较：ANI 95-97% → 建议90%阈值

---

### **操作建议流程**
1. **预处理**：  
   - 使用 `CheckM` 评估基因组质量（完整性>95%，污染<5%）。
   - 通过 `FastANI` 计算菌株间ANI值，排除异常株（如ANI<95%的非沙门菌）。
2. **工具选择**：  
   - **快速核心基因分析** → PanACoTA（`panacota pangenome -I 95`）  
   - **传统矩阵构建** → Roary（`roary -i 85 -f output_dir *.gff`）  
   - **结构变异研究** → PGGB（`pggb -p 90 -s 10000 -n 50 input.fa`）  
3. **阈值验证**：  
   - 检查核心基因集大小：在90%/95%阈值下，沙门菌属典型核心基因数应为 **~3,000-4,000个**（若偏差>20%，需调整阈值）。

> 📌 **重要提示**：PGGB 的资源消耗显著高于其他工具（需100+ GB内存），建议仅在需要探索复杂基因组结构时使用。

通过合理设置 Identity 阈值，可确保在沙门菌泛基因组分析中精准区分真实生物变异与测序/注释噪声。
