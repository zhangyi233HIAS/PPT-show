---第一部分：研究问题的确立与界定

Prompt 1: 构建开题报告的核心研究问题与论证起点

我正在构思开题报告的核心，需要将一个宽泛的研究兴趣转化为一个具体、有张力的核心议题。我将提供[我的研究领域、一个初步的研究方向和一些相关的观察或困惑]。请基于此，为我完成以下任务：

首先，第一个任务是识别论证张力。你需要帮助我识别该领域中存在的“理论与现实的矛盾”、“不同理论解释力的冲突”或“已有研究的盲点与悖论”，凝练出2-3个潜在的论证张力。

接下来，第二个任务是构建核心研究问题。请从最有潜力的一个张力中，选择一个，并将其表述为一个清晰、聚焦的核心研究问题。

最后，你需要撰写问题陈述。请撰写一段引导性的“研究问题陈述”段落，从宏观背景引入，通过论证张力的呈现，最终聚焦于这个核心研究问题，以此作为开题报告的逻辑起点。

Prompt 2: 撰写“研究现状述评”以论证研究的必要性

我需要撰写开题报告中的“国内外研究现状”部分，目标是通过述评来凸显我研究的必要性和独特性。我将提供[我的核心研究问题]和[10-15篇关键参考文献的列表及摘要]。请基于此，为我完成以下任务：

第一个任务是构建述评框架。你需要设计一个主题式的而非编年体的述评框架，将现有文献划分为2-4个核心议题或研究路径。

第二个任务是提炼“共识”与“盲区”。在每个议题下，你需要综合述评已有研究达成的“学术共识”，并敏锐地识别出当前研究存在的“理论盲区”、“方法论局限”或“经验证据空白”。

第三个任务是生成述评报告。请撰写一段结构化的“研究现状述评”。该述评需清晰地指出，“尽管前人已在...方面取得了进展，但在...方面仍存在显著不足”，并最终导向“因此，本研究旨在...”，从而有力论证研究的必要性。

Prompt 3: 界定论文的研究范围、边界与核心概念

为确保研究的可行性，我需要在开题时就清晰界定研究的边界。我将提供[我的研究问题和初步的研究设想]。请基于此，为我完成以下任务：

第一个任务是界定研究边界。你需要从时间跨度、地理空间、案例/样本类型、分析层次等维度，清晰界定本研究的范围边界。

第二个任务是明确排除范围。请撰写一个“研究边界声明”，明确指出本研究将“不涉及”或“不旨在”解决哪些相关但非核心的问题，以管理评审专家的预期。

第三个任务是撰写核心概念操作性定义。请针对研究中最重要的1-3个核心概念，撰写清晰的“操作性定义”，说明在本研究的特定语境下，这些概念具体指代什么，将如何被测量或识别。

Prompt 4: 构建研究的理论分析框架及其应用路径

我需要提出一个清晰的理论框架，用以指导后续的研究。我将提供[我的研究问题]和[我计划使用的1-3个核心理论或模型]。请基于此，为我完成以下任务：

第一个任务是论证理论选择的适配性。你需要撰写一段论证，解释为何选择这些特定理论来分析我的研究问题，重点阐述理论的核心解释力与研究问题的内在契合性。

第二个任务是构建整合性分析框架。如果使用多个理论，请阐明它们之间是互补关系、递进关系还是对话关系，并构建一个整合性的理论分析框架。

第三个任务是阐述框架应用路径。你需要清晰描述在后续研究中，我将如何具体地运用这个理论框架来指导数据收集、建立分析维度和解释研究发现。

第二部分：研究设计与方法论证

Prompt 5: 设计论文的总体研究思路与技术路线图

我需要清晰地呈现整个研究的实施步骤和逻辑流程。我将提供[我的研究目标和主要研究内容]。请基于此，为我完成以下任务：

第一个任务是研究阶段划分。你需要将整个博士论文研究过程划分为3-5个逻辑清晰的阶段（例如：理论准备、数据收集、分析写作、结论等）。

第二个任务是构建技术路线。请针对核心的研究分析阶段，设计一个具体的技术路线，清晰说明本研究将遵循的具体路径。

第三个任务是生成“研究思路”文本。请撰写“本论文总体研究思路”部分，用叙述性语言串联起所有研究阶段和核心步骤，让读者对研究的全貌一目了然。

Prompt 6: 构建博士论文的预期章节结构与各章核心功能

我需要在开题报告中提出一个逻辑清晰、结构完整的预期论文大纲。我将提供[我的研究主题和核心研究内容]。请基于此，为我完成以下任务：

第一个任务是设计章节结构。你需要设计一个包含5-7个章节的博士论文结构（例如：导论、文献综述、研究设计、实证分析章节、结论）。

第二个任务是明确各章核心功能。请为每一个章节撰写其“核心功能”描述，例如，“第三章：研究设计，本章旨在详细阐述研究方法...”。

第三个任务是阐述章节间的逻辑关系。请撰写一段概述性文字，说明各章节之间是如何环环相扣、层层递进的，共同构成一个完整的论证体系。

Prompt 7: 撰写研究可行性分析报告

我需要从多个维度全面、客观地分析并论证本研究是可行的。我将提供[我的研究计划、我的个人学术背景和可利用的资源条件]。请基于此，为我完成以下任务：

第一个任务是构建可行性分析框架。你需要从理论可行性、方法可行性、数据/资料可行性、能力可行性和时间/资源可行性五个核心维度构建分析框架。

第二个任务是匹配支撑证据。请将我提供的信息与上述框架进行匹配，为每个维度的可行性提供具体、有力的支撑证据。

第三个任务是生成分析报告。请撰写一份结构化的“可行性分析”报告，分点进行论证，主动识别潜在困难并暗示已有预案。

Prompt 8: 阐述论文的预期创新点与理论/实践贡献

在研究尚未开展时，我需要清晰地阐明研究完成后，预期会带来哪些创新与贡献。我将提供[我的研究问题和研究思路]。请基于此，为我完成以下任务：

第一个任务是凝练预期创新点。你需要帮助我从新视角、新方法、新材料、新观点等角度，凝练出本论文最具潜力的2-3个“预期创新点”。

第二个任务是区分预期理论与实践贡献。你需要清晰地区分本研究预期将产生的理论贡献（对学术知识的补充）和实践贡献（对现实问题的启示）。

第三个任务是撰写“创新与贡献”声明。请撰写“本论文的预期创新与贡献”部分，用高度凝练、充满自信的语言，分点阐述上述内容。

第三部分：研究规划与过程管理

Prompt 9: 制定详细的研究进度规划与关键里程碑

我需要一份详细、现实、可操作的研究时间表。我将提供[我的博士在读年限（例如，3-4年）]和[已拆分的主要研究任务]。请基于此，为我完成以下任务：

第一个任务是时间颗粒化分配。你需要以“学期”为基本单位，将所有研究任务（从文献阅读到论文送审）合理地分配到每个学期中。

第二个任务是设定关键里程碑。你需要在时间表中设定清晰的、可考核的“关键里程碑”，例如“完成开题报告”、“完成数据收集”等。

第三个任务是生成甘特图文本描述。你需要生成一个可以转化为甘特图的文本化时间规划表，包含“任务名称”、“起止时间”和“主要交付成果/里程碑”三列。

Prompt 10: 优化开题报告的暂定研究题目

我需要为我的开题报告拟定一个专业、信息量充足的暂定标题。我将提供[我的核心关键词和一句对研究的简单描述]。请基于此，为我完成以下任务：

第一个任务是设计“冒号”结构标题。你需要设计1-2个采用“主标题：副标题”结构的标题，主标题引人注目，副标题具体说明。

第二个任务是设计“基于/视角”型标题。你需要设计1-2个以“基于XX理论/方法的YY研究”或“从ZZ视角看YY问题”为结构的标题。

第三个任务是评估与建议。你需要对所有备选标题进行简要评估，分析其优劣，并推荐一个最能平衡学术性与信息量的暂定标题。

Prompt 11: 构建研究方法的选择与辩护论证

我需要在开题报告中为我选择的研究方法进行有力辩护。我将提供[我选择的研究方法（如：案例研究法、问卷调查法、实验法等）]和[我的核心研究问题]。请基于此，为我完成以下任务：

第一个任务是阐述方法的核心优势。你需要清晰阐述我所选方法的核心定义及其在回答特定类型问题上的主要优势。

第二个任务是构建“方法-问题”适配性论证。你需要构建一段强有力的论证，说明为何该方法是回答我核心研究问题的“最优”或“最适宜”选择。

第三个任务是回应潜在质疑。你需要预判评审专家可能会对该方法提出的1-2个典型性质疑，并提前在论述中埋入回应和解决方案。

Prompt 12: 设计详细的数据收集方案与操作流程

我需要向评委会展示，我对如何获取高质量数据已有周密计划。我将提供[我的研究方法]和[研究对象]。请基于此，为我完成以下任务：

第一个任务是方案细节具象化。你需要根据我的研究方法，设计具体的数据收集工具（如访谈提纲的核心问题、问卷的核心题项等）。

第二个任务是流程步骤化。你需要将数据收集的全过程分解为一系列可执行的步骤，从“样本招募”到“数据整理”。

第三个任务是撰写数据收集计划。你需要撰写一份详细的“数据收集计划”文本，清晰呈现所有细节，体现研究设计的专业性。

Prompt 13: 规划具体的数据分析策略与检验方法

我需要说明将如何分析收集到的数据，以回答研究问题。我将提供[我计划收集的数据类型（定量/定性）]和[我的研究假说/目标]。请基于此，为我完成以下任务：

第一个任务是选择分析技术。你需要根据我的数据类型和研究目标，建议最适合的核心数据分析技术。

第二个任务是阐述分析步骤。你需要描述一个清晰的数据分析步骤，说明将如何对原始数据进行处理，以及如何运用所选技术进行核心分析。

第三个任务是说明结果检验方法。你需要简要说明将如何确保分析结果的科学性（如稳健性检验或三角互证）。

Prompt 14: 为开题答辩准备潜在问题的模拟与回应

我希望在答辩前预判评委可能提出的尖锐问题。我将提供[我的开题报告核心内容（研究问题、方法、创新点）]。请基于此，为我完成以下任务：

第一个任务是扮演“理论”评审。你需要从理论深度角度，提出关于理论框架选择的局限性、或对核心概念理解不够深刻的质疑。

第二个任务是扮演“方法”评审。你需要从方法论严谨性角度，提出关于研究设计中的潜在漏洞、样本代表性不足的质疑。

第三个任务是扮演“创新”评审。你需要从贡献和创新性角度，提出关于“研究的实际创新程度有限”或“预期贡献是否足以达到博士水平”的质疑。

第四个任务是生成质询列表。你需要生成一个包含5-7个高质量、高难度问题的质询列表，并简要说明每个问题所针对的潜在弱点。

第五部分：开题报告文本的完善

Prompt 15: 撰写开题报告的引言部分

我需要为开题报告本身撰写一个简洁、有力的引言。我将提供[我的研究问题、研究意义和报告的章节结构]。请基于此，为我完成以下任务：

第一个任务是构建引言框架。你需要按照“研究背景与问题提出 -> 研究意义与目标阐述 -> 研究思路与框架简介 -> 开题报告结构安排”的四段式逻辑，构建引言的写作框架。

第二个任务是凝练核心信息。你需要将我提供的信息，分别精炼并填充到上述框架的各个部分。

第三个任务是生成引言初稿。你需要撰写一段约300-400字的开题报告引言，使其能够引导读者快速了解本研究的核心议题、价值所在。

Prompt 16: 为核心术语撰写操作性定义

我需要在开题报告中，对研究的核心术语进行清晰的界定。我将提供[我研究中的2-4个核心术语]。请基于此，为我完成以下任务：

第一个任务是回顾文献中的既有定义。请为每个术语，简要回顾文献中1-2个经典的或主流的定义。

第二个任务是构建本研究的操作性定义。请结合我的研究目的，为每个术语构建一个清晰、具体、可供测量的“操作性定义”。

第三个任务是论证定义的合理性。请简要论证，为何在本研究中需要采用你所构建的这个操作性定义，而非直接沿用既有定义。

Prompt 17: 总结探索性初步研究及其对正式研究的指导意义

如果我已经做了一些初步研究，我需要清晰说明其价值。我将提供[我的初步研究过程和一些探索性发现]。请基于此，为我完成以下任务：

第一个任务是提炼核心启示。你需要总结这项初步研究在验证研究方向可行性、测试研究方法有效性、或形成初步核心假说方面，提供了哪些核心启示。

第二个任务是构建“桥梁”作用。你需要论述这项初步研究是如何作为一座“桥梁”，引导我从一个宽泛的想法，走向当前这个更聚焦、更成熟的研究计划的。

第三个任务是撰写总结段落。你需要撰写一段关于“初步探索性研究”的总结性文字，将其定位为正式研究的“坚实基础”和“科学起点”。

Prompt 18: 撰写研究伦理考量与规避方案

我需要撰写一个严谨的研究伦理部分。我将提供[我的研究对象和数据收集方法]。请基于此，为我完成以下任务：

第一个任务是识别伦理风险。你需要识别本研究可能涉及的核心伦理议题，如知情同意、隐私保护、数据匿名化等。

第二个任务是设计规避方案。你需要针对每一个已识别的风险，设计具体、标准的伦理规避或应对方案。

第三个任务是撰写伦理声明。你需要撰写一段正式的“研究伦理考量”声明，清晰陈述上述内容，并承诺将严格遵守学术伦理规范。

Prompt 19: 评估研究所需的资源条件与保障措施

我需要向评委会证明，我拥有完成研究的必要支持。我将提供[我的大学、院系、实验室/导师的简要情况]。请基于此，为我完成以下任务：

第一个任务是资源需求盘点。你需要基于我的研究计划，识别出完成该研究必须的硬件资源（如图书馆资料、数据库、设备）和软件资源（如导师指导、课题组氛围）。

第二个任务是匹配现有资源。你需要将上述需求与我能获得的现有资源进行匹配，论证学校和导师已为本研究提供了充分的保障。

第三个任务是撰写“保障条件”段落。你需要撰写一段关于“研究保障条件”的文字，清晰陈述可利用的资源优势。

Prompt 20: 论证研究的潜在学术价值与社会意义

我需要在开题报告中，有力地阐述本研究的潜在价值。我将提供[我的研究问题和预期发现]。请基于此，为我完成以下任务：

第一个任务是论证学术价值。请撰写一段文字，论证本研究将如何填补现有学术文献的空白，以及它可能对相关理论发展做出的贡献。

第二个任务是论证社会意义。请撰写另一段文字，论证本研究的发现可能对理解或解决某一社会问题、或对相关政策制定产生的积极影响。

第三个任务是进行总结陈述。请将上述两方面价值，凝练为一段关于本研究总体意义的、强有力的总结性陈述。
