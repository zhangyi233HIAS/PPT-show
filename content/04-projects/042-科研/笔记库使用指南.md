# 笔记库使用指南

## 概述

本笔记库已经过整理，建立了清晰的分类目录结构和双链关系。以下是使用指南。

## 目录结构

```
042-科研/
├── 01-项目管理与进度/    # 任务管理、项目进度
├── 02-实验技术与方法/    # 实验方案、技术方法
├── 03-文献与参考/        # 文献阅读、参考文献
├── 04-鸡白痢研究/        # 鸡白痢相关研究
├── 05-生物信息学分析/    # 生信分析、服务器
├── 06-学术写作与汇报/    # 学术写作、汇报
├── 07-蛋白与分子生物学/  # 蛋白研究
├── 08-想法与设计/        # 想法、设计
├── 09-其他/              # 未分类内容
├── 研究笔记总览.md       # 总入口
├── 研究主题索引.md       # 主题索引
├── 短文件合并指南.md     # 合并指南
└── 笔记库使用指南.md     # 本文件
```

## 快速开始

### 1. 查看总览
打开 [[研究笔记总览.md]] 了解笔记库整体结构。

### 2. 浏览主题
打开 [[研究主题索引.md]] 查看研究主题和双链关系。

### 3. 查看目录
打开各目录下的 `目录索引.md` 文件，查看该目录中的所有文件。

## 主要功能

### 双链关系
- 使用 `[[文件名]]` 语法创建链接
- 使用Obsidian图谱视图查看关系网络
- 通过链接在不同笔记间跳转

### 分类浏览
- 按目录分类浏览笔记
- 使用目录索引快速定位文件
- 通过主题索引查看相关内容

### 搜索功能
- 使用Obsidian搜索功能查找内容
- 通过标签筛选相关笔记
- 使用图谱视图发现关联内容

## 常用操作

### 查找特定主题
1. 打开 [[研究主题索引.md]]
2. 找到相关主题分类
3. 点击链接查看详细内容

### 浏览实验方法
1. 打开 [[02-实验技术与方法/目录索引]]
2. 查看实验方法列表
3. 点击链接查看具体方法

### 查看研究进度
1. 打开 [[01-项目管理与进度/目录索引]]
2. 查看项目进度文件
3. 了解最新研究进展

## 维护指南

### 添加新笔记
1. 将新文件放入相应目录
2. 更新目录索引文件
3. 添加相关双链

### 整理短文件
1. 参考 [[短文件合并指南]]
2. 将相关短文件合并到主题页
3. 更新所有相关链接

### 建立双链
1. 识别相关内容
2. 使用 `[[文件名]]` 语法创建链接
3. 在主题索引中添加链接

## 最佳实践

### 1. 使用标签
为笔记添加标签，便于分类和搜索：
```yaml
---
tags:
  - 研究/鸡白痢
  - 实验/基因敲除
  - 写作/论文
---
```

### 2. 建立索引
为每个目录创建索引文件，便于浏览和管理。

### 3. 定期整理
定期检查笔记库，删除重复内容，合并短文件。

### 4. 备份数据
定期备份笔记库，防止数据丢失。

## 故障排除

### 链接失效
1. 检查文件名是否正确
2. 确认文件是否存在
3. 更新链接语法

### 内容丢失
1. 检查备份目录
2. 使用版本控制恢复
3. 从其他来源补充

### 结构混乱
1. 重新运行整理脚本
2. 参考目录结构重建
3. 手动调整分类
