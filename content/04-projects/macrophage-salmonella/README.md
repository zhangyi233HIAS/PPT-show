# 🦠 巨噬细胞-沙门氏菌互作项目

> 研究沙门氏菌（*Salmonella*）感染巨噬细胞过程中的宿主-病原体相互作用机制。

---

## 研究背景

沙门氏菌是重要的人畜共患病原体，能够侵入并存活于巨噬细胞内。理解这一互作机制对于：

1. 揭示沙门氏菌的免疫逃逸策略
2. 阐明宿主免疫应答的分子机制
3. 发现新的抗菌靶点和疫苗候选分子
4. 理解沙门氏菌的胞内存活策略

## 研究设计

### 实验体系

| 组分 | 描述 |
|------|------|
| 宿主细胞 | 巨噬细胞系（如 RAW264.7 / J774 / BMDM） |
| 病原体 | 沙门氏菌（具体血清型待记录） |
| 感染模型 | 体外感染实验 |
| 时间点 | 多时间点采样（如 0h, 2h, 4h, 8h, 24h） |

### 实验分组

```
1. 对照组（未感染巨噬细胞）
2. 感染组（沙门氏菌感染巨噬细胞）
3. [可选] 突变株感染组
4. [可选] 药物处理组
```

## 分析流程

### 步骤一：实验数据采集

```
1. 细胞培养与感染实验
2. 样本收集（RNA / 蛋白 / 上清）
3. 文库构建与测序（如适用）
4. 表型数据记录（CFU、存活率等）
```

### 步骤二：数据处理

```
1. 测序数据质控
2. 比对和定量
3. 差异表达分析
4. 功能富集分析（GO / KEGG）
```

### 步骤三：互作机制分析

```
1. 宿主免疫通路激活分析
2. 病原体毒力因子表达分析
3. 宿主-病原体互作网络构建
4. 关键调控因子鉴定
```

### 步骤四：验证与整合

```
1. 关键发现的实验验证
2. 与已有文献数据整合
3. 互作机制模型构建
4. 潜在靶点评估
```
