## 研究背景

鸽子（*Columba livia*）是重要的城市鸟类，也是多种病原体的潜在宿主和传播媒介。通过对大规模分离株进行基因组分析，可以：

1. 揭示鸽子相关病原体的种群遗传结构
2. 追踪传播路径和扩散模式
3. 识别关键的遗传变异位点
4. 为公共卫生风险评估提供依据

## 分析流程

### 步骤一：数据预处理

```
1. 原始测序数据质控 (FastQC / MultiQC)
2. 接头和低质量序列修剪 (Trimmomatic / fastp)
3. 参考基因组比对 (BWA-MEM2 / Minimap2)
4. 比对后处理 (Samtools sort + index)
5. PCR 重复标记 (Picard MarkDuplicates)
```

### 步骤二：变异检测

```
1. SNP calling (GATK HaplotypeCaller / Snippy)
2. 变异质控过滤 (GATK VQSR /硬过滤)
3. 核心基因组位点鉴定
4. cgSNP 矩阵构建
5. 变异注释 (SnpEff / VEP)
```

### 步骤三：cgSNP 分析

```
1. 核心基因组定义（所有菌株共有的基因组区域）
2. 核心区域 SNP 提取
3. cgSNP 距离矩阵计算
4. 系统发育树构建 (IQ-TREE / RAxML / FastTree)
5. 种群结构分析 (STRUCTURE / BAPS / cgMLST)
```

### 步骤四：下游分析

```
1. 系统发育可视化 (iTOL / Microreact)
2. 种群分化分析 (FST)
3. 基因组流行病学分析
4. 传播链推断
5. 抗性基因/毒力因子筛查
```
