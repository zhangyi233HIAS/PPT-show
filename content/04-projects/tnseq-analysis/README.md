## 研究背景

Tn-seq（Transposon Sequencing）是一种高通量功能基因组学方法，通过大规模转座子插入突变结合高通量测序，在全基因组水平鉴定细菌在特定条件下的必需基因和非必需基因。

### 核心概念

| 概念 | 说明 |
|------|------|
| **转座子插入** | 随机插入基因组，破坏基因功能 |
| **饱和度** | 基因组覆盖的插入密度 |
| **Fit 值** | 适应度指数，反映基因对生长的贡献 |
| **必需基因** | Fit 值显著为负 → 插入该基因导致生长缺陷 |

---

## Fit 值与 Fold Change

### 核心公式

```
Fit = log2(处理组插入丰度 / 对照组插入丰度)

当 Fit < 0（负值）时：
  → 该基因的转座子插入突变体在处理条件下丰度降低
  → 即 Fold Change (FC) 为负
  → 该基因在该条件下为必需基因
```

### 解读标准

| Fit 值范围 | 含义 | 分类 |
|------------|------|------|
| Fit > 0 | 插入突变体富集 | 非必需（可能有益） |
| Fit ≈ 0 | 无显著变化 | 非必需 |
| -2 < Fit < 0 | 轻度生长缺陷 | 条件必需 |
| Fit < -2 | 显著生长缺陷 | 强必需候选 |
| 插入数 ≈ 0 | 无有效插入 | 绝对必需 |

## 分析流程

### 步骤一：数据预处理

```
1. 原始读段质控 (FastQC / Trimmomatic)
2. 转座子接头序列识别和修剪
3. 读段比对到参考基因组 (BWA / Bowtie2)
4. 插入位点鉴定和去重
5. 插入位点统计（每个基因的插入数）
```

### 步骤二：插入饱和度评估

```
1. 统计总插入位点数
2. 计算基因组覆盖率
3. 评估每个基因的平均插入数
4. 饱和度 = 有插入的 TA 位点数 / 总 TA 位点数
5. 目标饱和度 > 90%
```

### 步骤三：Fit 值计算

```
1. 统计每个基因在对照和处理组的插入读段数
2. 标准化（RPKM / CPM / DESeq2 归一化）
3. 计算每个基因的 Fit 值
4. Fit 值 = log2(处理组丰度 / 对照组丰度)
5. 统计显著性检验
```

### 步骤四：必需基因鉴定

```
1. 设定阈值（如 Fit < -2, padj < 0.05）
2. 筛选显著负 Fit 值的基因
3. 与已知必需基因数据库比较 (DEG / OGRI)
4. 功能注释和通路富集分析
5. 生成必需基因清单
```

### 步骤五：结果验证与报告

```
1. 必需基因功能分类统计
2. 与文献已知必需基因的重叠分析
3. 新发现的条件必需基因标注
4. 关键基因的插入位点可视化 (IGV)
5. 生成最终分析报告
```
