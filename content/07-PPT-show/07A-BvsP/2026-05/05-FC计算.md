# FC 计算

**主题**：Fold Change 计算公式  
**来源**：[[TSAS软件]] 双样本分析  
**状态**：公式已确认

---

## 🎯 核心概念

**FC**（Fold Change）是处理组与对照组之间转座子插入密度的比值

**计算方式**：与初始的 LB 的 hit 进行比较

---

## 📐 计算公式

### 基本公式
```python
# 1. 插入密度计算
Density_LB = Unique_Hits_LB / Gene_Length
Density_Tissue = Unique_Hits_Tissue / Gene_Length

# 2. 文库大小校正
Library_Size_Correction = Total_Reads_LB / Total_Reads_Tissue

# 3. 校正后插入密度
Density_LB_Corrected = Density_LB
Density_Tissue_Corrected = Density_Tissue * Library_Size_Correction

# 4. FC 计算
FC = Density_Tissue_Corrected / Density_LB_Corrected
Log2FC = log2(FC)
```

### 简化公式（基因长度被约掉）
```python
Log2FC = log2((Unique_Hits_Tissue / Unique_Hits_LB) * (Total_Reads_LB / Total_Reads_Tissue))
```

**关键点**：
- 基因长度在比值中被约掉
- FC 反映插入频率变化
- 使用 [[TSAS软件]] 双样本分析（-a 2）

## ⚠️ FC 的意义

### ✅ 可以做的
1. **效应量评估**：Log2FC < -2 表示大幅下调（插入密度减少 4 倍以上）
2. **候选基因排序**：在 [[FWER]] 显著的基因中，按 FC 排序
3. **功能富集分析**：使用 FC 进行 GSEA 分析
4. **描述性分析**：n=1 设计下，FC 可用于描述性比较

### ❌ 不能做的
1. **统计显著性检验**：n=1 设计下，FC 无统计意义
2. **定量比较**：不能精确比较条件间差异
3. **机制推断**：需要实验验证
