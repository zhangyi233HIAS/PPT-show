## 🎯 核心概念

**FWER**（Family-Wise Error Rate）是多重检验中至少出现一个假阳性的概率

**关键**：n=1 设计下，[[FWER]] ✅ 有意义

---

## 📐 计算公式

### FWER 计算
```python
# Bonferroni 校正
FWER = min(1, m × p)

其中：
- m = 检验次数（基因总数）
- p = 原始 p 值
```

### 单样本分析的 p 值计算（基于 [[TSAS软件]]）
```python
# 二项分布检验
from scipy import stats

# 对每个基因
pvalue = stats.binom.sf(observed_hits, available_sites, genome_wide_rate)
essentiality_pvalue = 1 - pvalue

# Bonferroni 校正（FWER）
fwer = min(1, m * essentiality_pvalue)  # m = 基因总数
```

**关键点**：
- 使用 [[二项分布检验]]
- 不需要生物学重复
- 判断插入是否显著低于预期

## ⚠️ 为什么 FWER 有意义？

### 与 [[p值]]、[[FDR]] 的区别
| 统计指标 | 数据来源 | 统计方法 | n=1 时意义 |
|----------|----------|----------|------------|
| [[p值]]（Fisher） | 处理组 vs 对照组 | Fisher 检验 | ❌ 无意义 |
| [[FDR]] | 基于 p 值 | BH 校正 | ❌ 无意义 |
| [[FWER]]（单样本） | 基因内插入分布 | [[二项分布检验]] | ✅ 有意义 |

### 关键区别
- **双样本分析**（-a 2）：比较两组样本，需要生物学重复
- **单样本分析**（-a 1）：判断基因内插入是否异常，不需要生物学重复

## 🔗 案例分析

### JI728_23810（Hit=0 但 FWER=1.0）
**基因长度**：78 bp  
**Unique hits**：0  
**FWER**：1.0  
**问题**：TA 位点过少，统计显著性不足

**TSAS 计算过程**：
```python
available_sites = 3  # 估计 TA 位点数
observed_hits = 0    # 无插入
genome_wide_rate = 0.092  # 全基因组平均插入密度

pvalue = stats.binom.sf(observed_hits, available_sites, genome_wide_rate)
# pvalue = (1-0.092)^3 ≈ 0.747

essentiality_pvalue = 1 - pvalue  # ≈ 0.253
fwer = min(1, 4336 * essentiality_pvalue)  # = 1 (不显著)
```

**结论**：基因长度过短，TA 位点数不足，导致统计显著性不足
