# 低质量基因

**主题**：短基因和 TA 密度问题  
**来源**：[[数据质量评级]]  
**状态**：已识别

---

## 🎯 核心问题

**问题**：为什么有些基因质量低？

**答案**：TA 密度过低，统计显著性不足

---

## 📊 低质量基因统计

### 基因长度与质量（基于 [[result-K1]]）
| 基因长度组 | 总基因数 | FWER≤0.01 | 必需基因比例 | 质量评估 |
|------------|----------|-----------|--------------|----------|
| **<200bp** | **166** | **4** | **2.4%** | **⚠️ 低质量** |
| 200-500bp | 1019 | 83 | 8.1% | ⚠️ 中等质量 |
| 500-1000bp | 1646 | 187 | 11.4% | ✅ 良好 |
| 1000-2000bp | 1272 | 197 | 15.5% | ✅ 良好 |
| 2000-5000bp | 229 | 52 | 22.7% | ✅ 良好 |

**关键发现**：
- 短基因（<200bp）必需基因比例最低（2.4%）
- 4/8 的 Hit=0 基因集中在短基因组
- 短基因统计效力不足

| 指标 | 值 | 比例 | 说明 |
|------|-----|------|------|

## 📐 TA 密度分析

### TA 密度定义
```python
# TA 密度 = 基因内 TA 位点数 / 基因长度
TA_density = TA_sites / Gene_length

# 近似计算（基于 [[result-K1]]）
TA_density_approx = Unique_hits / Gene_length
```

### 低 TA 密度阈值
**阈值**：TA密度 < 0.001 hits/bp  
**影响**：统计显著性不足  
**建议**：排除或标记此类基因

---

## ⚠️ 案例分析

### JI728_23810（Hit=0 但 FWER=1.0）
| 指标 | 值 | 问题 |
|------|-----|------|
| 基因长度 | 78 bp | 极短 |
| Unique hits | 0 | 无插入 |
| FWER | 1.0 | 不显著 |
| TA 密度 | 极低 | 统计效力不足 |

**TSAS 计算过程**：
```python
available_sites = 3  # 估计 TA 位点数
observed_hits = 0    # 无插入
genome_wide_rate = 0.092  # 全基因组平均插入密度

pvalue = stats.binom.sf(observed_hits, available_sites, genome_wide_rate)
# pvalue = (1-0.092)^3 ≈ 0.747

essentiality_pvalue = 1 - pvalue  # ≈ 0.253
fwer = min(1, 4336 * essentiality_pvalue)  # = 1 (不显著)
```

**结论**：基因长度过短，TA 位点数不足，导致统计显著性不足

---

## 🔗 解决方案

### 筛选策略
1. **排除短基因**：将 <200bp 基因从必需基因列表中排除
2. **标记短基因**：在结果中标记短基因，谨慎解释
3. **单独分析**：对短基因进行单独分析，使用更宽松的阈值

### 质量控制
| 步骤 | 标准 | 阈值 | 说明 |
|------|------|------|------|
| 步骤 1 | 基因长度 | ≥ 200bp | 排除短基因 |
| 步骤 2 | TA 密度 | ≥ 5 | 排除低质量基因 |
| 步骤 3 | [[FWER]] | ≤ 0.01 | 主要标准 |
