## 📐 推荐筛选流程

### 4 步筛选法
| 步骤 | 标准 | 阈值 | 意义 | 说明 |
|------|------|------|------|------|
| **步骤 1** | [[FWER]] | ≤ 0.01 | ✅ 有意义 | 主要标准 |
| **步骤 2** | Hit | = 0 | ✅ 有意义 | 必需基因 |
| **步骤 3** | [[TA密度]] | ≥ 5 | ✅ 有意义 | 质量控制 |
| **步骤 4** | 基因长度 | ≥ 200bp | ✅ 有意义 | 排除 [[低质量基因]] |
| **步骤 5** | [[FC]] | < -2 | ⚠️ 描述性 | 辅助排序 |

### 筛选代码示例
```python
# 最终筛选（基于 [[result-K1]] 和 [[实验组报告]]）
final_genes = df[
    (df['FWER (Essential)'] <= 0.01) &  # 步骤 1：FWER ≤ 0.01
    (df['TA_density'] >= 5) &           # 步骤 3：TA密度 ≥ 5
    (df['Gene length (bp)'] >= 200)     # 步骤 4：基因长度 ≥ 200bp
]

print(f"最终必需基因数: {len(final_genes)}")
# 预期：约 400-500 个
```

## ⚠️ FWER 优先的理由

### 1. 统计严谨性
- [[FWER]] 使用 Bonferroni 校正，严格控制假阳性
- [[FC]] 没有统计显著性，n=1 时不可靠

### 2. 文献标准
- 高质量期刊要求统计显著性
- [[FWER]] ≤ 0.01 是公认的必需基因鉴定标准

### 3. 可重复性
- [[FWER]] 基于统计检验，可重复
- [[FC]] 受技术变异影响，不可重复

### 4. 假阳性控制
- FDR = 0.269（26.9%假阳性）
- 使用 [[FWER]] 可降低假阳性率

详见：[[统计意义]]

## 📊 FC 的作用

虽然 [[FWER]] 优先，但 [[FC]] 仍有重要作用：

### 1. 效应量评估
- Log2FC < -2 表示大幅下调（插入密度减少 4 倍以上）
- 用于评估生物学变化幅度

### 2. 候选基因排序
- 在 [[FWER]] 显著的基因中，按 [[FC]] 排序
- FC 越负，基因越可能是必需基因

### 3. 功能富集分析
- 使用 [[FC]] 进行 GSEA 分析
- 鉴定显著富集的通路

### 4. 描述性分析
- n=1 设计下，[[FC]] 可用于描述性比较
- 避免统计显著性声明
