## 🎯 核心概念

**[[FC]] 的作用**：在 [[FWER]] 显著的基因中，按效应量排序

**关键**：FC 仅用于描述性分析，不用于统计推断

---

## 📊 FC 的使用场景

### 1. 效应量评估
**定义**：Log2FC 反映生物学变化幅度  
**阈值**：
- Log2FC < -2：大幅下调（插入密度减少 4 倍以上）
- Log2FC > 2：大幅上调

**数据**（基于 [[result-B6]]）：

| 指标 | 值 | 说明 |
|------|-----|------|
| Log2FC 范围 | -7.96 到 5.83 | 全范围 |
| Log2FC 均值 | -0.54 | 整体偏向下调 |
| Log2FC < -2 的基因数 | 508 | 大幅下调基因 |
| Log2FC > 2 的基因数 | 11 | 大幅上调基因 |

### 2. 候选基因排序
**方法**：在 [[FWER]] 显著的基因中，按 [[FC]] 排序  
**代码**：
```python
# 在 FWER 显著的基因中，按 FC 排序
essential_genes_sorted = essential_genes.merge(
    df_cond[['Gene ID', 'Log-fold Change (Insertions)']],
    on='Gene ID',
    how='left'
).sort_values('Log-fold Change (Insertions)')

print("FWER 显著的必需基因（按 FC 排序）:")
print(essential_genes_sorted[['Gene ID', 'FWER (Essential)', 'Log-fold Change (Insertions)']].head(20))
```

### 3. 功能富集分析
**方法**：使用 [[FC]] 进行 GSEA 分析  
**输入**：基因列表（按 FC 排序）  
**输出**：显著富集的通路

### 4. 描述性分析
**方法**：n=1 设计下，[[FC]] 可用于描述性比较  
**限制**：避免统计显著性声明

---

## ⚠️ FC 的限制

### ❌ 不能做的
1. **统计显著性检验**：n=1 设计下，FC 无统计意义
2. **定量比较**：不能精确比较条件间差异
3. **机制推断**：需要实验验证

### ✅ 可以做的
1. **效应量评估**：评估生物学变化幅度
2. **候选基因排序**：在 FWER 显著的基因中排序
3. **功能富集分析**：GSEA 分析
4. **描述性分析**：描述性比较

详见：[[统计意义]]

## 📊 排序示例

### 条件特异性必需基因筛选
```python
# 筛选条件特异性必需基因
# 在组织中必需（FWER ≤ 0.01），但在 LB 中非必需
tissue_essential = df_tissue[df_tissue['FWER (Essential)'] <= 0.01]
lb_non_essential = df_lb[df_lb['FWER (Essential)'] > 0.01]

condition_specific = tissue_essential[
    tissue_essential['Gene ID'].isin(lb_non_essential['Gene ID'])
]

print(f"条件特异性必需基因数: {len(condition_specific)}")
```
