## 📝 关键表述对照

### ❌ 避免的表述
- "显著差异" → 使用 "鉴定为必需"
- "P < 0.05" → 使用 "[[FWER]] ≤ 0.01"
- "统计比较" → 使用 "集合比较"
- "验证靶点" → 使用 "候选基因"

### ✅ 推荐的表述
- "鉴定为必需"（而非 "显著差异"）
- "[[FWER]] ≤ 0.01"（而非 "P < 0.05"）
- "集合比较"（而非 "统计比较"）
- "候选基因"（而非 "验证靶点"）
