这个问题其实涉及到**统计学筛选逻辑**和**文献惯例**，两者不完全一样。

你说的三种方案本质上是：

|方法|做法|保留方向信息？|常见场景|
|---|---|---|---|
|方法 A|正负分开，各取前 20%|✅|生物学解释|
|方法 B|整体排序，取最高 20%和最低 20%|✅|差异分析|
|方法 C|按绝对值排序（abs）取前 20%|❌|特征筛选、机器学习|

---

# 方法 A：正负分开筛

例如：

```
-100-50-20-513102050100
```

负数单独排：

```
-100-50-20-5
```

正数单独排：

```
13102050100
```

然后：

- 最强负值一组
- 最强正值一组

分别选。

---

这种方法的优点：

正负不会互相干扰。

例如：

```
-30-25-20...100200300
```

即使有 300 这种超级大正值，

```
-30
```

仍然能被识别为最强负值。

---

很多：

- 相关系数
- Spearman 相关
- 微生物共现网络

喜欢这么干。

因为：

```
正相关负相关
```

生物学意义不同。

---

# 方法 B：整体排序取前后 20%

直接排序：

```
最小 ←——————→ 最大
```

取：

```
底部20%顶部20%
```

例如：

```
-100-50-20-513102050100
```

取：

```
-100-5050100
```

---

这是很多差异分析论文最常见的思路。

例如：

- DEG
- 差异代谢物
- 差异菌

经常写：

> Top 10% highest
> 
> Bottom 10% lowest

或者：

> Upper quartile
> 
> Lower quartile

---

# 方法 C：按绝对值排序

先变：

```
1005020513102050100
```

排序：

```
1001005050...
```

取最大的 20%。

得到：

```
-100100-5050
```

---

很多机器学习论文喜欢这样。

例如：

- Feature Importance
- SHAP
- Network Hub

他们关心：

```
影响大不大
```

而不是：

```
方向是什么
```

Tnseq 呢 基因的必需性 是否重要 正负筛是不是好一点

如果是 **Tn-seq（Transposon sequencing）基因必需性分析**，情况和相关系数、代谢物丰度其实不太一样。

关键先看你的数值代表什么。

---

## 情况 1：数值是 Log 2 FC

例如：

```
geneA   -4.2geneB   -3.5geneC    0.1geneD    2.3geneE    5.1
```

通常：

```
负值 → 插入减少     → 突变体消失     → 基因更可能是必需基因正值 → 插入增加     → 突变体富集     → 基因缺失反而有优势
```

这时：

### 正负绝对不是一回事

因为：

```
-5
```

和

```
+5
```

生物学含义完全相反。

所以文献里通常会：

- Essential / depleted genes
- Enriched genes

分开分析。

这种更接近你现在代码的逻辑。

---

## 情况 2：数值是 Essentiality Score

有些软件会输出：

- ESS score
- Gene fitness
- HMM state
- Hidden Markov score

例如：

```
-10-8-5024
```

负值越大：

```
越必需
```

正值越大：

```
越非必需
```

这时如果用绝对值筛：

```
|-10| = 10|+10| = 10
```

统计上成立。

但生物学上会把：

```
极度必需
```

和

```
极度有利
```

混成一类。

很多审稿人不喜欢。

---

# TnSeq 文献实际上怎么做？

大多数主流工具：

- TRANSIT
- Tn-Seq Explorer
- ESSENTIALS

通常不是按前 20%筛。

而是：

### 1. 统计显著性

例如：

```
log2FC < -1FDR < 0.05
```

---

### 2. 插入密度

例如：

```
Insertion Index
```

---

### 3. 贝叶斯/HMM 分类

直接分：

```
EssentialGrowth DefectNeutralGrowth Advantage
```

四类。

# 如果你一定要做 0/1 矩阵

比如为了：

- 聚类
- 热图
- 网络分析

我会推荐：

## 方案 A（最符合必需性）

```
负向前20% = 1其余 = 0
```

即：

```
最缺失最耗损最可能必需
```

编码为 1。

这其实和你当前代码完全一致。

---

## 方案 B

```
负向前20% = -1正向前20% = +1其余 = 0
```

形成：

```
-1 0 +1
```

三状态矩阵。

很多系统生物学分析更喜欢这种。

因为不会丢失方向信息。

# 如果我是做病原菌 TnSeq

例如：

- Acinetobacter baumannii
- Klebsiella pneumoniae
- Pseudomonas aeruginosa

想找：

```
宿主体内必需基因
```

我几乎肯定会选：

```
负向单独筛
```

而不会：

```
正负混一起筛
```

因为在 TnSeq 里：

> “强烈耗损（depletion）”和“强烈富集（enrichment）”是两种完全不同的生物学现象。

所以对于**基因必需性（essentiality）**这个问题，正负分开分析通常比整体排序更符合主流文献思路，也更容易向审稿人解释。

会不会有一种情况，就说基准不是 0，在这个条件整体都是负值会更多一点，这样正负筛可以吗

会，而且在 **TnSeq 里这种情况并不少见**。

你实际上问到了一个很重要的问题：

> 如果整个实验条件导致所有基因整体往负方向偏移，那么以 0 为中心分正负，会不会出问题？

答案是：

**会有风险。**

## 举个极端例子

假设对照组 vs 感染组。

理论上：

```
0 = 没变化
```

但由于实验条件特别严苛：

- 宿主环境
- 抗生素压力
- 营养缺乏

导致绝大部分突变体都变差。

结果：

```
-4-3-2-2-1.5-1-1-0.5-0.30.2
```

这时候数据分布长这样：

```
           0-----------|******************************
```

大量基因都在负侧。

---

## 这时候直接按正负筛

例如：

```
负值单独取前20%
```

得到：

```
-4-3
```

其实没错。

你找到的是：

> 最严重耗损基因

---

但问题在于：

```
-1.5
```

可能已经是非常明显的生物学效应。

只是因为：

```
-4-3
```

太极端，

所以被排除掉了。

## TnSeq 文献为什么喜欢统计模型

原因就在这里。

很多软件实际上会先做：

### 中心化（Normalization）

例如：

```

```

或者：

```
log2FC - median(log2FC)
```

把整体偏移拉回去。

---

原始：

```

```

中位数：

```
-2
```

校正后：

```
-2-100112
```

此时：

```
0
```

才真正代表：

> 普通基因

一个简单判断方法：

如果你画出所有基因的 fitness 或 log 2 FC 直方图：

- 峰值在 0 附近 → 正负分开没问题
- 峰值明显偏到负侧 → 应考虑重新中心化，或者直接按整体分位数筛选

这也是很多 TnSeq 研究在判定 essential / conditionally essential genes 时采用的思路。
