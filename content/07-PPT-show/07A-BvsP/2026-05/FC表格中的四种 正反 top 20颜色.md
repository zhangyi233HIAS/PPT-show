把它想象成一个老师在给 **44 列（你的是 10 列也完全一样）考试成绩** 自动打标签。

它做了两件事：

1. 给 Excel 里的数字自动染色（红色和蓝色）
2. 生成一个新的 0/1 矩阵表（类似判断题答案）

---

# 一、假设你的 10 列数据长这样

| 学生 | 指标 1 | 指标 2  | 指标 3 |
| -- | --- | ---- | --- |
| A  | 5   | -30  | 8   |
| B  | 10  | -5   | 1   |
| C  | -40 | 3    | -50 |
| D  | 20  | -100 | 4   |

程序会一列一列处理。

比如先看：

**指标 2**

```
-30
-5
3
-100
```

---

# 二、程序先把正数和负数分开

像老师分类一样：

正数：

```
3
```

负数：

```
-30
-5
-100
```

但负数会变成绝对值：

```
30
5
100
```

因为程序只关心：

> “负得有多厉害”

不关心负号本身。

---

# 三、什么叫前 10%、前 20%

假设一列有 100 个负数。

从小到大排列：

```
1
2
3
...
100
```

那么：

前 10%

```
91~100
```

前 20%

```
81~100
```

程序计算两个分界线：

### p 80

80 百分位

表示：

> 超过它就是前 20%

---

### p 90

90 百分位

表示：

> 超过它就是前 10%

---

# 四、颜色是什么意思

## 正数

### 浅红

前 20%但不是前 10%

例如：

```
80~90分
```

染浅红。

---

### 深红

前 10%

例如：

```
90分以上
```

染深红。

---

## 负数

注意：

这里比较的是绝对值。

例如：

```
-10
-20
-100
```

程序认为：

```
10
20
100
```

其中 100 最大。

---

### 浅蓝

负数里排名 10%-20%

例如：

```
-50
-60
```

---

### 深蓝

负数里最极端的前 10%

例如：

```
-100
-120
```

---

# 五、生成的新矩阵是什么

这是代码最重要的部分。

```vb
mark = 0
```

先默认全是 0。

---

然后判断：

```vb
If v < 0 And Abs(v) >= p80_neg Then
    mark = 1
End If
```

意思是：

如果这个数字：

* 是负数
* 并且进入负数前 20%

那么：

```vb
mark = 1
```

否则：

```vb
mark = 0
```

# 六、举个完整例子

原数据：

| 样本 | 指标 1  |
| -- | ---- |
| A  | -2   |
| B  | -5   |
| C  | -10  |
| D  | -20  |
| E  | -100 |

排序后：

```
2
5
10
20
100
```

假设：

```
p80 = 20
```

那么：

| 值    | 是否前 20% |
| ---- | ------ |
| -2   | 否      |
| -5   | 否      |
| -10  | 否      |
| -20  | 是      |
| -100 | 是      |

输出矩阵：

| 样本 | 指标 1 |
| -- | --- |
| A  | 0   |
| B  | 0   |
| C  | 0   |
| D  | 1   |
| E  | 1   |

# 七、如果你有 10 列数据

代码会这样干：

```text
第1列 → 算一次 → 输出0/1
第2列 → 算一次 → 输出0/1
第3列 → 算一次 → 输出0/1
...
第10列 → 算一次 → 输出0/1
```

最后得到一个新的 10 列矩阵：

| 样本 | 指标 1 | 指标 2 | 指标 3 | ... |
| -- | --- | --- | --- | --- |
| A  | 0   | 1   | 0   | ... |
| B  | 1   | 0   | 0   | ... |
| C  | 0   | 1   | 1   | ... |

---

# 用一句初中生能懂的话总结

这个程序就是：

> **每一列单独比赛，把“负得最厉害的前 20%数据”挑出来标记为 1，其余标记为 0；同时把这些极端值在原表里用蓝色显示出来。正数最大的部分则用红色显示。**

如果你做的是微生物、基因、代谢物这类科研数据，那么这个矩阵本质上是在找：

> **每个指标里“显著偏低（负向异常）”的样本，并把它们统一编码成 1。**
