把它想象成一个老师在给 **44 列（你的是 10 列也完全一样）考试成绩** 自动打标签。

它做了两件事：

1. 给 Excel 里的数字自动染色（红色和蓝色）
2. 生成一个新的 0/1 矩阵表（类似判断题答案）

# 三、什么叫前 10%、前 20%

假设一列有 100 个负数。

从小到大排列：

```
1
2
3
...
100
```

那么：

前 10%

```
91~100
```

前 20%

```
81~100
```

程序计算两个分界线：

### p 80

80 百分位

表示：

> 超过它就是前 20%

---

### p 90

90 百分位

表示：

> 超过它就是前 10%

## 正数

### 浅红

前 20%但不是前 10%

```

```

染浅红。

---

### 深红

前 10%

例如：

```
90分以上
```

染深红。

---

## 负数

注意：

这里比较的是绝对值。

例如：

```

-20
-100
```

程序认为：

```

```

其中 100 最大。

---

### 浅蓝

负数里排名 10%-20%

例如：

```

```

---

### 深蓝

负数里最极端的前 10%

例如：

```

```

# 五、生成的新矩阵是什么

这是代码最重要的部分。

```vb
mark = 0
```

先默认全是 0。

---

然后判断：

```vb
If v < 0 And Abs(v) >= p80_neg Then
    mark = 1
End If
```

意思是：

如果这个数字：

* 是负数
* 并且进入负数前 20%

那么：

```vb
mark = 1
```

否则：

```vb
mark = 0
```

# 用一句初中生能懂的话总结

这个程序就是：

> **每一列单独比赛，把“负得最厉害的前 20%数据”挑出来标记为 1，其余标记为 0；同时把这些极端值在原表里用蓝色显示出来。正数最大的部分则用红色显示。**

如果你做的是微生物、基因、代谢物这类科研数据，那么这个矩阵本质上是在找：

> **每个指标里“显著偏低（负向异常）”的样本，并把它们统一编码成 1。**



对于你这种代码的用途（筛选负向极端值），**不分正负一起筛，偏倚通常会更大，而且可能直接改变生物学含义。**

举个简单例子。

会被识别为最极端负值。

# 数学上叫什么？

这是：

z_i=\frac{x_i-\mu}{\sigma}

背后的问题属于：

**混合分布（mixed distribution）**

你的数据实际上包含两种生物学过程：

```text
正向关联
负向关联
```

如果混在一起计算：

```text
正向极端值
```

会影响：

```text
负向阈值
```

反之亦然。

# 在科研里怎么选？

### 如果你的目标是

找：

```text
显著负相关
显著下调
显著减少
显著缺失
```

例如：

- 微生物丰度下降
    
- 基因表达下调
    
- 代谢物减少
    

那么：

✅ 正负分开筛更合理。

---

### 如果你的目标是

找：

```text
变化幅度最大
```

不关心方向。

例如：

- Fold Change 绝对值
    
- 效应量绝对值
    
- 相关系数绝对值
    

那么：

直接用

```text
abs(x)
```

排序更合理。

即：

```text
-0.9
```

和

```text
+0.9
```

都算极端。

---

对于你之前提到的 **SNP、微生物、代谢物、网络节点、丰度矩阵** 这类分析，我会倾向于：

- 如果后续矩阵里的 **1 表示“负向异常”** → 保持现在这种正负分开。
    
- 如果后续要做 **聚类、机器学习特征筛选、网络中心性筛选** → 往往用 `abs(value)` 统一筛选更常见。
    

所以偏倚不是简单“大还是小”，而是：

> **不分正负会降低方向性偏倚，但会增加强正值对强负值的掩盖效应；分开筛会保留生物学方向信息。**

对于你这段代码的设计目的（输出负向异常矩阵），分开筛是更合理的做法。
