## 🔗 核心概念双链

### 统计指标
- [[FWER]] - 家族 wise 错误率（✅ 有意义）
- [[FC]] - 倍数变化（⚠️ 仅描述性）
- [[p值]] - 统计检验概率（❌ n=1 时无意义）
- [[FDR]] - 假发现率（❌ n=1 时无意义）

### 关键概念
- [[n=1设计]] - 单重复实验设计的局限性
- [[二项分布检验]] - 单样本分析的统计方法
- [[TA密度]] - 基因内 TA 位点密度
- [[Hit=0]] - 无转座子插入的基因
