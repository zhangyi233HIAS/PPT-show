## 二、分析方法说明

### 2.1 使用的软件与参数

**软件**：TSAS 2.0（Tn-seq Analysis Software）  
**来源**：https://github.com/srimam/TSAS  
**性质**：开源软件，可公开获取

**关键参数**：
| 参数 | 设置 | 说明 |
|------|------|------|
| `-a 1` | 单样本分析 | 计算每个样本的必需性 |
| `-seq TA` | 校正 TA 位点 | Mariner 转座子偏好性校正 |
| `-cl 10` | 裁剪 10% | 排除基因两端极性效应 |
| `-mh 1` | 最小插入阈值 | 1 个插入位点 |
| `-cap 1` | Capping 选项 | 平均值 + 2 标准差 |
| `-w 1` | 加权 | 平衡 PCR 偏倚 |

### 2.2 核心指标解释

| 指标                   | 定义                         | 在本研究中的意义              |
| -------------------- | -------------------------- | --------------------- |
| **FC (Fold Change)** | 插入密度比值的 log2 值             | 表示处理组 vs 对照组的插入频率变化   |
| **FWER**             | 家族 wise 错误率（Bonferroni 校正） | FWER ≤ 0.01 定义为必需基因   |
| **Hit**              | 独特插入位点数                    | Hit = 0 表示基因无法被打断（必需） |
| **P 值**              | 统计检验概率                     | **n=1 时组间比较的 p 值无意义** |

### 2.3 FC 计算公式

```
Density = (Unique Hits / Gene Length) × Library Size Correction
Log2FC = log2(Density_Treatment / Density_Control)
```

**特点**：

- 使用插入位点数而非 reads 数（更稳健）
- 校正基因长度和 TA 位点偏好性
- 不受 PCR 扩增偏倚影响

## 三、数据可用性评估

### 3.1 可以做的（高置信度）

| 分析类型       | 方法          | 发表接受度 |
| ---------- | ----------- | ----- |
| **必需基因鉴定** | FWER ≤ 0.01 | ✅ 高   |
| **功能富集分析** | GO/KEGG     | ✅ 高   |
| **核心必需基因** | 所有条件都必需     | ✅ 高   |
| **描述性比较**  | 韦恩图/集合分析    | ✅ 高   |

### 3.2 不能做的（低置信度）

| 分析类型        | 原因          | 替代方案    |
| ----------- | ----------- | ------- |
| **统计显著性检验** | n=1，无法估算方差  | 使用描述性语言 |
| **定量比较**    | 无法区分真实差异与噪音 | 使用集合比较  |
| **机制推断**    | 需要实验验证      | 提出验证计划  |

### 3.3 数据价值评估

**结论**：**数据仍然有价值，可以发表**

**理由**：

1. ✅ 单样本必需性分析统计上严谨（二项分布检验）
2. ✅ 文献中有 n=1 设计发表的先例（*Genome Research*, *PNAS*, *Nature Methods*）
3. ✅ 使用集合比较方法可以避免 p 值问题
4. ✅ 为后续实验验证提供候选基因

## 五、回应导师的标准答案

### 5.1 关于 FC 计算

> 我们使用 TSAS 2.0 计算 FC，基于插入密度比值（Unique Hits / Gene Length），校正了 TA 位点偏好性。使用插入位点数而非 reads 数，因为更稳健，不受 PCR 偏倚影响。

### 5.2 关于 P 值

> 公司说得对，**组间比较的 p 值确实没有统计学意义**，因为 n=1 无法估算组内方差。但**单样本分析的 FWER 是有意义的**，因为它使用二项分布检验，不需要生物学重复。

### 5.3 关于重复

> 我们的设计是将3个生物学重复混合测序。**数据仍然有价值**，但需要改变策略：使用单样本分析定义必需基因，通过集合比较鉴定条件特异性基因。

### 5.4 关于 TSAS 参数

> 我们使用了 `-seq TA`、`-cl 10`、`-cap 1`、`-w 1` 等参数，根据文献推荐选择，不是全部默认。

### 5.5 关于可重复性

> **可以复现**。TSAS 是开源软件，所有参数有记录。我们已向公司索要运行日志，并计划重新分析验证。
