### 1.2 FC 计算公式

**FC（Fold Change）是与初始的 LB 的 hit 进行比较算出的**：

```python
# FC 计算公式
# 基于 TSAS 双样本分析 (-a 2)

# 1. 插入密度计算
Density_LB = Unique_Hits_LB / Gene_Length
Density_Tissue = Unique_Hits_Tissue / Gene_Length

# 2. 文库大小校正
Library_Size_Correction = Total_Reads_LB / Total_Reads_Tissue

# 3. 校正后插入密度
Density_LB_Corrected = Density_LB
Density_Tissue_Corrected = Density_Tissue * Library_Size_Correction

# 4. FC 计算
FC = Density_Tissue_Corrected / Density_LB_Corrected
Log2FC = log2(FC)

# 简化公式（基因长度在比值中被约掉）：
Log2FC = log2((Unique_Hits_Tissue / Unique_Hits_LB) * (Total_Reads_LB / Total_Reads_Tissue))
```

**关键点**：

- FC 是组织样本与 LB 对照组的比较
- 使用插入密度（Unique Hits / Gene Length）而非直接使用 reads 数
- 进行文库大小校正（Library Size Correction）
- 基因长度在比值中被约掉，FC 反映插入频率变化

### 2.2 质量问题分析

#### 2.2.1 低质量必需基因（67个，28.9%）

**问题定义**：

- TA密度 < 5 的必需基因
- 统计显著性基于不可靠数据

**根本原因**：

1. **基因长度短**：短基因TA位点数少
2. **测序深度不足**：未能覆盖所有TA位点
3. **转座子插入偏好性**：某些区域插入效率低

**影响**：

- 28.9% 的必需基因可能不可靠
- 需要谨慎解释或排除

#### 2.2.2 零插入基因（1,651个，18.1%）

**问题定义**：

- 完全无转座子插入的基因
- 可能是必需基因，也可能是技术问题

**可能原因**：

1. **真正的必需基因**：无法被转座子打断
2. **技术假象**：
   - 基因长度短，TA位点数少
   - 测序深度不足
   - 转座子插入偏好性

**统计分析**：

```python
# 零插入基因分析
total_genes = 9113
zero_insertion_genes = 1651
zero_insertion_rate = zero_insertion_genes / total_genes * 100  # 18.1%

# 预期零插入基因数（假设随机插入）
# 如果每个TA位点插入概率为p，基因内有n个TA位点
# P(无插入) = (1-p)^n
# 对于平均基因（长度~900bp，TA密度~0.05/bp），n≈45
# 如果p=0.01，P(无插入) = (1-0.01)^45 ≈ 0.637（63.7%）
# 实际观察到18.1%，说明插入效率较高
```

**结论**：

- 18.1% 的零插入基因高于预期的技术噪音水平
- 可能包含真正的必需基因，但也可能有技术假象

#### 2.2.3 FDR 过高（0.269）

**问题定义**：

- 假发现率（False Discovery Rate）= 26.9%
- 意味着约27%的"必需基因"可能是假阳性

**根本原因**：

1. **n=1 设计**：无法估算组内方差
2. **多重检验**：9113个基因同时检验
3. **数据变异性大**：IQR=0.411

**影响**：

- 统计可靠性不足
- 不适合高质量发表

#### 2.2.4 IQR 过大（0.411）

**问题定义**：

- 四分位距（Interquartile Range）= 0.411
- 表明数据变异性和不确定性较大

**根本原因**：

1. **样本量不足**：n=1，无法估算组内变异
2. **技术变异**：PCR偏倚、测序错误
3. **生物学变异**：不同组织间差异大

**影响**：

- 置信区间过宽
- 统计检验效力不足

   - 转座子插入偏好性

   - 多重检验校正可能过于严格
