### 场景适配建议

* **处理生物信息学脚本与自动化环境：** **Claude Code** 是最直接的利器。如果你在跑 R 或 Python 脚本时遇到环境依赖报错、矩阵维度不匹配等问题，在终端里直接唤醒它，它能自主读取当前的报错日志、修改脚本并重新运行，省去了在 IDE 和终端之间来回复制粘贴的麻烦。
* **重度知识管理与实验记录管理：** **Obsidian + Claudian + Hermes** 是终极方案。这个架构能够完美契合你需要使用 Git 长期同步 `Lab-Notes` 的习惯。通过接入大模型，它能在你庞大的 Markdown 笔记库中实现智能检索和跨文献融合，确保你的实验思路和数据拥有 100% 的本地主权。
* **日常数据清洗与跨软件协同：** 如果需要将本地生成的报告快速同步给同门，或者整合零散的桌面文件，**WorkBuddy** 这种级别的 Agent 能直接越过浏览器，在本地系统和协作软件（如飞书、企业微信）之间自动搬运和处理数据。
* **主力沉浸式代码开发：** 当你需要从零构建一个复杂的数据可视化面板（比如用 ggplot 2 画复杂的 3D 图或热图）时，**Cursor** 的 `@Codebase` 能力和优秀的补全体验依然是目前最高效的开发基座。
