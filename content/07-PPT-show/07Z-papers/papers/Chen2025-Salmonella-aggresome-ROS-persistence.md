# Chen2025 — Macrophage-derived ROS promotes Salmonella aggresome formation & antibiotic persistence

> **Paper**: Chen et al. (2025) "Macrophage‐derived reactive oxygen species promote Salmonella aggresome formation contributing to bacterial antibiotic persistence"  
> **Journal**: iMeta  
> **DOI**: 10.1002/imt2.70059  
> **Type**: Correspondence (实验简报)

---

## 一、相关背景

### 1.1 细菌持留菌 (Bacterial Persisters)

细菌持留菌是一群**表型变异亚群**，能在抗生素攻击下存活，并在之后复苏增殖，成为**复发感染的储库**。

- 持留不同于耐药：持留菌不携带耐药基因突变，而是通过**表型休眠**暂时逃避杀灭。
- 持留菌是慢性/复发性感染的重要原因。

### 1.2 细菌休眠理论 (Dormancy Theory)

细菌休眠被认为是解释持留菌形成的**主流理论**：

| 机制 | 关键分子 | 效应 |
|------|---------|------|
| TCA 循环失活 | ROS | 呼吸降低、ATP 生成减少 |
| ATP 渗漏 | Type I 毒素 TisB / HokB | 细胞休眠 |
| 翻译抑制 | Type II 毒素 HipA → 磷酸化 EF-Tu | 细胞休眠 |

### 1.3 巨噬细胞诱导持留菌的争议

病原菌进入宿主后面对多重应激：酸性 pH、营养限制、ROS、活性氮等。

- **先前研究**：巨噬细胞吞噬后，空泡酸化和 (p)ppGpp 合成诱导多种 Type II 毒素-抗毒素 (TA) 基因表达 → 持留菌比例大幅升高。
- **后续反驳**：多个独立研究表明，敲除 10 个 Type II TA 模块**不影响**持留菌水平；Type II 毒素在多种应激条件下**不一定被激活**。
- **结论**：巨噬细胞诱导持留菌的**关键机制仍不清楚**。

### 1.4 细菌蛋白聚集体 (Aggresomes) 与休眠的新关联

近年研究揭示了细菌聚集体与休眠的相关性：

- 聚集体包含大量**碳代谢、氧化磷酸化、转录、翻译**相关功能蛋白。
- 聚集体的形成由**液-液相分离 (LLPS)** 驱动。
- 聚集体 = 蛋白质被隔离 → 功能蛋白失活 → 代谢休眠。

### 1.5 本研究核心问题

**巨噬细胞吞噬后，细菌聚集体的形成是否由巨噬细胞来源的 ROS 驱动？这些聚集体是否是持留菌形成的关键机制？**

## 二、结果详解

### Result 1: 沙门氏菌聚集体在巨噬细胞吞噬后快速形成

**实验方法**：将 S. Typhimurium SL1344 的 HslU（蛋白酶体标记蛋白）与 EGFP 融合，标记细菌蛋白聚集体。

**关键发现**：

- 巨噬细胞吞噬后 **0.5 小时**即可检测到 HslU-EGFP 焦点（聚集体）。
- RAW264.7 巨噬细胞中，**19.7%** 的细菌含有聚集体。
- 在人 THP-1 巨噬细胞和小鼠 iBMDM 中均可观察到，**跨细胞类型一致**。
- 指数期和稳定期细菌均可形成聚集体 → **与细菌生长状态无关**。
- 在其他细菌中也观察到：福氏志贺菌 (*S. flexneri*)、耻垢分枝杆菌 (*M. smegmatis*) → **非沙门氏菌特异**。

**意义**：聚集体形成是巨噬细胞吞噬后的**早期、普遍事件**。

---

### Result 2: 巨噬细胞来源的 ROS 驱动聚集体形成

**关键证据**：

| 实验 | 结果 |
|------|------|
| roGFP2 氧化应激探针 | 含聚集体的细菌受到 **1.3 倍**更高氧化应激 |
| ROS 抑制剂处理巨噬细胞 | 聚集体阳性细菌数量**减少** |
| Cybb⁻/⁻ (NADPH 氧化酶缺陷) 小鼠 | 沙门氏菌聚集体比例**低于**野生型小鼠（48 hpi，脾脏等器官） |

**意义**：巨噬细胞通过 NADPH 氧化酶 (Cybb/NOX2) 产生的 ROS 是驱动细菌聚集体形成的**关键外源信号**。

---

### Result 3: 聚集体赋予沙门氏菌抗生素持留能力

**核心数据**：

- 被巨噬细胞吞噬的沙门氏菌，持留菌比例比 LB 培养对照**高 10 倍**。
- **67.9%** 的持留菌来源于含聚集体的细菌。
- 考虑到只有 19.7% 的被吞噬细菌含聚集体 → 含聚集体细菌成为持留菌的概率是不含聚集体细菌的 **8.6 倍**。

**实时成像验证**：

- 氨苄西林 (100 μg/mL, 10×MIC) 快速裂解**无聚集体**沙门氏菌。
- 含 HslU-EGFP 焦点的沙门氏菌进入**非增殖状态**，在新鲜 LB 中可恢复生长。

**体内验证**：

- Cybb⁻/⁻ 小鼠经头孢噻肟治疗后，器官中沙门氏菌持留菌比例**显著低于**野生型小鼠。

**排除 (p)ppGpp 的作用**：

- ΔrelAΔspoT、Δlon、ΔlonΔsulA 突变体在巨噬细胞中**未显示**持留菌比例降低。
- 与之前的 Type II TA 争议一致 → 本文提出**聚集体是替代机制**。

**葡萄糖补充实验**：

- 葡萄糖补充可有效**抑制**聚集体形成 → 持留菌形成也随之**减少**。

---

### Result 4: 聚集体介导细菌代谢休眠

**蛋白质组学分析**：

从巨噬细胞释放的沙门氏菌中分离不溶性蛋白，质谱鉴定出 **779 个蛋白**。

KEGG 通路富集：

| 通路 | 被隔离的关键蛋白 |
|------|-----------------|
| 核糖体 | rpsA, rplQ, rplC → **翻译受损** |
| 碳代谢 | — |
| 氨基酸生物合成 | asnB, trpB, gltB → **代谢稳态破坏** |
| 氧化磷酸化 | — |

**聚集体成分在感染、延长培养、ROS 应激条件下一致** → 通用机制。

**单细胞 ATP 动态**：

- ROS 应激后，细菌整体 ATP 水平**下降近 10 倍**。
- QUEEN 7μ_A81D 生物传感器单细胞检测：含聚集体细菌 ATP **显著低于**不含聚集体细菌。

**聚集体细菌仍保持活性**：

- 聚集体细菌的 SPI-1 启动子活性**高于**无聚集体细菌。
- RNA-seq：ROS (H₂O₂) 应激可诱导 SPI-1 效应子表达。
- 含聚集体细菌仍能表达毒力基因 → **休眠但不死亡**。

---

### Result 5: ROS 下降 → SPI-2 表达 → 聚集体解体 → 细菌复苏

**时间动态**：

| 时间点 | ROS 水平 | SPI-2 活性 | 细菌状态 |
|--------|---------|-----------|---------|
| 1.5 hpi | 高 | 低 | 聚集体形成、休眠 |
| 24 hpi | 下降 | 上调 | sifA、sspH2 表达 → 细胞内增殖 |

**实时成像验证**（MOI=5，单菌/单巨噬细胞）：

- SPI-2 基因表达增加时 → 沙门氏菌聚集体**解体** → 细菌恢复生长和复制。

**机制模型**：

```
巨噬细胞 ROS ──→ 细菌蛋白聚集 (LLPS) ──→ 代谢休眠 ──→ 抗生素持留
       ↓ 随时间下降
  SPI-2 表达上调 ──→ 聚集体解体 ──→ 细菌复苏 ──→ 复发感染
```

## 三、核心机制总结

```
巨噬细胞吞噬沙门氏菌
         │
         ▼
NADPH 氧化酶 (Cybb) 产生 ROS
         │
         ▼
细菌蛋白质发生液-液相分离 (LLPS)
形成蛋白聚集体 (Aggresomes)
         │
    ┌────┴────┐
    ▼         ▼
隔离功能蛋白    ATP 下降近 10 倍
(核糖体/代谢)   进入代谢休眠
    │         │
    └────┬────┘
         ▼
抗抗生素持留菌 (8.6倍富集)
         │
         ▼
ROS 随时间下降 → SPI-2 上调
         │
         ▼
聚集体解体 → 细菌复苏 → 复发感染
```

## 四、关键创新点

1. **机制创新**：首次证明巨噬细胞 ROS 是驱动细菌聚集体形成的直接因素（之前仅有相关性描述）。
2. **与传统理论的分歧**：Type II TA / (p)ppGpp 并非巨噬细胞诱导持留菌的关键机制 → 聚集体是**替代解释**。
3. **从体外到体内**：Cybb⁻/⁻ 小鼠模型验证了 ROS-聚集体-持留菌轴的体内功能。
4. **动态模型**：不只是描述"休眠"，而是完整描绘了**形成 → 维持 → 解体 → 复苏**的全周期。
5. **治疗启示**：葡萄糖补充可抑制聚集体形成 → 潜在的抗生素增敏策略。

## 五、局限性与待解决问题

| 局限性 | 说明 |
|--------|------|
| 模型 | 主要使用 RAW264.7 细胞系；iBMDM 为永生化细胞；人体原代巨噬细胞数据有限 |
| 因果性 | LLPS 作为聚集体形成的驱动机制在本文中未直接验证（未做相分离抑制实验） |
| 分子靶点 | 聚集体中哪些特定蛋白被隔离导致休眠？尚未精确鉴定 |
| 体内治疗验证 | 葡萄糖补充的体内增敏效果未验证 |
| 竞争机制 | 是否有其他非聚集体依赖的持留机制并存？ |
