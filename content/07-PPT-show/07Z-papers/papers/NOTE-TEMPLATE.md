# 论文解析笔记模板（llm-for-zotero 专用）

> 此文件是 llm-for-zotero 生成笔记时的参考模板。
> 笔记结构参考 Chen2025-Salmonella-aggresome-ROS-persistence.md 的质量标准。

---

## 笔记结构要求

### 头部信息
```markdown
# [论文标题]

> **作者**: [作者列表]
> **期刊**: [期刊名] (年份)
> **DOI**: [DOI链接](https://doi.org/xxx)
> **Zotero**: [在 Zotero 中打开](zotero://select/items/0/{ITEM_KEY})
> **PDF**: [打开原文 PDF](zotero://open-pdf/items/0/{ATTACHMENT_KEY})
```

⚠️ **Zotero 链接必须用 `zotero://select/items/0/{ITEM_KEY}` 格式（直接 item key），不要用 `?q=` 搜索格式。**

### 正文结构

#### 一、核心概念与研究背景 (Context & Concepts)
- **一句话总结**：用通俗语言概括论文解决的核心问题
- **关键概念解析**：解释核心技术名词/理论背景，说明重要性

#### 二、遭遇的瓶颈与中间问题 (The "Middle" Problems)
- **现有挑战**：该领域在本研究前的最大痛点
- **具体难点**：作者遇到的"拦路虎"（数据不足/算法失效/场景限制等）
- 明确指出阻碍真相揭示的"中间问题"

#### 三、抽丝剥茧：揭秘过程与解决方案 (Unveiling & Solutions)
- **破局思路**：核心灵感或切入点
- **一步步揭秘**：按时间/逻辑顺序还原解决步骤
- 体现"侦探破案"般的逻辑推演
- 先做了什么实验 → 发现什么异常 → 修正假设 → 锁定真理

#### 四、核心技术路线 (Technical Roadmap)
- **整体架构**：技术方案/模型架构
- **关键创新点**：相比传统方法的独特改进
- 用流程图文字描述：`输入 → 模块A处理 → 模块B优化 → 最终输出`

#### 五、结果呈现与证据链 (Results & Evidence)
- **核心结论**：最终研究结果
- **证据展示**：关键图表、数据、对比实验
- 说明结果如何回应"中间问题"

#### 六、局限性与待解决问题
- 表格形式列出局限性及说明

#### 七、与我的研究关联
- 可直接借鉴的方法/思路
- 可改进的策略
- 应避免的陷阱
- 激发的新项目想法

## Tags（笔记末尾）

每篇笔记末尾必须添加标签行：

```markdown
Tags: #论文笔记 #[研究领域] #[病原体] #[关键方法] #[关键通路] #[期刊名]
```

**标签规则：**
- 第一个标签固定 `#论文笔记`
- 研究领域：微生物学/免疫学/基因组学/蛋白质组学/生物信息学 等
- 病原体/生物体：沙门氏菌/链球菌/金黄色葡萄球菌 等
- 关键方法：Tn-seq/CRISPRi/RNA-seq/蛋白质组学 等
- 关键通路/概念：毒力岛/持留菌/ROS/嘌呤合成 等
- 期刊名：去掉空格，如 NatureMicrobiology/PLOSPathogens/iMeta

**示例：**
```
Tags: #论文笔记 #微生物学 #脑膜炎 #链球菌 #PTS系统 #严紧反应 #NatureMicrobiology
```

## 质量标准（参考 Chen2025 笔记）

| 维度 | 要求 |
|------|------|
| 背景 | 有争议的地方要列出不同观点 |
| 结果 | 每个 Result 有独立的"关键发现"和"意义" |
| 数据 | 具体数字必须准确（如"19.7%"、"8.6倍"） |
| 机制 | 用流程图/ASCII art 呈现信号通路 |
| 对比 | 有表格对比不同条件/实验结果 |
| 批判 | 局限性要具体，不泛泛而谈 |
| 关联 | 必须联系到自己的研究方向 |
