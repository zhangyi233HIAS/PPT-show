# P01: SPI-1 注射器重编程宿主细胞翻译

## 中文摘要

本研究通过时间分辨的平行翻译组和转录组分析，揭示了沙门氏菌致病性岛1（[[SPI-1]]）编码的[[III型分泌系统]]（T3SS）针状复合物如何重编程宿主巨噬细胞的翻译机制，从而逃避宿主[[炎症反应]]。

研究发现，沙门氏菌感染后，宿主细胞的转录和翻译发生解偶联——细菌利用T3SS效应蛋白快速重塑宿主翻译景观。关键发现是早期生长反应因子1（[[EGR1]]）的快速翻译上调，EGR1作为转录抑制因子，能够迅速抑制促炎基因的表达，从而为沙门氏菌建立早期感染生态位争取时间。

## 核心方法

- **时间分辨平行翻译组-转录组分析**（Time-resolved parallel translatome & transcriptome profiling）
- [[Ribo-seq]]（核糖体印迹测序）结合 RNA-seq
- 巨噬细胞感染模型（RAW264.7 / BMDM）
- SPI-1 T3SS突变株 vs 野生型对比
- 翻译效率（TE, Translation Efficiency）计算

## 关键发现

1. **转录-翻译解偶联**：感染早期（30-60 min），宿主细胞大量mRNA的翻译效率发生显著变化，但转录水平变化相对滞后
2. **EGR1快速翻译**：[[EGR1]] 在感染后30分钟内即通过翻译水平快速上调，不依赖于转录激活
3. **炎症抑制机制**：EGR1作为早期响应因子，通过翻译后迅速产生蛋白，抑制下游促炎细胞因子（如[[TNF-α]]、[[IL-6]]）的表达
4. **SPI-1依赖性**：该翻译重编程依赖于完整的T3SS针状复合物，SPI-1缺失突变株无法实现宿主翻译重编程
5. **时间窗口效应**：EGR1介导的翻译抑制为细菌提供了约2-4小时的"免疫逃逸窗口"

## 沙门菌研究相关性

- 揭示了 [[SPI-1]] T3SS的全新功能：不仅用于细菌蛋白注入，还可重塑宿主翻译机器
- 为理解沙门氏菌如何在巨噬细胞内建立早期感染提供了新机制
- [[EGR1]] 作为宿主-病原互作的关键节点，可能是新的治疗靶点
- 与 [[沙门氏菌]] 毒力调控和免疫逃逸的其他机制（如SPI-2介导的SCV形成）互补
