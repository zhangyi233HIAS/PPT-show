Obsidian 的核心快捷键以 **高效文本操作和知识管理** 为主，而 Windows 系统下的光标定位快捷键是 **通用文本编辑逻辑**，两者在 Obsidian 中可直接结合使用。以下按功能分类整理最实用的操作，**重点标注高频场景**。

---

## 一、Obsidian 核心快捷键（Windows 版）

### 1. **基础操作**

- **快速切换文件**：`Ctrl + O`（输入文件名秒搜）。
- **命令面板**：`Ctrl + P`（执行所有功能的核心入口）。
- **新建笔记**：`Ctrl + N`（默认在根目录创建，建议通过设置修改为指定文件夹）。
- **保存/撤销/重做**：`Ctrl + S` / `Ctrl + Z` / `Ctrl + Y`（基础但高频）。

### 2. **文本编辑与光标定位**

- **移动到当前行开头/结尾**：`Home` / `End`。Ctrl+←和右定位光标
- **移动到文档开头/结尾**：`Ctrl + Home` / `Ctrl + End`。
- **移动到前一个/后一个单词开头**：`Ctrl +shift ←` /
- **选中当前行**：将光标置于行首，按 `Shift + End`。
- Ctrl 】 【上一级标题

### 3. **格式化与链接**

- **加粗/斜体**：`Ctrl + B` / `Ctrl + I`（直接插入 `**` 或 `*`）。

- **关闭当前标签页**：`Ctrl + W`（替代鼠标点击 ×）。

## 二、Windows 通用文本编辑光标定位

在 Obsidian 或任何文本编辑场景中，以下快捷键 **无需依赖软件**，直接通过系统级操作实现精准定位：

### 1. **行级操作**

- **换行**：直接按 `Enter` 键（所有编辑器通用）。
- **移动到当前行开头/结尾**：`Home` / `End`。
- **移动到上一行开头**：先按 `↑` 上箭头，再按 `Home`。
- **移动到文档开头/结尾**：`Ctrl + Home` / `Ctrl + End`。

### 2. **词级操作**

- **移动到当前单词开头**：`Ctrl + ←`（向左跳至单词起始）。
- **移动到当前单词结尾**：`Ctrl + →`（向右跳至单词末尾）。
- **选中当前单词**：双击单词，或按 `Ctrl + ←` + `Shift + →`。

### 3. **高效组合示例**

- **快速删除当前行**：`Ctrl + Shift + K`（Obsidian 专属）。
- **从本行开头删除到光标处**：`Shift + Home` 选中内容，再按 `Delete`。
- **跨单词跳转并选中**：`Ctrl + Shift + ←` / `Ctrl + Shift + →`（逐词扩展选区）。

## 关键总结

- Obsidian 的快捷键体系 **高度依赖通用文本编辑逻辑**（如 `Home` / `End` / `Ctrl+←`），因此掌握 Windows 基础光标操作能大幅提升效率。
- **最需记忆的 5 个 Obsidian 专属快捷键**：`Ctrl + O`（快速切换）、`Ctrl + P`（命令面板）、`Ctrl + G`（图谱）、`Ctrl + E`（切换模式）、`Ctrl + L`（任务列表）。
- 若需自定义快捷键，进入 **设置 → 快捷键**，优先绑定高频操作（如模板插入建议设为 `Ctrl + T`）。

以上快捷键在 Obsidian 1.0+ 版本中稳定适用，无需插件即可生效。实际使用时，**先熟悉通用文本操作，再叠加 Obsidian 特色功能**，能避免记忆负担。
