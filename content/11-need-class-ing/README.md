# 11-need-class-ing（待分类区）

> 此文件夹是文件安全回收站。
> Hermes Agent 在归档 vault 时，遇到以下情况的文件会放在这里，而不是删除：

## 放入规则

1. **内容非空但无法判断分类** — 不确定属于哪个学科/目录
2. **格式异常** — 内容损坏、编码问题、空文件但有文件名暗示意义
3. **跨学科/多主题** — 同时涉及多个学科，无法归入单一目录
4. **待用户确认** — Agent 认为可能有价值但需要用户判断

## 处理流程

```
发现未分类文件 → 检查内容 → 
  ├─ 能分类 → 移动到正确目录 + 更新 index.md + log.md
  └─ 不能分类 → 移动到 11-need-class-ing/ + 记录原因
```

## 安全承诺

- ✅ **永远不删除有内容的 .md 文件**
- ✅ 可以移动、重命名、归档
- ✅ 不能确定分类时 → 放这里
- ❌ 不会静默丢弃任何笔记
