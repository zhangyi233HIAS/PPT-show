# 免疫球蛋白的分类、分子结构、生物学功能与临床意义

## 1. 概述与基本定义

**免疫球蛋白** 是由B淋巴细胞在抗原刺激下分化为浆细胞后，所产生的一类能与相应抗原特异性结合的糖蛋白。它是**体液免疫应答**最重要的效应分子。从化学结构上讲，具有抗体活性或化学结构与抗体相似的球蛋白统称为免疫球蛋白。因此，**抗体**是免疫球蛋白，但免疫球蛋白并非都具有抗体活性（如骨髓瘤蛋白）。

免疫球蛋白主要存在于血清、组织液及外分泌液中，而作为**B细胞抗原受体**的膜免疫球蛋白则是B细胞表面的跨膜蛋白。

## 2. 免疫球蛋白的分子结构

### 2.1 单体基本结构
一个典型的免疫球蛋白单体（如IgG、IgD、IgE及血清型IgA）呈 **“Y”字型** 结构，由**两条相同的重链**和**两条相同的轻链**通过**链间二硫键**及非共价键连接而成。

```
        V_H   C_H1    C_H2   C_H3
         |      |       |      |
        / \     |       |      |
       /   \    |       |      |
      /     \   |       |      |
     /       \  |       |      |
    V_L --- C_L C_H1 - C_H2 - C_H3
    |    |      |       |      |
    |   二硫键   |       |      |
    |__________|       |      |
         抗原结合位点       Fc段
                         (效应功能区)
```
*   **图注：** V：可变区；C：恒定区；H：重链；L：轻链。Fc段是与细胞Fc受体或补体结合的部位。

### 2.2 功能区
*   **可变区：** 位于Y的两臂顶端，由重链可变区和轻链可变区组成，共同构成**抗原结合位点**。可变区内存在**高变区**或**互补决定区**，是与抗原表位精确结合的关键区域。
*   **恒定区：** 位于Y的主干部分。重链恒定区决定了免疫球蛋白的**类和亚类**，并介导多种生物学效应功能。轻链恒定区分为κ和λ两型，其功能尚不完全明确。
*   **铰链区：** 位于CH1和CH2之间，富含脯氨酸，赋予分子**柔韧性**，有利于同时结合不同距离的抗原表位，并暴露补体结合位点。

### 2.3 多聚体结构
部分免疫球蛋白以多聚体形式存在：
*   **分泌型IgA：** 由两个IgA单体、一个**连接链**和一个**分泌片**组成。
*   **IgM：** 由五个IgM单体通过连接链和二硫键连接成五聚体。

### 2.4 抗体多样性的分子机制
免疫系统能够产生超过10^11种不同特异性的抗体，其多样性源于：
1.  **V区基因重排：** 在B细胞发育过程中，V、D、J基因片段发生**V(D)J重组**，这是多样性的主要来源。
2.  **组合多样性：** 不同重链和轻链的随机配对。
3.  **连接多样性：** 在基因片段连接处，核苷酸的插入或删除增加了变异。
4.  **体细胞高频突变：** 成熟B细胞在抗原刺激后，V区基因发生高频率点突变，产生更高亲和力的抗体。

## 3. 免疫球蛋白的分类与亚类

根据**重链恒定区**抗原性的不同，可将免疫球蛋白分为五类：
*   **IgG：** 重链为γ链，有四个亚类（IgG1-4）。
*   **IgA：** 重链为α链，有两个亚类（IgA1-2）。
*   **IgM：** 重链为μ链。
*   **IgD：** 重链为δ链。
*   **IgE：** 重链为ε链。

## 4. 各类免疫球蛋白的特性与功能

### 4.1 [[IgG]]
*   **结构与分布：** 血清中含量最高，半衰期最长。主要以单体形式存在。
*   **功能特性：**
    1.  **再次免疫应答的主力：** 亲和力高，半衰期长，提供长期保护。
    2.  **被动免疫：** **唯一能通过胎盘**的Ig，对新生儿抗感染免疫至关重要。
    3.  **效应功能广泛：** 通过Fc段与多种细胞Fc受体（FcγR）及补体C1q结合，介导**调理作用**、**ADCC**和激活**补体经典途径**。
*   **临床意义：** IgG亚型缺陷（如IgG2缺陷）与特定细菌感染相关。免疫球蛋白治疗（IVIG）主要成分是IgG。

### 4.2 [[IgM]]
*   **结构与分布：** 以**五聚体**形式存在于血液中，分子量最大。未成熟B细胞表面表达单体形式的膜IgM。
*   **功能特性：**
    1.  **初次免疫应答先锋：** 个体发育和抗原刺激后**最先产生**的抗体，血清IgM升高提示**近期感染**。
    2.  **强大的补体激活能力：** 一个IgM分子即可高效激活补体经典途径，在感染早期发挥重要作用。
    3.  **天然抗体：** 如ABO血型系统的天然抗体多为IgM。
*   **临床意义：** 脐带血IgM升高是诊断**宫内感染**的重要指标。

### 4.3 [[IgA]]
*   **结构与分布：** 分为**血清型**和**分泌型**。sIgA由黏膜相关淋巴组织产生，经上皮细胞转运至黏膜表面。
*   **功能特性：**
    1.  **黏膜免疫的核心：** sIgA是**黏膜表面**最重要的防御因素，能阻止病原体黏附。
    2.  **新生儿保护：** 初乳中的sIgA为婴幼儿提供**被动免疫**。
    3.  **中和与调理：** 在黏膜局部中和病原体和毒素。
*   **临床意义：** IgA缺乏是最常见的原发性免疫缺陷病之一，与反复呼吸道和消化道感染有关。

### 4.4 [[IgE]]
*   **结构与分布：** 血清含量极低，主要存在于呼吸道、胃肠道黏膜固有层。
*   **功能特性：**
    1.  **介导I型超敏反应：** 其Fc段能以高亲和力结合**肥大细胞**和**嗜碱性粒细胞**表面的FcεRI，交联后触发细胞脱颗粒，引起**过敏反应**。
    2.  **抗寄生虫感染：** 在抗蠕虫等寄生虫感染中发挥重要作用。
*   **临床意义：** 血清总IgE和特异性IgE升高是**过敏性疾病**（如哮喘、特应性皮炎）的重要诊断依据。

### 4.5 [[IgD]]
*   **结构与分布：** 血清含量极低，功能尚不完全清楚。主要作为**膜免疫球蛋白**表达于成熟B细胞表面。
*   **功能特性：**
    1.  **B细胞成熟标志：** 成熟初始B细胞同时表达mIgM和mIgD，是B细胞发育的重要阶段标志。
    2.  **抗原识别与活化：** 作为BCR复合物的一部分参与抗原识别，可能在B细胞活化中起调节作用。

## 5. 免疫球蛋白的生物学功能与信号机制

免疫球蛋白的功能由其**可变区**和**恒定区**协同完成。

### 5.1 可变区介导的功能：特异性识别
可变区通过其高变区与抗原表位特异性结合，这是所有功能的基础，可直接中和病原体或毒素。

### 5.2 恒定区介导的功能：效应功能
抗体结合抗原后，其Fc段构象改变，从而招募和激活其他免疫细胞或分子，执行清除功能。

```
                 抗原
                   |
                  \ /
             抗体可变区 (识别)
                  |____|
                  |    |
                  |    |
             抗体铰链区 (柔韧)
                  |    |
                  |    |
             ______|    |______
            |                  |
            |   抗体恒定区Fc段  | (效应)
            |__________________|
           /        |        \
          /         |         \
         /          |          \
        /           |           \
   FcγR结合      补体C1q结合    FcεR结合
   (调理作用)   (经典途径激活)  (过敏反应)
   (ADCC)      
        ↓           ↓            ↓
   吞噬细胞激活  补体活化膜攻击  肥大细胞脱颗粒
   NK细胞杀伤   C3a/C5a趋化    组胺释放
```
*   **图注：** 抗体识别抗原后，Fc段成为信号平台，通过与不同受体/分子结合，启动下游效应。

### 5.3 B细胞受体信号传导
膜免疫球蛋白作为**B细胞受体**复合物的一部分，其胞内段很短，信号传导依赖于与之非共价结合的**Igα/Igβ**异二聚体。当抗原交联多个BCR后：
1.  Iga/Igb胞内段的**免疫受体酪氨酸激活基序**被Src家族激酶磷酸化。
2.  磷酸化的ITAM招募并激活**Syk**激酶。
3.  Syk通过接头蛋白**BLNK**激活下游通路，包括**磷脂酶Cγ2**、**BTK**激酶等。
4.  最终导致钙离子动员、MAPK通路活化、基因转录，促进B细胞增殖、分化或发生**类别转换**。

## 6. 临床意义总结

*   **疾病诊断：**
    *   **感染：** 特异性IgM提示近期感染；IgG动态变化或亲和力成熟有助于判断感染进程。
    *   **免疫缺陷病：** 各类Ig的选择性或联合缺乏。
    *   **过敏与自身免疫病：** 特异性IgE检测用于过敏原诊断；某些自身抗体（如IgG类抗核抗体）是诊断标志。
    *   **浆细胞疾病：** 多发性骨髓瘤时出现单克隆免疫球蛋白（M蛋白）。
*   **疾病治疗与预防：**
    *   **被动免疫治疗：** 注射**抗毒素血清**、**高效价免疫球蛋白**（如抗乙肝免疫球蛋白）、**单克隆抗体药物**（多为IgG型）。
    *   **主动免疫预防：** **疫苗**接种诱导机体产生保护性抗体（主要为IgG）。
    *   **静脉注射免疫球蛋白** 用于治疗原发性免疫缺陷、自身免疫性疾病等。
