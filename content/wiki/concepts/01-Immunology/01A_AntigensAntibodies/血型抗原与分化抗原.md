# 抗原多态性、血型系统与组织相容性系统

本文档整合了免疫学中关于细胞表面重要抗原系统的核心概念，重点阐述其多态性（polymorphism）的本质、遗传基础及生物学意义。

## 1. 核心概念框架

*   **细胞表面标志 (Surface Marker)**：泛指存在于细胞膜上，与细胞特定形态、功能及发育阶段密切相关的功能分子，是[[免疫应答]]识别与作用的基础界面。
*   **分化抗原 (Cluster of Differentiation, CD)**：一类重要的[[细胞表面标志]]。其定义基于==单克隆抗体==的鉴定，特指具有==明确基因编码及特定细胞表达谱==的[[白细胞分化抗原]]。CD分子广泛参与[[免疫应答]]的识别、活化与效应阶段，是免疫细胞分群与功能研究的关键工具。

## 2. 血型抗原 (Blood Group Antigens)

血型抗原是红细胞膜上具有高度[[多态性]]的糖蛋白或糖脂，是临床输血医学的基石。

*   **ABO血型系统**
    *   **遗传基础**：由9号染色体上的单一基因座控制，包含`A`、`B`、`O`三个[[复等位基因 (Multiple Allele)]]。`A`和`B`为显性，`O`为隐性。因此，个体基因型可为`AA`、`AO`（A型）、`BB`、`BO`（B型）、`AB`（AB型）、`OO`（O型）。`A`和`B`等位基因产物均表达于红细胞表面，体现了[[共显性 (Codominance)]]。
    *   **生化本质**：抗原特异性由H抗原前体上连接的特定糖基决定。A基因编码α-1,3-N-乙酰半乳糖胺转移酶，B基因编码α-1,3-半乳糖转移酶。O基因为无功能突变体，不进行糖基修饰。
    *   **多态性起源与维持**：ABO系统的[[多态性 (Polymorphism)]]极其稳定，可能与不同血型对特定病原体（如疟原虫、霍乱弧菌）易感性的差异有关，反映了自然选择压力。

*   **Rh血型系统**
    *   **抗原**：最重要的为RhD和RhC/c、RhE/e抗原。RhD抗原的免疫原性最强，是引起新生儿溶血病和溶血性输血反应的主要原因。
    *   **遗传基础**：由1号染色体上紧密连锁的`RHD`和`RHCE`基因控制。Rh阴性（d/d）个体缺乏RHD基因或该基因失活。该系统是**单体型 (Haplotype)** 的典型例子，如常见的单体型为`Dce`。不同种族间单体型频率差异显著。

## 3. 组织相容性抗原 (Histocompatibility Antigens)

亦称**移植抗原 (Transplantation Antigen)**，是决定移植物能否被受体接受（组织相容性）的[[细胞表面标志]]。

*   **主要组织相容性抗原 (Major Histocompatibility Antigen)**
    *   **定义**：能诱导迅速、强烈排斥反应的[[组织相容性抗原]]。
    *   **基因基础**：由**主要组织相容性复合体 (Major Histocompatibility Complex, MHC)** 编码。在人类称为**人类白细胞抗原 (Human Leukocyte Antigen, HLA)** 复合体，位于6号染色体短臂。
    *   **核心功能**：其最主要的功能是结合、加工和提呈肽段给T细胞，是连接固有免疫与适应性免疫的桥梁。因此，MHC分子是T细胞识别“自我”与“非我”的分子基础。
    *   **分子分类与结构**
        ```
        MHC I类分子                    MHC II类分子
        ┌─────────────┐            ┌─────────────┐
        │  α1   α2   │ 肽结合槽     │  α1    β1  │ 肽结合槽
        │   域   域   │◄────────►│    域    域   │◄────────►
        ├─────────────┤            ├─────────────┤
        │     α3     │            │     α2     │
        │     域     │            │     域     │
        ├─────┬───────┤            ├─────┬───────┤
        │  β2-微球蛋白 │            │     β2     │
        └─────┴───────┘            └─────┴───────┘
        表达：所有有核细胞             表达：专职抗原提呈细胞
        (APC: B细胞, 巨噬细胞, DC)
        提呈肽段：内源性抗原           提呈肽段：外源性抗原
        (如病毒蛋白)                  (如细菌蛋白)
        识别细胞：CD8+ T细胞          识别细胞：CD4+ T细胞
        ```
    *   **多态性的核心地位**：HLA系统是人类基因组中**多态性**最丰富的区域。这种极端多态性的维持机制复杂，包括**超显性选择 (Heterozygote Advantage)** 和**频率依赖性选择 (Frequency-Dependent Selection)**。其进化意义在于确保种群在面对不断变化的病原体时，总有一部分个体拥有有效的抗原提呈能力。
    *   **遗传特点**
        *   **复等位基因**：每个HLA基因座存在大量[[复等位基因]]。
        *   **共显性**：父母双方的同源染色体上的等位基因产物均表达于细胞表面，如一个个体可同时表达HLA-A2和HLA-A3。
        *   **单体型遗传**：紧密连锁在一条染色体上的HLA等位基因组合（如`A1-B8-DR3`）作为一个整体遗传给子代，称为**单体型 (Haplotype)**。
        *   **连锁不平衡 (Linkage Disequilibrium)**：观察到的特定等位基因组合（如`A1`和`B8`）出现在同一单体型上的频率，显著高于根据其各自基因频率计算的随机组合期望值。这源于自然选择、群体奠基者效应或种群迁移历史，是研究人类进化和疾病关联的重要线索。

*   **次要组织相容性抗原 (Minor Histocompatibility Antigen)**
    *   **定义**：主要指由Y染色体编码的HY抗原等，能诱导缓慢、较弱的排斥反应。
    *   **临床意义**：在同种异体造血干细胞移植中，次要组织相容性抗原不匹配是导致移植物抗宿主病 (GvHD) 和移植物抗白血病 (GvL) 效应的重要原因。

## 4. 遗传学基础深度解析：多态性 (Polymorphism)

*   **定义**：在随机婚配人群中，同一基因座以稳定频率（通常>1%）存在两种或以上等位基因的现象。它是生物多样性的遗传基础。
*   **产生机制**：主要源于**基因突变**（如点突变、基因重复）。
*   **维持机制**：
    1.  **平衡选择**：包括**杂合子优势**（如镰状细胞贫血与疟疾）、**频率依赖性选择**（稀有等位基因具有适应性优势）。
    2.  **中性选择**：不同等位基因对个体生存无显著影响，通过遗传漂变维持。
    3.  **异质性优势**：在免疫系统中尤为突出，如MHC的极端多态性使得病原体难以在人群中完全“逃逸”。

## 5. 总结与整合

血型抗原、组织相容性抗原与免疫细胞表面标志共同构成了免疫识别与应答的**分子地理图**。它们的共同遗传特征是**多态性**，但其选择压力和功能意义迥异：

*   **血型抗原**的多态性更多源于对**感染性疾病**的平衡选择，其临床焦点在于**抗体介导的超敏反应**（如输血反应）。
*   **MHC分子**的多态性则直接服务于**T细胞免疫监视**的核心功能，其极端多样性是群体对抗病原体**快速进化**的进化策略。在移植医学中，它是介导**细胞介导的排斥反应**的“主要”障碍。
*   **共显性**、**复等位基因**、**单体型**和**连锁不平衡**是理解这些系统复杂遗传行为的关键概念。特别是**连锁不平衡**，不仅解释了单体型的非随机关联，也为疾病风险预测和进化遗传学研究提供了重要工具。

理解这些概念，不仅对基础免疫学至关重要，更是临床移植医学、输血医学、疾病关联研究和个性化医疗的基石。
