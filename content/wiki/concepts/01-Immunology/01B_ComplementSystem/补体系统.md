# 补体系统：活化途径、效应功能与调节机制

**关键词**: 补体系统 (Complement System), 经典途径 (Classical Pathway), 旁路途径 (Alternative Pathway), 凝集素途径 (Lectin Pathway), 攻膜复合物 (Membrane Attack Complex, MAC), 调理作用 (Opsonization), 补体受体 (Complement Receptors)

补体系统是先天性免疫的核心效应和调节枢纽，由超过30种血浆和膜结合蛋白组成，通过精密的级联反应被激活。其核心功能是识别“自我”与“非我”，并通过直接杀伤、调理吞噬及炎症介导等方式清除病原体。活化过程严格受控，失调将导致自身免疫或免疫缺陷。

## 1. 活化途径：三条会聚的起始路径

所有途径最终都汇聚于**C3转化酶 (C3 convertase)** 的形成，这是补体级联反应的关键放大节点。

### 1.1 经典途径 (Classical Pathway)
- **触发物**: 主要由**抗原-抗体复合物 (Ag-Ab complex)** 激活，尤其是IgM和IgG（特别是IgG1, IgG3）。
- **识别分子**: **C1复合物** (C1q, C1r, C1s)。C1q的球形头部结合抗体Fc段。
- **关键反应**:
    1.  C1q结合Ag-Ab → 构象改变激活C1r/C1s。
    2.  活化的C1s依次裂解**C4**和**C2**。
    3.  形成经典途径C3转化酶：**C4b2a**。
    4.  C4b2a裂解大量**C3**为C3a和C3b。
    5.  C3b与C4b2a结合，形成C5转化酶：**C4b2a3b**。
- **重要性**: 连接适应性免疫（抗体）与先天性免疫效应的桥梁。[[C反应蛋白]] (CRP) 等急性期蛋白也可直接结合C1q，以非抗体依赖方式激活此途径。

### 1.2 旁路途径 (Alternative Pathway)
- **触发物**: **病原体表面（如细菌脂多糖、酵母聚糖）** 或“受损”的自身细胞。为持续的**低水平自发“滴答” (tick-over)** 机制。
- **关键反应**:
    1.  **自发水解**: 血浆中C3缓慢水解为C3(H₂O)，获得类似C3b的构象。
    2.  C3(H₂O)与血浆**B因子**结合，在**D因子**作用下裂解B因子，形成**C3(H₂O)Bb**（初始C3转化酶）。
    3.  C3(H₂O)Bb裂解C3，产生**C3b**。
    4.  C3b沉积于附近颗粒表面（如细菌），与B因子结合，再次被D因子裂解，形成**C3bBb**（放大C3转化酶）。**备解素 (P因子, Properdin)** 稳定C3bBb。
    5.  C3bBb裂解更多C3，产生C3b。新的C3b与C3bBb结合，形成C5转化酶：**C3bBb3b**。
- **重要性**: 提供**即时、特异性较弱但强大**的早期防御，是感染早期的主要屏障。

### 1.3 凝集素途径 (Lectin Pathway)
- **触发物**: **病原体相关分子模式 (PAMPs)**，特别是病原体表面的**甘露糖、N-乙酰葡糖胺**等糖结构。
- **识别分子**: **[[甘露糖结合凝集素]] (MBL)** 或**纤胶凝蛋白 (Ficolins, FCN)**。
- **关键反应**:
    1.  MBL/FCN识别并结合病原体糖结构。
    2.  结合导致与MBL/FCN相关联的**MBL相关丝氨酸蛋白酶 (MASP-1, MASP-2)** 被激活。
    3.  活化的**MASP-2**发挥与C1s类似的功能，裂解**C4**和**C2**。
    4.  形成与经典途径相同的C3转化酶：**C4b2a**，以及后续的C5转化酶：**C4b2a3b**。
- **重要性**: 在**感染早期、特异性抗体产生前**，提供基于模式识别的、快速的补体激活。

**三条途径的会聚与放大**:
```
                     抗体-抗原复合物
                            ↓
                      [经典途径]
                        C1q/r/s
                            ↓
病原体表面糖结构 → [凝集素途径] → C4 + C2 → C4b2a (C3转化酶) → C3
    MBL/FCN                         ↑
                            C3b ←──┘
                            ↓
病原体表面/“tick-over” → [旁路途径] → B + D因子 → C3bBb (C3转化酶)
                            ↓
                    ┌────────┴────────┐
                    ↓                 ↓
                  C3a               C3b (扩大循环)
                  (炎症)                ↓
                              与C4b2a或C3bBb结合
                                        ↓
                              C5转化酶 (C4b2a3b 或 C3bBb3b)
                                        ↓
                                      C5a (强炎症)
                                      C5b (启动MAC)
```

## 2. 效应功能：从溶解到免疫调节

补体活化后，其裂解片段发挥三大核心效应：

### 2.1 胞毒作用 (Cytolysis) - 直接杀伤
- **核心结构**: **[[攻膜复合物]] (MAC)**，即C5b-C6-C7-C8-C9n复合物。
- **形成过程** (末端通路):
    1.  **C5转化酶**裂解C5，产生强炎症介质**C5a**和起始片段**C5b**。
    2.  **C5b**依次与C6、C7稳定结合，形成**C5b67**，该复合物可插入靶细胞膜脂质双层。
    3.  **C5b67**结合**C8**，形成**C5b678**，开始形成小孔。
    4.  **C5b678**聚合多个(12-18个)**C9**分子，形成跨膜的**中空管状通道**，即MAC。
- **效应**: 导致细胞渗透性溶解。主要用于对抗**革兰氏阴性菌**等有外膜的病原体及某些包膜病毒。[[补体依赖的细胞毒性]] (CDC) 是抗体治疗的重要机制。

### 2.2 调理作用 (Opsonization) - 促进吞噬
- **主要调理素**: **C3b**, **iC3b** (C3b的灭活形式)。
- **机制**: C3b/iC3b共价结合于病原体表面，被吞噬细胞（中性粒细胞、巨噬细胞）表面的[[补体受体]]特异性识别。
    - **CR1 (CD35)**: 主要结合C3b，介导粘附和吞噬。
    - **CR3 (CD11b/CD18, Mac-1)** 和 **CR4 (CD11c/CD18)**: 属于整合素家族，主要结合iC3b，促进牢固粘附和“拉链式”吞噬。
- **重要性**: 是补体清除病原体**最有效和普遍**的方式，尤其对于缺乏特异性抗体的感染。

### 2.3 炎症介导 (Inflammation) - 趋化与活化
- **主要过敏毒素**: **C5a** >> **C3a** > **C4a**。
- **机制**:
    - **趋化作用**: C5a是中性粒细胞、单核细胞和嗜酸性粒细胞的**强效趋化因子**。
    - **激活白细胞**: 引起吞噬细胞“呼吸爆发”，增加其杀菌和杀伤能力。
    - **脱颗粒**: 诱导肥大细胞和嗜碱性粒细胞释放组胺等血管活性胺。
    - **血管效应**: 增加血管通透性，促进炎症细胞和血浆蛋白外渗。
- **受体**: 这些效应通过与相应**G蛋白偶联受体 (GPCRs)** 结合实现，如**C5aR (CD88)** 和 **C3aR**。

## 3. 调节机制：维持自我耐受与防止损伤

补体的强大效应必须受到严格控制，以防止攻击宿主细胞。

### 3.1 液相调节因子 (Protease Inhibitors)
- **C1抑制剂 (C1-INH)**: 丝氨酸蛋白酶抑制剂，灭活C1r/C1s和MASP-1/MASP-2，从源头控制经典和凝集素途径。
- **I因子 (Factor I)**: 丝氨酸蛋白酶，需要辅因子参与。
- **H因子 (Factor H)**: I因子的辅因子，促进C3b在液相中降解；竞争性置换旁路途径C3转化酶上的Bb。
- **C4bp (C4b结合蛋白)**: I因子的辅因子，促进C4b降解；置换经典途径C3转化酶上的C2a。
- **S蛋白 (Vitronectin)** 与 **Clusterin (SP-40,40)**: 结合液相中的C5b67复合物，阻止其插入细胞膜。

### 3.2 膜结合调节蛋白 (Membrane Regulators)
- **衰变加速因子 (DAF, CD55)**: 加速C3/C5转化酶（C4b2a和C3bBb）的衰变（解离）。
- **膜辅因子蛋白 (MCP, CD46)**: I因子的辅因子，促进结合在自身细胞膜上的C3b/C4b被I因子降解。
- **[[攻膜复合物|MAC]]抑制蛋白**:
    - **CD59 (MIRL, protectin)**: 阻止C9的多聚化，从而抑制MAC的最终组装。
    - **同源限制因子 (HRF)**: 功能类似CD59。
- **受体介导的内吞**: 如CR1介导的C3b-免疫复合物清除。

```
            补体调节的“自我保护”网络
            ┌──────────────────────────────┐
            │         宿主细胞膜            │
            │  ┌────────┐      ┌────────┐  │
            │  │  DAF   │      │  MCP   │  │
            │  │(加速衰变)│      │(辅助降解)│  │
            │  └───┬────┘      └───┬────┘  │
            │      ↓               ↓       │
            │  C3/C5转化酶  ←─  C3b/C4b   │
            │  (C4b2a, C3bBb)      │       │
            │                  ←───┤ I因子  │
            │                      ↓       │
            │                  iC3b, C3c,d │
            │                              │
            │          ┌────────────┐      │
            │          │  CD59/HRF  │      │
            │          │ (阻止MAC)  │      │
            │          └─────┬──────┘      │
            │                ↓             │
            │         C5b-8 复合物         │
            └──────────────────────────────┘
                        ↑
            液相调节因子: C1-INH, H因子, I因子, C4bp, S蛋白, Clusterin
```

**总结**: 补体系统是一个高度网络化、自我调节的精密效应系统。三条活化途径（经典、旁路、凝集素）感知不同危险信号，汇聚于C3的活化，产生C3b等片段执行**调理**，并生成C5a等片段驱动**炎症**，最终通过组装**MAC**实现直接**胞毒**。其功能受到一系列液相和膜相调节蛋白的严格控制，以确保免疫监视的有效性并避免自身组织损伤。对补体调节机制的深入理解，为治疗补体介导的疾病（如阵发性睡眠性血红蛋白尿症、非典型溶血尿毒综合征）提供了关键靶点。
