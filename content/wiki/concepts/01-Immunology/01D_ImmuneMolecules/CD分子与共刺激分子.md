# CD分子、共刺激分子与黏附分子的分类、结构与免疫功能整合笔记

## 1. 概述与核心框架：CD分子（Cluster of Differentiation）
**CD分子**是应用单克隆抗体对细胞表面分子进行鉴定和分类的国际统一分组体系，其本质是一类表达于细胞膜表面的**糖蛋白（glycoprotein）**。它们不仅是细胞的“身份标签”，更是执行免疫应答功能的**关键结构基础**。几乎所有参与免疫应答的细胞表面重要分子均归属于CD分子范畴，包括抗原识别受体复合物组分、共刺激/共抑制受体、黏附分子、细胞因子受体等。理解CD分子是解析免疫细胞识别、活化、效应及归巢等所有环节的钥匙。

**核心ASCII Art：TCR-CD3复合物——免疫识别的基石**
```
          +-----------------+
          |      TCR        | <-- 抗原识别特异性
          |  (α 和 β 链)    |
          +--------+--------+
                   | 盐桥连接
    +--------------+--------------+
    |          CD3 复合物         |
    |                             |
    |  +-------+  +-------+      |
    |  | γε 异二聚体 | δε 异二聚体 |      | <-- 胞外区短小
    |  +-------+  +-------+      |
    |                             |
    |  +------------------------+ |
    |  | ζζ 同源二聚体 (或 ζη)  | | <-- 含有关键ITAM
    |  +------------------------+ |
    +-----------------------------+
```
**结构注解**：TCR（T Cell Receptor）负责特异性识别MHC-抗原肽复合物，但其胞内区极短，无法独立转导信号。**CD3分子**由γε、δε和ζζ（或ζη）异/同二聚体通过非共价键组装而成，其**胞内区均含有一个或多个免疫受体酪氨酸激活基序（immunoreceptor tyrosine-based activation motif, ITAM）**。TCR与CD3共同构成**TCR-CD3复合物**，实现了“特异性识别”与“信号转导”功能的偶联。

## 2. 第一信号枢纽：T细胞活化的第一信号与共受体
在T细胞与APC（[[抗原提呈细胞|APC]]）或靶细胞的接触中，TCR-CD3复合物提供**抗原特异性识别信号（第一信号）**。然而，此信号强度不足以完全激活T细胞，需要**共受体（Coreceptor）** 的辅助来稳定结合并增强信号。

*   **CD4分子**：单链跨膜蛋白。其胞外区第一个结构域（D1）可与[[HLAⅡ类分子]]的β2结构域非多态区结合。主要表达于辅助性T细胞（Helper T cell, Th）表面。
    *   **功能**：
        1.  **稳定黏附**：增强T细胞与表达MHC II类分子的APC之间的相互作用。
        2.  **信号增强**：将胞内酪氨酸激酶**Lck**募集至TCR-CD3复合物附近，磷酸化CD3链的ITAM，从而**放大活化信号**，提高TCR对抗原的敏感性。
        3.  **疾病关联**：是人类免疫缺陷病毒（HIV）的主要受体。

*   **CD8分子**：通常以α和β链组成的异二聚体形式存在。其α链可与[[HLAⅠ类分子]]的α3结构域结合。主要表达于细胞毒性T细胞（Cytotoxic T cell, Tc）表面。
    *   **功能**：与CD4类似，但结合MHC I类分子，主要辅助识别病毒感染细胞或肿瘤细胞，同样通过募集Lck来增强信号转导。

**关键双向链接**：CD4/CD8作为共受体，其功能的实现依赖于[[MHC分子]]的正确呈递，这直接连接了[[抗原加工与提呈]]的核心过程。

## 3. 活化“开关”与“刹车”：共刺激与共抑制分子
T细胞活化除第一信号外，还必须依赖于**第二信号**，即由APC表面的共刺激分子与T细胞表面的相应受体结合所提供的信号。此信号决定T细胞是充分活化、无能（Anergy）还是凋亡。

### 3.1 共刺激分子（Costimulatory Molecules）
提供“活化”或“促进”的正性第二信号。

*   **CD28**：
    *   **结构**：同源二聚体。
    *   **配体**：B7家族分子（主要包括B7-1/CD80， B7-2/CD86），主要表达于活化的APC（如[[树突状细胞|DC]]、活化的B细胞、巨噬细胞）。
    *   **功能**：结合B7后，通过其胞内区募集磷脂酰肌醇3激酶（PI3K）等，启动强烈的下游信号通路。**核心功能是促进IL-2等细胞因子的转录与合成，驱动T细胞克隆扩增和分化**，是初始T细胞（Naive T cell）活化的**必要条件**。

*   **CD154 (CD40L)**：
    *   **受体**：CD40，广泛表达于B细胞、DC、巨噬细胞等。
    *   **功能**：主要由活化的CD4+ T细胞表达。与B细胞上的CD40结合，是B细胞活化、类别转换、亲和力成熟和记忆B细胞形成的关键信号。同时，也能促进APC上调B7分子和分泌细胞因子，形成**正向反馈环路**，放大免疫应答。

### 3.2 共抑制分子（Co-inhibitory Molecules）/ 免疫检查点（Immune Checkpoint）
提供“抑制”或“刹车”的负性第二信号，对维持免疫耐受、防止自身免疫病和适时终止免疫应答至关重要。

*   **CD152 (CTLA-4)**：
    *   **配体**：与CD28相同，均为B7分子，但亲和力更高。
    *   **功能**：
        1.  **竞争性抑制**：CTLA-4与CD28竞争结合B7，但传递抑制性信号。
        2.  **主动抑制**：募集磷酸酶SHP-2，去磷酸化TCR信号通路中的关键分子。
        3.  **细胞外信号阻断**：通过反式内吞作用（Trans-endocytosis）移除APC表面的B7分子。
        **核心作用是限制T细胞的活化和增殖**，是免疫应答早期重要的“刹车”分子。

**网络调控视角**：T细胞的活化状态是[[CD28]]与CTLA-4（CD152）信号**动态平衡**的结果。肿瘤微环境中，肿瘤细胞常高表达PD-L1（B7-H1）等配体，与T细胞上的PD-1（CD279）结合，传递强烈的抑制信号，导致T细胞耗竭。这构成了**肿瘤免疫治疗（如PD-1/PD-L1抗体）** 的理论基础。

## 4. 稳定“握手”：黏附分子（Adhesion Molecules）
黏附分子介导细胞间或细胞与细胞外基质间的非特异性、可逆的黏附作用。它们在免疫细胞向炎症部位的**归巢（Homing）**、与靶细胞的**紧密接触**（形成免疫突触）以及信号转导的稳定中起决定性作用。

### 4.1 选择素家族（Selectin Family）
介导白细胞与血管内皮细胞间的**初始、可逆的滚动黏附**，是白细胞跨内皮迁移的第一步。
*   **结构特征**：均为Ⅰ型跨膜糖蛋白，其N端具有一个**C型凝集素样结构域**，可识别特定的糖基配体。
*   **主要成员**：
    *   **L-选择素 (CD62L)**：表达于大多数白细胞（除记忆T细胞亚群外）。其配体包括内皮细胞上的GlyCAM-1（[[GlyCAM-1]]）、CD34等。介导白细胞向外周淋巴结的归巢。
    *   **P-选择素 (CD62P)**：储存于内皮细胞的Weibel-Palade小体和血小板的α颗粒中。受组胺、凝血酶等刺激后迅速表达于细胞表面。配体为白细胞上的PSGL-1。介导炎症早期白细胞向损伤部位的募集。
    *   **E-选择素 (CD62E)**：由细胞因子（如TNF-α， IL-1）刺激后的内皮细胞合成并表达。配体为白细胞上的唾液酸化路易糖（sLe^x）等。在慢性炎症和免疫应答中发挥重要作用。

### 4.2 整合素家族（Integrin Family）
介导**稳固的细胞间黏附**，并参与双向信号传导（由外向内和由内向外）。
*   **结构特征**：由α和β亚基非共价连接形成的异二聚体。胞外区识别配体（如ICAM， VCAM， 纤连蛋白），胞内区通过接头蛋白（如Talin， Vinculin）与细胞骨架相连。
*   **重要成员（常与CD编号并用）**：
    *   **LFA-1 (CD11a/CD18， αLβ2整合素)**：配体为ICAM-1 (CD54)， ICAM-2等。是T细胞与APC/靶细胞形成**免疫突触**的核心黏附分子，极大增强[[CD2]]与CD58的相互作用。
    *   **VLA-4 (CD49d/CD29， α4β1整合素)**：配体为VCAM-1 (CD106)和纤连蛋白。参与淋巴细胞、单核细胞等向炎症部位的迁移。

### 4.3 免疫球蛋白超家族（Immunoglobulin Superfamily, IgSF）
此类分子胞外区具有一个或多个Ig样结构域。
*   **重要成员**：
    *   **CD2**：配体为CD58 (LFA-3)。[[CD2]]与CD58的结合是早期T细胞与APC接触的重要途径，有助于稳定后续的TCR-MHC相互作用。
    *   **ICAM-1 (CD54)** 和 **VCAM-1 (CD106)**：是整合素LFA-1和VLA-4的配体，在活化的内皮细胞上高表达，介导白细胞的牢固黏附和跨内皮迁移。
    *   **MHC分子**：也属于IgSF，其抗原提呈功能已在前文阐述。

**关键概念：免疫突触（Immunological Synapse）**：T细胞与APC接触面形成的超分子激活簇。外圈由LFA-1/ICAM-1等黏附分子构成**外周黏附环（pSMAC）**，稳定细胞接触；中心圈由TCR-CD3-pMHC复合物及CD28/B7等共刺激分子构成**中央超分子激活簇（cSMAC）**，进行高效的信号传递。黏附分子是构建这一精密结构的“骨架”。

## 5. 总结与整合
下表总结了关键分子及其核心功能，体现了它们在免疫应答网络中的协同作用：

| 分子类别 | 代表分子 (CD) | 主要配体/受体 | 核心免疫功能 | 功能关键词 |
| :--- | :--- | :--- | :--- | :--- |
| **抗原识别复合物** | TCR-CD3 | MHC-抗原肽 | 产生抗原特异性第一信号 | **识别**、**信号启动** |
| **共受体** | CD4 / CD8 | MHC II / MHC I | 稳定结合，增强第一信号 | **稳定**、**信号放大** |
| **共刺激分子** | CD28 (CD28) | B7 (CD80/86) | 提供促活化的第二信号，驱动增殖分化 | **活化**、**扩增** |
| **共抑制分子** | CTLA-4 (CD152) | B7 (CD80/86) | 竞争性抑制活化，限制免疫应答 | **刹车**、**耐受** |
| | PD-1 (CD279) | PD-L1/PD-L2 | 抑制T细胞功能，诱导耗竭 | **耗竭**、**肿瘤逃逸** |
| **黏附分子** | LFA-1 (CD11a/CD18) | ICAM-1 | 介导稳固细胞接触，形成免疫突触 | **黏附**、**突触形成** |
| | L-选择素 (CD62L) | GlyCAM-1 | 介导淋巴细胞归巢至淋巴结 | **滚动**、**归巢** |
| | CD2 | CD58 (LFA-3) | 早期辅助性T-APC黏附 | **辅助黏附** |

**结论**：CD分子、共刺激分子和黏附分子共同构成了免疫细胞间**信息交流的“分子语言系统”**。从TCR-CD3复合物的精密抗原识别，到CD4/CD8共受体的信号增强，再到CD28/CTLA-4等共刺激/抑制分子对活化状态的“油门”与“刹车”式调控，最后依赖整合素和选择素等黏附分子实现稳定的细胞接触和定向迁移，这些分子在时序和空间上精密协作，确保了免疫应答**特异、适度、有效**地启动、执行与终止。对它们的深入理解是掌握适应性免疫调控、理解免疫病理机制（如自身免疫、肿瘤逃逸）以及开发免疫治疗策略（如单抗、CAR-T）的基石。
