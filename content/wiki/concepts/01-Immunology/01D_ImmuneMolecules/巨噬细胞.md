# 巨噬细胞 (Macrophage)

> [!info] 细胞概述
> **类型**: 免疫细胞（单核吞噬细胞系统）
> **来源**: 骨髓造血干细胞 → 单核细胞 → 巨噬细胞
> **功能**: 吞噬、抗原呈递、免疫调节
> **分布**: 全身各组织

---

## 1. 概述

[[巨噬细胞]]是先天免疫系统的核心效应细胞，具有强大的吞噬、杀菌和抗原呈递能力。巨噬细胞在[[宿主-病原体互作]]中发挥关键作用。

### 1.1 巨噬细胞类型

| 类型 | 分布 | 功能 |
|-----|------|------|
| **组织驻留巨噬细胞** | 各组织 | 组织稳态、免疫监视 |
| **单核细胞来源巨噬细胞** | 炎症部位 | 炎症反应、病原清除 |
| **库普弗细胞** | 肝脏 | 清除血液病原体 |
| **小胶质细胞** | 中枢神经系统 | 神经免疫 |
| **肺泡巨噬细胞** | 肺 | 清除吸入病原体 |
| **破骨细胞** | 骨 | 骨重塑 |

### 1.2 巨噬细胞极化

| 表型 | 诱导因子 | 功能 | 标志物 |
|-----|---------|------|-------|
| **M1 (经典激活)** | IFN-γ, LPS | 促炎、杀菌 | iNOS, TNF-α, IL-1β |
| **M2 (替代激活)** | IL-4, IL-13 | 抗炎、组织修复 | Arg1, CD206, IL-10 |

**详细**: [[巨噬细胞极化]]

## 3. 巨噬细胞功能

### 3.1 吞噬作用

**吞噬过程**:
1. **识别**: 受体识别病原体
2. **附着**: 病原体附着于细胞表面
3. **内化**: 形成吞噬体
4. **成熟**: 吞噬体酸化
5. **杀伤**: 吞噬溶酶体形成
6. **消化**: 酶降解病原体

**杀伤机制**:
- **活性氧 (ROS)**: O₂⁻, H₂O₂, HOCl
- **活性氮 (RNS)**: NO, ONOO⁻
- **抗菌肽**: 防御素、溶菌酶
- **水解酶**: 组织蛋白酶、核酸酶

**详细**: [[吞噬作用]]

### 3.2 抗原呈递

**过程**:
1. 病原体降解为肽段
2. 肽段与 MHC-II 结合
3. MHC-II-肽复合物呈递至细胞表面
4. CD4⁺ T 细胞识别

**相关分子**:
- [[MHC-II]]: HLA-DR, HLA-DP, HLA-DQ
- [[共刺激分子]]: CD80, CD86
- [[wiki/concepts/immunology/604细胞因子/细胞因子]]: IL-12, IL-6

**详细**: [[抗原呈递]]

### 3.3 免疫调节

| 因子 | 类型 | 功能 |
|-----|------|------|
| [[TNF-α]] | 促炎 | 炎症反应、细胞凋亡 |
| [[IL-1β]] | 促炎 | 发热、炎症 |
| [[IL-6]] | 促炎 | 急性期反应 |
| [[IL-12]] | 促炎 | Th1 极化 |
| [[IL-10]] | 抗炎 | 抑制炎症 |
| [[TGF-β]] | 抗炎 | 免疫抑制、组织修复 |
| [[wiki/concepts/immunology/604细胞因子/趋化因子]] | 招募 | 免疫细胞招募 |

## 4. 巨噬细胞与沙门氏菌互作

### 4.1 感染过程

```
沙门氏菌
    ↓
识别与附着 (TLR, FcγR)
    ↓
吞噬 (形成吞噬体)
    ↓
┌─────────────────────────────────┐
│  正常清除                    免疫逃逸  │
│      ↓                        ↓      │
│  吞噬溶酶体融合           SCV形成    │
│      ↓                   (T3SS-2)   │
│  杀伤与降解                      ↓    │
│                            存活与复制  │
│                                 ↓    │
│                            SIF形成    │
│                                 ↓    │
│                            细菌播散   │
└─────────────────────────────────┘
```

### 4.2 沙门氏菌逃逸机制

| 机制 | 分子基础 | 效应 |
|-----|---------|------|
| **SCV形成** | SifA, SseF, SseG | 吞噬体内生存 |
| **抑制吞噬溶酶体融合** | SifA | 避免降解 |
| **抵抗ROS** | SodA, KatG | 抵抗氧化杀伤 |
| **抵抗RNS** | HmpA | 抵抗氮化杀伤 |
| **抑制NF-κB** | AvrA | 抗炎 |
| **调节细胞因子** | SseL | 免疫调节 |

**详细**: [[沙门氏菌胞内存活机制]]

### 4.3 巨噬细胞应答

| 应答 | 机制 | 效应 |
|-----|------|------|
| **炎症反应** | NF-κB 激活 | 细胞因子产生 |
| **自噬** | 捕获胞质细菌 | 细菌清除 |
| **细胞焦亡** | 炎症小体激活 | 细胞死亡、炎症 |
| **凋亡** | 线粒体途径 | 细胞死亡 |

**详细**: [[巨噬细胞应答]]

### 5.1 巨噬细胞培养

| [[RAW264.7]] | 小鼠 | 易培养、常用 |

| [[U937]] | 人 | 需 PMA 分化 |
| **BMDM** | 骨髓 | 原代、生理相关 |

**详细**: [[巨噬细胞培养]]

### 5.2 感染实验

**基本步骤**:
1. 巨噬细胞培养至适当密度
2. 加入细菌 (MOI 1-100)
3. 孵育 30-60 分钟
4. 洗去胞外细菌
5. 加入庆大霉素杀灭胞外细菌
6. 不同时间点收集细胞
7. 裂解细胞，计数 CFU

**详细**: [[巨噬细胞感染实验]]

| **细胞因子** | ELISA、RT-qPCR | 免疫应答 |
