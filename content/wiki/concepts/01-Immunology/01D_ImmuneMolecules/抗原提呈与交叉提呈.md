# 抗原提呈的分子机制与MHC限制性 (Molecular Mechanisms of Antigen Presentation and MHC Restriction)

**核心概念**：适应性免疫应答的启动，依赖于抗原提呈细胞（APC）将抗原加工处理，并以抗原肽-MHC分子复合物的形式展示于细胞表面，供T细胞识别。这一过程具有严格的**MHC限制性 (MHC Restriction)**，即T细胞受体（TCR）必须同时识别抗原肽和自身MHC分子，才能被有效激活。

## 1. 引言与核心分子：MHC (Introduction & Key Molecule: MHC)

[[主要组织相容性复合体 (Major Histocompatibility Complex, MHC)]] 是编码一组关键免疫分子的基因群，在人类称为[[人类白细胞抗原复合体 (HLA complex)]]，位于**6号染色体**短臂（6p21.31），跨度约3600kb，包含224个基因座。其核心产物是**MHC分子**，分为两大类：

- **MHC I 类分子 (MHC class I)**:  由 α链（多态性）和 β₂微球蛋白（β₂m，非多态性）组成。α链包含三个胞外结构域（α1, α2, α3）。
- **MHC II 类分子 (MHC class II)**:  由 α链和 β链以非共价键结合而成，每条链各有两个胞外结构域（α1, α2; β1, β2）。

两者均在细胞膜外形成一个**抗原肽结合槽 (Peptide-binding groove)**，用于结合并展示加工后的抗原肽。

```
+------------------+          +------------------+
|    MHC I 类分子   |          |   MHC II 类分子   |
|                  |          |                  |
|  α1+α2: 抗原肽槽 |          |  α1+β1: 抗原肽槽  |
|  结合8-10aa肽    |          |  结合12-18aa肽   |
|  α3: 结合CD8     |          |  α2+β2: 结合CD4  |
|  β2m: 稳定结构   |          |                  |
+--------|---------+          +--------|---------+
         |                             |
     细胞膜 (Cell Membrane)         细胞膜
```

**MHC分子的显著特性是其高度的多态性 (Polymorphism)**，即在同一基因位点上存在大量等位基因变异。这由**平衡选择 (Balancing selection)** 等进化压力维持，其意义在于确保种群能够提呈种类繁多的病原体抗原肽，增强群体免疫力，但同时也是同种异体移植排斥反应的根本原因。

## 2. 抗原提呈的两大经典途径 (The Two Classical Pathways of Antigen Presentation)

抗原根据其来源和性质，被导入不同的细胞内加工途径，最终由不同的MHC分子提呈给特定的T细胞亚群。

### 2.1 MHC I 类途径 (MHC Class I Pathway)：提呈内源性抗原，激活CD8⁺ T细胞

此途径主要提呈**内源性抗原 (Endogenous antigens)**，如病毒感染细胞内合成的病毒蛋白、肿瘤细胞内突变蛋白等。

**核心流程：**

1.  **抗原加工 (Antigen Processing)**：
    - 内源性抗原在胞浆中被**蛋白酶体 (Proteasome)** 降解成短肽（8-10个氨基酸）。免疫性蛋白酶体（含LMP2, LMP7, MECL-1亚基）更擅长产生适合MHC I结合的肽段。
    - 抗原处理相关转运蛋白 **TAP (Transporter Associated with Antigen Processing)** 位于内质网膜上，将胞浆中的抗原肽主动转运至内质网腔 (ER lumen)。
2.  **肽-MHC I 复合物组装 (Peptide-MHC I Complex Assembly)**：
    - 在内质网中，新合成的MHC I α链与伴侣分子（如钙联蛋白）结合，直到β₂m结合上来。
    - TAP转运的肽段，经过**内质网氨肽酶 (ERAP)** 的进一步修剪，与MHC I分子在**伴侣蛋白复合物 (如tapasin)** 的辅助下结合。只有高亲和力的肽段才能稳定MHC I分子，防止其被降解。
3.  **转运与提呈 (Transport and Presentation)**：
    - 稳定的肽-MHC I复合物经高尔基体转运至细胞膜表面，提呈给**CD8⁺ T细胞**（[[单阳性细胞 (SP细胞)]]的一种）。

**[[交叉提呈 (Cross-presentation)]]** 是一个重要的例外：某些**抗原提呈细胞 (APC)**（主要是树突状细胞）能将**外源性抗原**通过MHC I类途径提呈给CD8⁺ T细胞。这对于启动针对病毒（如疱疹病毒、HIV）或肿瘤的CTL免疫应答至关重要，因为专职APC（如DC）感染病毒或直接接触所有肿瘤细胞的可能性较低。

### 2.2 MHC II 类途径 (MHC Class II Pathway)：提呈外源性抗原，激活CD4⁺ T细胞

此途径主要提呈**外源性抗原 (Exogenous antigens)**，如细菌、寄生虫等被APC吞噬的胞外病原体。

**核心流程：**

1.  **抗原加工 (Antigen Processing)**：
    - 外源性抗原被APC（如巨噬细胞、B细胞、树突状细胞）通过吞噬、吞饮或受体介导的内吞作用摄入，形成**内体 (Endosome)**。
    - 内体逐步酸化，与**溶酶体 (Lysosome)** 融合，其中的酸性蛋白酶（如组织蛋白酶）将抗原降解为较大的肽段（12-18个氨基酸）。
2.  **MHC II 分子的合成与转运 (Synthesis and Transport of MHC II)**：
    - 新合成的MHC II分子在内质网中，其抗原肽槽被**恒定链 (Invariant chain, Ii, CD74)** 的**CLIP (Class II-associated invariant chain peptide)** 区域占据，阻止其过早结合内源性肽段。
    - Ii链还引导MHC II分子离开内质网，经高尔基体转运至富含蛋白酶的**MHC II 类区室 (MIIC)**。
3.  **肽-MHC II 复合物组装 (Peptide-MHC II Complex Assembly)**：
    - 在酸性的MIIC中，Ii链被逐步降解，仅留下CLIP片段。
    - **HLA-DM** 分子发挥关键的肽编辑功能：它催化CLIP从MHC II分子上解离，并促进抗原肽的结合。只有高亲和力的肽段能稳定MHC II分子。
4.  **转运与提呈 (Transport and Presentation)**：
    - 稳定的肽-MHC II复合物被转运至细胞膜表面，提呈给**CD4⁺ T细胞**（[[单阳性细胞 (SP细胞)]]的另一种）。

**两条途径的流程对比图：**

## 3. MHC限制性 (MHC Restriction)

**MHC限制性**是指T细胞的**抗原受体 (TCR)** 在识别抗原时，必须同时识别由**特定MHC分子**提呈的抗原肽。这意味着：
1.  T细胞不仅识别抗原肽本身，还识别将其“装载”并展示出来的MHC分子。
2.  一个T细胞只能识别由**自身MHC分子**提呈的抗原（自身MHC限制性）。
3.  识别MHC I提呈抗原肽的T细胞通常是CD8⁺ T细胞，而识别MHC II提呈抗原肽的T细胞通常是CD4⁺ T细胞。CD4和CD8分子作为**共受体 (Co-receptor)**，分别与MHC II的β2结构域和MHC I的α3结构域结合，稳定TCR-肽-MHC三元复合物，并参与启动T细胞活化信号。

```
   TCR (T细胞受体)
   /        \
  /          \
 识别抗原肽   识别MHC分子 (α1/α2 或 α1/β1 螺旋)
  \          /
   \________/
        |
  CD8共受体结合MHC I (α3) 或 CD4共受体结合MHC II (β2)
        |
    信号转导 -> T细胞活化
```

**MHC限制性的意义**：
- **免疫监视的精准性**：确保T细胞只攻击展示异常抗原（如病毒肽）的“自身”细胞，而非随机攻击。
- **胸腺选择的基础**：在T细胞发育过程中，只有那些能以适当亲和力识别自身MHC分子的T细胞才能存活（阳性选择），而那些对自身抗原肽-MHC复合物反应过强的T细胞则被清除（阴性选择），从而形成既能识别外来抗原又对自身免疫耐受的T细胞库。

## 4. 不同类型APC与提呈特化的意义 (Significance of Different APCs)

并非所有细胞都是专职APC。
- **专职APC (Professional APCs)**：包括**树突状细胞 (DC)**、**巨噬细胞 (Macrophages)** 和 **B细胞**。它们**组成性表达MHC II类分子和共刺激分子 (如B7)**，是启动初始T细胞应答的关键。DC是最强大的专职APC。
- **有核细胞**：几乎所有有核细胞都表达MHC I类分子，从而能够向CD8⁺ T细胞提呈内源性抗原（如病毒肽），这使得CTL能够监视和清除任何类型的病毒感染细胞或肿瘤细胞。
- **B细胞的独特性**：其BCR能特异性捕获低浓度抗原，并通过MHC II途径高效提呈给CD4⁺ T细胞，从而获得T细胞的“帮助”，这是体液免疫应答的核心环节。

## 5. 临床意义 (Clinical Significance)

- **移植排斥反应 (Transplant Rejection)**：供体与受体MHC分子的差异是移植排斥的根本原因。MHC的高度多态性导致难以找到完全匹配的供体。
- **自身免疫病 (Autoimmune Disease)**：特定的HLA等位基因与多种自身免疫病（如强直性脊柱炎与HLA-B27，1型糖尿病与HLA-DR3/DR4）强相关，提示这些MHC分子可能异常提呈自身抗原肽。
- **疫苗设计 (Vaccine Design)**：了解抗原提呈途径有助于设计更有效的疫苗。例如，旨在激活CTL的疫苗需要考虑如何将抗原导入MHC I途径（如使用病毒载体、交叉提呈诱导策略）。
- **肿瘤免疫治疗 (Tumor Immunotherapy)**：肿瘤细胞常通过下调MHC I表达来逃逸CTL攻击。免疫检查点抑制剂等疗法的作用基础之一，是恢复T细胞对肿瘤抗原-MHC复合物的识别和攻击能力。
