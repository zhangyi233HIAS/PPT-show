# 固有免疫：基本概念、组成与功能
# Innate Immunity: Fundamental Concepts, Components, and Functions

## 1. 引言：免疫系统概览
[[免疫]]系统是机体防御的基石。它的核心任务是识别并清除“非己”（non-self）物质，如病原体（pathogens）和突变细胞，同时维持对自身组织的耐受（tolerance）。这一复杂的防御网络主要由两大分支协同构成：**[[固有免疫]]（Innate immunity）** 与 **[[适应性免疫]]（Adaptive immunity）**。本笔记聚焦于固有免疫系统，它是抵御入侵者的**第一道，且反应迅速的防线**。

```
+-----------------+       +----------------------+
|     免疫系统      |       |                      |
| (Immune System) +------>| 协同防御网络          |
+-----------------+       | (Collaborative        |
                          |  Defense Network)      |
            +-------------+------------------------+
            |                                     |
    +-------v-------+                   +---------v---------+
    |  [[固有免疫]]    |                   | [[适应性免疫]]     |
    | (Innate)      | <--- 桥梁与启动 ---> | (Adaptive)       |
    | 快速、非特异性  |     (抗原提呈等)      | 缓慢、特异性、记忆 |
    +---------------+                   +-------------------+
```

## 2. 固有免疫的分期与核心特点
### 2.1 应答分期
固有免疫并非单一的即时反应，而是根据感染后的时间动态演进：
*   **即刻固有免疫应答（Immediate innate immune response）**：发生在感染后 **==0⁓4小时==**。主要由预先存在的物理化学屏障（如皮肤、黏膜）和组织驻留的细胞（如巨噬细胞）执行，无需新蛋白合成。
*   **早期诱导固有免疫应答（Early induced innate immune response）**：发生在感染后 **==4⁓96小时==**。需要通过模式识别受体（PRRs）识别病原体相关分子模式（PAMPs），从而激活信号通路，合成并释放大量效应分子（如细胞因子、急性期蛋白），并招募更多的免疫细胞至感染部位。

### 2.2 核心特点
*   **先天具备（Genetically determined）**：由遗传基因编码，出生时即已具备完整功能，无需经历抗原特异性克隆扩增。
*   **模式识别（Pattern recognition）**：通过胚系基因编码的**模式识别受体（Pattern recognition receptors, PRRs）** 识别病原微生物共有的、进化上保守的分子结构——**病原体相关分子模式（Pathogen-associated molecular patterns, PAMPs）**，以及内源性危险信号——**损伤相关分子模式（Damage-associated molecular patterns, DAMPs）**。这是一种“对一类而非一个”的识别策略。
*   **无免疫记忆（No immunological memory）**：应答模式相对固定，再次遇到相同病原体时，反应强度和速度无显著增强。（**训练免疫**（Trained immunity）是近年发现的固有免疫细胞功能可塑性现象，是这一经典概念的例外）。
*   **效应快速且广泛（Rapid and broad-spectrum）**：能够在病原体入侵后数分钟至数小时内启动，提供即时保护，作用范围覆盖多种病原体。

## 3. 固有免疫的组成
固有免疫系统由**物理化学屏障**、**细胞组分**和**体液/可溶性因子**三大部分构成。

### 3.1 物理化学屏障 (Physical and Chemical Barriers)
*   **物理屏障**：皮肤（皮肤黏膜屏障，[[皮肤免疫]]）和与外界相通的腔道内表面的黏膜上皮。其完整性是关键。
*   **化学屏障**：分泌物（如汗液中的乳酸、胃酸、泪液中的溶菌酶、呼吸道黏液）中的抗菌物质。
*   **微生物屏障**：正常菌群（[[微生物组]]）通过竞争性排斥（competitive exclusion）抑制病原体定植。

### 3.2 细胞组分 (Cellular Components)
这些细胞均属于固有免疫细胞（Innate immune cells），它们通常表面表达PRRs，并直接执行清除功能或调节反应。

| 细胞类型 (Cell Type)          | 英文术语                      | 主要功能 (Key Functions)                                                                                               | 关键标志物/特点                                                                 |
| :---------------------------- | :---------------------------- | :--------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |

| **中性粒细胞 (Neutrophil)**   | Neutrophil                    | **最丰富的循环白细胞**。快速招募至感染部位，执行吞噬和**脱颗粒**（degranulation），释放活性氧（ROS）和抗菌肽。形成**中性粒细胞胞外诱捕网（NETs）**。 | 寿命短（数小时至数天），CD15+ (人)，多形核。                                     |

### 3.3 体液/可溶性因子 (Humoral/Soluble Factors)
*   **补体系统（Complement system）**：由一系列血浆蛋白组成的酶促反应链（经典、旁路、凝集素途径）。功能包括：**调理作用**（opsonization，标记病原体以促进吞噬）、**细胞溶解**（形成膜攻击复合物MAC）、**趋化/促炎**（产生过敏毒素C3a, C5a）。
*   **细胞因子（Cytokines）**：细胞间信号蛋白，如：
    *   **白细胞介素-1β (IL-1β)**, **肿瘤坏死因子-α (TNF-α)**：促炎，诱导发热。
    *   **白细胞介素-6 (IL-6)**：诱导急性期蛋白产生。
    *   **干扰素-α/β (IFN-α/β)**：I型干扰素，是**抗病毒**的核心因子。
    *   **趋化因子（如IL-8/CXCL8）**：吸引中性粒细胞等至感染部位。
*   **急性期蛋白（Acute-phase proteins）**：由肝脏在IL-6等刺激下合成，如**C反应蛋白（CRP）**、**甘露糖结合凝集素（MBL）**，可激活补体、调理病原体。
*   **抗菌肽（Antimicrobial peptides）**：如**防御素（defensins）**，可直接破坏微生物细胞膜。

## 4. 固有免疫的功能
固有免疫系统通过高度协调的机制执行四大核心功能：

### 4.1 防御功能 (Defense Function)
这是最经典的功能。通过**物理屏障**阻挡、**细胞吞噬**（neutrophils, macrophages）、**细胞毒作用**（NK cells）、**补体溶解**以及**抗菌肽/细胞因子**的直接杀伤，快速清除入侵的病原微生物。

### 4.2 监视与清除功能 (Surveillance and Clearance Function)
NK细胞和巨噬细胞等持续监视体内环境，通过识别“丧失自我”（NK细胞）或“改变自我”（巨噬细胞识别凋亡细胞）的信号，及时清除**病毒感染细胞**、**早期肿瘤细胞**以及体内产生的**凋亡细胞**（防止自身抗原暴露引发自身免疫）。这一过程对维持内稳态至关重要。

### 4.3 调节与启动适应性免疫的功能 (Regulation and Initiation of Adaptive Immunity)
这是固有免疫作为“导师”的核心角色。
*   **抗原提呈（Antigen presentation）**：树突状细胞等专业APC将加工后的抗原肽-MHC II类分子复合物提呈给初始T细胞（naïve T cells），并提供共刺激信号（CD80/86-CD28），这是**启动特异性适应性免疫应答的必备条件**。
*   **细胞因子环境塑造（Cytokine milieu polarization）**：固有免疫细胞根据识别的病原体类型，分泌不同的细胞因子组合，**定向诱导**初始CD4+ T细胞分化为不同的效应亚群（如Th1, Th2, Th17, Treg），从而定制最适合清除该病原体的适应性免疫应答类型。

### 4.4 组织修复与稳态维持 (Tissue Repair and Homeostasis)
在感染或损伤后期，巨噬细胞（特别是M2型）等会转向分泌促进修复的因子（如TGF-β, IL-10, VEGF），参与清除碎片、促进血管生成和成纤维细胞增殖，最终实现**组织重塑**和功能恢复。

```
固有免疫功能网络 (Functional Network of Innate Immunity)
        +-----------------+
        |  物理化学屏障    |  (阻挡)
        +--------+--------+
                 |
    +------------v------------+      (早期清除)
    | 细胞吞噬/杀伤 (NK, Mac) | <---  PAMPs/DAMPs识别
    +------------+------------+
                 | (调节与启动)
    +------------v------------+
    | APC (DC) 抗原提呈       | +---> [[适应性免疫]]启动
    | 细胞因子环境塑造        |
    +------------+------------+
                 | (协同与支持)
    +------------v------------+
    | 促进组织修复与稳态      | <---  M2 Macrophages, ILCs
    +-------------------------+
```

## 5. 总结与展望
固有免疫系统是机体免疫防御的基石和快速反应部队。它不仅直接清除病原体，更通过精密的模式识别机制，向[[适应性免疫]]系统“汇报敌情”并“下达指令”，从而启动高度特异、持久有效的免疫应答。近年来，对**固有淋巴样细胞（ILCs）**、**训练免疫（Trained immunity）** 以及固有免疫在**代谢性疾病**和**神经免疫**中作用的研究，极大地拓展了我们对这一古老而基础防御系统的认识，揭示其广泛而深远的生理与病理意义。

[[固有免疫]]与[[适应性免疫]]的界限并非绝对，两者在细胞（如NK细胞、γδ T细胞）、分子和功能层面存在着广泛的交叉与对话，共同构成了一个完整、动态、可塑的免疫防御网络。
