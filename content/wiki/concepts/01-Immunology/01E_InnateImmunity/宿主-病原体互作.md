# 宿主-病原体互作 (Host-Pathogen Interaction)

> [!info] 定义
> **宿主-病原体互作** 是病原体与宿主之间的复杂相互作用，包括病原体的入侵、定植、免疫逃逸，以及宿主的免疫应答和防御机制。

---

## 1. 概述

[[宿主-病原体互作]]是感染性疾病的核心研究领域。理解这些相互作用对于开发新的诊断、治疗和预防策略至关重要。

### 1.1 互作类型

| 类型 | 描述 | 示例 |
|-----|------|------|
| **共生** | 双方互利 | 肠道菌群 |
| **共栖** | 一方受益，另一方不受影响 | 皮肤菌群 |
| **寄生** | 一方受益，另一方受损 | 病原菌感染 |
| **致病** | 导致疾病 | 沙门氏菌感染 |

### 1.2 互作阶段

```
病原体暴露
    ↓
粘附与定植
    ↓
入侵与穿透
    ↓
免疫逃逸
    ↓
增殖与扩散
    ↓
组织损伤
    ↓
疾病表现
    ↓
免疫清除 或 慢性感染
```

## 4. 沙门氏菌-宿主互作

### 4.1 感染过程

```
沙门氏菌摄入
    ↓
胃酸屏障 (酸耐受系统)
    ↓
小肠 (菌毛粘附)
    ↓
上皮细胞入侵 (T3SS-1)
    ↓
┌─────────────────────────────────┐
│  肠道感染              全身感染    │
│      ↓                    ↓      │
│  炎症反应           M细胞摄取    │
│  腹泻                   ↓        │
│                   派尔集合淋巴结  │
│                        ↓        │
│                   巨噬细胞吞噬    │
│                        ↓        │
│                   SCV形成 (T3SS-2)│
│                        ↓        │
│                   血液播散        │
│                   ↓          ↓  │
│                  肝脏       脾脏 │
└─────────────────────────────────┘
```

### 4.2 组织特异性互作

| 组织 | 病原体策略 | 宿主应答 | 关键基因 |
|-----|-----------|---------|---------|
| **肝脏** | SCV形成 | 巨噬细胞杀伤 | [[SPI-2]] |
| **脾脏** | SCV形成 | 免疫监视 | [[SPI-2]] |
| **肠道** | 上皮入侵 | 炎症反应 | [[SPI-1]] |
| **卵巢** | 特异代谢 | 待研究 | 待研究 |

### 4.3 巨噬细胞-沙门氏菌互作

**详细**: [[巨噬细胞-沙门氏菌-互作]]

**关键机制**:
1. **吞噬**: 巨噬细胞吞噬沙门氏菌
2. **SCV形成**: 沙门氏菌在吞噬体内生存
3. **免疫调节**: 沙门氏菌抑制巨噬细胞功能
4. **免疫逃逸**: 沙门氏菌逃避免疫清除

## 5. 研究方法

### 5.1 体外方法

| 方法 | 应用 | 优点 |
|-----|------|------|
| **细胞感染** | 细胞水平互作 | 简单、可重复 |
| **共培养** | 细胞间互作 | 生理相关 |
| **3D培养** | 组织水平 | 更接近体内 |

| **小鼠感染** | 整体互作 | 生理相关 |
| **组织病理** | 组织损伤 | 形态学 |
