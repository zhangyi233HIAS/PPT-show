# T细胞受体结构、信号转导与T细胞亚群功能

## 概述
T细胞是[[适应性免疫应答|适应性免疫]]的核心执行者，其功能的启动与执行高度依赖于**T细胞受体(T cell receptor, TCR)** 对抗原的特异性识别。TCR的结构决定了其识别的特异性，其介导的**信号转导(Signal transduction)** 决定了T细胞的活化、分化和效应命运。不同的信号背景与微环境指令促使初始T细胞(Naive T cell)分化为功能各异的**T细胞亚群(T cell subsets)**，从而精准调控免疫应答的类型、强度与持续时间。本笔记将系统整合TCR的结构基础、信号转导机制以及主要T细胞亚群的分化与功能。

---

## 第一部分：T细胞受体的结构与识别
### 1.1 TCR复合物的基本结构
TCR并非孤立存在，而是与**CD3复合物**共同组成**TCR-CD3复合物**，是T细胞抗原识别与信号转导的功能单元。
- **抗原识别亚单位：TCR异二聚体**
    - **分类**：
        - **TCRαβ**：由α链和β链组成，是外周血中绝大多数T细胞(>95%)的TCR形式，负责识别由**主要组织相容性复合体(Major Histocompatibility Complex, MHC)** 分子提呈的抗原肽。
        - **TCRγδ**：由γ链和δ链组成，主要分布于上皮和黏膜组织，可直接识别未经MHC提呈的磷酸化抗原、脂类抗原等，具有类似[[固有免疫]]的快速应答特性。
    - **链结构**：每条链均包含一个可变区(V)和一个恒定区(C)，通过二硫键连接。**互补决定区(Complementarity Determining Regions, CDRs)**，特别是CDR3，构成了与抗原肽-MHC(pMHC)复合物接触的关键界面，赋予了TCR极高的多样性。
- **信号传导亚单位：CD3复合物**
    - 由γε、δε和ζζ(或ζη)三种异二聚体非共价结合于TCR胞内区。
    - **胞内信号基序**：每条CD3链的胞内段均含有一个或多个**免疫受体酪氨酸活化基序(Immunoreceptor Tyrosine-based Activation Motif, ITAM)**。ITAM是信号转导的起始平台。
    ```
    (示意图：TCR-CD3复合物)
                    ┌─────────────┐
                    │   抗原肽-MHC │
                    └──────┬──────┘
                           │ 特异性结合
                    ┌──────┴──────┐
                    │ TCRαβ (或γδ) │  <-- 抗原识别
                    │  V    C     │
                    └──────┬──────┘
                           │ 非共价结合
        ┌──────────────────┼──────────────────┐
        │                  │                  │
    ┌───┴───┐          ┌───┴───┐          ┌───┴───┐
    │  CD3γε │          │  CD3δε │          │  ζζ   │
    │  ITAM  │          │  ITAM  │          │ 3x ITAM│
    └───────┘          └───────┘          └───────┘
    ↑______信号传导核心______↑
    ```
- **共受体(Co-receptor)**：
    - **CD4**：表达于辅助性T细胞，胞内结合**酪氨酸激酶Lck**，能与MHC-II类分子β2结构域结合，稳定TCR-pMHC相互作用，并将Lck带至CD3 ITAM附近。
    - **CD8**：表达于细胞毒性T细胞，同样结合Lck，与MHC-I类分子α3结构域结合。
- **共刺激分子(Co-stimulatory molecules)**：
    - T细胞的完全活化需要“双信号”。TCR识别pMHC提供**第一信号(抗原特异性信号)**，而**共刺激信号(第二信号)** 由T细胞表面的共刺激分子与APC上的配体结合提供。
    - **经典通路**：T细胞上的**CD28**与APC上的**B7-1(CD80)/B7-2(CD86)** 结合，传递关键的生存与增殖信号。缺乏共刺激信号的抗原识别可导致T细胞失能(Anergy)。

### 1.2 抗原识别的特异性
TCRαβ识别的是**抗原肽-MHC复合物(pMHC)**。这种识别具有严格的**MHC限制性(MHC restriction)**。
- **TCRαβ** 同时接触抗原肽的表位和MHC分子的多态性区域。
- **TCRγδ** 识别谱更广，可识别非肽类抗原，且多数无MHC限制性。

## 第二部分：TCR信号转导
TCR信号转导是一个高度动态、多阶段的生化级联反应，最终导致基因表达程序的改变。

### 2.1 信号起始与早期事件
1.  **TCR交联与Lck活化**：TCR识别pMHC并聚集，使共受体(CD4/CD8)携带的**Lck**激酶靠近CD3链的ITAM。
2.  **ITAM磷酸化**：活化的Lck磷酸化ITAM上的酪氨酸残基。
3.  **ZAP-70招募与活化**：磷酸化的ITAM招募并结合胞浆内的**ZAP-70**激酶。Lck进一步磷酸化并完全活化ZAP-70。
    ```
    [pMHC] → TCR/CD3聚集 → CD4/CD8-Lck靠近
            ↓
    Lck磷酸化ITAM (Y→pY)
            ↓
    ZAP-70-SH2结构域结合pITAM
            ↓
    Lck磷酸化活化ZAP-70
    ```

### 2.2 信号传导与平台搭建
活化的ZAP-70磷酸化关键的接头蛋白，如**LAT**和**SLP-76**，这些磷酸化的接头蛋白作为**信号转导平台(Signalosome)**，招募下游效应分子。
- **磷脂酶Cγ1(PLCγ1)通路**：
    - LAT招募PLCγ1，ZAP-70将其磷酸活化。
    - 活化的PLCγ1水解膜磷脂PIP2，产生**第二信使**：
        - **IP3**：结合内质网受体，释放Ca²⁺。胞内Ca²⁺浓度升高，激活钙调磷酸酶(Calcineurin)，后者使转录因子**NFAT**去磷酸化并入核。
        - **DAG**：留在膜上，激活蛋白激酶Cθ(PKCθ)，进而激活转录因子**NF-κB**。
- **Ras-MAPK通路**：
    - LAT/SHP-76复合物通过Grb2-SOS等接头蛋白激活小G蛋白Ras，启动MAPK级联反应(如ERK)，最终激活转录因子**AP-1**。
- **PI3K-Akt通路**：
    - CD28共刺激信号可强烈激活PI3K，产生PIP3，招募并激活Akt，促进细胞存活、代谢和增殖。

### 2.3 信号整合与转录调控
以上通路汇聚，共同激活**NFAT、NF-κB、AP-1**等核心转录因子。这些转录因子入核后，协同结合于关键基因(如IL-2、IFN-γ、细胞周期蛋白等)的启动子区域，启动T细胞活化、增殖、分化和效应功能相关的基因表达程序。
- **负性调控**：信号转导受到精密负调控，防止过度活化。例如：
    - **PD-1**：[[PD-1]]与配体PD-L1/PD-L2结合后，其胞内ITSM基序招募**SHP-2**磷酸酶，去磷酸化TCR信号分子(如ZAP-70、PLCγ1)，直接抑制TCR信号通路，是**免疫检查点**的核心。
    - **CTLA-4**：与CD28竞争结合B7分子，但传递抑制信号。

## 第三部分：T细胞亚群的分化与功能
初始CD4+ T细胞在TCR信号(抗原特异性)和细胞因子微环境(非特异性)的共同指令下，分化为功能特化的辅助性T细胞(Th)亚群。初始CD8+ T细胞分化为细胞毒性T淋巴细胞(CTL)。

### 3.1 CD4+ 辅助性T细胞(Th)亚群
| 亚群 | 关键诱导细胞因子 | 主要转录因子 | 效应细胞因子 | 核心功能 | 相关链接 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Th1** | IL-12, IFN-γ | **T-bet** | **IFN-γ**, TNF-α, IL-2 | 激活巨噬细胞，清除胞内病原体(病毒、胞内菌)，参与[[细胞免疫]]和迟发型超敏反应。 | [[细胞免疫]] |
| **Th2** | IL-4 | **GATA-3** | **IL-4, IL-5, IL-13** | 辅助[[骨髓依赖性淋巴细胞|B细胞]]产生抗体(尤其是IgE)，促进嗜酸性粒细胞、嗜碱性粒细胞活化，清除胞外寄生虫，参与过敏反应。 | [[体液免疫]] |
| **Th17** | TGF-β, IL-6, IL-23 | **RORγt** | **IL-17A/F, IL-22** | 招募和激活[[中性粒细胞]]，清除胞外细菌和真菌，在黏膜防御中起关键作用。过度活化与自身免疫病相关。 | [[中性粒细胞]] |
| **Tfh** | IL-6, IL-21, ICOS信号 | **Bcl-6** | **IL-21, IL-4** | 定位于**[[三级淋巴结构|三级淋巴结构(TLS)]]** 或次级淋巴器官生发中心，辅助B细胞进行亲和力成熟、类别转换和分化为记忆B细胞及浆细胞。 | [[三级淋巴结构]] |
| **Th9** | **TGF-β + IL-4** | PU.1, IRF4 | **IL-9** | 激活**[[肥大细胞]]**、嗜碱性粒细胞和固有淋巴样细胞，参与抗胞外寄生虫感染和过敏性炎症。 | [[Th9]] |
| **Th22** | TNF-α, IL-6 | **AHR** | **IL-22** | 作用于上皮细胞，促进增殖、修复和产生抗菌肽，参与皮肤和黏膜屏障的维持。 | |

### 3.2 CD8+ 细胞毒性T淋巴细胞(CTL)
- **分化与极化**：初始CD8+ T细胞的完全活化通常需要CD4+ T细胞的“许可”(通过细胞因子如IL-2，或通过激活DC)。活化后，在IL-2、I型干扰素等细胞因子作用下，分化为效应CTL。当TCR识别靶细胞表面pMHC-I后，CTL发生**[[CTL极化]]**。
- **效应机制**：
    1.  **穿孔素/颗粒酶途径**：极化后，CTL胞质颗粒向免疫突触定向释放。**穿孔素(Perforin)** 在靶细胞膜上形成孔道，**颗粒酶(Granzymes)** 由此进入细胞，激活 caspase 级联反应，诱导靶细胞凋亡。
    2.  **Fas/FasL途径**：CTL表面表达FasL，与靶细胞表面的Fas结合，同样诱导靶细胞凋亡。
- **功能**：特异性杀伤病毒感染细胞、肿瘤细胞及移植细胞，是[[细胞免疫]]的关键执行者。

### 3.3 调节性T细胞(Treg)
- **分类**：
    - **自然调节性T细胞(nTreg)**：在[[胸腺]]中由TCR识别自身抗原后分化，表型为**CD4+CD25+Foxp3+**。
    - **诱导型调节性T细胞(iTreg)**：外周初始CD4+ T细胞在**TGF-β**和**IL-2**诱导下分化，也表达Foxp3。
- **功能**：
    - **核心功能**：维持自身免疫耐受，抑制过度的免疫应答。
    - **机制**：
        1.  **分泌抑制性细胞因子**：如**IL-10, TGF-β, IL-35**。
        2.  **细胞接触依赖性抑制**：通过CTLA-4竞争性消耗APC上的B7分子，或通过颗粒酶B直接杀伤效应细胞。
        3.  **代谢干扰**：高表达CD25，竞争性消耗微环境中的IL-2，抑制效应T细胞增殖。
- **临床意义**：Treg功能缺陷与自身免疫病、过敏性疾病相关；肿瘤微环境中，肿瘤细胞可招募Treg，导致局部免疫抑制，是免疫治疗的障碍之一。

### 3.4 特殊分布的T细胞亚群
- **[[上皮内淋巴细胞(Intraepithelial lymphocyte, IEL)]]**：
    - **诱导型**：CD8αβ+ TCRαβ+ T细胞，由外周活化后归巢至上皮，具有经典CTL功能。
    - **自然型**：CD8αα+ TCRαβ+ 或 TCRγδ+ T细胞，在胸腺外或胸腺内以独特方式发育，直接识别上皮应激抗原，具有快速的细胞毒性和细胞因子分泌能力，是黏膜屏障的“哨兵”。
- **滤泡调节性T细胞(Tfr)**：表型与Tfh类似，但表达Foxp3。定位于生发中心，负调控Tfh和B细胞的活性，防止自身抗体产生。

## 结论与整合视角
从TCR的精密结构启动特异性识别，到复杂的信号网络解码与放大抗原信息，再到指令各种T细胞亚群分化为功能多样、相互制衡的效应与调节细胞，构成了一个逻辑严密、动态可调的免疫决策系统。
- **核心脉络**：**TCR特异性识别 → 信号转导与整合 → 基因表达程序重置 → 亚群分化与效应功能**。
- **双向调控**：免疫应答的效能不仅取决于Th1/CTL等效应细胞的活化，也受到Treg和PD-1等检查点分子的严格负调控。这种平衡的破坏是感染、自身免疫、肿瘤和移植排斥等疾病的共同病理基础。
- **临床意义**：深入理解此系统，为**免疫检查点抑制剂**(如抗PD-1抗体，解除T细胞抑制)、**CAR-T细胞疗法**(重塑TCR特异性)、**自身免疫病治疗**(增强Treg功能)等免疫干预策略提供了坚实的理论基础。
