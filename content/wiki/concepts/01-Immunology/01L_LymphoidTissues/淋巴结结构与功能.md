# **淋巴结：结构、微环境与免疫枢纽**

**英文**: Lymph Node: Structure, Microenvironment, and Immune Nexus
**摘要**: 淋巴结是次级淋巴器官中最具代表性的高度组织化结构，是适应性免疫应答启动的关键部位。其精密的空间分区为T细胞、B细胞、抗原提呈细胞及基质细胞提供了独特的微环境，使得抗原捕获、淋巴细胞归巢、活化、选择与效应分化得以高效有序地进行。

## **一、 组织结构概述**

淋巴结（Lymph Node, LN）呈豆形，由**结缔组织被膜**包裹，被膜深入实质形成**小梁**，构成支撑骨架。其内部可分为**皮质**、**副皮质区**和**髓质**三个功能区域，淋巴液从输入淋巴管流入，经滤过后从输出淋巴管流出，形成了具有方向性的细胞与抗原流。

```
    +------------------------------------------------------+
    |                      被膜 (Capsule)                   |
    |    输入淋巴管 (Afferent Lymphatic Vessel)             |
    |          ↓                                           |
    |  +--------------------------------------------------+|
    |  | 皮质 (Cortex)                ||                  ||
    |  | [浅层皮质] B细胞区           || [副皮质区] T细胞区||
    |  |  +--------+  +--------+     ||   大片弥散淋巴组织||
    |  |  |淋巴小结|  |淋巴小结|     ||   +高内皮微静脉+ ||
    |  |  |(生发中心)| |       |     ||   +------------+ ||
    |  |  +--------+  +--------+     ||                  ||

    |  |                 ↓            |                  ||
```

## **二、 组织结构详解与微环境**

### **2.1 皮质 (Cortex)**
位于被膜下方，富含B细胞。

#### **[[浅层皮质]] (Superficial Cortex / B细胞区 (B-cell Zone))**
- **组成**:
    - **[[淋巴小结]] (Lymphoid Follicles)**: 球形结构。未受抗原刺激时为**初级滤泡**，由静息的成熟[[骨髓依赖性淋巴细胞|B淋巴细胞]]构成。受抗原刺激后形成**次级滤泡**，其特征性结构为**[[生发中心]] (Germinal Center, GC)**。
    - **[[弥散淋巴组织]]**: 淋巴小结之间的区域，主要为B细胞。
- **微环境意义**:
    - 为B细胞的定居、增殖和初级分化提供了基础空间框架。
    - **滤泡树突状细胞 (Follicular Dendritic Cells, FDCs)** 在此形成网络，通过其Fc受体和补体受体长时间保留抗原-抗体复合物，对生发中心的B细胞选择至关重要。

#### **[[生发中心]] (Germinal Center, GC) —— 体液免疫的核心微环境**
次级淋巴小结的核心，是B细胞在抗原刺激后发生**克隆扩增**、**体细胞高频突变 (Somatic Hypermutation, SHM)**、**亲和力成熟 (Affinity Maturation)** 和**类别转换重组 (Class-Switch Recombination, CSR)** 的动态结构。
- **空间分区**:
    - **[[暗区]] (Dark Zone, DZ)**:
        - 组成: 密集、快速增殖的[[中心母细胞]] (Centroblasts)。
        - 功能: B细胞在此进行快速分裂和SHM，产生大量携带不同BCR亲和力突变的子代细胞。
        - 微环境: 主要由**成纤维网状细胞**样细胞（称为**暗区网状细胞**）支持，提供趋化因子CXCL12，引导中心母细胞定位。
    - **[[亮区]] (Light Zone, LZ)**:
        - 组成: 体积较小、排列疏松的[[中心细胞]] (Centrocytes)、**FDCs**和**滤泡辅助性T细胞 (T Follicular Helper Cells, Tfh)**。
        - 功能: 进行**选择**。中心细胞以其突变的BCR竞争结合FDCs表面的抗原，进而将抗原内吞、加工提呈给Tfh细胞。只有能有效结合抗原并向Tfh细胞提呈的中心细胞，才能获得Tfh细胞提供的生存信号（如CD40L， IL-21），免于凋亡。此过程即**亲和力成熟**。
        - 生存信号缺失或亲和力过低的中心细胞将在此凋亡，并被巨噬细胞清除。
    - **外套层 (Mantle Zone)**: 包绕生发中心的、由初始B细胞构成的区域。
- **输出**:
    - 成功经历选择的中心细胞可分化为：
        - **浆母细胞 (Plasmablasts)** → **长寿命浆细胞 (Long-lived Plasma Cells)**，迁移至骨髓或炎症部位，持续分泌高亲和力抗体。
        - **记忆B细胞 (Memory B Cells)**，分布于淋巴器官或循环中，提供长期免疫记忆。

#### **[[皮质淋巴窦]] (Cortical Sinuses)**
- **构成**: 包括紧贴被膜下方的**[[被膜下窦]] (Subcapsular Sinus)** 和沿小梁周围延伸的**[[小梁周窦]] (Peritrabecular Sinus)**。
- **功能**: 来自输入淋巴管的抗原和细胞首先流入被膜下窦。抗原可被窦内的**巨噬细胞**捕获、处理，或直接传递给FDCs和B细胞。淋巴细胞和抗原呈递细胞由此进入实质。

### **2.2 [[副皮质区]] (Paracortex / T细胞区 (T-cell Zone))**
- **位置与组成**: 位于皮质深层，介于皮质与髓质之间。为**大片**的**[[弥散淋巴组织]]**，是**T淋巴细胞**的主要定居区。
- **关键结构——[[高内皮微静脉]] (High Endothelial Venules, HEVs)**:
    - **特征**: 内皮细胞呈立方形，而非一般的扁平形。
    - **功能**: **淋巴细胞归巢**的特化通道。血液循环中的初始T细胞（和B细胞）通过HEVs上的地址素（如PNAd）与淋巴细胞上的归巢受体（如L-选择素）相互作用，以及趋化因子（如CCL19, CCL21）的吸引，穿越HEV进入淋巴结实质。
- **细胞组成**:
    - **T细胞** (主要为初始CD4+和CD8+ T细胞)。
    - **树突状细胞 (Dendritic Cells, DCs)**: 组织中的**未成熟DC**捕获抗原后，通过输入淋巴管迁移至淋巴结副皮质区，分化为**成熟DC**，高表达MHC分子和共刺激分子，是激活初始T细胞的最有效抗原提呈细胞。
    - **基质细胞**: **成纤维网状细胞 (Fibroblastic Reticular Cells, FRCs)** 形成导管网络，包裹T细胞和DC，并分泌IL-7、CCL19/CCL21等，维持T细胞存活和定位。

### **2.3 [[髓质]] (Medulla)**
由**[[髓索]]**和**[[髓窦]]**交错构成，是淋巴液汇入输出淋巴管的最后关口。

#### **[[髓索]] (Medullary Cords)**
- **外观**: 相互连接的**索条状**[[淋巴组织]]。
- **组成**: 含B细胞、T细胞、大量**浆细胞**和巨噬细胞。浆细胞是产生抗体的效应细胞，在此处大量聚集。
- **结构**: 可见**高内皮微静脉**，支持淋巴细胞再循环。

#### **[[髓窦]] (Medullary Sinuses)**
- **特点**: 结构与[[皮质淋巴窦]]相似，但更为**宽大**，腔内**巨噬细胞**丰富。
- **功能**: 具有极强的**滤过**功能。巨噬细胞吞噬清除病原体、细胞碎片等，对淋巴液进行“最后的净化”，最终洁净的淋巴液经输出淋巴管离开淋巴结。

## **三、 免疫功能整合**

淋巴结的结构是其功能的完美体现，实现了免疫应答的“时空有序性”。

1.  **抗原捕获与提呈**:
    - 抗原经输入淋巴管进入[[被膜下窦]]，被**巨噬细胞**或**FDCs**捕获。
    - 组织中的**未成熟DC**捕获抗原后，迁移至副皮质区，成为成熟DC，为激活T细胞做准备。

2.  **淋巴细胞归巢与区隔化**:
    - 初始T细胞通过**HEVs**进入**[[副皮质区]]**。
    - 初始B细胞也通过HEVs进入，但迅速迁移至**[[浅层皮质]]**的B细胞区。
    - 这种**区隔化**保证了T、B细胞在正确的位置与抗原和彼此相遇。

3.  **免疫突触与活化**:
    - 在**副皮质区**，成熟DC向初始T细胞提呈抗原肽-MHC复合物，提供第一信号；通过CD80/86-CD28等提供共刺激信号（第二信号），并在细胞因子环境下（第三信号），导致T细胞活化、增殖、分化。
    - 活化的**滤泡辅助性T细胞 (Tfh)** 前体迁移至B细胞滤泡边缘。

4.  **T-B细胞协作与生发中心反应**:
    - B细胞在[[浅层皮质]]识别抗原后，活化并迁移至滤泡间区，与Tfh细胞相互作用。
    - 获得T细胞帮助的B细胞进入滤泡，启动**[[生发中心]]**反应。
    - 在**[[暗区]]**发生SHM和增殖，在**[[亮区]]**经历基于抗原亲和力的选择，最终分化为**浆细胞**和**记忆B细胞**。这是产生高亲和力抗体和长效免疫记忆的核心过程。

5.  **效应细胞输出与免疫监视**:
    - 新生成的**效应T细胞**、**记忆T/B细胞**以及**浆细胞**，经**髓窦**过滤后，通过输出淋巴管离开淋巴结，进入血液循环，奔赴感染或炎症部位。
    - **长寿命浆细胞**可迁移至骨髓等生存微环境，持续产生抗体。

**结论**:
淋巴结并非简单的“过滤站”，而是一个高度动态的**免疫微环境生态系统**。其精确的空间架构，由**基质细胞网络**（FRCs， FDCs）与**可溶性因子**（细胞因子， 趋化因子）共同构建和维持，指导着免疫细胞的定向迁移、相互作用和命运决定。理解淋巴结的组织学与微环境，是解析适应性免疫应答精细调控机制的基础。
