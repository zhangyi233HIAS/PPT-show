# 脾的组织结构与免疫功能

**主题概述**
脾（Spleen）是人体最大的外周免疫器官和储血器官，位于左上腹。其核心功能在于 **“血液滤过”** 与 **“免疫应答”**，是连接固有免疫与适应性免疫的关键枢纽。与[[淋巴结]]不同，[[脾]]的免疫应答直接针对血液循环中的病原体。本笔记将系统阐述其独特的组织结构与对应的免疫学功能。

---

## 一、 脾的整体结构与组织学分区

从剖面观察，脾的实质可分为颜色不同的两个区域，此为理解其功能的基础。

```

|  +-------------------------------------------------------------------+|
|  |                              小 梁                                ||

|  |                                                                   ||
|  |     +---------------------------+                                 ||

|  |     | (动脉周围淋巴鞘 + 脾小体) |                                 ||
```

**1.1 被膜（Capsule）与脾小梁（Trabeculae）**
- **被膜**：由致密[[结缔组织]]构成，内含少量平滑肌。
- **脾小梁**：**形成**——被膜结缔组织伸入脾实质形成粗大的支架网络。
- **功能**：
    - **结构支持**：与[[网状组织]]共同构成脾的微细与宏观支架。
    - **血容量调节**：小梁内[[平滑肌]]纤维收缩，可挤出脾内储存的血液，调节循环血量。
- **脉管**：**小梁动脉（Trabecular artery）** 由脾门进入，沿小梁走行，随后分支进入脾实质。

**1.2 实质（Parenchyma）的两种结构**
脾实质由**白髓（White Pulp, WP）** 和**红髓（Red Pulp, RP）** 组成，两者交界处为**边缘区（Marginal Zone, MZ）**。

## 二、 白髓（White Pulp）—— 适应性免疫应答的启动区

**英文**：White Pulp
**概述**：相当于[[淋巴结]]的皮质区，是淋巴细胞（T、B细胞）聚集和发生适应性免疫应答的部位。约占脾实质的20%。
**脉管核心**：**中央动脉（Central Artery）**，由小梁动脉分支而来，纵贯白髓。

**2.1 动脉周围淋巴鞘（Periarteriolar Lymphoid Sheath, PALS）**
- **位置**：围绕中央动脉分布的**弥散淋巴组织**。
- **构成**：主要由**T淋巴细胞**（尤其是CD4+ T细胞）聚集而成，是脾脏的**T细胞区**。
- **功能**：初始T细胞在此处被抗原提呈细胞（如[[树突状细胞]]）激活，启动细胞免疫应答。

**2.2 脾小体（Splenic Corpuscle）/ 脾小结（Splenic Nodule）**
- **英文**：Splenic Corpuscle
- **位置**：位于[[动脉周围淋巴鞘]]的一侧，是白髓内的**淋巴小结（Lymphoid Nodule）**。
- **构成**：大量**B淋巴细胞**密集聚集，是脾脏的**B细胞区**。
- **生发中心**：抗原刺激后，脾小体内可形成生发中心（Germinal Center），进行B细胞克隆扩增、体细胞高频突变、亲和力成熟及类别转换。
- **小结帽（Corona）**：朝向[[红髓]]。在此产生的幼浆细胞（Plasmablast）和浆细胞多迁移至红髓的[[脾索]]中定居，分泌抗体。
- **动态变化**：正常情况下数量较少；当发生针对血液抗原的免疫应答时，数量显著增多。

**2.3 边缘区（Marginal Zone, MZ）**
- **英文**：Marginal Zone
- **位置**：**白髓**与**红髓**交界处的狭窄区域（宽约100μm）。
- **构成**：
    - **边缘区B细胞（Marginal Zone B Cells, MZ B Cells）**：一类独立于滤泡B细胞的独特B细胞亚群，表达特定表面标志（如CD1d， CD21high）。可快速活化，分化为浆细胞，产生IgM为主的第一波抗体，参与固有免疫样应答。
    - **巨噬细胞（Macrophages）**：如边缘区巨噬细胞（MMM），负责捕获和处理血液中的抗原。
    - **树突状细胞（Dendritic Cells）**：参与抗原提呈。
    - **少量T细胞**。
- **特殊结构——边缘窦（Marginal Sinus）**：
    - **形成**：中央动脉的侧支末端在边缘区膨大形成。
    - **本质**：一种小血窦。
    - **核心功能**：是**血液中抗原及再循环淋巴细胞进入白髓**的主要通道。血液中的病原体被边缘区的巨噬细胞和MZ B细胞捕获，启动免疫应答。

## 三、 红髓（Red Pulp）—— 血液滤过与储存区

**英文**：Red Pulp
**分布**：被膜下、小梁周围及白髓边缘区外侧的广大区域。
**占比**：约占脾实质的80%。
**构成**：主要由**脾索（Splenic Cord）** 和**脾血窦（Splenic Sinus）** 相互交织而成。

**3.1 脾索（Splenic Cord / Cords of Billroth）**
- **英文**：Splenic Cord
- **构成**：富含血细胞的**淋巴组织**，呈不规则索条状，由[[网状细胞]]和[[网状纤维]]构成三维网络。
- **细胞组成**：
    - **大量巨噬细胞**：特别是红髓巨噬细胞，是执行“过滤”和“清除”功能的主力。
    - **B细胞与浆细胞**：迁移至此的浆细胞是**脾脏局部抗体**的主要来源。
    - 淋巴细胞、网状细胞、血细胞（包括衰老和异常的红细胞）。
- **核心功能**：
    - **血液滤过**：流经脾索的血液在**开放循环**中，必须穿过网状结构的缝隙才能进入脾血窦。衰老、畸形、被抗体或补体标记的红细胞、血小板以及血液中的病原体，会被脾索中的巨噬细胞识别并吞噬清除。
    - **免疫效应**：浆细胞在此分泌大量抗体进入血液。

**3.2 脾血窦（Splenic Sinus / Sinusoidal Capillaries）**
- **英文**：Splenic Sinus
- **本质**：一种**非连续性、有孔的毛细血管**，构成红髓中的静脉端。
- **结构特点**：内皮细胞呈长杆状，纵向排列，细胞间有裂隙，基底膜不完整。
- **功能**：允许经过脾索“净化”后的血细胞（主要是可塑性好的正常红细胞）**变形**后，穿过内皮裂隙进入血窦腔，汇入小梁静脉，最终经脾静脉离开脾脏。

**血液通路总结（开放循环为主）**：
脾动脉 → 小梁动脉 → 中央动脉 → **（部分血液直接经笔毛动脉进入脾血窦，为“闭合循环”）** → 大部分血液进入**脾索** → **开放循环滤过** → （正常红细胞变形通过）→ 脾血窦 → 小梁静脉 → 脾静脉。

## 四、 脾脏的核心免疫功能整合

**4.1 对T细胞依赖性抗原（TD-Ag）的应答**
1.  **抗原捕获与提呈**：血液中的病原体或免疫复合物在**边缘区**被巨噬细胞和树突状细胞捕获。
2.  **启动与迁移**：抗原被提呈给初始T细胞，同时，MZ B细胞可能通过“穿梭”机制将抗原运送至白髓的生发中心或PALS。
3.  **T细胞活化**：在PALS，抗原特异性初始T细胞被树突状细胞活化，分化为效应T细胞（Th细胞）。
4.  **B细胞活化与生发中心反应**：活化的Th细胞迁移至脾小体，辅助被抗原激活的B细胞。在脾小体生发中心发生体细胞突变、亲和力成熟和类别转换。
5.  **效应输出**：
    - 长寿浆细胞迁移至**红髓脾索**，持续分泌高亲和力抗体入血。
    - 记忆B细胞和记忆T细胞进入再循环。

**4.2 对T细胞非依赖性抗原（TI-Ag）的快速应答**
- **主要执行者**：**边缘区B细胞（MZ B）**。
- **过程**：血液中的TI-Ag（如细菌多糖）在边缘区被MZ B细胞直接识别，无需T细胞辅助，可快速（数小时内）分化为浆细胞，产生以**IgM**为主的早期抗体，提供快速的、第一线的体液免疫防御。

**4.3 血液滤过与“红细胞质量控制”**
- 这是脾脏**独特的、非免疫性的重要功能**。
- 通过**开放循环**机制，脾脏是一个高效的“细胞筛”。衰老（膜脆性增加）、畸形（如球形红细胞、镰状细胞）、被抗体/补体标记（如自身免疫性溶血）或被疟原虫感染的红细胞，因其**变形能力下降**，无法穿过脾索基质和血窦内皮裂隙，而被截留并由红髓巨噬细胞吞噬清除。
- 此功能也适用于清除衰老血小板和血液中的病原体（如疟原虫、细菌）。

**4.4 免疫调节与耐受**
- 脾脏是诱导外周免疫耐受的重要场所。特殊的微环境（如调节性T细胞、特定细胞因子）有助于清除自身反应性淋巴细胞或诱导其无能。
- 脾脏切除后，机体对某些 encapsulated bacteria（如肺炎链球菌、脑膜炎奈瑟菌、流感嗜血杆菌）的清除能力显著下降，易发生**凶险的全身性感染（OPSI）**，凸显了脾脏在抗这类细菌免疫中的关键作用。

## 五、 总结

脾是一个结构精密、功能复杂的免疫-血液器官。其**白髓**是适应性免疫应答（尤其是针对血液抗原）的精密策源地，**边缘区**是固有免疫与适应性免疫的快速接口，**红髓**则是高效的血液滤池和免疫效应（抗体分泌）的执行场。通过精细的血管结构和开放循环，脾脏实现了对全身循环血液的持续监控与净化，在维持免疫稳态、清除病原体和衰老血细胞方面发挥着不可替代的作用。理解脾脏的结构-功能关系，是理解全身免疫，特别是抗感染免疫和自身免疫性疾病的重要基石。

**关键词**：脾 (Spleen), 白髓 (White Pulp), 红髓 (Red Pulp), 边缘区 (Marginal Zone), 动脉周围淋巴鞘 (PALS), 脾小体 (Splenic Corpuscle), 脾索 (Splenic Cord), 脾血窦 (Splenic Sinus), 开放循环 (Open Circulation), 血液滤过 (Blood Filtration), 边缘区B细胞 (MZ B Cells), 免疫应答 (Immune Response)。
