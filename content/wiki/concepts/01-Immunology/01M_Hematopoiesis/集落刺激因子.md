- **定义** 能刺激[[多能造血干细胞]]和不同发育分化阶段的造血祖细胞==分化、增殖为相应血细胞==的[[wiki/concepts/immunology/604细胞因子/细胞因子]]
- **得名** 在体外半固体培养基中能形成相应细胞集落
- **分类** 
	- 粒细胞集落刺激因子 ( #G-CSF )
	- 巨噬细胞集落刺激因子 ( #M-CSF )
	- 粒细胞-巨噬细胞集落刺激因子 ( #CM-CSF )
	- 多集落刺激因子 ( #IL-3 )
	- 干细胞因子 ( #SCF )
	- 促红细胞生成素 ( #EPO )
	- 血小板生成素 ( #TPO )
