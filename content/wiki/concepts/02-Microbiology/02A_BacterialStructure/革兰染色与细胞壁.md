# 革兰染色原理与细胞壁结构

## 1. 革兰染色法：原理与意义

革兰染色法（Gram stain）由丹麦医生Hans Christian Gram于1884年创立，是微生物学，尤其是细菌分类学中最重要、最基础的鉴别染色法。其核心在于利用**细菌细胞壁（cell wall）结构**的差异，将细菌区分为两大类：**革兰阳性菌（Gram-positive bacteria）** 和**革兰阴性菌（Gram-negative bacteria）**。

### 1.1 染色步骤

1.  **初染（Primary stain）**：使用结晶紫（crystal violet）染液。所有细菌均被染成紫色。
2.  **媒染（Mordant）**：使用碘液（Gram's iodine）。碘与结晶紫形成不溶于水的**结晶紫-碘复合物（CV-I complex）**，增大分子体积，并被细胞内的大分子（主要是肽聚糖）吸附。
3.  **脱色（Decolorization）**：关键步骤。使用乙醇或丙酮。
    *   **革兰阳性菌**：其**肽聚糖层（peptidoglycan layer）** 厚实、交联度高，乙醇使其脱水收缩，形成更致密的网状结构，**孔隙缩小**，复合物被**截留**在细胞壁内，保持紫色。
    *   **革兰阴性菌**：其肽聚糖层薄，但外有一层**外膜（outer membrane）** 富含脂质。乙醇**溶解脂质**，破坏外膜，使**薄层肽聚糖网孔不足以截留**复合物，紫色被洗脱。
4.  **复染（Counterstain）**：使用沙黄（safranin）或品红。脱色后的细菌被染成红色。革兰阳性菌因保持紫色而不显现复染颜色。

### 1.2 染色结果与核心原理

| 特性 | 革兰阳性菌 (Gram-positive) | 革兰阴性菌 (Gram-negative) |
| :--- | :--- | :--- |
| **最终颜色** | 紫色 (Violet) | 红色 (Red) |
| **核心结构差异** | **厚而致密的肽聚糖层**，含大量磷壁酸 | **薄而疏松的肽聚糖层**，外有**外膜**（含脂多糖） |
| **脱色机制** | 肽聚糖脱水致孔隙闭合，**截留**结晶紫-碘复合物 | 乙醇溶解外膜脂质，肽聚糖层不足以截留复合物，**洗脱**结晶紫 |

```ASCII Art: 革兰染色原理与细胞壁结构对比
                     结晶紫染色
                         |
                     碘液媒染
                         |
                   CV-I复合物形成
                         |
                +--------脱色(乙醇)--------+
                |                           |
     [革兰阳性菌]                   [革兰阴性菌]
        细胞壁                         细胞壁
        肽聚糖层厚                   肽聚糖层薄
       (15-50层)                      (1-2层)
        + 磷壁酸                       + 外膜(含LPS)
                |                           |
    乙醇使其脱水收缩               乙醇溶解外膜脂质
    孔隙变小,截留复合物             复合物从薄层肽聚糖洗脱
                |                           |
        保持紫色                       被复染成红色
```

**结论**：革兰染色的差异**并非**源于染料对细胞壁的化学亲和力不同，而是源于两种细胞壁在**物理结构（孔隙大小、完整性）** 和**化学组成（脂质含量）** 上的根本性差异。

## 2. 细菌细胞壁：结构与功能概览

细胞壁是位于细菌细胞膜外的一层坚韧、有弹性的结构，维持细菌的**固有形态（inherent shape）** 和**抗低渗（osmotic protection）** 环境。其主要成分为**肽聚糖（peptidoglycan）**，又称**粘肽（murein）**。

### 2.1 肽聚糖的基本结构

肽聚糖是由**聚糖骨架（glycan backbone）** 和**四肽侧链（tetrapeptide side chain）** 交织而成的巨大网状分子。

```ASCII Art: 肽聚糖单体与交联示意
         NAG -β-1,4- NAM -β-1,4- NAG -β-1,4- NAM
         |              |                |              |
        R1             四肽侧链         R2            四肽侧链
                       (图示如下)                   (与相邻链交联)
                          |
                   L-丙氨酸 (1)
                          |
                   D-谷氨酸 (2)
                          |
                   L-赖氨酸/DAP (3)
                          |
                   D-丙氨酸 (4) ---- (通过肽桥或直接)连接到相邻肽聚糖链的第三个氨基酸
```

*   **聚糖骨架**：
    *   由两种氨基糖交替排列，通过**β-1，4糖苷键**连接：
        *   **N-乙酰葡糖胺（N-acetylglucosamine, NAG）**
        *   **N-乙酰胞壁酸（N-acetylmuramic acid, NAM）**
    *   **β-1，4糖苷键**是溶菌酶（lysozyme）的作用靶点，可水解此键导致细菌裂解。

*   **四肽侧链**：
    *   连接在**NAM**的乳酰基上。
    *   组成因菌种而异，典型顺序为：**L-丙氨酸 -> D-谷氨酸 -> L-赖氨酸或二氨基庚二酸（DAP） -> D-丙氨酸**。
    *   **D型氨基酸**和**DAP**的存在是肽聚糖的独特特征，可抵抗大多数蛋白酶的水解。

### 2.2 细胞壁结构的差异：革兰阳性 vs. 革兰阴性

这是理解革兰染色、细菌致病性及抗生素作用靶点的核心。

#### 2.2.1 [[革兰阳性菌]] 细胞壁

其结构相对“简单”，但“厚实”。

```ASCII Art: 革兰阳性菌细胞壁模型
     ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ (细胞外)
     |||||||||||||||||||||||||||||||||||||||||||||  <- 厚层肽聚糖 (15-50层)
     | NAG-NAM-NAG-NAM-NAG-NAM-NAG-NAM-NAG-NAM |     含大量磷壁酸
     |  |   |   |   |   |   |   |   |   |   |  |     (壁磷壁酸: 共价连接NAM)
     |  R1  四肽 R2  四肽 R1  四肽 R2  四肽 R1  |     (膜磷壁酸: 锚定在细胞膜)
     |      |      |      |      |      |      |
     +------+      +------+      +------+      +---> 肽交联桥 (富含甘氨酸)
     +------+      +------+      +------+      +---> 连接相邻四肽侧链
     _____________________________________________  <- 细胞膜 (Cytoplasmic membrane)
     (细胞内)
```

*   **肽聚糖层**：
    *   **厚度**：非常**厚**，可达**15-50层**，形成坚韧的三维网状结构。
    *   **交联方式**：四肽侧链之间常通过**肽交联桥（peptide interbridge）**（如甘氨酸五肽）进行交联，交联度**高**。
*   **特有成分 - [[磷壁酸]]（Teichoic acid）**：
    *   **构成**：由**核糖醇（ribitol）** 或**甘油（glycerol）** 残基通过**磷酸二酯键**连接而成的多聚物。
    *   **分类与连接**：
        *   **壁磷壁酸（Wall teichoic acid, WTA）**：一端与肽聚糖中的**NAM**共价结合，另一端游离于壁外。
        *   **膜磷壁酸（Lipoteichoic acid, LTA）**：一端以**糖脂**形式锚定在**细胞膜**磷脂双分子层，另一端穿过肽聚糖层游离于壁外。
    *   **功能**：
        *   **表面抗原**：是革兰阳性菌重要的**表面抗原（surface antigen）**，具有种、型特异性。
        *   **离子调节**：带负电荷，可结合环境中的Mg²⁺等阳离子，维持细胞壁酶活性及离子稳态。
        *   **粘附**：参与细菌对宿主细胞的初始粘附。

#### 2.2.2 [[革兰阴性菌]] 细胞壁

结构更为复杂，是“三明治”结构。

```ASCII Art: 革兰阴性菌细胞壁模型
     ~~~~~~~~~~~~~~~~ 脂多糖 (LPS) ~~~~~~~~~~~~~~~~ (细胞外)
     ^  ^  ^  ^  ^  ^  ^  ^  ^  ^  ^  ^  ^  ^  ^
    |  |  |  |  |  |  |  |  |  |  |  |  |  |  |
     ====外膜（Outer Membrane）=======================  <- 含脂多糖(LPS)
     |  磷脂双分子层，含孔蛋白(Porin)    载体蛋白  |     磷脂与脂蛋白
     |  |  |  |  |  |  |  |  |  |  |  |  |  |  |
     ------------------------------------------------  <- 脂蛋白连接层
     | NAG-NAM-NAG-NAM |                        |     <- 薄层肽聚糖 (1-2层)
     |  R1  四肽  R2  -DAP-- R1  四肽  R2  -DAP-- |     直接交联 (DAP-D丙氨酸)
     _______________________________________________  <- 周质空间 (Periplasmic space)
     =================================================  <- 内膜/细胞膜 (Cytoplasmic membrane)
     (细胞内)
```

*   **肽聚糖层**：
    *   **厚度**：非常**薄**，仅**1-2层**，形成二维平面网状结构。
    *   **交联方式**：四肽侧链之间通常**直接交联**（如一个四肽侧链的DAP与相邻四肽侧链的D-丙氨酸直接相连），交联度**低**。
*   **外膜（Outer membrane）**：
    *   革兰阴性菌最独特的结构，位于肽聚糖层外侧。
    *   **化学组成**：内层为磷脂，外层为**脂多糖（Lipopolysaccharide, LPS）**。
    *   **功能**：
        *   **渗透屏障**：作为抵御抗生素、染料、去污剂等疏水性大分子的第一道防线。**孔蛋白（Porin）** 形成亲水性通道，允许小分子营养物通过。
        *   **致病性**：其外层的LPS是关键的毒力因子。
*   **特有成分 - [[脂多糖]]（Lipopolysaccharide, LPS）**：
    *   又称**内毒素（endotoxin）**，是革兰阴性菌外膜的主要成分。
    *   **结构**：由三部分组成，从内到外依次为：
        1.  **脂质A（Lipid A）**：
            *   一种**糖磷脂（glycophospholipid）**，嵌入外膜。
            *   **是LPS的毒性部分（toxic component）**，**无种属特异性**，引发发热、白细胞反应、内毒素性休克等全身性病理效应。
        2.  **核心多糖（Core polysaccharide）**：
            *   分为内核心（高度保守，含KDO等特殊糖）和外核心（结构可变）。
            *   将脂质A与O-特异性多糖连接。
        3.  **O-特异性多糖（O-specific polysaccharide, O-antigen）**：
            *   由重复的寡糖单位构成。
            *   **具有高度种属特异性**，是革兰阴性菌的**主要表面抗原（major surface antigen）**，用于血清学分型（如O157:H7）。
    *   **致病机制**：当细菌死亡裂解后，LPS释放。**脂质A**被宿主免疫细胞（如巨噬细胞）的TLR4识别，激活NF-κB等信号通路，大量释放炎症因子（如TNF-α， IL-1），引起**发热（fever）** 和**全身毒血症状（systemic toxemia）**，严重时可导致**内毒素性休克（endotoxic shock）**。
*   **周质空间（Periplasmic space）**：
    *   位于内膜与外膜（或薄层肽聚糖）之间的凝胶状空间。
    *   含有多种水解酶（如β-内酰胺酶）、结合蛋白和运输蛋白，在营养获取、毒素分泌和信号传导中起重要作用。

## 3. 总结与比较

| 特征 | **革兰阳性菌** | **革兰阴性菌** |
| :--- | :--- | :--- |
| **革兰染色** | 紫色 | 红色 |
| **肽聚糖层** | 厚（15-50层），三维网状，交联度高 | 薄（1-2层），二维网状，交联度低 |
| **磷壁酸** | 有，是重要表面抗原与离子调节器 | 无 |
| **外膜** | 无 | 有，含LPS，是渗透屏障和致病关键 |
| **脂多糖(LPS)** | 无 | 有，**脂质A**为内毒素毒性中心 |
| **周质空间** | 窄 | 宽，含多种酶类 |
| **主要表面抗原** | 磷壁酸 | O-特异性多糖（O-抗原） |
| **对溶菌酶** | 敏感 | 较不敏感（外膜保护） |
| **对青霉素** | 敏感（作用于肽聚糖合成） | 较不敏感（但仍有作用靶点） |
| **对机械渗透压** | 抗性强 | 抗性相对较弱 |
| **代表属** | **链球菌属（*Streptococcus*）**、**葡萄球菌属（*Staphylococcus*）**、**芽孢杆菌属（*Bacillus*）** | **大肠杆菌（*Escherichia*）**、**沙门氏菌属（*Salmonella*）**、**假单胞菌属（*Pseudomonas*）** |

**[[双向链接]]示例**：
*   本笔记提及的**肽聚糖**合成抑制剂，如β-内酰胺类抗生素（青霉素、头孢菌素），其作用靶点为**青霉素结合蛋白（Penicillin-Binding Proteins, PBPs）**。
*   革兰阴性菌的**外膜**是其对多种抗生素天然耐药的主要原因，这一机制被称为**外膜屏障（Outer membrane barrier）**。
*   **LPS**中的**脂质A**是先天免疫系统识别**病原相关分子模式（Pathogen-Associated Molecular Patterns, PAMPs）** 的重要配体，通过**Toll样受体4（Toll-Like Receptor 4, TLR4）** 信号通路激活炎症反应。
