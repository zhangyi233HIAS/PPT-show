# Type III Secretion System (III型分泌系统)

> [!info] 定义
> **Type III Secretion System (T3SS)** 是革兰氏阴性菌的分子注射器，直接将毒力效应蛋白注入宿主细胞，操纵宿主细胞功能。

---

## 1. 概述

[[Type III Secretion System|T3SS]] 是细菌最复杂的分泌系统之一，由20多种蛋白质组成，形成跨越细菌内外膜和宿主细胞膜的通道。T3SS 在[[沙门氏菌]]致病中发挥核心作用。

### 1.1 分泌系统分类

| 类型 | 结构 | 底物 | 代表菌 |
|-----|------|------|-------|
| [[T1SS]] | 3组分 | 蛋白质 | 大肠杆菌 |
| [[T2SS]] | Sec依赖 | 蛋白质 | 霍乱弧菌 |
| [[T3SS]] | 针状 | 效应蛋白 | 沙门氏菌 |
| [[T4SS]] | 接合 | DNA/蛋白 | 幽门螺杆菌 |
| [[T5SS]] | 自动转运 | 蛋白质 | 淋球菌 |
| [[T6SS]] | 注射 | 效应蛋白 | 霍乱弧菌 |

## 2. T3SS 结构

### 2.1 结构组成

```
                    ┌─────────────┐
                    │  宿主细胞膜  │
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │   转位子     │
                    │  (Translocon)│
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │  针状复合体   │
                    │ (Needle)     │
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │   基体       │
                    │ (Basal Body) │
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │   细菌膜     │
                    └─────────────┘
```

### 2.2 结构蛋白

| 组件 | 蛋白 | 功能 |
|-----|------|------|
| **基体** | InvG, PrgH, PrgK | 形成跨膜通道 |
| **针状体** | PrgI | 形成针状结构 |
| **针尖** | PrgJ | 针尖组装 |
| **转位子** | SipB, SipC, SipD | 形成宿主细胞膜孔 |

### 2.3 沙门氏菌 T3SS

沙门氏菌拥有两套 T3SS：

| 系统 | 基因簇 | 功能 |
|-----|-------|------|
| **T3SS-1** | [[SPI-1]] | 上皮细胞入侵 |
| **T3SS-2** | [[SPI-2]] | 胞内存活 |

## 3. T3SS-1 (SPI-1)

### 3.1 基因组织

[[SPI-1]] 基因簇 (~40 kb) 包含：

| 基因 | 功能 |
|-----|------|
| [[invA-invJ]] | 基体和针状体组装 |
| [[spaOPQRS]] | 分泌伴侣 |
| [[prgHIJK]] | 基体和针状体 |
| [[sipABCD]] | 效应蛋白和转位子 |
| [[sicA]] | 分子伴侣 |
| [[iacP]] | 脂肪酸修饰 |

### 3.2 效应蛋白

| 效应蛋白 | 功能 | 靶点 |
|---------|------|------|
| [[SipA]] | 肌动蛋白聚合 | 肌动蛋白 |
| [[SipC]] | 肌动蛋白成核 | 肌动蛋白 |
| [[SopE]] | Rho GTPase 激活 | Cdc42, Rac1 |
| [[SopE2]] | Rho GTPase 激活 | Cdc42, Rac1 |
| [[SptP]] | Rho GTPase 失活 | Cdc42, Rac1 |
| [[SopA]] | 泛素连接酶 | 宿主蛋白 |
| [[SopB]] | 磷酸肌醇磷酸酶 | 膜运输 |

### 3.3 入侵机制

```
沙门氏菌附着
    ↓
T3SS-1 激活
    ↓
效应蛋白注入 (SipA, SipC, SopE, SopE2)
    ↓
Rho GTPase 激活
    ↓
肌动蛋白聚合
    ↓
膜褶皱形成 (Ruffling)
    ↓
细菌内化
    ↓
SCV 形成
```
