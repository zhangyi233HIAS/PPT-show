# 沙门氏菌 (Salmonella)

> [!info] 分类
> **域**: 细菌 (Bacteria)
> **门**: 变形菌门 (Proteobacteria)
> **纲**: γ-变形菌纲 (Gammaproteobacteria)
> **目**: 肠杆菌目 (Enterobacterales)
> **科**: 肠杆菌科 (Enterobacteriaceae)
> **属**: 沙门氏菌属 (Salmonella)

---

## 1. 概述

[[沙门氏菌]]是一类革兰氏阴性、兼性厌氧的杆状细菌，是重要的人畜共患病原菌。沙门氏菌属包含两个种：

- **肠道沙门氏菌** (S. enterica): 包含超过2600种血清型
- **邦戈沙门氏菌** (S. bongori): 较少见

### 1.1 主要血清型

| 血清型 | 宿主 | 疾病 |
|-------|------|------|
| [[Typhimurium]] | 广谱宿主 | 胃肠炎 |
| [[Enteritidis]] | 禽类、人类 | 胃肠炎 |
| [[Typhi]] | 人类 | 伤寒 |
| [[Paratyphi]] | 人类 | 副伤寒 |
| [[Dublin]] | 牛 | 全身感染 |
| [[Choleraesuis]] | 猪 | 全身感染 |

---

## 2. 生物学特性

### 2.1 形态与培养

- **形态**: 杆状，0.7-1.5 × 2-5 μm，周生鞭毛
- **培养**: 兼性厌氧，最适温度 37°C，pH 6.5-7.5
- **生化**: 氧化酶阴性，发酵葡萄糖产酸产气（多数血清型）

### 2.2 基因组特征

- **基因组大小**: 4.5-5.0 Mb
- **GC含量**: 约 52%
- **质粒**: 常携带毒力质粒 (~90 kb)
- **致病岛**: [[SPI-1]] 至 [[SPI-23]]+

**详细**: [[沙门氏菌基因组学]]

### 2.3 抗原结构

| 抗原 | 成分 | 功能 |
|-----|------|------|
| O 抗原 | 脂多糖 (LPS) | 血清分型，内毒素活性 |
| H 抗原 | 鞭毛蛋白 | 运动性，血清分型 |
| Vi 抗原 | 荚膜多糖 | 毒力因子（伤寒沙门氏菌） |

---

## 3. 致病机制

### 3.1 毒力因子

沙门氏菌的毒力因子主要编码在[[致病岛]]和质粒上：

#### 3.1.1 III型分泌系统 (T3SS)

- [[T3SS-1]] (SPI-1): 介导上皮细胞入侵
- [[T3SS-2]] (SPI-2): 介导胞内存活

**详细**: [[Type III Secretion System]]

#### 3.1.2 效应蛋白

| 效应蛋白 | 分泌系统 | 功能 |
|---------|---------|------|
| [[SipA]] | T3SS-1 | 肌动蛋白聚合，膜褶皱 |
| [[SipC]] | T3SS-1 | 肌动蛋白成核 |
| [[SopE]] | T3SS-1 | Rho GTPase 激活 |
| [[SopE2]] | T3SS-1 | Rho GTPase 激活 |
| [[SptP]] | T3SS-1 | Rho GTPase 失活，恢复细胞骨架 |
| [[SseF]] | T3SS-2 | SCV 完整性 |
| [[SseG]] | T3SS-2 | SCV 定位 |
| [[SifA]] | T3SS-2 | SIF 形成 |

#### 3.1.3 其他毒力因子

- [[菌毛]] (Fim, Pef): 粘附
- [[鞭毛]]: 运动性，趋化性
- [[脂多糖]] (LPS): 内毒素，血清抗性
- [[铁摄取系统]]: 铁载体，血红素利用
- [[酸耐受系统]]: 胃酸存活

### 3.2 感染过程

```
口服摄入
    ↓
胃酸屏障 (酸耐受系统)
    ↓
小肠 (菌毛粘附)
    ↓
上皮细胞入侵 (T3SS-1)
    ↓
┌─────────────────────────────────────┐
│  肠道感染路径              全身感染路径  │
│      ↓                        ↓      │
│  炎症反应              M细胞摄取      │
│  腹泻                 ↓              │
│                   派尔集合淋巴结      │
│                        ↓            │
│                   巨噬细胞吞噬        │
│                        ↓            │
│                   SCV形成 (T3SS-2)   │
│                        ↓            │
│                   血液播散            │
│                   ↓          ↓      │
│                  肝脏       脾脏     │
└─────────────────────────────────────┘
```

### 3.3 细胞内生存

沙门氏菌在巨噬细胞内的生存策略：

1. **吞噬体修饰**: 形成[[SCV]] (Salmonella-Containing Vacuole)
2. **抑制吞噬溶酶体融合**: SifA, SseF, SseG
3. **营养获取**: 从宿主获取氨基酸、铁、磷
4. **免疫逃逸**: 抑制[[NF-κB]]信号，调节[[wiki/concepts/immunology/604细胞因子/细胞因子]]

**详细**: [[沙门氏菌胞内存活机制]]

## 4. 宿主免疫应答

### 4.1 先天免疫

- **上皮细胞**: 产生[[抗菌肽]]、[[wiki/concepts/immunology/604细胞因子/细胞因子]]
- **巨噬细胞**: 吞噬、[[活性氧]]、[[活性氮]]
- **树突状细胞**: 抗原呈递
- **中性粒细胞**: 炎症反应

**详细**: [[先天免疫应答]]

### 4.2 适应性免疫

- **Th1反应**: [[IFN-γ]] 激活巨噬细胞
- **Th17反应**: 招募中性粒细胞
- **抗体反应**: 清除胞外细菌

**详细**: [[适应性免疫应答]]

### 4.3 免疫逃逸策略

1. **抑制抗原呈递**: 降低 MHC-II 表达
2. **调节细胞因子**: 抑制促炎因子
3. **抵抗杀伤**: 抵抗[[活性氧]]、[[活性氮]]
4. **逃逸到胞质**: 利用 T3SS-1 逃逸到胞质

**详细**: [[免疫逃逸策略]]

## 5. 临床意义

### 5.1 沙门氏菌病

| 类型 | 症状 | 严重程度 |
|-----|------|---------|
| 胃肠炎 | 腹泻、发热、腹痛 | 轻-中度 |
| 伤寒 | 持续高热、头痛、玫瑰疹 | 严重 |
| 菌血症 | 高热、寒战 | 严重 |
| 局灶感染 | 骨髓炎、脑膜炎 | 严重 |

### 5.2 耐药性

- **多重耐药** (MDR): 对3种以上抗生素耐药
- **广泛耐药** (XDR): 仅对1-2种抗生素敏感
- **耐药机制**: 质粒介导、基因突变、外排泵

**详细**: [[沙门氏菌耐药性]]

### 5.3 防控策略

- **疫苗**: Ty21a (口服减毒活疫苗), Vi 疫苗
- **食品安全**: 巴氏消毒、冷链
- **抗生素**: 氟喹诺酮、三代头孢
