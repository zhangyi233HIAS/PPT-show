# 沙门氏菌基因组学 (Salmonella Genomics)

> [!info] 概述
> 沙门氏菌基因组学研究沙门氏菌的基因组结构、功能和进化，为理解其致病机制、耐药性和宿主适应提供基础。

---

## 1. 基因组特征

### 1.1 基本参数

| 参数 | 数值 | 范围 |
|-----|------|------|
| **基因组大小** | 4.5-5.0 Mb | 4.4-5.2 Mb |
| **GC含量** | ~52% | 51-53% |
| **基因数** | ~4,500 | 4,200-5,000 |
| **编码密度** | ~85% | 83-87% |
| **基因间区** | ~15% | 13-17% |

### 1.2 基因组结构

```
┌─────────────────────────────────────────┐
│           沙门氏菌基因组                  │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │      核心基因组 (~3.8 Mb)        │   │
│  │  - 代谢基因                      │   │
│  │  - 复制/转录/翻译基因            │   │
│  │  - 细胞结构基因                  │   │
│  └─────────────────────────────────┘   │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │      可变基因组 (~1.2 Mb)        │   │
│  │  - 致病岛 (SPI)                 │   │
│  │  - 噬菌体                       │   │
│  │  - 质粒                         │   │
│  │  - 岛屿                         │   │

└─────────────────────────────────────────┘
```

## 4. 耐药基因组学

### 4.1 耐药基因

| 耐药类型 | 基因 | 机制 |
|---------|------|------|
| **β-内酰胺类** | [[blaTEM]], [[blaSHV]], [[blaCTX-M]] | β-内酰胺酶 |
| **氟喹诺酮类** | [[qnr]], [[aac(6')-Ib-cr]] | 靶点保护、酶修饰 |
| **氨基糖苷类** | [[aac]], [[ant]], [[aph]] | 酶修饰 |
| **氯霉素类** | [[cat]], [[cml]] | 酶修饰、外排 |
| **四环素类** | [[tet]], [[tetR]] | 外排、核糖体保护 |
| **磺胺类** | [[sul]], [[dfr]] | 靶点替代 |
| **甲氧苄啶** | [[dfr]] | 靶点替代 |
| **多粘菌素** | [[mcr-1]] | 脂多糖修饰 |

### 4.2 耐药机制

| 机制 | 描述 | 示例 |
|-----|------|------|
| **酶修饰** | 酶降解/修饰抗生素 | β-内酰胺酶 |
| **靶点改变** | 突变降低亲和力 | gyrA 突变 |
| **外排泵** | 主动排出抗生素 | AcrAB-TolC |
| **膜通透性** | 降低膜通透性 | OmpF 缺失 |
| **靶点替代** | 产生替代靶点 | PBP2a |

### 4.3 耐药基因传播

| 机制 | 描述 | 速度 |
|-----|------|------|
| **质粒转移** | 接合、转化、转导 | 快 |
| **转座子移动** | 跳跃基因 | 中 |
| **整合子** | 基因盒捕获 | 中 |
| **点突变** | 靶点突变 | 慢 |

## 5. 比较基因组学

### 5.1 核心基因组分析

| 分析 | 方法 | 应用 |
|-----|------|------|
| **SNP分析** | 全基因组比对 | 系统发育 |
| **MLST** | 多位点序列分型 | 分型 |
| **cgMLST** | 核心基因组MLST | 高分辨率分型 |
| **Pangenome** | 核心+可变基因组 | 基因组多样性 |

### 5.2 基因组变异

| 变异类型 | 频率 | 影响 |
|---------|------|------|
| **SNP** | 高 | 氨基酸替换 |
| **InDel** | 中 | 移码、缺失 |
| **基因组重排** | 低 | 倒位、易位 |
| **水平基因转移** | 中 | 新基因获得 |

### 5.3 系统发育

| 方法 | 分辨率 | 应用 |
|-----|-------|------|
| **MLST** | 血清型水平 | 大规模分型 |
| **wgMLST** | 菌株水平 | 暴发调查 |
| **SNP** | 单核苷酸水平 | 传播链分析 |
| **全基因组** | 最高 | 精细进化 |

**详细**: [[沙门氏菌系统发育]]
