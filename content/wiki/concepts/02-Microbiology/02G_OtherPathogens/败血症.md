- **定义** 
	- 病原体在==血液生长繁殖并产生毒素==，引起==全身严重中毒==（医学微生物学）
	- 病原菌==侵入血液循环==，在其中==生长繁殖==产生大量==毒素==并诱发[[全身炎症反应综合征]]的急性全身性感染（传染病学）
- **病原** 阴性菌70%，阳性菌30%
	- 革兰氏阳性球菌
		- 主要是葡萄球菌、肠球菌和链球菌
		- 以金黄色葡萄球菌最为常见
		- 耐药性严重
	- 革兰氏阴性杆菌 较多
		- 以肠杆菌科细菌为常见
		- 耐药性严重
	- 厌氧菌
		- 主要是脆弱类杆菌、梭状芽孢杆菌属
		- 其次为消化链球菌及产气荚膜杆菌等
	- 真菌
		- 白色假丝酵母菌占绝大多数
	- 其他细菌
		- 单核细胞增多性李斯特菌、聚团肠杆菌及腐生葡萄球菌等

# 机制

- 人体因素 机体免疫功能缺陷或下降是败血症的重要诱因
	- **遗传**
	- **药物** 
		- 化疗
		- 细胞毒药物
		- 放射治疗
		- 广谱抗菌药物
		- 肾上腺皮质激素
		- 免疫抑制剂
	- **手术** 
		- 重要器官大手术
		- 气管插管
		- 人工呼吸机的使用
		- 静脉导管
		- 保留尿管等操作
		- 内镜检查
		- 内引流管安置
	- **疾病** 
		- 严重外伤
		- 烧伤
		- 糖尿病
		- 结缔组织病
		- 肝硬化
		- 尿毒症
		- 痴呆
		- 慢性肺部疾病
- 病原菌因素
	- [[革兰阳性菌|革兰氏阳性菌]] [[外毒素]]
	- [[革兰阴性菌|革兰氏阴性菌]] [[脂多糖|内毒素]]

# 病理

- **全身** 组织和细胞变性，出现水肿、脂肪变性和坏死
- **毛细血管** 损伤造成皮肤和黏膜瘀点、瘀斑及皮疹
- **迁徙性脓肿** 多见于肺、肝、肾及皮下组织等
- **并发** 心内膜炎、脑膜炎、骨髓炎等
- **其他** 单核 / 巨噬细胞增生活跃，肝、脾均可肿大

# 表现

## 共同

- 毒血症状 
	- ==寒战高热==
		- **热型** 多为[[弛张热]]或[[间歇热]]型，少数为稽留热、不规则热
		- **伴随** 全身不适、头痛、关节疼痛、软弱无力，脉搏、呼吸增快
	- ==胃肠道症状== 可有恶心、呕吐、腹胀、腹泻等
	- 严重 可有中毒性脑病、中毒性心肌炎、肠麻痹、感染性休克及 DIC 等
- **皮疹** ==注意==
	- 瘀点 常见
		- **位置** 多分布于躯干、四肢、口腔黏膜及眼结膜等处
		- **数量** 少
	- 荨麻疹、猩红热样皮疹、脓疱疹、瘀斑等
		- **特化** 球菌所致瘀斑可融合成片
	- 坏死性皮疹
		- **分布** 可见于铜绿假单胞菌败血症
- **关节损害** ==注意==
	- **分布** 革兰氏阳性球菌和产碱杆菌败血症
	- **表现** 
		- 膝关节等大关节红肿、疼痛、活动受限
		- 少数有关节腔积液或积脓
- **肝脾大** ==注意==
	- 常为轻度大
	- 并发中毒性肝炎或肝脓肿时肝脏可显著大
		- **伴随** 压痛，也可有黄疸
- 原发感染病灶
	- 多为毛囊炎、痈或脓肿等
	- 皮肤烧伤
	- 压疮
	- 呼吸道、胆道、消化道、泌尿生殖系统感染
	- 开放性创伤感染等
- 迁徙性病灶 
	- **分布** 常见于病程较长的革兰氏阳性球菌和厌氧菌败血症
	- **时间** 自第 2 周起可不断出现转移性脓肿
	- **典例** 
		- 皮下及深部软组织脓肿、肺脓肿、骨髓炎、关节炎及心包炎等
		- 少数可发生急性或亚急性感染性心内膜炎

# 分类

- 革兰氏阳性菌
	- **分布** 多见于严重痈、 急性蜂窝织炎、骨与关节化脓症以及大面积烧伤时
	- **表现** 
		- **起病** 急
		- **寒战高热** 呈[[弛张热]]或[[稽留热]]型
		- **皮疹** ==多形性皮疹、脓点常见==，也可有脓疱疹
		- **关节损害** 约 1/4病例伴大关节红肿、疼痛
		- **迁徙性病灶** 
			- 常见于腰背、四肢，以及肺炎、肺脓肿、肝脓肿等
			- 有心脏瓣膜病或其他基础病的老年人和静脉药瘾者易并发心内膜炎
		- **注意** ==感染性休克较少见==
- 革兰氏阴性菌
	- **分布** 
		- 病前一般情况常较差， 多有严重基础疾病或有影响免疫功能的药物干预
		- 原发感染包括肺部炎症、泌尿道感染、腹膜炎及胆道感染
	- **症状** 
		- **中毒** 明显，可出现心动过速、血管阻力下降、心射血分数降低、管壁通透性增加而发生[[感染性休克]]
		- **休克** 发生率高、发生早、持续时间长
		- 临床常以寒战开始，间歇[[发热]]，可体温不升或低于正常
- 厌氧菌
	- **分布** 以==胃肠道及女性生殖道==为主， 其次为压疮溃疡与坏疽
	- **表现** 
		- 发热，体温高于 38℃
		- 约 30% 的患者可发生感染性休克或 DIC
		- 可出现黄疸、脓毒性血栓性静脉炎及转移性化脓病灶
- 真菌
	- **分布** 常见于老年、体弱久病者
	- **表现** 与革兰氏阴性菌败血症相似，病情严重，可有寒战、发热、出汗、肝脾大等
	- **注意** 偶可仅为低热，甚至不发热，毒血症可被合并细菌感染所掩盖

# 特化

- 老年人
	- **来源** 由压疮侵入者常见
	- **病原** 以大肠埃希菌、克雷伯菌等革兰氏阴性菌及厌氧菌为主
	- **注意** 病程中容易并发心内膜炎
- 新生儿
	- **来源** 常由母亲产道感染，吸入感染羊水或脐带、皮肤等感染而入侵
	- **病原** 以大肠埃希菌、B 组溶血性链球菌为主
	- **表现** 
		- 食欲缺乏、呕吐、精神萎靡、呼吸困难、惊厥等
		- 部分有发热
	- **注意** 新生儿血脑屏障功能不健全，易并发颅内感染
- 烧伤
	- **病原** 早期多为单一细菌，晚期常为多种细菌混合感染，也可为真菌所致
		- 以金黄色葡萄球菌、铜绿假单胞菌、大肠埃希菌或变形杆菌为主
	- **时间** 常发生于烧伤后 2 周，也可发生于烧伤后 36 小时，创面肉芽肿形成后败血症发生机会减少
	- **表现** 
		- 较一般败血症为重，可为过高热（ ＞41℃）或低体温，多为弛张热，心动过速，可出现中毒性心肌炎、中毒性肝炎及休克等
		- 常发生麻痹性肠梗阻或意识障碍
- 医院感染
	- **特点** 常有严重基础疾病，或接受过胸腔、心脏、腹部、盆腔等较大手术或介入性检查操作，或长期应用免疫抑制剂或广谱抗生素等
	- **病原** 以大肠埃希菌、铜绿假单胞菌、不动杆菌等革兰氏阴性耐药菌为主，革兰氏阳性球菌中MRSA 较多见，真菌引起者逐年增加
- 免疫功能低下
	- **病原** 主要是耐药葡萄球菌（如 MRSA）、肺炎链球菌、肠球菌、流感嗜血杆菌、大肠埃希菌、肺炎克雷伯菌、嗜水气单胞菌、假丝酵母菌等
	- **表现** 常不典型，可有发热，有时发热是唯一的症状，也可呈低体温状态，或出现低血压，或感染性休克，或 MOF 表现

# 检查

- 一般
	- 外周血 
		- 白细胞数增高，常为（10～30）×109/L，中性粒细胞百分率增高，可有明显核左移及细胞内中毒颗粒
		- 免疫反应差及少数革兰氏阴性菌败血症患者的白细胞数可正常或降低，但中性粒细胞百分数增高
		- 并发 DIC 时血小板减少
		- 病程长者可有贫血
	- 尿 可见蛋白或少量管型
- 病原学
	- 血培养 
		- **时间** 应用抗菌药物前、寒战、高热时
		- **对象** 尽可能同时作需氧菌、厌氧菌和真菌培养
		- **注意** 对已用抗菌药物者，宜在培养基中加入硫酸镁、β内酰胺酶或对氨苯甲酸等，以破坏某些抗菌药物，或采用血块培养法
	- 骨髓培养 
		- 细菌较多，受抗菌药物影响较小，培养阳性率高
	- 体液培养 
		- 脓液、胸腔积液、腹水、脑脊液或瘀点挤液涂片或培养
- 炎症相关 判断炎症应答强度
	- 血清 [[C反应蛋白]]（CRP）
		- 细菌感染时升高显著
		- 病毒感染时大多正常或轻微升高
	- 血清降钙素原（PCT）细菌感染较为特异的炎症标志物
	- IL-6 细菌感染时明显升高
- **其他** 
	- NGS
	- 鲎试验 
		- 阳性可提示血清中存在内毒素，有助于诊断革兰氏阴性菌败血症
	- 血气分析
		- 有助于判断酸碱平衡紊乱及缺氧状况等
	- 凝血纤溶相关
		- DIC
	- 影像学
		- 骨髓炎或化脓性关节炎

# 并发

- 一般 肾衰竭、中毒性心肌炎、中毒性脑病、肝损害、肠麻痹或急性呼吸窘迫综合征
- 阳性菌 多处脓肿及化脓性脑膜炎、心包炎、心内膜炎等
- 阴性菌 感染性休克及 DIC

# 诊断

- **疑诊** 或
	- 急性高热，白细胞数及中性粒细胞百分率明显增高，不限于某一系统感染者
	- 新近出现皮肤、黏膜感染或创伤，有挤压疮疖史，局部症状加重伴高热、寒战及全身中毒症状者
	- 尿路、胆道、呼吸道或局部感染，有效抗菌药物治疗不能控制者
	- 急性高热、寒战，而化脓性关节炎、骨髓炎、软组织脓肿、皮肤脓点疑为迁徙病灶者
	- 有严重基础疾病、静脉或动脉放置器械或导管而出现发热（T＞38℃）或低体温，低血压（收缩压＜90mmHg）或少尿（ ＜20ml/h），原有疾病或其他原因不能解释者
- **确诊** ==血培养和 / 或骨髓培养阳性==
- **鉴别** 
	- 成人斯蒂尔（Still） 病
		- 高热，但毒血症状轻
		- 皮疹短暂，反复出现
		- 多次培养均为阴性
		- 抗生素无效，激素有效
	- [[伤寒]]
	- 粟粒型结核病
	- 其他

# 预后

 - 因免疫状态、病原菌种类、有无并发症而异，病死率为 30%～40%

# 治疗

## 病原治疗

- **原则** 
	- 治疗应==个体化==， 重视药动学 / 药效学（ PK/PD），注意抗菌药物的不良反应，以确保安全、有效
	- 根据==药物敏感试验==选择抗菌药物
	- 在未获得病原学资料前==可行经验性抗菌治疗==
		- **定义** 根据患者年龄、原发疾病、免疫状态、可能的入侵途径等推测病原菌种类，结合当地病原菌耐药流行状况，针对性地选用抗菌药物
		- **场景** 
			- 原发感染在肺部 多为[[肺炎链球菌]]或流感嗜血杆菌等所致，可选用青霉素或半合成青霉素或第一代头孢菌素等
			- 原发感染在膈肌以下 多为[[革兰阴性菌|革兰氏阴性菌]]所致，可选用第三代头孢菌素等β- 内酰胺类（或加氨基糖苷类）抗菌药物
			- 免疫功能低下者 多为产 ESBLs 革兰氏阴性菌所致，可采用第三代头孢菌素 / 酶抑制剂或广谱碳青霉烯类抗生素治疗
	- 严重病例采用==降阶梯治疗==
		- **优点** 发挥碳青霉烯类、糖肽类等抗菌活性强和/ 或抗菌谱广的优势
		- **缺点** 易致二重感染、菌群失调，引发铜绿假单胞菌耐药，诱导耐碳青霉烯类菌株
- **剂量** 根据 PK/PD 原理优化药物剂量
- **疗程** 取决于感染的严重程度、患者的基础疾病等综合因素
	- 一般疗程为 2 周左右，有原发性或转移性感染病灶者适当延长，通常用药至体温正常及感染症状、体征消失后 5～10 天
	- 合并感染性心内膜炎者疗程应为 4～6 周
	- **评估** 建议治疗期间动态监测 PCT 水平来评估败血症患者抗菌药物使用的疗程
- **注意** 不必等待培养结果出来再用药，真菌感染不用广谱抗生素
## 去除感染病灶

- 对于脓肿应==切开引脓，胸腔、腹腔或心包腔等脓液均应穿刺抽脓或手术切开引流==
- 胆道或泌尿道梗阻者应==手术治疗==
- 对导管相关性败血症，应及早==去除或更换导管==等

## 其他治疗

- 对高热患者
	- 物理降温
- 对感染性休克
	- 扩容 液体复苏（==晶体液==）
	- 纠酸 碳酸氢钠
	- 采用血管活性药物
	- [[糖皮质激素|激素]]
- 对医院感染败血症者
	- 应积极治疗原发基础疾病
	- 器官移植后或免疫功能低下者败血症患者应酌情减量或停用免疫抑制剂
- 营养支持
- 输液 严重败血症者酌情输入新鲜血浆、血或白蛋白等
