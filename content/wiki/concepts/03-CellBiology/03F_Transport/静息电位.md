  - resting membrane potential

- **定义** 安静状态时, 细胞膜两侧存在的外正内负的电位差
- **指标** 以细胞外为零电位
- **典例** 
	- [[骨骼肌纤维|骨骼肌细胞]] -90mV
	- [[神经元|神经细胞]] -70mV
	- [[平滑肌纤维|平滑肌细胞]] -55mV
	- [[红细胞]] -10mV
- **形成** 
	- 细胞膜两侧离子浓差和平衡电位 ( $E$ )
		- 膜外 #钠离子 ( $E_{Na}$ =+67mV )
		- 膜内 #钾离子 ( $E_K$ =-98mV )
		- 膜内带负电的有机大分子 (核酸和蛋白质)
		- **注意** 多数细胞膜不存在对氯离子的原发性主动转运，故对静息电位贡献小
		- **计算** 戈德曼方程 
			- $V_m = (RT/F) ln((P_Na[Na^+]_{out} + P_K[K^+]_{out} + P_Cl[Cl^-]_{in}) / (P_Na[Na^+]_{in} + P_K[K^+]_{in} + P_Cl[Cl^-]_{out}))$
	- 静息时细胞膜对离子的通透性
		- 钾漏通道持续开放, 钾离子通透性较高, 因此静息电位总是接近钾离子平衡电位
		- 钠离子和氯离子通透性低, 钠离子少量内流
	- [[钠泵]]的生电作用
		- 每分解1ATP, 排出3 #钠离子 , 摄入2 #钾离子 
- **调节** 
	- 细胞外液钾离子浓度
	- 膜对钾和钠的相对通透性
	- 钠泵活动水平
