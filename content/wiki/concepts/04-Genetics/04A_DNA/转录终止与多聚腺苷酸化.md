# 真核mRNA的3'端加工

## 1. 概述与重要性

真核生物mRNA的3'端成熟是一个关键且高度调控的转录后加工过程，决定了mRNA的稳定性、出核转运及翻译效率。与原核生物不同，真核mRNA并非简单终止于转录终止位点，而是经历一系列有序的**内切断裂（cleavage）** 和**多聚腺苷酸化（polyadenylation）** 修饰。这个过程主要发生在细胞核内，且与RNA聚合酶II（RNA polymerase II）的转录终止紧密偶联，是基因表达调控的重要节点。

```
    +-----------+     +------------+     +-----------+
    | RNA Pol II| --> | Pre-mRNA   | --> | Maturation |
    | Transcription|    | 3' End     |     | of 3' End  |
    +-----------+     +------------+     +-----------+
                           |
                           v
                   +------------------+
                   |  Process of 3'   |
                   |  End Processing  |
                   +------------------+
                           |
              +---------------------------+
              | Cleavage and Polyadenylation |
              +---------------------------+
```

**核心概念**：
- **断裂（Cleavage）**：在特定位点切断前体mRNA（pre-mRNA）。
- **聚腺苷酸化（Polyadenylation）**：在断裂产生的3'端添加约200-250个腺苷酸残基，形成poly(A)尾。

## 2. 关键顺式作用元件与信号序列

加工过程由pre-mRNA 3'端区域的几个保守序列元件驱动，它们被相应的反式作用因子识别：

1.  **多聚腺苷酸化信号（Polyadenylation Signal, PAS）**：
    - **序列**：哺乳动物中为高度保守的 **AAUAAA**，或其变体（如AUUAAA）。
    - **功能**：是加工复合物组装的主要信号，由[[断裂和聚腺苷酸化特异性因子]]（CPSF）识别。位于断裂位点上游约10-30个核苷酸处。

2.  **断裂位点（Cleavage Site）**：
    - 通常位于一个二核苷酸 **CA** 之后。
    - 是内切酶进行精确切割的位置。

3.  **下游元件（Downstream Element, DSE）**：
    - 位于断裂位点下游，富含GU或U。
    - 被**断裂刺激因子（Cleavage Stimulation Factor, CstF）** 识别，对加工效率至关重要。

4.  **上游序列元件（Upstream Sequence Elements, USE）**：
    - 存在于某些基因中，可增强加工效率。

```
            +---- Upstream Region ----+---- Downstream Region ----+
            |                        |                           |
   ...NNNNNNAAUAAAANNCA NNNNGUGUGUNN... (Pre-mRNA 3' End Region)
        |         |   |        |
        |         |   |        +---> DSE (GU-rich)
        |         |   +---> Cleavage Site (CA)
        |         +---> Poly(A) Signal (AAUAAA)
        +---> Upstream Sequences (optional)
```

## 3. 核心反式作用因子：蛋白复合物

### 3.1. 断裂和聚腺苷酸化特异性因子 (Cleavage and Polyadenylation Specificity Factor, CPSF)

- **组成**：至少包含4个主要亚基（如CPSF160, CPSF100, CPSF73, CPSF30）。
- **质量**：总分子量约为 **360 kDa**。
- **功能**：
    1.  **识别PAS**：其亚基CPSF160直接结合AAUAAA信号。
    2.  **提供内切酶活性**：亚基**CPSF73**是负责在断裂位点进行精确切割的内切酶。
    3.  **招募其他因子**：作为组装平台，招募多聚腺苷酸聚合酶（PAP）等。

### 3.2. 断裂因子 (Cleavage Factors)

- **断裂因子Ⅰ (Cleavage Factor I, CF I)** 和 **断裂因子Ⅱ (Cleavage Factor II, CF II)**：
    - 它们与CPSF和CstF协同作用，共同组成 **“断裂复合物”**。
    - 功能：精确对齐断裂位点，稳定复合物，辅助内切酶活性。CF I可能参与识别上游序列。

### 3.3. 断裂刺激因子 (Cleavage Stimulation Factor, CstF)

- **功能**：识别下游GU-rich元件，增强断裂和聚腺苷酸化效率。它与CPSF通过桥接蛋白相互作用，将信号位点与断裂位点在空间上拉近。

### 3.4. 多聚腺苷酸聚合酶 (Poly(A) Polymerase, PAP)

- **功能**：
    1.  **催化聚合**：以ATP为底物，不依赖模板，催化AMP逐个添加到断裂产生的3'-OH末端，起始poly(A)合成。
    2.  **慢速合成期**：最初添加的约10个腺苷酸速度较慢，此阶段受 **[[多聚腺苷酸结合蛋白Ⅱ]]** (PABP II) 调控。

### 3.5. 多聚腺苷酸结合蛋白Ⅱ (Poly(A) Binding Protein II, PABP II)

- **功能**：
    1.  **结合新生poly(A)尾**：特异结合在 **慢速期合成** 的较短poly(A)尾上。
    2.  **加速延伸**：结合后，构象变化刺激PAP，使其进入 **快速合成期**，以极高的速率延伸poly(A)尾。
    3.  **终止合成**：当poly(A)尾长度达到约200-250个腺苷酸时，PABP II可能通过信号反馈使PAP停止作用，从而 **精确控制尾长**。

## 4. 分子机制：加工步骤与复合物组装

整个3'端加工是一个动态、有序的组装过程，可大致分为以下阶段：

**第一步：信号识别与起始复合物形成**
- 转录中的RNA Pol II延伸复合物通过其CTD（C-terminal domain）的磷酸化状态（Ser2磷酸化）募集加工因子。
- **CPSF** 和 **CstF** 最先分别识别 **AAUAAA** 和 **DSE** 元件，形成一个初始的“锚定复合物”。CF I/II等随后加入，形成完整的 **“加工体”** 或 **“断裂复合物”**。

**第二步：内切断裂**
- **CPSF73** 亚基在断裂位点（CA）切割RNA链，产生两个片段：
    - 上游片段：3'端为断裂产生的羟基（-OH），将被添加poly(A)尾。
    - 下游片段：5'端为磷酸基，通常被降解。

**第三步：多聚腺苷酸化**
1.  **慢速起始期**：**PAP** 被招募至断裂位点，开始以极低速率添加腺苷酸（约10个）。
2.  **快速延伸期**：**PABP II** 结合到新生的短poly(A)尾上，与PAP相互作用，激活PAP，使其以高速率（每秒数十个腺苷酸）延伸poly(A)尾。
3.  **终止与成熟**：当poly(A)尾长度达标（~250 nt），PABP II发出信号，PAP活性被抑制，**成熟mRNP** 形成。全长poly(A)尾随后被细胞质中的PABP I结合，保护其免受降解。

```
[Pre-mRNA 3' End Region]
          |
          v
+-----------------------+
| CPSF (binds AAUAAA)   |
| CstF (binds DSE)      |
| CF I, CF II           | <-- 形成断裂复合物
+-----------------------+
          |
          v (Cleavage by CPSF73)
          |
[----mRNA---OH]  +  [p----downstream fragment]
          |
          v (PAP begins adding A's slowly)
[----mRNA---AAAAA...(~10nt)]
          |
          v (PABP II binds, accelerates PAP)
[----mRNA---AAAAAAAAAAA...(250nt)]  <--- Mature poly(A) tail
          |
          v (PABP II signals termination)
[----mRNA---AAAAAAA...AAA]  <-- Mature 3' end in nucleus
```

## 5. 调控与生物学意义

### 5.1. 与转录终止的偶联
- RNA Pol II的转录终止 **“鱼雷模型”** ：加工复合物切割RNA后，下游RNA片段暴露出5'-3'外切核酸酶Xrn2的结合位点。Xrn2从下游向RNA Pol II方向“追赶”，最终导致聚合酶从模板上解离，实现转录终止。因此，3'端加工是有效转录终止的前提。

### 5.2. 选择性多聚腺苷酸化
- 许多基因具有多个PAS。细胞通过调控加工因子的活性或丰度，选择不同的断裂位点，产生具有不同长度3'UTR的mRNA异构体。
    - **短3'UTR**：通常更稳定，翻译效率更高，与细胞增殖相关。
    - **长3'UTR**：可能包含更多调控元件（如miRNA结合位点），在分化、应激反应中发挥精细调控作用。

### 5.3. 质量控制
- 加工失败或异常的pre-mRNA会被核外体等监控机制降解，防止错误mRNA进入细胞质。

### 5.4. 疾病关联
- 加工因子（如CPSF, CstF, PAP）的突变或表达失调与多种疾病相关，包括神经退行性疾病（如ALS/FTD）、癌症和病毒感染（病毒劫持宿主加工机制）。

## 6. 研究方法

1.  **体外重建（In vitro Reconstitution）**：使用纯化的重组蛋白和体外转录的RNA底物，在试管中重现断裂和聚腺苷酸化反应，是研究生化机制的金标准。
2.  **交联免疫沉淀（CLIP）与测序**：如eCLIP、iCLIP，用于在全基因组水平鉴定加工因子在RNA上的结合位点。
3.  **3'端测序技术**：如3'READS、PARE-seq等，用于全基因组范围内精确绘制断裂位点和poly(A)尾长度。
4.  **结构生物学**：冷冻电镜（Cryo-EM）和X射线晶体学技术正在逐步揭示加工复合物的高分辨率结构，阐明其组装和催化机制。
5.  **突变分析**：对因子进行点突变或结构域缺失，结合报告基因系统，分析其功能。

## 7. 总结与展望

真核mRNA的3'端加工是一个精密调控的分子机器过程。以 **CPSF**、**CstF**、**CF I/II**、**PAP** 和 **PABP II** 等为核心的多个因子，通过识别特定的RNA序列元件，有序组装，协同完成pre-mRNA的断裂和poly(A)尾的合成。这一过程不仅决定了单个mRNA的命运，其调控（尤其是选择性多聚腺苷酸化）更是基因表达调控网络的重要组成部分，深刻影响发育、分化、应激和疾病。

未来的研究将更深入地聚焦于：
- 加工复合物的**动态组装与解构**的实时成像。
- **细胞状态特异性**的调控机制（如代谢、信号通路如何影响加工因子活性）。
- **非经典加工途径**（如组蛋白mRNA的3'端加工）。
- 靶向加工因子的**疾病治疗策略**的开发。
