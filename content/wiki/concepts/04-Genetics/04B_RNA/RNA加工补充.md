# RNA加工与修饰的补充知识
**主题**：真核生物前体mRNA (pre-mRNA) 的核内加工与化学修饰，构建从初级转录本到成熟mRNA的知识网络。

---

## 1. 核内加工 (Nuclear Processing)：从初级转录本到成熟mRNA

真核生物的初级转录本 (primary transcript) 或称[[前体mRNA]] (pre-mRNA) 必须经过一系列精密的加工步骤，才能成为具有功能的成熟mRNA，并被运送到细胞质中指导蛋白质合成。这些加工几乎都在细胞核内完成。

```text
   5' Cap                                    Poly(A) Tail
      |                                          |
      v                                          v
   [m7GpppN]----[Exon 1]----[Intron]----[Exon 2]----[Exon 3]----AAAA...
   (Primary Transcript / pre-mRNA)
```
*图示：真核生物初级转录本的基本结构。Cap: 5‘端帽子；Exon: 外显子；Intron: 内含子；Poly(A): 3’端多聚腺苷酸尾。*

### 1.1 5‘端加帽 (5’ Capping)
- **时机**：转录起始后不久，当新生RNA链长约20-30个核苷酸时即开始。
- **化学结构**：一个通过**5‘-5’三磷酸键**连接到转录本第一个核苷酸上的**7-甲基鸟苷酸 (m⁷G)**。
  ```text
        m⁷G
         | (5‘-5’ PPP)
         N (第一个转录的核苷酸)
  ```
- **功能**：
  1. **保护**：防止5‘→3’核酸外切酶的降解。
  2. **识别**：作为翻译起始因子（如eIF4E）的识别标志，对**帽子依赖性翻译**至关重要。
  3. **剪接与运输**：参与核内剪接体的组装和成熟mRNA的核质运输。

### 1.2 3’端多聚腺苷酸化 (3’ Polyadenylation)
- **信号**：由内切核酸酶识别pre-mRNA 3‘端特定的**多聚腺苷酸化信号** (如AAUAAA)。
- **过程**：
  1. 内切核酸酶在信号序列下游10-30个核苷酸处进行切割。
  2. **多聚腺苷酸聚合酶 (Poly(A) Polymerase, PAP)** 以ATP为前体，向新产生的3‘端添加约200-250个腺苷酸残基，形成poly(A)尾。
- **功能**：
  1. **稳定**：保护mRNA免受3‘→5’核酸外切酶的攻击。
  2. **翻译效率**：poly(A)尾与**poly(A)结合蛋白 (PABP)** 结合，可与5‘帽结构相互作用，环化mRNA，增强翻译起始效率。
  3. **核质运输与发育调控**：参与mRNA出核和某些发育阶段的翻译控制（如卵母细胞中的“掩蔽”）。

### 1.3 RNA剪接 (RNA Splicing)
这是去除内含子 (intron) 并将外显子 (exon) 连接起来的核心步骤，极大地增加了**蛋白质组的多样性**（通过可变剪接）。

- **剪接体 (Spliceosome)**：执行剪接的大型核糖核蛋白 (RNP) 复合体。其核心是五种[[核小RNA]] (snRNA: U1, U2, U4, U5, U6) 与多种蛋白质结合形成的**小核核糖核蛋白颗粒 (snRNPs)**。
  ```text
          U4
           \
            U6 -- U2
           /     /
      U1 -- U5
       \     /
        Pre-mRNA (Intron)
  ```
  *图示：剪接体组装的简化模型。snRNPs通过与内含子的保守序列（5‘剪接位点、分支点、3’剪接位点）及相互作用逐步组装。*

- **剪接的化学机制**：两步连续的**转酯反应 (transesterification)**。
  ```text
  第一步：                第二步：
  O   O                   O   O
   \ /                     \ /
    P---OH   + 套索中间体      P---O-Exon1-Exon2
   / \                     / \
  Base  Branch Point      Exon1  O
   |    (2'OH攻击)        (3'OH攻击)
  Intron                套索(lariat)被释放
  ```
  1. **分支点序列 (BPS)** 内特定腺苷酸 (A) 的2‘-OH亲核攻击5’剪接位点 (5‘SS)，形成**套索结构 (lariat)** 和游离的5’外显子。
  2. 第一个外显子的3‘-OH亲核攻击3’剪接位点 (3‘SS)，将两个外显子连接起来，并释放出套索状内含子。

- **可变剪接 (Alternative Splicing)**：一个基因的pre-mRNA可以通过使用不同的5‘SS或3’SS、跳过外显子或保留内含子等方式，产生多种不同的mRNA变体。这是**真核生物蛋白质多样性的主要来源**。

### 1.4 RNA编辑 (RNA Editing)
在转录后水平，通过插入、删除或替换核苷酸来改变mRNA编码序列的过程。
- **碱基转换 (Deamination)**：
  - **C→U**：**载脂蛋白B (ApoB)** mRNA在肠细胞中由**APOBEC1**酶催化发生编辑，产生截短的ApoB-48，与肝中的全长ApoB-100功能不同。
  - **A→I (肌苷)**：由**ADAR**酶催化，在神经系统中普遍存在。由于I被翻译机器识别为G，可导致**非同义密码子改变**，极大地增加了神经受体等蛋白质的多样性。
- **指导RNA (gRNA)**：在锥虫线粒体中，以gRNA为模板，通过尿苷酸的插入和删除来编辑mRNA。

## 2. RNA的化学修饰 (Chemical Modifications of RNA)

除了加工，RNA分子（尤其是tRNA、rRNA和snRNA）会经历广泛的、功能多样的化学修饰。这些修饰主要由特定的酶催化。

- **[[核仁小RNA]] (snoRNA) 的作用**：snoRNA是指导rRNA、tRNA和snRNA修饰的关键分子。它们通过与靶RNA碱基配对，为修饰酶提供“地址”。
  - **C/D box snoRNA**：指导**2‘-O-甲基化 (Nm)**。snoRNA的特定序列与靶RNA配对，甲基转移酶将SAM的甲基转移到靶核苷酸核糖的2‘-OH上。
  - **H/ACA box snoRNA**：指导**假尿嘧啶化 (Ψ)**。snoRNA的假尿嘧啶化引导序列 (pseudouridylation pocket) 与靶RNA配对，假尿嘧啶合酶将尿苷 (U) 的糖苷键从N-C1‘连接转换为C5-C1’连接，形成假尿苷 (Ψ)。

- **重要的化学修饰**：
  - **tRNA**：含有最密集的修饰（~100种类型），如**二氢尿苷 (D)**、**肌苷 (I)**、**硫代尿苷 (s²U)**等，对其结构稳定性、密码子识别和氨酰化效率至关重要。**稀有碱基**如**假尿苷 (ψ)** 和**甲基化碱基**在此尤为突出。
  - **rRNA**：除上述2‘-O-Me和Ψ外，还有特定的碱基甲基化，影响核糖体结构和翻译保真度。
  - **mRNA**：近年来研究最为火热的领域是**N6-甲基腺苷 (m⁶A)** 修饰。
    - **催化**：由“写入器”(Writer) 复合物（如METTL3/14）添加，由“擦除器”(Eraser) 酶（如FTO， ALKBH5）去除。
    - **识别**：被“阅读器”(Reader) 蛋白（如YTH家族）识别。
    - **功能**：作为**表观转录组 (epitranscriptomic)** 标记，影响mRNA的剪接、出核、稳定性、定位和翻译效率，广泛参与发育、干细胞分化、神经功能和肿瘤发生。

## 3. 质控与运输 (Quality Control & Transport)

### 3.1 核内质量监控
未正确加工的RNA在核内会被识别并降解。
- **核外切体 (Nuclear Exosome)**：降解异常或过量RNA的核心机器。
- **核仁监控**：如**Trf4/5-Air1/2-Mtr4 多聚腺苷酸化复合体 (TRAMP)** 可向异常RNA添加短poly(A)尾，靶向其被外切体降解。

### 3.2 核质运输 (Nuclear Export)
成熟mRNA与多种蛋白（如外体复合体 **Exon Junction Complex， EJC**、核孔复合体结合蛋白）形成**mRNP (messenger ribonucleoprotein)** 复合物。
- **出核受体**：**NXF1-NXT1**异源二聚体是主要的mRNA出核受体，它与mRNP结合并介导其通过核孔复合体 (NPC)。
- **连接翻译**：mRNP在细胞质侧被“解码”，去包装，并启动翻译。mRNA的**环化**（通过帽结合蛋白与PABP的相互作用）是翻译起始的高效形式。

## 4. 核内过程的整合与调控 (Integration & Regulation)

```text
          [特异转录因子] & [RNA聚合酶II]
                      |
                      v
                 启动子清除 (Promoter Clearance)
                      |
        -------------|--------------------
       |                               |
   [[流产式起始]]                  延伸
       |                               |
       v                               v
   (5‘加帽) <--------------------- (CTD磷酸化)
                                       |
                          ------------|-----------
                         |            |            |
                      剪接       3’端加工      甲基化
                         |            |            |
                         v            v            v
                    [剪接体]    [CPSF, CstF]    [m6A Writers]
                         \           |           /
                          \          |          /
                           \         |         /
                            v        v        v
                          成熟mRNP (带有EJC， m⁶A， poly(A)等)
                                      |
                                      v
                                [[核孔复合体]] (NPC)
                                      |
                                      v
                               细胞质翻译或降解
```
*图示：真核生物mRNA合成、加工与输出的整合模型。CTD: RNA聚合酶II的C末端结构域，是协调加工步骤的“平台”。*

- **CTD的作用**：RNA聚合酶II最大亚基的**C端结构域 (CTD)** 的**磷酸化状态**（如Ser2, Ser5磷酸化）动态变化，像一个“分子时钟”一样，招募不同的加工因子到转录位点，确保加工步骤的顺序性与协调性。
- **[["核小RNA" (U7)]]** 在加工**组蛋白前体mRNA**中起特殊作用，其3‘端无poly(A)尾，而是由U7 snRNP协助识别并切割其特有的茎环结构。
- **与[[真核基因|断裂基因]]结构的联系**：pre-mRNA加工直接作用于[[真核基因]]的转录产物。内含子/外显子的边界由剪接位点序列和剪接机制决定，而可变剪接是表达“断裂基因”中遗传信息的主要方式。
- **与[[线粒体基因组]]的对比**：线粒体拥有独立的转录和RNA加工系统，其RNA加工（如rRNA和tRNA的加工）通常更简单，但依赖核基因编码的蛋白质。

## 关键概念关联
- **核心机器**：[[核小RNA]] (snRNA) 是剪接体核心；[[核仁小RNA]] (snoRNA) 是rRNA/tRNA修饰的核心向导。
- **产物功能**：成熟mRNA是[[核糖体]]进行翻译的模板。在翻译中，mRNA通过其密码子序列与[[氨酰tRNA]]的反密码子配对。
- **信息流**：加工后的mRNA携带了来自[[模板链]]的信息，并经过了转录后调控层的“编辑”，体现了中心法则的复杂性。
- **全局调控**：RNA加工与修饰不是独立事件，而是与转录起始（受[[特异转录因子]]调控）和转录终止紧密耦合，并受到细胞信号通路的精密调控，是基因表达调控的关键环节。
