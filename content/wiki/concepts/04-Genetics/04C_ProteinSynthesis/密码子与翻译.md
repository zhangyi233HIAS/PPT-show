# 遗传密码与翻译 (The Genetic Code & Translation)

## **1. 概述 (Overview)**
[[翻译]]是中心法则的核心环节，指在核糖体（ribosome）上，以信使RNA（mRNA）为模板，将遗传密码（genetic code）解码为具有特定氨基酸序列的多肽链（polypeptide chain）的过程。此过程将核酸语言转化为蛋白质语言，是基因表达的关键步骤。本笔记将系统阐述翻译的分子基础、核心机器、过程与调控。

## **2. 遗传密码：规则与特性 (The Genetic Code: Rules & Properties)**
遗传密码是指mRNA上核苷酸序列与蛋白质中氨基酸序列的对应规则。

### **2.1 密码子 (Codon)**
根据[[密码子]]的定义，mRNA上每三个相邻的核苷酸构成一个密码子，编码一个氨基酸或起始/终止信号。mRNA的阅读从固定的起始点开始，以三个核苷酸为单位进行，称为“阅读框”（reading frame）。

### **2.2 通用密码子表 (The Universal Code Table)**
标准遗传密码（Standard Genetic Code）包含64个密码子：
- **61个有义密码子 (sense codons)**：编码20种标准氨基酸。
- **3个终止密码子 (stop codons)**：UAA, UAG, UGA，也称为“无义密码子”（nonsense codons）。
- **1个起始密码子 (initiation codon)**：AUG（编码甲硫氨酸，在真核生物中常为甲硫氨酸，原核生物中为甲酰甲硫氨酸）。

```
                          第二位核苷酸
                    U       C       A       G
         ┌───────┬───────┬───────┬───────┐
    U    │ UUU F │ UCU S │ UAU Y │ UGU C │ U
         │ UUC F │ UCC S │ UAC Y │ UGC C │ C
         │ UUA L │ UCA S │ UAA * │ UGA * │ A   第三位
         │ UUG L │ UCG S │ UAG * │ UGG W │ G   核苷酸
         ├───────┼───────┼───────┼───────┤
    C    │ CUU L │ CCU P │ CAU H │ CGU R │ U
         │ CUC L │ CCC P │ CAC H │ CGC R │ C
         │ CUA L │ CCA P │ CAA Q │ CGA R │ A
         │ CUG L │ CCG P │ CAG Q │ CGG R │ G
         ├───────┼───────┼───────┼───────┤
    A    │ AUU I │ ACU T │ AAC N │ AGU S │ U
         │ AUC I │ ACC T │ AAC N │ AGC S │ C
         │ AUA I │ ACA T │ AAA K │ AGA R │ A
         │ AUG M │ ACG T │ AAG K │ AGG R │ G
         ├───────┼───────┼───────┼───────┤
    G    │ GUU V │ GCU A │ GAU D │ GGU G │ U
         │ GUC V │ GCC A │ GAC D │ GGC G │ C
         │ GUA V │ GCA A │ GAA E │ GGA G │ A
         │ GUG V │ GCG A │ GAG E │ GGG G │ G
         └───────┴───────┴───────┴───────┘
* 代表终止密码子。M (AUG) 为起始密码子。
```

### **2.3 密码子的关键特性**
- **简并性 (Degeneracy)**：除甲硫氨酸（AUG）和色氨酸（UGG）外，所有氨基酸均由多个密码子编码。这主要源于密码子的第三位核苷酸（“摇摆碱基”， wobble base）与[[转运RNA|tRNA]]反密码子配对的灵活性，降低了突变带来的有害影响。
- **无逗号性与不重叠性 (Commaless & Non-overlapping)**：密码子之间无间隔，连续阅读；且相邻密码子共享核苷酸的情况极为罕见。
- **通用性 (Universality)**：从细菌到人类，绝大多数生物使用同一套遗传密码，是生命统一性的有力证据。但也存在一些线粒体或某些原生生物中的变异密码子。

## **3. 翻译机器的核心组分 (Core Components of the Translation Machinery)**

### **3.1 信使RNA (mRNA)**
作为模板，其结构直接决定蛋白质序列。
- **5‘ 端**：真核生物具有[[5‘-非翻译区]]（5’-UTR），包含核糖体结合位点（Kozak序列），对翻译起始至关重要。
- **可读框 (Open Reading Frame, ORF)**：从起始密码子（AUG）到终止密码子（UAA/UAG/UGA）的连续编码区。
- **3‘ 端**：具有poly(A)尾，与翻译效率和mRNA稳定性相关。

### **3.2 转运RNA (tRNA)**
作为“接头分子”（adaptor），兼具识别密码子和携带氨基酸的功能。
- **结构**：75-95个核苷酸，形成特征性的“三叶草”二级结构（cloverleaf）和倒“L”型三级结构。
```
   氨基酸臂 (Acceptor Stem)
       3' -A C C A- (氨基酸附着位点)
        |
   ┌────┘
   │ DHU臂 ──── 反密码子臂 ──── TΨC臂
   │ (D环)        (反密码子环)    (TΨC环)
   └────┐
        |
   可变环 (Variable Loop)
```
- **关键位点**：
  - **3‘ 端 -CCA**：氨基酸共价结合位点。
  - **反密码子 (Anticodon)**：由三个核苷酸组成，通过碱基互补配对识别mRNA上的密码子。遵循“摇摆假说”（Wobble Hypothesis），反密码子第一位（5‘端）的I（次黄嘌呤）或G/U可与密码子第三位的多种碱基配对，解释了简并性。
- **氨基酰-tRNA合成酶 (Aminoacyl-tRNA synthetase)**：一类酶，负责将正确的氨基酸连接到对应的tRNA上，形成“氨基酰-tRNA”（aminoacyl-tRNA）。该过程消耗ATP，是确保翻译准确性的关键步骤。

### **3.3 核糖体 (Ribosome)**
翻译的“分子工厂”，是一个巨大的核糖核蛋白复合物。其核心是[[核糖体RNA|rRNA]]。
- **组成**：由大、小两个亚基构成，包含rRNA和数十种核糖体蛋白。
  - **原核生物**：70S核糖体 = 30S小亚基 + 50S大亚基
  - **真核生物**：80S核糖体 = 40S小亚基 + 60S大亚基
- **功能位点**：
  - **A位点 (Aminoacyl site)**：接受新进入的氨基酰-tRNA。
  - **P位点 (Peptidyl site)**：结合携带肽链的tRNA。
  - **E位点 (Exit site)**：释放去酰化的tRNA。
  - **肽酰转移酶中心 (Peptidyl transferase center)**：位于大亚基，核心由rRNA催化肽键形成，故核糖体本质上是一种**核酶 (ribozyme)**。

## **4. 翻译过程 (The Process of Translation)**
可分为起始（Initiation）、延伸（Elongation）和终止（Termination）三个阶段。

### **4.1 起始 (Initiation)**
目标是组装起始复合物，将起始tRNA置于核糖体的P位点，对准mRNA的起始密码子。
- **原核生物**：依赖于mRNA上的**Shine-Dalgarno序列**与核糖体16S rRNA配对，精确定位起始密码子AUG。起始tRNA携带甲酰甲硫氨酸（fMet-tRNA^fMet^）。
- **真核生物**：过程更复杂，依赖于**5‘帽结构**。起始因子（eIFs）首先识别帽结构，并沿5‘-UTR扫描（scanning），直至遇到第一个AUG（遵循Kozak规则）才停下，开始组装80S起始复合物。起始tRNA携带甲硫氨酸（Met-tRNAi^Met^）。

### **4.2 延伸 (Elon gation)**
一个由**延伸因子 (elongation factors, EFs)** 调控的循环过程。
1. **进位 (Decoding)**：氨基酰-tRNA在EF-Tu（原核）/eEF1A（真核）及GTP的辅助下进入核糖体A位点，通过密码子-反密码子配对进行校对。
2. **转肽 (Peptide bond formation)**：肽酰转移酶催化P位点tRNA上肽链的羧基与A位点氨基酸的氨基形成肽键。肽链转移至A位点的tRNA上。
3. **移位 (Translocation)**：在EF-G（原核）/eEF2（真核）及GTP水解的驱动下，核糖体沿mRNA向3‘方向移动一个密码子长度。结果：原A位点的tRNA（现携带肽链）移至P位点，原P位点的去酰化tRNA移至E位点并随后被释放，A位点空出以接收下一个氨基酰-tRNA。此循环不断重复，肽链得以延伸。

### **4.3 终止 (Termination)**
当核糖体A位点遇到**终止密码子**（UAA, UAG, UGA）时，没有相应的tRNA能与之结合。
- **释放因子 (Release factors, RFs)** 识别终止密码子并进入A位点。
- RF激活肽酰转移酶，催化一个多肽分子（或水分子）与P位点tRNA上的肽链连接，导致肽链从tRNA上水解释放。
- 核糖体解离因子（RRF和EF-G，或真核的eRF3）促使核糖体大小亚基、mRNA和最后一个tRNA解离，翻译终止。

## **5. 翻译的调控与质量控制 (Regulation & Quality Control of Translation)**

### **5.1 翻译调控**
翻译可在多个层次受到精细调控，是基因表达调控的重要环节：
- **起始水平调控**：通过磷酸化起始因子（如eIF2α）、调控5‘-UTR的结构（如内部核糖体进入位点，IRES）、或通过[[微RNA]]（miRNA）引导的RISC复合物与mRNA 3‘-UTR结合，抑制翻译起始或促进mRNA降解。
- **mRNA稳定性**：poly(A)尾长度、特定序列元件（如AU-rich elements）影响mRNA半衰期，从而影响翻译总量。
- **核糖体调控**：**核糖体暂停 (Ribosome pausing)** 和 **核糖体碰撞 (Ribosome collisions)** 不仅调控特定蛋白质合成速率，也是重要的质量控制信号。

### **5.2 翻译质量控制**
细胞拥有多重机制确保翻译保真度和处理错误：
- **氨基酰-tRNA合成酶的校对 (Proofreading)**：具有水解错误氨基酸的编辑功能。
- **核糖体的解码中心 (Decoding center)**：16S/18S rRNA监控密码子-反密码子配对的几何构型，进行动力学校对。
- **无义介导的mRNA降解 (Nonsense-Mediated mRNA Decay, NMD)**：识别并降解含有提前终止密码子（premature termination codon, PTC）的mRNA，防止截短蛋白的产生。
- **非终止介导的mRNA降解 (Non-Stop Decay, NSD)** 和 **无go介导的mRNA降解 (No-Go Decay, NGD)**：分别处理因缺乏终止密码子或遇到强二级结构/稀有密码子而导致核糖体停滞的mRNA。

## **6. 总结 (Conclusion)**
遗传密码将核酸序列信息转化为蛋白质功能信息。翻译是一个在空间和时间上高度有序、受多重因子精密调控的动态过程。其核心组分——mRNA、tRNA、核糖体（rRNA与蛋白质）——协同工作，确保了遗传信息流的高保真传递。对翻译机制的理解，不仅是分子生物学的基石，也为诸多疾病（如遗传病、癌症、感染）的诊治和生物技术的发展提供了理论基础。
