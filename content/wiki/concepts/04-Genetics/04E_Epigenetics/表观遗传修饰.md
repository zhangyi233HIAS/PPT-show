# 表观遗传的分子机制
**Molecular Mechanisms of Epigenetics**

## 1. 概述与核心概念
表观遗传学（Epigenetics）研究的是在不改变DNA序列的前提下，通过可遗传的化学修饰调控基因表达，从而影响细胞表型与生物学功能的机制。其核心在于，这些修饰模式能够在细胞分裂过程中**稳定维持**，并通常对环境信号做出响应。表观遗传的可塑性是发育、细胞分化以及疾病发生的关键基础。

主要分子机制包括：
- **DNA 甲基化**
- **组蛋白共价修饰**
- **染色质重塑**
- 非编码RNA调控（本笔记主要聚焦前三种）

这三种机制并非独立运作，而是形成一个**协同的表观遗传调控网络**，共同决定染色质的开放/闭合状态（[[染色质重塑]]），从而控制转录机器对DNA的可及性。

## 2. DNA 甲基化
**DNA Methylation**

DNA甲基化是研究最深入、最稳定的表观遗传标记之一，通常与基因转录沉默相关。

### 2.1 化学基础与酶系统
在哺乳动物中，DNA甲基化主要发生在**胞嘧啶（C）** 的第五位碳原子上，形成**5-甲基胞嘧啶（5-methylcytosine, 5-mC）**，该反应主要位于**CpG二核苷酸**序列中。

催化此反应的酶是**DNA甲基转移酶（DNA methyltransferases, DNMTs）**，主要分为两大类：
1.  **维持型甲基转移酶（Maintenance DNMT）**：
    - **Dnmt1**。其功能是在DNA复制后，识别**半甲基化（hemimethylated）** 的DNA子链（亲代链甲基化，新生链未甲基化），并催化新生链上相应CpG位点的甲基化，从而**忠实复制亲代细胞的甲基化模式**。这对表观遗传信息的传递至关重要。
2.  **从头合成型甲基转移酶（De novo DNMTs）**：
    - **Dnmt3a** 和 **Dnmt3b**。它们**不依赖**于半甲基化模板，能够在**未甲基化**的DNA双链上**从头开始（de novo）** 建立新的甲基化模式。它们在早期胚胎发育和细胞分化过程中设定细胞特异性的甲基化图谱。
    - Dnmt3L是Dnmt3a/3b的辅助因子，虽无催化活性，但对其功能至关重要。

### 2.2 生物学功能
- **基因表达沉默**：启动子区CpG岛（CpG islands）的高甲基化通常通过阻碍转录因子结合或招募转录抑制复合物（如MBD蛋白）来抑制基因转录。
- **[[基因组印迹]] (Genomic Imprinting)**：由亲本来源决定的单等位基因表达现象。其分子基础是：**两个亲本等位基因**在特定区域存在**差异性甲基化**（一个等位基因甲基化而沉默，另一个非甲基化而表达），这是经典的DNA甲基化直接调控基因表达的例子。
- **X染色体失活**：雌性哺乳动物细胞中，两条X染色体之一发生大规模沉默，DNA甲基化在维持该沉默状态中起关键作用。
- **转座子沉默**：甲基化是抑制基因组内“跳跃”的转座子活性、维持基因组稳定的主要机制。

### 2.3 检测技术
- **亚硫酸氢钠测序法（Bisulfite Sequencing）**：金标准。亚硫酸氢钠处理可使未甲基化的C脱氨变为尿嘧啶（U），而甲基化的C不受影响。通过PCR和测序比对，可精确绘制单碱基分辨率的甲基化图谱。
- **甲基化特异性PCR（MSP）**、**限制性内切酶-PCR法**等。

## 3. 组蛋白修饰
**Histone Modification**

组蛋白是真核生物染色质的基本结构蛋白。其N-端尾部可发生多种共价修饰，构成复杂的“组蛋白密码（histone code）”，被特定蛋白质“阅读器”识别，从而招募效应复合物，改变染色质结构和功能。

### 3.1 主要修饰类型与功能
以下为常见修饰及其一般效应（效应具有上下文依赖性）：

| 修饰类型         | 主要靶氨基酸残基         | 一般效应         | 备注与双向性                                 |
|------------------|--------------------------|------------------|----------------------------------------------|
| **乙酰化**       | H3, H4 上的赖氨酸 (Lys)  | **转录激活**     | 中和组蛋白正电荷，削弱DNA-组蛋白相互作用，开放染色质 |
| **甲基化**       | H3, H4 上的赖氨酸 (Lys), 精氨酸 (Arg) | **双向（激活/抑制）** | **关键点：效应高度依赖位点和甲基化程度。** 例如：H3K4me3（激酶）vs. H3K9me3（抑制）。 |
| **磷酸化**       | 丝氨酸 (Ser), 苏氨酸 (Thr) | **转录激活**     | 与有丝分裂染色体凝缩、DNA损伤应答、信号转导相关 |
| **泛素化**       | H2A, H2B 的C端赖氨酸 (Lys) | **双向**         | H2B单泛素化通常与转录延伸相关               |
| **苏木化 (SUMO化)** | 赖氨酸 (Lys)             | **转录抑制**     | 通常拮抗乙酰化，稳定异染色质                 |
| **乳酸化**       | 赖氨酸 (Lys)             | **转录激活**     | 新近发现的修饰，将细胞代谢状态（乳酸水平）与基因表达直接联系 |

**注意双向性**：组蛋白甲基化是一个典型例子。其功能并非一成不变，而是由**被修饰的特定残基、甲基化程度（单、双、三甲基化）以及周围的染色质环境共同决定**。例如，H3第4位赖氨酸的三甲基化（H3K4me3）是活跃启动子的标志，而H3第9位或第27位赖氨酸的三甲基化（H3K9me3， H3K27me3）则与基因沉默相关。

### 3.2 “书写器”、“擦除器”与“阅读器”
- **书写器 (Writers)**：催化添加修饰的酶，如组蛋白乙酰转移酶（HATs）、组蛋白甲基转移酶（HMTs）。
- **擦除器 (Erasers)**：催化去除修饰的酶，如组蛋白去乙酰化酶（HDACs）、组蛋白去甲基化酶（KDMs）。
- **阅读器 (Readers)**：识别特定修饰并招募下游效应复合物的蛋白结构域，如溴结构域（识别乙酰化）、染色质结构域（识别甲基化）。

## 4. 染色质重塑
**Chromatin Remodeling**

染色质重塑是指在不改变DNA序列的情况下，利用ATP水解提供的能量，**改变核小体位置、组成或结构**的动态过程。这是表观遗传调控的**执行层面**，使得DNA序列对转录机器变得“可及”或“不可及”。

### 4.1 作用机制与复合物
- **核心原理**：[[DNA甲基化]]、[[组蛋白修饰]]以及**ATP依赖的染色质重塑复合物**协同作用，共同改变染色质的局部高级结构。
- **主要作用**：
    1.  **核小体滑动 (Sliding)**：沿DNA移动核小体位置，暴露或掩蔽调控序列。
    2.  **核小体驱逐 (Ejection)**：暂时或永久移除核小体，产生“无核小体区”（NFR），如启动子区。
    3.  **组蛋白变体置换 (Exchange)**：将核心组蛋白替换为具有特殊功能的**组蛋白变体**（如H2A.Z， H3.3），从而影响染色质性质。
- **主要复合物家族**：SWI/SNF, ISWI, CHD, INO80等。它们识别特定的**组蛋白修饰**或**DNA序列特征**，被招募至特定位点进行重塑。

### 4.2 染色质状态的转化
染色质重塑是实现以下两种功能状态转化的关键驱动力：
- **[[常染色质]] (Euchromatin)**：结构松散、转录活跃的区域。富含**H3K4me3、H3K36me3**等激活标记，以及**乙酰化**修饰。
- **[[异染色质]] (Heterochromatin)**：结构致密、转录沉默的区域。分为：
    - **组成型异染色质**：着丝粒、端粒等区域，富含**H3K9me3**，由HP1蛋白识别并维持。
    - **兼性异染色质**：发育过程中被程序性沉默的区域（如失活的X染色体），富含**H3K27me3**，由多梳抑制复合物（PRC）建立和维持。

## 5. 染色质的结构层次：从核小体到螺线管
染色质的高级结构为上述分子机制的执行提供了物理基础。

```ascii
图1: 染色质组装层次
(约11 nm)        (30 nm)           (更高阶)
  DNA双螺旋
      |
     \ /
      V
+-----------+      +------+      +------------+
| 核小体    |----->| 螺线管 |----->| 染色质环   | -> ...
| (核心颗粒)|      |      |      |            |
+-----------+      +------+      +------------+
      |                |
      |                |
     V V              V V
```

1.  **[[核小体]] (Nucleosome)**：染色质的基本结构单位。
    - **[[核心颗粒]] (Core Particle)**：直径约11 nm的盘状颗粒，由**八聚体核心组蛋白**（2拷贝的H2A, H2B, H3, H4）和缠绕其上的**约146 bp DNA双链**（缠绕1.75圈）构成。核心组蛋白的N端尾巴从颗粒表面伸出，是发生各种修饰的位点。
    - **连接DNA与组蛋白H1**：相邻核小体之间由约20-80 bp的连接DNA（linker DNA）相连。[[组蛋白 H1]]（连接组蛋白）结合在连接DNA与核小体核心的进出口处，**稳定核小体结构**，并参与更高层次的折叠。

2.  **30 nm染色质纤维（螺线管模型）**：
    - **[[中空状螺线管]] (Solenoid)**：这是描述30 nm染色质纤维的经典模型之一。它由**6个左右的核小体**螺旋排列形成，[[组蛋白 H1]]位于**内侧**，起稳定作用。核小体串按照**左手螺旋**方式盘绕卷曲，形成直径约30 nm的中空管状结构。

## 6. 协同调控与疾病关联

### 6.1 表观遗传网络的整合
在细胞内，这些机制紧密交织：
- **DNA甲基化与组蛋白修饰**：DNA甲基化常与H3K9me3、H3K27me3等抑制性组蛋白标记共存，并可通过招募含MBD结构域的蛋白（同时能结合HDACs）来强化沉默。
- **组蛋白修饰与染色质重塑**：特异的组蛋白修饰“密码”直接被染色质重塑复合物的“阅读器”识别，从而在正确的位置进行重塑。例如，SWI/SNF复合物可被乙酰化的组蛋白招募。
- **正反馈环路**：某些修饰可促进同一区域更多同类型修饰的添加（如H3K9me3招募更多HMT），或抑制去修饰酶的活性，从而使表观遗传状态具有**稳定性和记忆性**。

### 6.2 表观遗传失调与疾病
表观遗传机制的异常与多种疾病，尤其是癌症和神经发育障碍密切相关。
- **癌症**：全球性的抑癌基因启动子**CpG岛异常高甲基化**导致其沉默，是癌症的普遍特征。同时，全基因组范围内的**低甲基化**可能导致基因组不稳定和癌基因激活。组蛋白修饰酶（如EZH2， HDACs）的突变或表达异常也是重要病因。
- **Rett综合征 (Rett Syndrome)**：
    - **成因**：位于**X染色体（Xq28）** 的**MECP2基因**发生功能丧失性突变。
    - **机制**：MECP2蛋白是一个关键的“阅读器”，其主要功能是**特异性结合甲基化的CpG位点**（尤其是广泛分布于基因间的5-mC），并招募转录抑制复合物（包括HDACs），从而调控大量基因的表达。
    - **后果**：MECP2突变破坏了正常的**DNA甲基化解读**过程，导致神经元中大量基因表达失调，引发严重的神经发育障碍。这完美阐释了“读取”表观遗传标记与执行生物功能之间的直接联系。

## 总结
表观遗传的分子机制构成了一个精密的、多层次的信息存储和调控系统。**DNA甲基化**提供稳定的长期沉默信号；**组蛋白修饰**作为一个动态的、可逆的“密码”层，提供精细的调控；而**ATP依赖的染色质重塑复合物**则是执行者，物理性地改变染色质结构。它们共同作用于**染色质的结构层次**（从核小体到螺线管），将基因组信息在时间和空间上进行“解压缩”或“压缩”，从而精确控制基因表达程序。理解这些机制的协同与失调，是解析发育奥秘和攻克复杂疾病的关键。
