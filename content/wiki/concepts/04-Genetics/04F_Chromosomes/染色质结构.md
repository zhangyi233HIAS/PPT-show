# **染色质结构：从DNA纤维到表观遗传景观**

## **1. 引言：染色质——遗传信息的功能性载体**
在真核生物的细胞核中，线性DNA分子并非裸露存在，而是与一组称为**组蛋白 (histones)** 的碱性蛋白质精密组装，形成动态的复合物——**染色质 (chromatin)**。染色质是遗传物质在细胞间期的存在形式，其核心功能在于将长达数米的DNA分子压缩容纳于微米级的细胞核内，并为基因表达的精密调控提供结构基础。进入有丝分裂期，染色质进一步高度螺旋化，形成在光学显微镜下可见的**染色体 (chromosome)**。因此，染色质结构不是静态的包装，而是一个高度动态的“信息界面”，其构象状态直接决定了基因组的可及性与转录活性。

## **2. 核小体：染色质的基本结构单位**
染色质的基本重复单位是**核小体 (nucleosome)**。每个核小体由一个核心颗粒和连接DNA组成。
- **核心颗粒**：由约146个碱基对 (bp) 的DNA以左手超螺旋方式缠绕在由**H2A、H2B、H3、H4**四种核心组蛋白各两个拷贝组成的八聚体上约1.65圈。
- **连接DNA (linker DNA)**：相邻核小体核心颗粒之间的DNA片段，长度在0-80bp间变化，通常约20-60bp。**H1组蛋白 (linker histone)** 结合于此，对稳定30nm纤维的高级结构至关重要。
核小体的形成实现了DNA的初步压缩（约6-7倍），是更高层次染色质折叠的基石。

## **3. 从核小体到染色体：多层次压缩**
核小体串珠结构如何进一步折叠，是染色质结构领域的经典问题。当前模型认为存在多层次折叠，且具有显著的细胞类型和状态特异性。
1.  **30nm染色质纤维 (30nm chromatin fiber)**：核小体串珠在H1和离子环境（特别是Mg²⁺）作用下，折叠形成直径约30nm的螺线管 (solenoid) 或锯齿形 (zigzag) 纤维，实现约40倍的压缩。**然而，在活体细胞中，如此均一、稳定的30nm纤维是否普遍存在，近年受到挑战。更多证据支持存在由“核小体 clutches”形成的非均匀、不规则折叠的纤维。**
2.  **染色质环 (chromatin loops)**：30nm或更高级纤维通过蛋白质复合物（如**粘连蛋白 cohesin**、**CTCF**）形成大小从数kb到数百kb不等的环状结构。这些环将增强子 (enhancer) 等调控元件在空间上拉近启动子 (promoter)，是基因调控的关键。
3.  **拓扑关联结构域 (Topologically Associating Domains, TADs)**：由CTCF和cohesin界定，其内部DNA元件相互作用频率远高于TAD之间。TAD是基因组折叠的基本功能单元，将增强子-启动子的相互作用限制在特定结构域内。
4.  **染色质区室 (Chromatin Compartments)**：在单细胞水平，染色质进一步划分为活跃的**A区室 (A compartment)** 和沉默的**B区室 (B compartment)**。A区室对应[[常染色质]]，富含活跃基因和开放染色质标记；B区室对应[[异染色质]]。
5.  **染色质域与染色体疆域 (Chromatin Territories)**：每条染色体在细胞核内占据一个相对离散的区域，即染色体疆域。疆域内部又分为不同的染色质域。

## **4. 表观遗传修饰：塑造染色质结构的“密码”**
染色质结构并非仅由DNA序列决定，更受到一系列可遗传的、不改变DNA序列本身的化学修饰的调控，即**表观遗传修饰 (epigenetic modifications)**。
- **组蛋白修饰 (histone modifications)**：组蛋白N端尾巴上的氨基酸残基可发生乙酰化、甲基化、磷酸化、泛素化等修饰。例如：
    - **H3K4me3**、**H3K27ac**：与活跃的启动子和增强子相关，促进开放染色质。
    - **H3K9me3**、**H3K27me3**：与基因沉默和[[异染色质]]形成相关。H3K9me3是结构异染色质的标志，被HP1蛋白识别并导致染色质凝聚。
- **DNA甲基化 (DNA methylation)**：主要发生在CpG二核苷酸的胞嘧啶上，形成5-甲基胞嘧啶。启动子区的高甲基化通常与基因沉默相关，而在基因体内的甲基化可能与转录延伸有关。
- **染色质重塑复合物 (chromatin remodeling complexes)**：利用ATP水解的能量，滑动、剔除或重组核小体，改变DNA与组蛋白的接触，从而调控基因的可及性。

这些修饰相互关联、协同作用，形成一个复杂的“**组蛋白密码 (histone code)**”，被特定的“阅读器 (reader)”蛋白识别，进而招募“效应器 (effector)”蛋白，最终决定染色质状态和基因表达。

## **5. 常染色质与异染色质：功能二元性的结构基础**
根据凝集程度和转录活性，间期染色质可分为两大功能性类别：
- **[[常染色质]] (euchromatin)**：染色质纤维折叠松散，呈疏松状态。富含基因，转录活跃，是[[常染色质|基因表达最活跃]]的区域。其特征性组蛋白修饰包括H3K4me3、H3K36me3等，DNA甲基化水平通常较低。
- **[[异染色质]] (heterochromatin)**：染色质纤维高度凝集、压缩。[[异染色质|基因表达沉默]]，结构致密。根据其形成机制和稳定性，又分为：
    - **[[异染色质|结构异染色质]]**：在所有细胞类型的整个细胞周期中都保持凝集状态，主要定位于[[卫星DNA|着丝粒区]]、端粒区以及染色体臂的特定区域。富含[[卫星DNA]]、中度重复序列。其形成依赖于H3K9me3修饰及HP1蛋白的招募。
    - **[[异染色质|功能异染色质]] (兼性异染色质)**：只在特定的细胞类型或发育阶段凝集，其形成和解除是发育调控的关键。最经典的例子是雌性哺乳动物体细胞中一条[[X染色体]]的失活。失活的X染色体凝聚成**巴氏小体 (Barr body)**，其上的大部分基因被沉默，组蛋白修饰以抑制性的H3K27me3（由PRC2复合物催化）为特征，这是一种典型的发育调控的功能异染色质。

```
    结构异染色质 (Constitutive Heterochromatin)
    +-----------------------------------------+
    | 位置: 着丝粒, 端粒                         |
    | 标记: H3K9me3, HP1                       |
    | DNA: [[卫星DNA]], 重复序列                 |
    | 状态: 永久性沉默, 紧凑                      |
    +-----------------------------------------+

    功能异染色质 (Facultative Heterochromatin)
    +-----------------------------------------+
    | 位置: 可变，如失活X染色体                   |
    | 标记: H3K27me3 (PRC2介导)                 |
    | DNA: 可含单拷贝基因                        |
    | 状态: 可逆性沉默，受发育调控                 |
    +-----------------------------------------+
```

## **6. 性染色体：特殊染色质结构的范例**
性染色体（[[X染色体]]和[[Y染色体]]）在结构和基因含量上极具特点，其染色质调控机制是研究剂量补偿和性别决定的模型。
- **[[X染色体]]失活 (X-chromosome inactivation, XCI)**：为实现雌雄性体细胞X连锁基因剂量的平衡，雌性哺乳动物早期胚胎发育过程中，两条[[X染色体]]中的一条会随机发生大规模沉默，形成之前提及的功能异染色质——巴氏小体。此过程由**X失活中心 (XIC)** 的**XIST基因**启动，其转录产物**Xist RNA**包裹在待失活的X染色体上，招募染色质修饰复合物（如PRC2），导致H3K27me3等抑制性修饰的建立和异染色质化。这是一个**发育阶段特异性**和**细胞类型特异性**的功能异染色质形成过程。
- **[[Y染色体]]**：作为近端着丝粒染色体，[[Y染色体]]基因含量极少，[[基因密度]]最低。其长臂大部分由高度重复的异染色质序列构成。但其短臂上携带**[[Y染色体性别决定区]]**，该区域内的**[[SRY]]基因**编码的**[[睾丸决定因子]]**是启动雄性性腺发育的关键转录因子。Y染色体的异染色质化状态对其稳定性和SRY基因的正常表达环境至关重要。

## **7. 总结：染色质——动态的调控网络**
染色质结构远非简单的DNA包装。它是一个多层次、动态、可塑的**功能网络**。从**核小体**的形成，到**拓扑关联结构域 (TADs)** 和**染色质区室**的建立，染色质在物理空间上组织基因组。**表观遗传修饰**作为信息层，通过改变染色质的化学特性和可及性，将发育信号、环境刺激与特定的基因表达程序连接起来。[[常染色质]]与[[异染色质]]的划分，以及性染色体如[[X染色体失活]]的例子，生动地展示了染色质结构状态与基因功能之间的紧密联系。理解染色质结构，就是理解真核生物基因组如何在物理约束下实现精确、时空调控的核心逻辑。
