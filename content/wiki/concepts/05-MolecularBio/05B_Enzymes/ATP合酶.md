# $F_1$

- **特点** 亲水 
- **位置** 线粒体基质侧
- **外观** 蘑菇头状突起
- **功能** 催化 ATP 合成
- **构成** $α_3$ $β_3$ γ δ ε 亚基（5 个类型、9 个亚基）

## α β 功能单元

- **构成** 六聚体
- **排列** 两种亚基交错

### β亚基

- **行为** 质子回流驱动 γ 亚基转动时，会依次接触 3 组 β 亚基
- **β-ATP 构象**
	- **又称** *紧密型*（tight conformation，T）
	- **功能** 有催化 ATP 合成的活性，可紧密结合  #ATP 
- **β-ADP 构象**
	- **又称** *疏松型*（loose conformation，L）
	- **功能** 可与 ADP 和 Pi 底物结合
- **β- 空位（β-empty）构象**
	- **又称** 开放型（open conformation，O）
	- **功能** 释放了 ATP 后的空位


# $F_o$

- **特点** 疏水 
- **特点** 对寡霉素敏感（oligomycin-sensitive）
- **位置** 大部分结构嵌入线粒体内膜
- **功能** 组成跨内膜离子通道，用于质子回流至线粒体基质
	- **动力** 质子梯度
- **构成** $a$ $b_2$ $c_{8～17}$ 亚基（3 个类型、11～20 个亚基）

## c 亚基环

- **调节** 寡霉素结合位点
- **功能** 可旋转使两个半通道在质子回流时重合
- **构成** c 亚基，数目具有*物种特异性*

## 质子半通道

- #亲水
- **位置** 紧靠 c 亚基环外侧
- **构成** a 亚基
- **开口** 位于线粒体的基质侧（N 侧）和膜间隙侧（P 侧）
- **数目** 2
