# 化学本质

- 多羟基醛/多羟基酮

# 分类

- 单糖(monosacchride)
- 寡糖(oligosacchride)
	- 含有2-10个糖苷键
- 多糖(polysacchride)
	- 含有10个以上糖苷键
- 结合糖 (glycoconjugate)
	- 糖与非糖物质的结合物

# 功能

- 贮存和提供能量
- 参与构成组织结构
- 节约蛋白质作用
- 抗生酮作用
- 预防慢性病

# 指标

- EAR 120g/d
- 孕妇 130g/d
- 乳母 160g/d

# 来源

- 粮谷类
- 薯类
- 根茎类

# 碳原子编号及糖苷键

![[糖的碳原子编号.jpg]]

- α-1,6-糖苷键（支链淀粉）
- α-1,4-糖苷键（直链淀粉，糖苷键氧在2号位羟基同侧）
- β-1,4-糖苷键（纤维素，糖苷键氧在2号位羟基异侧）
