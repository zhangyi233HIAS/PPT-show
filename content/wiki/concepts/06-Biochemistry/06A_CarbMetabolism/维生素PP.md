# 分类

- 烟酸/尼克酸（nicotinic [[acid]]）
	- 吡啶-3-羧酸
	- 稳定的白色针状结晶
	- 维生素中 #最 稳定的一种
- 烟酰胺/尼克酰胺（nicotinamide）
# 来源

- 广泛存在于自然界
- 体内[[氨基酸#^0f472d|色氨酸]]代谢
	- 效率较低，60mg 色氨酸仅能生成 1mg 烟酸
	- 需要[[维生素B1]]、[[维生素B2]]和[[维生素B6]] 的参与
## 化学成分

- 氮杂环吡啶衍生物

# 活性形式 #掌握

- [[辅酶Ⅰ]]
	- [[辅酶Ⅰ|nicotinamideadenine dinucleotide]]， $NAD^+$
- [[辅酶Ⅱ]]
	- nicotinamide adenine dinucleotidephosphate，$NADP^+$
- **来源** 维生素PP被运输到组织细胞再 #合成 $NAD^+$或$NADP^+$
# 生化作用 #掌握
## 不需氧脱氢酶的[[辅因子]]

- 活性形式分子中的烟酰胺部分具有可逆的加氢及脱氢的特性
- [[糖酵解]]和[[三羧酸循环]]
	- 一些脱氢酶以$NAD^+$为受氢体
	- [[辅酶Ⅰ|NADH]] + $H^+$ 又为丙酮酸生成乳酸提供氢
- [[戊糖磷酸途径]]
	- G6PD 以 $NADP^+$ 作为受氢体进而生成 [[辅酶Ⅱ|NADPH]] + #氢离子
	- [[辅酶Ⅱ|NADPH]] + #氢离子 可作为供氢体参与[[脂肪酸]] 、胆固醇等物质的合成
		- 作为药物已用于 #临床 治疗高胆固醇血症？

# 缺乏症 #疾病 #熟悉

- **成因**
	- 长期服用与维生素PP结构相似而竞争性拮抗的抗结核药物[[异烟肼]] #临床 
	- 摄入不足
## 糙皮病（pellagra）

- 表现 #皮炎 、 #腹泻 及 #痴呆
# 长期过量 #疾病

- 大量服用烟酸或烟酰胺（1～6g/d）
	- 引发[[血管]]扩张、脸颊潮红、痤疮及胃肠不适等毒性症状
- 长期日服用量超过 500mg 
	- 引起[[肝]]损伤
