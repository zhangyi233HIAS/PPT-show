# 1 氨酰tRNA的合成

- **ATP 的分解** #氨酰tRNA合成酶 催化 #ATP 分解为焦磷酸与AMP
- **中间复合体的形成** AMP、酶、氨基酸三者结合为中间复合体（氨酰 -AMP- 酶），其中氨基酸的羧基与磷酸腺苷的磷酸以酐键相连而活化
- **氨酰 tRNA 的形成** 活化氨基酸与 tRNA 的 3′-CCA 末端的腺苷酸的核糖 2′ 或 3′ 位的游离羟基以酯键结合，形成相应的氨酰 tRNA，腺苷一磷酸（AMP）以游离形式被释放出来

- **酶** #氨酰-tRNA合成酶 
	- **辅因子** #镁离子 
- **底物** [[氨基酸]] [[转运RNA|tRNA]] #ATP 
- **产物** [[氨酰tRNA]] #AMP #焦磷酸

# 2 翻译起始复合物的形成

## #原核生物 

- **核糖体大小亚基分离**
	- IF3 稳定大小亚基分离状态
- **mRNA与核糖体小亚基结合**
- **起始氨酰-tRNA结合在核糖体P位**
	- $fMet-tRNA^{fMet}$ 与结合了 #GTP 的 IF2 一起，识别并结合对应于小亚基 P 位的 mRNA 的 AUG 处
	- A位被IF1占据
- **翻译起始复合物形成**
	- 结合于 IF2 的 GTP 被水解，释放的能量促使 3 种 IF 释放
	- 大小亚基结合形成翻译起始复合物
		- [[核糖体]]
		- [[编码RNA|mRNA]]
		- [[起始氨酰tRNA]]

- 43S 前起始复合物的形成

	- GTP-eIF2 与[[起始氨酰tRNA]] 结合
- mRNA与核糖体小亚基结合

# 终止

- **标志** [[核糖体]] A位与mRNA终止密码子对应
- **识别** 不被[[氨酰tRNA]] 识别, 由释放因子RF识别
	- #原核生物  
		- RF1 UAA 或 UAG
		- RF2 UAA 或 UGA
		- RF3 具有 GTPase活性，当新生肽链从核糖体释放后，促进RF1 或 RF2 与核糖体分离
	- #真核生物 仅有一种释放因子 eRF，3 种终止密码子均可被其识别
	- **耗能** #GTP
