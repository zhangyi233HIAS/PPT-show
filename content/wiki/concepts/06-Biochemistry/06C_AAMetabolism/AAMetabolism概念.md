# Amino Acid Metabolism (AAMetabolism) 的核心概念

## 1. 代谢库 (Metabolic Pool) 与来源 (Sources)
氨基酸代谢的核心是一个动态的、共享的“[[氨基酸代谢库]]” (Amino Acid Metabolic Pool)。该库由体内各处分布的游离氨基酸 (Free Amino Acids) 组成，其总和是衡量机体氨基酸状态的基本指标。

该库的来源包括：
1.  **外源性来源 (Exogenous Source)**: 食物蛋白质经消化、吸收后进入血液的氨基酸。这是健康成人氮平衡 (Nitrogen Balance) 的主要输入。
2.  **内源性来源 (Endogenous Source)**: 体内组织蛋白质的降解 (Protein Turnover)。这是一个持续不断的过程，每天产生的内源性氨基酸数量巨大，其中大部分被重新利用用于合成新的蛋白质，仅少部分进入分解代谢途径。内源性降解主要通过两种途径：
    *   **[[ATP 依赖途径]] (ATP-Dependent Pathway)**: 主要发生于**细胞质**与**细胞核**。核心是**[[蛋白酶体]] (Proteasome)**，一个大型的多催化蛋白酶复合物。其降解底物具有高度特异性：
        *   **标记**: 目标蛋白质首先被**多次泛素化 (Ubiquitination)** 标记，形成**[[泛素]]链 (Ubiquitin Chain)**。泛素是一个高度保守的76氨基酸小蛋白。
        *   **降解**: 被标记的蛋白质被识别并送入蛋白酶体的20S核心颗粒，其内部具有类胰蛋白酶 (Trypsin-like)、类糜蛋白酶 (Chymotrypsin-like) 和肽基谷氨酰水解 (Caspase-like) 活性，在**ATP**供能下被降解为短肽。
        *   **靶标**: 主要针对**异常蛋白质** (如错误折叠、受损) 和**短寿命调节蛋白** (如细胞周期蛋白)。
    *   **[[ATP 非依赖途径]] (ATP-Independent Pathway)**: 主要发生于**溶酶体 (Lysosome)**。由多种**组织蛋白酶 (Cathepsin)** 催化，主要在酸性环境下发挥作用。
        *   **靶标**: 主要针对通过自噬 (Autophagy)、内吞 (Endocytosis) 等途径进入溶酶体的**细胞外源性蛋白质**、**膜蛋白**以及部分**胞内长寿命蛋白质**。

## 2. 分解代谢的共同起始：脱氨基作用 (Deamination)
氨基酸分解代谢的首要步骤是脱去氨基 (α-amino group)，释放氨 (Ammonia, NH₃/NH₄⁺)，并将其碳骨架 (Carbon Skeleton) 转化为可进入共同代谢途径 (如TCA循环) 的中间物。主要机制如下：

### 2.1 转氨基作用 (Transamination)
*   **定义**: α-氨基在**氨基转移酶 (Aminotransferase/Transaminase)** 催化下，从氨基酸转移到α-酮酸 (α-Keto Acid) 上的过程。
*   **辅酶**: 磷酸吡哆醛 (Pyridoxal Phosphate, PLP)，维生素B₆的活性形式，作为氨基的暂时载体。
*   **平衡**: 反应可逆，是体内合成非必需氨基酸 (Non-essential Amino Acids) 的主要途径。
*   **典例**:
    *   **谷丙转氨酶 (Alanine Aminotransferase, ALT/GPT)**: [[丙氨酸]] + α-酮戊二酸 ⇌ **丙酮酸** + [[谷氨酸]]。主要存在于[[肝]]。
    *   **谷草转氨酶 (Aspartate Aminotransferase, AST/GOT)**: [[天冬氨酸]] + α-酮戊二酸 ⇌ **草酰乙酸** + [[谷氨酸]]。存在于[[肝]]、[[心肌]]等。
*   **意义**: 将不同氨基酸的氨基汇集到**谷氨酸** (Glutamate, Glu) 上，是氨基代谢的“枢纽”。**注意**: [[赖氨酸]]、[[苏氨酸]]、[[脯氨酸]]及羟脯氨酸不参与标准的转氨基反应。

### 2.2 氧化脱氨基作用 (Oxidative Deamination)
*   **主要酶**: **L-谷氨酸脱氢酶 (L-Glutamate Dehydrogenase, GDH)**。
*   **位置**: 主要存在于**线粒体**基质，活性高的组织包括[[肝]]、[[肾]]、[[脑]]。
*   **反应**: [[谷氨酸]] + NAD(P)⁺ + H₂O ⇌ **α-酮戊二酸 (α-Ketoglutarate)** + **NH₄⁺** + NAD(P)H + H⁺。
*   **意义**:
    *   直接释放游离氨 (NH₄⁺)。
    *   是将汇集于谷氨酸的氨基最终“卸载”进入代谢池的关键步骤。
    *   反应可逆，α-酮戊二酸可利用游离氨合成谷氨酸，是生物固氨的重要方式之一。

### 2.3 联合脱氨基作用 (Transdeamination)
*   **定义**: 这是体内脱氨基**最高效、最主要**的方式，是**[[转氨基作用]]** 与 **[[氧化脱氨基作用]]** 的偶联。
*   **流程**:
    ```
    氨基酸₁ (如丙氨酸)
        │
        │ 转氨酶 (如ALT)
        ▼
    α-酮酸₁ (丙酮酸)      +      谷氨酸
                                  │
                                  │ L-谷氨酸脱氢酶
                                  ▼
                           α-酮戊二酸 + NH₄⁺
    ```
    绝大多数氨基酸首先通过转氨基作用，将氨基转移给α-酮戊二酸生成**谷氨酸**；随后谷氨酸在线粒体中经**谷氨酸脱氢酶**催化，进行氧化脱氨基，生成α-酮戊二酸并释放游离氨。生成的α-酮戊二酸可再次参与转氨基作用，构成循环。

## 3. 氨的转运与解毒：两个关键的代谢循环
释放的氨 (NH₃/NH₄⁺) 对神经系统有剧毒，必须安全运输至[[肝]]或[[肾]]进行解毒。主要依赖两个循环：

### 3.1 丙氨酸-葡萄糖循环 (Alanine-Glucose Cycle)
*   **生理场景**: 将[[骨骼肌]]中蛋白质分解产生的氨安全运输至肝。
*   **核心过程**: 肌肉中，氨基酸经**转氨基作用**将氨基转给丙酮酸生成**丙氨酸** (Alanine)。丙氨酸经血液运至肝。在肝中，丙氨酸经**逆向转氨基作用** (主要由ALT催化)，将氨基转给α-酮戊二酸生成**谷氨酸**和丙酮酸。
    ```
    [骨骼肌]
    葡萄糖 -> 丙酮酸 -> (接受氨基) -> 丙氨酸 (入血) -> [肝]
    [肝]
    丙氨酸 -> (转移氨基) -> 谷氨酸 -> (氧化脱氨) -> NH₃ (进入鸟氨酸循环)
            + 丙酮酸 -> (糖异生) -> 葡萄糖 (入血) -> [骨骼肌]
    ```
*   **双重意义**:
    1.  **氨的运输**: 以无毒的丙氨酸形式运输氨基。
    2.  **碳骨架的回收**: 肝利用丙酮酸进行糖异生，生成的葡萄糖可返回肌肉，形成“碳-氮穿梭”。

### 3.2 谷氨酰胺合成与转运 (Glutamine Synthesis and Transport)
*   **生理场景**: 在脑、肌肉等组织中，将游离氨转化为无毒形式，并运输至肝或[[肾]]。
*   **核心过程**: 在**谷氨酰胺合成酶 (Glutamine Synthetase)** 催化下，谷氨酸与氨、**ATP**反应生成**谷氨酰胺 (Glutamine)**。
    ```
    [脑/骨骼肌]
    谷氨酸 + NH₃ + ATP -> (谷氨酰胺合成酶) -> 谷氨酰胺 (入血) -> [肝/肾]
    [肝/肾]
    谷氨酰胺 -> (谷氨酰胺酶) -> 谷氨酸 + NH₃
    ```
*   **意义**:
    1.  **解毒**: 谷氨酰胺是中性、无毒的氨的运输和储存形式。
    2.  **氮的供体**: 在肾中，谷氨酰胺酶水解谷氨酰胺产生的NH₃可直接排入尿液中和H⁺，对维持酸碱平衡至关重要。

## 4. 氨的最终去路：鸟氨酸循环 (Urea Cycle)
在肝中，来自以上途径的游离氨最终进入**鸟氨酸循环 (Ornithine Cycle)**，转化为水溶性、无毒的**尿素 (Urea)** 排出体外。这是陆生哺乳动物排氨的主要方式。

## 5. 氮平衡 (Nitrogen Balance)
[[氮平衡]]是评估机体蛋白质代谢状况的经典指标，反映每日摄入氮（主要来自食物蛋白质）与排出氮（主要为尿素、尿酸、肌酐等）之间的差值。
*   **氮的总平衡 (Zero Nitrogen Balance)**: 摄入氮 ≈ 排出氮。见于健康成年人，表明体内蛋白质合成与分解速率大致相等。
*   **氮的正平衡 (Positive Nitrogen Balance)**: 摄入氮 > 排出氮。见于生长发育期的儿童、孕妇、恢复期病人，表明体内有蛋白质净合成。
*   **氮的负平衡 (Negative Nitrogen Balance)**: 摄入氮 < 排出氮。见于饥饿、消耗性疾病、大面积烧伤或创伤后，表明体内蛋白质分解大于合成。临床上监测氮平衡对营养支持治疗具有指导意义。

---
**总结**: 氨基酸代谢的核心在于**氨基的转移、汇集、转运与解毒**，以及**碳骨架的再利用**。从代谢库的输入输出，到以谷氨酸为中心的转氨基-脱氨基联合机制，再通过丙氨酸-葡萄糖循环、谷氨酰胺穿梭等途径安全转运，最终在肝内经鸟氨酸循环将氨转化为尿素。整个网络精密协调，维持着机体的氮稳态与能量供应。
