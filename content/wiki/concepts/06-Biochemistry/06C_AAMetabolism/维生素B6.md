# 溶解性

- #水溶性
- 易溶于水及乙醇，微溶于有机溶剂
# 分类

- 吡哆醇（pyridoxine）
- 吡哆醛（pyridoxal）
- 吡哆胺（pyridoxamine）
# 来源

- [[肝]]
- 鱼
- 肉类
- 全麦
- 坚果
- 蛋黄
# 化学性质

- 基本结构 2- 甲基 -3- 羟基 -5- 甲基吡啶
- **外观** 白色结晶
- **敏感性**
	- 酸 在酸性条件下稳定
	- 碱 在碱性条件下易被破坏
	- 光 对光较敏感
	- 温 不耐高温
# 吸收

- 其磷酸酯在[[小肠]]碱性磷酸酶的作用下水解，以去磷酸化形式被吸收
# 运输

- 吡哆醛和磷酸吡哆醛是[[血液]]中的主要运输形式
# 储存

- 体内约 80% 以磷酸吡哆醛的形式存在于[[肌组织]]中，并与 [[糖原磷酸化酶]] 结合
# 拮抗
- 抗结核药[[异烟肼]]能与磷酸吡哆醛的醛基结合使其失去活性，在服用异烟肼时，应补充维生素$B_6$
# 活性形式 #掌握

- 主要是磷酸吡哆醛
# 生化作用 #掌握

## 多种酶的[[辅因子]]，参与多个代谢过程

- [[氨基酸]]脱氨基与转氨基作用
- [[鸟氨酸循环]]
- [[糖原分解]]
- [[血红素]]合成
	- [[血红素]]合成关键酶 ALA合酶的辅因子
- 同型半胱氨酸生成[[半胱氨酸]] 
	- 胱硫醚 β 合成酶的辅因子
	- 防止高同型半胱氨酸血症 #疾病
- 大脑抑制性 [[神经递质]] [[γ-氨基丁酸]] 的生成
	- 谷氨酸脱羧酶的辅因子
	- #临床 #疾病 上常用维生素 $B_6$ 治疗小儿[[惊厥]]、妊娠呕吐和精神焦虑等
## 终止类固醇激素的作用

- 可作用于类固醇激素 - 受体复合物，终止激素作用
# 推荐摄入量

- 15～50 岁人群维生素 B6 的RNI为1.4mg/d
- RNI为1.6mg/d 

# 缺乏症 #疾病 #熟悉

- #Q 人类尚未发现维生素 B6 缺乏的典型病例
- 可造成低血色素小细胞性贫血（又称维生素 B6 反应性贫血）和血清铁增高
- 可出现 #皮炎/脂溢性
- 可增加人体对 #雌激素 、 #雄激素 、皮质激素及[[维生素D]] 作用的敏感性，与乳腺、[[前列腺]]和[[子宫]]激素相关肿瘤的发生发展有关
# 长期过量 #疾病

- 过量可引起中毒
- 日摄入量超过 20mg 可引起肢体远端的麻木、疼痛等感觉性周围神经病的症状
