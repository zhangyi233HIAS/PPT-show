# 溶解性

- #水溶性
- 易溶于水，不溶于脂溶性溶剂
# 分类

# 来源

- 新鲜深色蔬菜和水果
- 久存的水果和蔬菜中含量会大量减少
	- 植物中的抗坏血酸氧化酶能将其氧化灭活为二酮古洛糖酸
- 干种子中不含
- 幼芽可以合成 ，故豆芽富含
# 化学性质

- **成分** L- 己糖酸内酯，具有不饱和的一烯二醇结构
- **转化** 分子中$C_2$和$C_3$羟基可以氧化脱氢生成脱氢抗坏血酸，后者可接受氢再还原成抗坏血酸
- **外观** 无色无臭的片状晶体
	- **敏感性**
		- 酸 在酸性溶液中比较稳定
		- 在中性、碱性溶液中加热易被氧化破坏
# 吸收

- 主要通过主动转运由[[小肠]]上段吸收进入[[血液]]循环
# 活性形式

- 是天然的活性形式
# 生化作用 #掌握
## 参与羟化反应

- 含铜羟化酶和α-酮戊二酸-铁羟化酶的辅因子
	- 在含酮（ #Q 铜？）羟化酶催化的反应中，被氧化生成 $Cu^{2+}$ ，后者在维生素 C 作用下，再还原为 Cu+
- 对-羟苯丙酮酸羟化酶的辅因子
	- 参与对-羟苯丙酮酸生成尿黑酸的反应
	- 缺乏时，尿中可出现大量对-羟苯丙酮酸
- 多巴胺 β- 羟化酶的辅因子
	- 缺乏引起[[肾上腺髓质]]和中枢神经系统的儿茶酚胺的代谢异常
- 胆汁酸合成关键酶 7α- 羟化酶的辅因子
	- 参与将 40% 的胆固醇正常转变成胆汁酸
	- 参与[[肾上腺皮质]]类固醇合成中的羟化作用
- 含铁羟化酶的辅因子
	- 参与蛋白质翻译后的修饰
- 体内肉碱合成过程中羟化酶的辅因子
	- 缺乏时，由于[[脂肪酸]] β- 氧化减弱，病人往往出现倦怠乏力
## 参与体内氧化还原反应

- 使巯基酶的—SH 保持还原状态
	- 在谷胱甘肽还原酶作用下，将[[医学联合/118生殖系统/女性生殖系统/乳房疾病/谷胱甘肽]]由氧化型转化成还原型 #todo
- 使[[红细胞]]中高铁血红蛋白质（MHb）还原为血红蛋白质（[[血红蛋白]]），使其恢复运氧能力
- [[小肠]]中可将$Fe^{3+}$还原成$Fe^{2+}$，有利于食物中铁的吸收
- 作为 #抗氧化剂 ，影响细胞内活性氧敏感的信号转导系统，从而调节基因表达，影响细胞分化与细胞功能。[[维生素C]] 还可以清除 $O_2^{\overline·}$ 及和 $OH^·$ 等活性氧类物质
## 增强机体免疫力

- 促进体内抗菌活性、[[自然杀伤细胞|NK 细胞]]活性、[[淋巴细胞]]增殖和趋化作用
- 能提高吞噬细胞的吞噬能力
- 促进[[wiki/concepts/immunology/602抗体/免疫球蛋白]]的合成
- #临床 用于心血管疾病、感染性疾病等的支持性治疗
