# **炎症 (Inflammation): 核心概念与病理生理学全景**

## **1. 核心定义与目的**
**炎症 (Inflammation)** 是活体组织对损伤因子（如病原体、物理化学损伤、坏死组织）所发生的**以防御为主的复杂局部血管反应**。其核心目的是**清除有害因子、限制损伤、启动修复**。但持续或失调的炎症亦会导致组织损伤和疾病，是许多慢性疾病（包括[[肿瘤]]) 的共同病理基础。

```
损伤因子 → 组织损伤
          ↓
   炎症反应 (防御/清除)
          ↓
    ↗ 转归：愈合/纤维化
   ↙
转归：慢性化 → 组织损伤 → 疾病（如肿瘤、纤维化、自身免疫病）
```

---

## **2. 炎症的基本病理变化：三位一体**
无论病因如何，炎症局部都表现为三种基本病理变化：**变质 (alteration)**、**渗出 (exudation)** 和 **增生 (proliferation)**。它们的时间主导性决定了炎症的分类。

| 变化类型 | 英文 | 定义 | 主导时期 | 细胞类型 |
| :--- | :--- | :--- | :--- | :--- |
| **变质** | Alteration | 炎症局部组织发生的**可逆性损伤（变性）**和**不可逆性损伤（坏死）**。 | 急性早期 | 实性细胞、间质细胞 |
| **渗出** | Exudation | 血管内液体、蛋白质和**白细胞**通过血管壁进入组织的过程。 | 急性期 | [[中性粒细胞]]、单核细胞等 |
| **增生** | Proliferation | 包括**实质细胞**（如上皮细胞）和**间质细胞**（[[成纤维细胞]]、内皮细胞、炎症细胞）的增生。 | 慢性期/后期 | 成纤维细胞、内皮细胞 |

## **3. 急性炎症 (Acute Inflammation)**
以**渗出**和**变质**为主要病变，病程短（数分钟至数天）。其核心是**血管反应**和**白细胞渗出**。

### **3.1 血管反应与渗出**
1.  **血流动力学改变**：短暂血管收缩 → **血管扩张（充血）** → 血流减慢。
2.  **==血管通透性增加==**：是**渗出 (exudation)** 的关键。富含蛋白质的液体（**渗出物 (exudate)**）漏出，导致**炎性水肿 (inflammatory edema)**。
    *   **机制**：内皮细胞收缩、穿胞作用增强、内皮细胞损伤/坏死。
    *   **作用**：稀释毒素、运送抗体/补体、提供营养。

### **3.2 [[白细胞渗出]] (Leukocyte Extravasation)**
白细胞从血管内游出到组织间隙的过程，是炎症防御的核心环节。这形成了**炎性细胞浸润 (inflammatory cell infiltration)**。

**[ASCII Art: 白细胞渗出级联反应]**
```
血管腔 (Blood Vessel Lumen)
────────────────────────────
 1. [[白细胞边集]] (Margination)
    - 血流减慢，白细胞贴壁。
      ↓
 2. [[白细胞滚动]] (Rolling)
    - 内皮细胞激活，表达E-/P-[[选择素 (Selectin)|选择素]]。
    - 白细胞通过选择素与内皮**可逆性结合**，在内皮表面滚动。
      ↓
 3. [[白细胞黏附]] (Adhesion)
    - 信号激活白细胞，表达整合素（如LFA-1, VLA-4）。
    - 与内皮细胞表面的ICAM-1/VCAM-1等**牢固结合**。
      ↓
 4. [[白细胞游出]] (Transmigration)
    - 白细胞穿过内皮细胞间连接（主要为**CD31/PECAM-1**介导）。
    - 穿过基底膜进入组织。
      ↓
组织间隙 (Tissue Interstitial Space)
────────────────────────────
 5. [[趋化作用]] (Chemotaxis)
    - 白细胞沿化学梯度（如C5a, LTB4, IL-8, 细菌产物）定向移动至损伤部位。
      ↓
 6. **到达损伤灶**，行使功能（吞噬、杀菌、释放酶和介质）。
```

**[[渗出物]]的分类（按成分）**：
*   **浆液性炎 (Serous Inflammation)**：以血清渗出为主。
*   **[[纤维蛋白性炎]] (Fibrinous Inflammation)**：渗出物中含大量纤维蛋白。发生在黏膜时形成**[[假膜性炎]] (Pseudomembranous Inflammation)**，如白喉。
*   **[[化脓性炎]] (Purulent/Suppurative Inflammation)**：以**中性粒细胞**大量渗出并伴有组织坏死、脓液形成为特征。常由化脓菌（如金黄色葡萄球菌）引起。
*   **[[出血性炎]] (Hemorrhagic Inflammation)**：血管损伤严重，渗出物中含大量红细胞。见于病毒（如流行性出血热）、鼠疫等。

## **4. 慢性炎症 (Chronic Inflammation)**
以**增生**为主要病变，病程长（数月至数年）。特征是**单核-巨噬细胞、淋巴细胞、浆细胞**等**[[慢性炎症细胞]] (chronic inflammatory cells)** 浸润，以及**组织破坏**和**修复反应**（成纤维细胞和血管增生）同时存在。

### **4.1 成因**
*   急性炎症迁延不愈。
*   病原微生物持续存在（如结核杆菌）。
*   长期暴露于毒性因子（如二氧化硅）。
*   **自身免疫反应**。

### **4.2 慢性炎症的细胞与形态**
**1. 巨噬细胞 (Macrophage) 的核心作用**
*   **来源**：血液中的**单核细胞 (Monocyte)** 渗出后，分化为巨噬细胞。是慢性炎症的**主导细胞**。
*   **功能**：强大的**吞噬**、**抗原呈递**和**免疫调节**功能。能释放多种生物活性分子（如IL-1, TNF-α, TGF-β, PDGF），驱动后续的损伤和修复。
*   **形态特化**：在特定刺激下（如IFN-γ），巨噬细胞可转变为**[[上皮样细胞]] (Epithelioid Cell)**。
    *   **特征**：胞质丰富淡染、边界不清；核圆形，染色浅。见于肉芽肿性炎。

**2. [[淋巴细胞]] (Lymphocyte)**
*   慢性炎症中**最常见**的细胞之一，提供特异性免疫应答（T细胞介导细胞免疫，B细胞分化为浆细胞产生抗体）。

**3. 其他细胞**
*   **[[肥大细胞]] (Mast Cell)**：广泛分布于结缔组织，释放组胺、TNF-α等。
*   **[[嗜酸性粒细胞]] (Eosinophil)**：多见于寄生虫感染和过敏性炎症。
*   **[[成纤维细胞]] (Fibroblast)**：增生并产生胶原，导致**纤维化 (fibrosis)** 和**瘢痕 (scar)** 形成，是组织修复和器官结构破坏的关键。

### **4.3 慢性炎症的特殊形式：肉芽肿性炎 (Granulomatous Inflammation)**
一种以**肉芽肿**形成为特征的慢性增生性炎症。
*   **肉芽肿 (Granuloma)**：由**巨噬细胞/上皮样细胞**和**多核巨细胞**（由巨噬细胞融合而成）局部聚集形成的结节状病灶，常伴有淋巴细胞。
*   **本质**：是细胞介导免疫反应的形态学表现。
*   **常见病因**：结核病（**结核结节**）、梅毒、真菌感染、异物等。

## **5. 炎症介质 (Inflammatory Mediators)**
介导炎症反应的化学物质。来源多样，作用复杂。

| 来源 | 代表介质 | 主要作用 |
| :--- | :--- | :--- |
| **细胞释放** | **组胺 (Histamine)** | 血管扩张，通透性↑（速发反应） |
| | **前列腺素 (PGs)** | 血管扩张，痛，热 |
| | **白三烯 (LTs)** | 血管通透性↑，趋化，支气管收缩 |
| | **细胞因子 (Cytokines)** 如TNF-α, IL-1 | 激活内皮和白细胞，发热，急性期蛋白 |
| | **趋化因子 (Chemokines)** | 白细胞定向趋化 |
| **体液产生** | **补体系统 (Complement)** C3a, C5a | 趋化，调理，细胞溶解 |
| | **激肽系统 (Kinin)** 缓激肽 | 血管通透性↑，痛 |

**关键概念**：**[[炎症小体]] (Inflammasome)** 是细胞质内**感知危险信号**并激活**caspase-1**的多蛋白复合物。NLRP3炎症小体被多种信号（如尿酸结晶、β-淀粉样蛋白）激活，导致**IL-1β**和**IL-18**的成熟与释放，是连接固有免疫与炎症反应的关键平台。

## **6. 炎症与肿瘤：从防御到促进**
**慢性炎症是公认的肿瘤发生的“第七大特征”**。这一关联在肿瘤生物学中至关重要。

**[ASCII Art: 炎症-肿瘤轴心]**
```
持续性慢性炎症 (如慢性胃炎、肝炎、肠炎)
          ↓
      微环境中的变化
          ↙         ↘
 活性氧/氮 (ROS/RNS)   持续释放生长因子 (EGF, VEGF)
          ↓                     ↓
 DNA损伤/突变         促增殖、促血管生成
          ↘         ↙
       上皮细胞恶性转化
          ↓
    肿瘤起始与进展
          ↓
    肿瘤相关炎症
          ↘         ↙
 免疫抑制 (Tregs, MDSCs)    基质重塑 (MMPs)
          ↓                     ↓
    逃避免疫监视          侵袭与转移
```

### **6.1 核心机制**
1.  **遗传毒性**：慢性炎症产生的**ROS/RNS**直接造成DNA损伤，增加突变率。
2.  **促增殖与存活**：炎症因子（如TNF-α, IL-6）激活NF-κB、STAT3等信号通路，促进肿瘤细胞增殖、抑制凋亡。
3.  **促血管生成**：VEGF等因子促进肿瘤新生血管形成。
4.  ****免疫抑制与逃逸**：慢性炎症塑造的**肿瘤微环境 (Tumor Microenvironment, TME)** 富含**肿瘤相关巨噬细胞 (Tumor-Associated Macrophages, TAMs)**、髓源性抑制细胞 (MDSCs)、调节性T细胞 (Tregs)，共同抑制抗肿瘤免疫。
5.  **促进侵袭与转移**：炎症因子刺激**基质金属蛋白酶 (MMPs)** 产生，降解细胞外基质，促进肿瘤细胞侵袭。

### **6.2 关键细胞：[[肿瘤相关巨噬细胞]] (TAMs)**
TAMs是TME中浸润的主要免疫细胞，通常极化为**M2型**（促修复/促肿瘤表型）。
*   **功能**：促进肿瘤细胞增殖、血管生成、免疫抑制、组织重塑和转移。
*   **靶向TAMs**已成为肿瘤免疫治疗的重要策略。

---

## **7. 总结与展望**
炎症是一把双刃剑。急性炎症是关键的生理防御机制；而**慢性炎症**则与广泛的组织病理改变和疾病，特别是**肿瘤的发生、发展、转移及治疗抵抗**密切相关。理解炎症的分子和细胞基础，尤其是**巨噬细胞的可塑性**、**炎症小体的信号转导**以及**慢性炎症微环境的构建**，为开发新的抗炎及抗癌疗法（如免疫检查点抑制剂、靶向TAMs的疗法）提供了理论基础。
