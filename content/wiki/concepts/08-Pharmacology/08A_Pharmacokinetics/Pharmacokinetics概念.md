# 药代动力学核心概念 (Core Concepts of Pharmacokinetics)

**课程定位**：本笔记旨在为药理学博士生构建系统性的药代动力学 (Pharmacokinetics, PK) 知识框架，深入探讨药物在体内吸收、分布、代谢和排泄的动态规律、数学模型及其临床意义。PK与药效动力学 (Pharmacodynamics, PD) 共同构成药理学的核心，是指导临床合理用药、新药研发及个体化治疗的基础。

---

## 1. 定义与核心框架 (Definition and Core Framework)

**药代动力学 (Pharmacokinetics)** 是定量研究药物在生物体内吸收、分布、代谢和排泄（Absorption, Distribution, Metabolism, Excretion, **ADME**）随时间变化规律的学科。其核心任务是揭示药物在体内的“命运”，并建立数学模型来描述这一过程，预测药物浓度-时间关系。

```
    [给药部位]
          |
          V
      +----------+      +----------+      +----------+      +----------+
      |          |      |          |      |          |      |          |
      |  吸收    | ---> |  分布    | ---> |  代谢    | ---> |  排泄    | ---> [体外]
      | Absorption|      |Distribution|    | Metabolism|    | Excretion|
      +----------+      +----------+      +----------+      +----------+
          |                  |                  |                  |
          |   (受首过效应影响)  | (与血浆蛋白结合， | (生物转化，      | (肾脏，胆汁等)
          |                  |   穿透屏障)       |   酶促反应)       |
          +------------------+------------------+------------------+
                                  |

```

## 2. 吸收 (Absorption)

**吸收 (Absorption)** 是指药物从给药部位进入血液循环的过程。其速率和程度直接影响药物的起效时间、峰值浓度和生物利用度。

- **关键参数**：
    - **生物利用度 (Bioavailability, F)**：药物经血管外给药后，被吸收进入体循环的相对量和速度。静脉注射的F定义为1（100%）。是评价制剂质量与吸收效率的核心指标。
    - **首过效应 (First-pass effect)**：口服药物在通过肠壁及经肝脏时，被代谢酶部分灭活，使进入体循环的药量减少，生物利用度降低的现象。是[[代谢]]与吸收相互作用的典型例证。
- **影响因素**：
    1.  **药物因素**：理化性质（脂溶性、分子量、解离度）、剂型、晶型。
    2.  **机体因素**：胃肠道pH、胃排空与肠蠕动、血流量、吸收表面积。
    3.  **给药途径**：
        - **消化道吸收 (Gastrointestinal absorption)**：口服、舌下、直肠给药。
        - **消化道外吸收 (Parenteral absorption)**：静脉、皮下、肌内注射；[[分布|透皮]]、吸入、黏膜给药。不同途径绕过首过效应的程度不同，直接影响F。

**临床意义**：理解吸收过程是设计合理给药方案（如选择给药途径、间隔时间）的基础。对于首过效应强的药物（如硝酸甘油），舌下给药是更优选择。

## 3. 分布 (Distribution)

**分布 (Distribution)** 是指吸收入血的药物随血流转运至组织和器官的过程。这是一个动态平衡过程，决定了药物在靶器官的浓度和[[分布|储存库]]的形成。

- **关键参数**：
    - **表观分布容积 (Apparent Volume of Distribution, Vd)**：指体内药物总量与血浆药物浓度的比值（Vd = D / C）。它是一个理论容积，反映药物在体内分布的广泛程度。Vd大，提示药物广泛分布于组织或与组织成分结合；Vd小，则提示药物主要局限在血浆。
- **影响因素与机制**：
    1.  **血浆蛋白结合 (Plasma protein binding)**：药物与血浆蛋白（主要是白蛋白）的结合是可逆的。只有**游离型药物 (free drug)** 才能穿透毛细血管壁、发挥药理作用并被消除。结合型药物是暂时的储存形式。药物间可能竞争结合位点，导致游离浓度升高，药效或毒性增强。
    2.  **组织亲和力与细胞结合**：药物对特定组织（如脂肪、骨骼、肝肾）的高亲和力导致其在该组织浓集。
    3.  **特殊屏障**：
        - **血-脑屏障 (Blood-brain barrier, BBB)**：由脑毛细血管内皮紧密连接构成，能有效阻挡大多数水溶性及大分子药物进入中枢神经系统。是[[受体|中枢神经系统药物]]研发的挑战。
        - **胎盘屏障 (Placental barrier)**：非绝对屏障，多数药物可通过，是孕妇用药需谨慎的原因。
        - **血眼屏障 (Blood-ocular barrier)**。

**临床意义**：Vd是计算负荷剂量的关键。了解药物的分布特性有助于预测其起效部位、潜在蓄积（如脂肪组织）以及药物相互作用的风险（如高蛋白结合率药物间的置换）。

## 4. 代谢 (Metabolism) / 生物转化 (Biotransformation)

[[代谢|**代谢 (Metabolism)**]]，亦称**生物转化 (Biotransformation)**，是药物在体内受酶系统催化发生化学结构改变的过程。其主要目的是将药物转化为极性更大、水溶性更高的物质，以利于排泄。

- **代谢结果**：
    1.  **灭活 (Inactivation)**：活性药物转化为无活性代谢物。
    2.  **活化 (Activation)**：**前药 (Prodrug)** 经代谢转化为活性形式。
    3.  **生成活性或毒性代谢物**。
- **代谢时相**：
    - **I相反应 (Phase I reactions)**：氧化、还原、水解。引入或暴露极性基团（如-OH， -NH2）。关键酶系为**细胞色素P450 (Cytochrome P450, CYP450)** 单加氧酶系，具有多态性、可诱导和可抑制的特点。
    - **II相反应 (Phase II reactions)**：结合反应（如葡萄糖醛酸结合、硫酸结合、乙酰化）。极性基团与内源性物质结合，生成高水溶性结合物。
- **关键概念**：
    - **酶诱导 (Enzyme induction)** 与 **酶抑制 (Enzyme inhibition)**：许多药物或物质可影响代谢酶活性，导致合用药物代谢速率改变，是临床[[副作用|药物相互作用]]的重要机制。
    - **饱和动力学 (Saturation kinetics)**：当药物浓度远超酶浓度时，代谢速率不再随浓度增加而增加，表现为**零级动力学 (Zero-order kinetics)**，易导致中毒。米氏方程（Michaelis-Menten equation）是描述此过程的数学模型。

**临床意义**：代谢是药物个体差异、药物相互作用和中毒解救的核心环节。基因多态性可解释不同人群对同一药物代谢速率的巨大差异。

## 5. 排泄 (Excretion)

**排泄 (Excretion)** 是指药物及其代谢物被排出体外的过程。肾脏是主要的排泄器官，胆汁也是重要途径。

- **肾排泄 (Renal excretion)**：
    1.  **肾小球滤过 (Glomerular filtration)**：游离型药物可经肾小球滤过进入肾小管。
    2.  **肾小管分泌 (Tubular secretion)**：药物由近曲小管细胞主动分泌入肾小管腔。
    3.  **肾小管重吸收 (Tubular reabsorption)**：脂溶性药物在远曲小管被动重吸收回血液。尿液pH可通过改变药物解离度来影响重吸收（如碱化尿液加速酸性药物排泄）。
    - **关键参数**：**肾清除率 (Renal clearance, CLr)** 是衡量肾脏排泄药物效率的指标。
- **肝胆排泄 (Hepatobiliary excretion)**：药物经肝脏代谢后，部分代谢物随胆汁排入肠道。具有**肝肠循环 (Enterohepatic circulation)** 的药物，其代谢物在肠道被水解重吸收，可延长药物作用时间。
- **其他途径**：肺（挥发性药物）、乳汁（对哺乳婴儿有潜在影响）、汗液、唾液。

**临床意义**：对于主要经肾排泄的药物，在肾功能不全患者中需调整剂量。肝肠循环可解释某些药物出现双峰血药浓度的现象。

## 6. 药代动力学模型与参数 (PK Models and Parameters)

为了定量描述和预测ADME过程，我们使用数学模型。

- **房室模型 (Compartment models)**：
    - **一室模型**：假设机体为一个均匀的房室，药物瞬间分布平衡。
    - **二室模型**：分为中央室（血流丰富组织）和周边室（血流较少组织），更符合多数药物分布实际。
- **速率过程 (Rate processes)**：
    - **一级动力学 (First-order kinetics)**：单位时间内药物消除的比例恒定（线性动力学）。大多数药物在治疗浓度范围内遵循此规律。
    - **零级动力学 (Zero-order kinetics)**：单位时间内药物消除的量恒定（非线性动力学）。见于酶饱和（如乙醇、苯妥英钠）或主动转运饱和。
- **核心药动学参数**：
    - **消除半衰期 (Elimination half-life, t1/2)**：血药浓度下降一半所需的时间。是确定给药间隔的关键。
    - **清除率 (Clearance, CL)**：单位时间内从体内清除药物的等效血浆体积。是消除能力的综合指标。
    - **稳态浓度 (Steady-state concentration, Css)**：恒速静脉滴注或多次等量给药时，给药速率与消除速率达到平衡时的血药浓度。**坪值 (Plateau)**。多数药物需4-5个半衰期达到Css。
    - **AUC (Area Under the Curve)**：血药浓度-时间曲线下面积，代表药物的总吸收量，是计算生物利用度和清除率的基础。

## 7. 药代动力学与药效动力学的整合 (PK/PD Integration)

PK研究“机体对药物的作用”，PD研究“药物对机体的作用”。PK/PD整合模型将血药浓度（PK）与药理效应（PD）联系起来，是优化给药方案的金标准。

- **概念**：
    - **效应室 (Effect compartment)**：一个虚拟的房室，其药物浓度与效应部位浓度相关，并与血浆浓度平衡存在延迟。
    - **治疗窗 (Therapeutic window)**：产生疗效而不引起不可接受毒性的血药浓度范围。其上下限分别为**最小中毒浓度 (Minimum toxic concentration)** 和**最低有效浓度 (Minimum effective concentration)**，即[[最小有效量]]（阈浓度）。
- **临床应用**：
    - **个体化给药 (Individualized dosing)**：通过治疗药物监测 (TDM) 测量患者血药浓度，结合PK/PD模型调整剂量，使浓度落在治疗窗内，实现安全有效的治疗。
    - **剂量方案设计**：根据t1/2设计给药间隔，根据CL和Vd设计维持剂量与负荷剂量。

## 8. 总结与展望

药代动力学是一门动态的、定量的科学。从[[吸收]]进入体循环，经历广泛的[[分布]]，通过复杂的[[代谢]]转化，最终被[[排泄]]出体外，药物的每一步历程都影响着其最终疗效与[[副作用|安全性]]。掌握**ADME**规律、理解**Vd, CL, t1/2, F**等核心参数、运用**PK/PD模型**，是开展临床药学服务、进行新药研发和推进精准医疗的基石。未来，基于基因组学、生理药代动力学（PBPK）模型和人工智能的PK研究，将进一步将理论转化为个体化用药的实践指南。
