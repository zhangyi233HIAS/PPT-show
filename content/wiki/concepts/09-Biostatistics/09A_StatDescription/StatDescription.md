# **统计描述：原理、方法与生物医学应用**

**Statistical Description (Statistical Description / Descriptive Statistics)** 是生物医学研究数据分析的基石。它旨在通过计算、整理和展示数据，概括样本的基本特征，揭示其内在模式、趋势和变异，而非对总体进行推断。本笔记将系统阐述统计描述的核心原理、关键方法，并结合生物医学场景探讨其应用。

---

## **1. 核心范式：从数据到信息**
统计描述的核心任务是将原始的、杂乱的**数据（Data）** 转化为易于理解的**信息（Information）**。其工作流程可概括为：
1.  **数据整理**：检查、清理、编码数据。
2.  **特征计算**：计算描述数据集中趋势、离散程度和分布形态的统计量。
3.  **可视化呈现**：使用图表直观展示数据特征。

这一过程完全依赖于样本本身，是进行任何推断统计（如假设检验、置信区间估计）之前必不可少的步骤。详见 [[资料分类]]。

## **2. 数据分类与描述策略**
统计描述的方法高度依赖于数据的类型。根据 [[资料分类]]，主要分为：

### **2.1 计量资料（数值型资料 / Quantitative Data）的描述**
此类数据具有数值意义，可进行数学运算。

*   **集中趋势（Central Tendency）** 描述数据的“中心位置”。
    *   **均数（Mean, \(\bar{x}\)）**：算术平均数，适用于对称分布（尤其是正态分布）的数据。易受[[异常值]]影响。
    *   **中位数（Median, \(M\)）**：将数据按大小排序后位于中间位置的值。适用于偏态分布或有[[异常值]]的数据，稳健性强。
    *   **众数（Mode）**：出现频率最高的值。
    *   **几何均数（Geometric Mean, \(G\)）**：适用于对数正态分布或等比数据（如抗体滴度、细菌计数）。

*   **离散程度（Dispersion / Variability）** 描述数据围绕中心值的波动或 spread。
    *   **极差（Range）**：最大值与最小值之差。粗糙，仅依赖于两个极端值。
    *   **四分位数间距（Interquartile Range, IQR / CoQ）**：\(P_{75} - P_{25}\)。描述中间50%数据的范围，对[[异常值]]稳健，是[[箱式图]]的核心。
    *   **方差（Variance, \(s^2\)）**：各数据与均数差值的平方和的平均值（样本方差用 \(n-1\) 校正）。量纲为原数据量纲的平方。
    *   **标准差（Standard Deviation, \(s\)）**：方差的平方根。与原始数据量纲相同，是最常用的离散程度指标。对于正态分布数据，约95%的观测值落在 \(\bar{x} \pm 2s\) 范围内。
    *   **变异系数（Coefficient of Variation, CV）**：\(CV = (s / \bar{x}) \times 100\%\)。无量纲，用于比较量纲不同或均数相差悬殊的两组数据的离散程度。

*   **分布形态（Distribution Shape）**
    *   **偏度（Skewness）**：描述分布的不对称性。正值为右偏（正偏），负值为左偏（负偏）。
    *   **峰度（Kurtosis）**：描述分布尾部的厚重程度。正态分布峰度为0。

### **2.2 计数资料（分类型资料 / Categorical Data）的描述**
此类数据按类别分组，计算各组的频数。

*   **绝对数（Absolute Number）**：各类别的实际观察例数（频数）。
*   **相对数（Relative Number）**：
    *   **率（Rate）**：表示在特定条件下，某现象实际发生的频率或强度。如发病率、死亡率。**注意其时间、人群等特定条件**。
    *   **构成比（Proportion / Percentage）**：表示事物内部各组成部分所占的比重。所有部分构成比之和为100%。
    *   **比（Ratio）**：表示两个相关指标之比，如性别比（男:女）。

## **3. 核心可视化工具：从抽象到直观**
图表是统计描述的灵魂，能够高效传达数据模式。

### **3.1 展示分布与比较**
*   **直方图（Histogram）**：用于展示连续型计量资料的频率分布。横轴为变量取值区间（组距），纵轴为频数或频率。
*   **箱式图（Box Plot / Box-and-Whisker Plot）**：[[箱式图]]是展示计量资料分布、比较组间差异的极其强大的工具。一个标准箱式图包括：
    ```
    |
    |    ┌─────────────┐   <-- 上边缘 (Upper Fence)：通常为 P75 + 1.5*IQR
    |    |     |       |   <-- 上触须线
    |    |     ├───────┤   <-- P75 (上四分位数)
    |    |     |       |
    |    |     ├──┤    |   <-- 中位数 (Median)
    |    |     |       |
    |    ├───────┤     |   <-- P25 (下四分位数)
    |    |     |       |   <-- 下触须线
    |    └─────────────┘   <-- 下边缘 (Lower Fence)：通常为 P25 - 1.5*IQR
    |        o o           <-- [[异常值]] (Outliers)
    |______________________ 数据尺度
    ```
    **应用**：可用于直观判断数据的对称性、离散程度（IQR）和识别[[异常值]]。

*   **误差条图（Error Bar Plot）**：[[误差条图]]常用于比较多组计量资料的**均值**及其变异性。常见形式有：
    1.  **“工”字形**：线条高度表示均值，上下横线分别表示均值的95%可信区间（CI）的上限和下限，中间竖线连接。
    2.  **“┬”字形**：线条高度表示均值，下方的短横线表示均值的标准误（SE）。SE反映样本均数的抽样误差，\( SE = s / \sqrt{n} \)。

### **3.2 展示趋势与关系**
*   **线图（Line Chart）**：适用于展示连续型资料随时间或其他连续变量变化的趋势。特别是当多个组进行比较时非常直观。
*   **半对数线图（Semi-logarithmic Line Chart）**：[[半对数线图]]的**纵坐标采用对数尺度，横坐标为算术尺度**。其核心优势在于：
    *   若终点相对于起点的**相对改变量（如倍数变化）相同**，则在半对数线图上表现为平行的、斜率相同的直线。
    *   **应用场景**：非常适合用于描述和比较**增长或衰减速率**，例如细菌培养的生长曲线、病毒载量的变化、药物的消除过程等。当数据跨越多个数量级时，它能更清晰地展示相对变化。
    ```
    | Log(Y)
    |     /          /         <-- 两组数据以相同倍数增长，呈现平行直线
    |    /          /
    |   /          /
    |  /__________/__________ X (算术尺度)
    ```

## **4. 高级主题与特殊考量**

### **4.1 缺失值的处理**
缺失数据会影响所有描述统计量的计算和解释。描述阶段应明确报告：
*   缺失值的数量和比例。
*   对缺失机制的初步判断（完全随机缺失MCAR、随机缺失MAR、非随机缺失MNAR）。
*   采用的处理方法（如列表删除、均值/中位数填补、多重填补），并说明其潜在影响。

### **4.2 数据变换（Data Transformation）**
当数据严重偏态或方差不齐时，常通过数学变换使其更接近正态分布或方差齐性，以便于描述和后续分析。
*   **对数变换（Log Transformation）**：适用于右偏、方差与均数相关的数据（如细菌计数、收入）。变换后，[[半对数线图]]变得更有意义。
*   **平方根变换（Square Root Transformation）**：适用于泊松分布数据（如单位时间内的事件数）。
*   **倒数变换（Reciprocal Transformation）**：适用于某些特殊分布。

### **4.3 描述统计与推断统计的桥梁**
描述统计量是推断统计的基础：
*   样本均数\(\bar{x}\)和标准差\(s\)用于计算t统计量，进行t检验。
*   样本率\(p\)用于构建率的置信区间或进行卡方检验。
*   相关系数\(r\)（描述两变量线性相关强度和方向）是回归分析的基础。

## **5. 生物医学研究中的应用实例**
*   **临床试验基线特征表（Table 1）**：这是统计描述的典范。它使用均数±标准差或中位数(IQR)描述计量资料，用频数(百分比)描述计数资料，以比较不同治疗组在治疗前是否具有可比性。
*   **生存分析中的生存率**：使用Kaplan-Meier曲线（一种特殊的线图）描述生存概率随时间的变化。
*   **诊断试验评价**：用灵敏度、特异度、预测值等率来描述诊断工具的准确性。
*   **疾病监测**：用发病率、患病率等描述疾病在人群中的分布和强度，常用线图展示时间趋势。

## **6. 实践资源与工具**
掌握统计描述离不开理论与实践的结合。以下资源可供深入学习和应用：

*   **概念学习与理论深化**：
    *   **在线课程**：[Khan Academy (Statistics & Probability)](https://www.khanacademy.org/math/statistics-probability) 提供了优秀的直观讲解。[Coursera](https://www.coursera.org/) 上有众多大学开设的生物统计课程。
    *   **经典教材**：Zar, J. H. 的 *Biostatistical Analysis* 和 Armitage, P. 等人的 *Statistical Methods in Medical Research* 是生物医学统计领域的权威著作。
    *   **问答社区**：遇到具体问题时，[Cross Validated (Stack Exchange)](https://stats.stackexchange.com/) 是一个高质量的统计专业问答论坛。

*   **软件实现与教程**：
    *   **R语言**：[R documentation](https://www.rdocumentation.org/) 官方文档是查询函数用法的首选。[R-bloggers](https://www.r-bloggers.com/) 汇集了大量实用教程。学习贝叶斯统计的经典教材 *Statistical Rethinking* 配有极佳的R语言代码和[视频教程](https://github.com/rmcelreath/statrethinking_winter2019)。
    *   **Python**：[statsmodels](https://www.statsmodels.org/) 和 [scipy.stats](https://docs.scipy.org/doc/scipy/reference/stats.html) 是核心的统计建模和科学计算库。[Towards Data Science](https://towardsdatascience.com/) 上有大量数据分析和统计的Python实现案例。
    *   **在线计算工具**：[GraphPad](https://www.graphpad.com/quickcalcs/), [VassarStats](http://vassarstats.net/), [OpenEpi](http://www.openepi.com/) 提供了便捷的在线统计计算功能，适合快速验证和初步分析。

*   **交流与讨论**：
    *   除 [Cross Validated](https://stats.stackexchange.com/) 外，[Reddit r/statistics](https://www.reddit.com/r/statistics/) 社区活跃。[ResearchGate](https://www.researchgate.net/) 等学术社交网络也是向同行请教和交流的好地方。

**总结**：统计描述是科学研究的“地图绘制学”，它以数据为原料，以统计量为坐标，以可视化为画笔，描绘出样本世界的全貌。熟练掌握其原理、方法及工具，并深刻理解其在生物医学研究中的应用语境，是每一位博士生和研究人员进行严谨、可信研究的必备技能。
