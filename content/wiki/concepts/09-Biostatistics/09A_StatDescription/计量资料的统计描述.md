# 频数与频数分布表
## 频数
每组内的数据个数
## 频数分布表的制作
1. 求极差（全距）
2. 决定组数、组段和组距
3. 列出组段
4. 划记计数
## 重要特征
### 集中趋势
- 所有观察值向某一中心值靠拢的趋势
#### 描述
##### 平均数（average）
###### 算术均数（均数mean）
- 总体均数μ，样本均数$\overline{x}$
- 计算方法
	- 直接计算法$\overline{x}=\frac{1}{n}\sum^n_{i=1}x_i$
	- 加权法$\overline{x}$=$\frac{\sum{f_ix_{Mi}}}{\sum{f_i}}$($f_i$为第i组段的频数，$x_{Mi}$为对应组段的组中值)
- 适用范围 对称分布
###### ==几何均数G==
- 适用范围
	- **对数正态分布**[[资料分类]]（数值顺序排列后各观察值（近似）呈倍数关系，如[[wiki/concepts/immunology/602抗体/免疫球蛋白|抗体]]滴度10 、 100 、1000 、10000 、100000）
	- 存在少数偏大的极端值的[[#正偏态分布|正偏态分布]], 如
		- 细菌计数
		- [[wiki/concepts/immunology/602抗体/抗体]]滴度
		- 血清凝集效价
- 计算方法 G=ln$^{-1}(\frac{1}{n}lnx_i)$=$^n\sqrt{\prod{x_i}}$=ln$^{-1}[\frac{\sum{f_ilnx_{Mi}}}{n}]$
	- 先取对数
	- 再取平均
	- 最后取反对数
###### 中位数M/$P_{50}$
- 特征
	- 只利用了位置居中的测量值
	- 优点 对极值不敏感，不易受异常值影响
	- 缺点 并非考虑到每个观测值
- 均数与中位数的关系
	- 对于正态分布，一致
	- 正偏态，均数在左
	- 负偏态，均数在右
- 推广 百分位数P
	- 对于频数分布表数据 $P_{x}=L+\frac{i}{f_x}(nx\%-\sum{f_L})$
	- 对于个体观测值数据
		- if n $\times$ x%=j,j$\in$N,$P_x$=$\frac{x_j+x_{j+1}}{2}$
		- if n $\times$ x%=j,j$\notin$N,$P_x$=$x_{\lceil{j}\rceil}$($\lceil\rceil$为向上取整)
### 离散趋势
观测值偏离中心的程度
### 描述
#### 极差R
- 计算R=$x_{max}-x_{min}$
- 优点 简单易用
- 缺点 结果不稳定
#### 四分位数间距Q
- Q= $P_{75}-P_{25}$
- 适用范围 主要用于衡量明显偏态分布资料的变异程度
- 优点 考虑了中间值
- 缺点 结果不稳定
#### 离均差平方和
SS=$\sum{(x_i-\overline{x})^2}$
- 均值差的平方和
#### [[第6章 数理统计的基本概念#^972fce|方差]]与[[第6章 数理统计的基本概念#^477c3f|标准差]]
#### 变异系数
- CV=$\frac{s}{\overline{x}}\times{100\%}$
- 算法
	- 先算平均
	- 再算标准差
	- 标准差除以平均，记为百分数
- 优点 无单位，不依赖数量级
- 用途 **比较**不同单位变量的变异程度

## 对称分布
