# SurveyDesign：抽样调查设计的原理、应用与高级实践

**核心概念**：Survey Design (调查设计) 是一项系统性的科学活动，旨在通过从目标人群中选取一个具有代表性的样本，来高效、准确地估计总体参数。其核心在于**以最小的成本，将抽样误差和非抽样误差控制在可接受的范围内**。在医学研究中，一个精心设计的调查是获取高质量证据、制定公共卫生政策的基石。

[[横断面调查]]， [[队列研究]]， [[病例对照研究]] 等观察性研究的内部效度，很大程度上依赖于初始的调查设计。

## 1. 调查设计的核心框架

一个完整的调查设计过程可遵循以下逻辑流程，确保从概念到执行的严谨性。

```
+----------------+     +-----------------+     +---------------+     +----------------+
| 明确研究目标   | --> | 定义目标总体     | --> | 制定抽样框     | --> | 选择抽样方法   |
| (Estimands)   |     | (Target Pop.)   |     | (Sampling Frame)|     | (Sampling Method)|
+----------------+     +-----------------+     +---------------+     +----------------+
                                                                  |
                                                                  v
+----------------+     +-----------------+     +---------------+     +----------------+
| 设计问卷/量表  | --> | 确定数据收集方式 | --> | 制定质量控制方案 | --> | 制定数据分析计划|
| (Instrument)  |     | (Data Collection)|     | (QC Protocol) |     | (Analysis Plan)|
+----------------+     +-----------------+     +---------------+     +----------------+
```
**图1：调查设计系统性流程图**

**关键链接**：
*   **研究目标 (Estimands)**：清晰定义要估计的总体参数（如某病患病率、某指标的均值）。
*   **目标总体 (Target Population)**：研究结论希望推论到的全体对象。
*   **抽样框 (Sampling Frame)**：可用于实际抽样的目标总体成员列表。它与目标总体的不一致是**抽样框误差**的主要来源。[[抽样框]] 的质量直接决定调查的效度。
*   **抽样方法**：从抽样框中选取个体的具体规则，是本文讨论的核心。

## 2. 核心抽样方法论：从基础到复杂

抽样方法分为**概率抽样**与**非概率抽样**。在科学推断中，概率抽样是黄金标准，因为它为计算抽样误差、进行统计推断提供了理论基础。

### 2.1 概率抽样 (Probability Sampling)

#### 2.1.1 简单随机抽样 (Simple Random Sampling, SRS)
**定义**：从包含N个个体的总体中，以等概率、不放回地随机抽取n个个体组成样本。
**优点**：理论最简单，是其他复杂抽样方法的理论基准。
**缺点**：需要完整的抽样框；在大总体中实施不便；当总体内部分布不均时，其精度可能不如[[分层抽样]]。

#### 2.1.2 系统抽样 (Systematic Sampling)
**定义**：先将总体观察单位按某一顺序（如住院号、姓氏笔画）等分成n个部分，从第一部分随机确定一个起始号k，然后每隔k个单位抽取一个样本。
**优点**：操作简便，易于在现场实施；样本在抽样框中分布均匀。
**缺点**：**当总体的观察单位按顺序有周期趋势或单调增减趋势时，抽取的样本可能产生严重偏倚**。例如，按门诊日志每7天抽取一个病人，若疾病发病有周周期性，则会导致偏倚。
**适用**：适用于无明显周期性的大型总体快速抽样。

#### 2.1.3 分层抽样 (Stratified Sampling)
**定义**：将总体中全部个体按某种与主要研究指标相关的特征（如年龄、性别、疾病严重程度）分成若干“层”，再从每一层内独立地进行[[简单随机抽样]]（或系统抽样），最后将各层样本合并组成总样本。
**优点**：
1.  **提高估计精度**：通过使层内变异小、层间变异大，可以减少抽样误差。
2.  **保证子群代表性**：确保每个重要亚组（层）都有足够样本进行分析。
3.  **便于管理**：不同层可采用不同的抽样比或调查方法。
**缺点**：需要详细的辅助信息用于分层；**分层不当时（选择的分层变量与研究结局无关），分层抽样将失去其优势，甚至可能降低效率**。
**关键**：分层变量应选择与主要结局变量相关性强的变量。

#### 2.1.4 整群抽样 (Cluster Sampling)
**定义**：先将总体划分为K个“群”（如社区、学校、医院），每个群包含若干观察单位；再随机抽取k个群，对抽中的群进行全面调查（一级整群抽样）或再从中抽样（二级/多级整群抽样）。
**优点**：在没有完整个体抽样框，但有群抽样框时极为实用；实施便捷，成本较低，尤其适用于地域分散的总体。
**缺点**：**当样本例数一定时，其抽样误差一般大于单纯随机抽样的误差**。这是因为同一群内的个体往往具有相似性（组内相关性，ICC>0），导致样本信息量不如SRS。这种效率损失通过**设计效应 (Design Effect, DEFF)** 来量化，DEFF = V(复杂抽样)/V(SRS)。在整群抽样中，DEFF通常 >1。
**延伸**：当群规模过大或不均时，常采用**按规模大小成比例概率抽样 (Probability Proportional to Size, PPS)**。

#### 抽样方法比较与选择
```
方法            | 原理                         | 优点                   | 缺点/适用条件
----------------|------------------------------|------------------------|----------------------------
SRS            | 等概率不放回                 | 简单，理论基准         | 需完整框，效率可能不高
系统抽样       | 按间隔抽取                   | 简便，分布均匀         | 惧周期趋势
分层抽样       | 层内同质，层间异质           | 精度高，保子群         | 需好的分层变量
整群抽样       | 随机选群，普查或再抽         | 成本低，无需个体框     | 精度通常低于SRS (DEFF>1)
```

### 2.2 非概率抽样 (Non-probability Sampling)
虽然在进行统计推断时存在局限，但在探索性研究、资源极度受限或针对特殊群体（如罕见病患者）时仍有应用价值。主要包括：
*   **方便抽样**：选择最易于接触的个体。
*   **判断抽样**：研究者根据专业知识主观选择“典型”个体。
*   **滚雪球抽样**：通过已有参与者推荐找到更多参与者，适用于隐蔽群体。
*   **配额抽样**：非随机地实现预设的各类别样本量。

**注意**：基于非概率样本的推断，其结论的外推性存在巨大不确定性。[[横断面调查]] 若采用非概率抽样，其结果通常仅用于生成假设。

## 3. 调查设计的其他关键要素

### 3.1 问卷设计 (Questionnaire Design)
*   **信度与效度**：必须评估工具的重测信度、内部一致性信度和内容效度、结构效度。
*   **问题措辞**：避免引导性、双重否定、专业术语。
*   **应答选项**：穷尽、互斥，考虑使用李克特量表。
**资源**：**GraphPad** 的指南对设计调查问题和理解测量尺度非常有帮助：[GraphPad Statistics Guide: Questionnaires and surveys](https://www.graphpad.com/guides/prism/latest/statistics/stat_questionnaires_surveys.htm)

### 3.2 样本量估算 (Sample Size Estimation)
样本量取决于：
1.  **允许误差 (Margin of Error, E)**：对估计精度的要求。
2.  **置信水平 (1-α)**：通常为95%。
3.  **总体变异度**：用标准差σ或率P估计。
4.  **抽样设计**：需要引入**设计效应 (DEFF)** 来调整。例如，对于整群抽样，调整后的样本量 n_adj = n_srs * DEFF。
5.  **预计无应答率**：需按比例扩大样本量。

**通用公式（估计均值时）**：`n = (Z_{α/2} * σ / E)^2 * DEFF`， 然后 `n_final = n / (1 - Non-response Rate)`
**资源**：**statsmodels** (Python) 和 R 的 `survey` 包提供了在复杂调查设计下进行样本量计算的工具。
*   **statsmodels 文档**：[Power and Sample Size Calculations](https://www.statsmodels.org/stable/stats.html#power-and-sample-size-calculations)

### 3.3 数据收集与无应答处理
*   **模式**：面对面、电话、邮件、网络调查。模式选择会影响应答率和数据质量。
*   **无应答 (Non-response)**：是调查误差的主要来源之一。
    *   **处理**：通过电话、邮件追访；在分析阶段使用**加权调整**（如事后分层、倾向得分加权）来校正。
    *   **关键**：必须尽可能记录无应答者的特征，以评估无应答偏倚。

## 4. 复杂调查数据的分析

来自复杂抽样设计（如分层、整群、加权）的数据，其分析**不能**使用标准统计方法（假设数据是i.i.d.的）。否则会低估标准误，增加I类错误。

### 4.1 核心概念：设计效应与加权
*   **设计效应 (Design Effect, DEFF)**：量化复杂抽样相对于SRS的效率损失。`DEFF = Var_complex / Var_SRS`。
*   **抽样权重 (Sampling Weight)**：每个样本个体被选中概率的倒数 `w_i = 1 / π_i`。权重代表了该样本个体在总体中所“代表”的人数。加权分析旨在还原总体结构。

### 4.2 分析方法
1.  **加权描述**：计算加权的均值、比例、标准误。
2.  **加权回归模型**：使用加权最小二乘法或伪最大似然估计。
3.  **考虑设计信息的方差估计**：必须使用**泰勒级数线性化法 (Taylor Series Linearization)** 或**重抽样法**（如刀切法、自助法）来正确估计标准误。

## 5. 总结与展望

**Survey Design** 是一项融合了统计学、社会科学和项目管理学的综合性科学。一个成功的调查始于一个清晰的研究问题和一个严谨的设计方案。

*   **设计选择**：根据研究目标、总体特征、资源约束，在**精度、成本和可行性**之间做出最优权衡。[[分层抽样]]追求精度，[[整群抽样]]追求成本效益。
*   **误差控制**：贯穿始终的核心任务是控制**抽样误差**（通过概率抽样和足够的样本量）和**非抽样误差**（包括抽样框误差、测量误差、无应答误差）。
*   **分析适配**：复杂设计的调查必须采用配套的、考虑设计信息的复杂分析方法，否则将得出错误的结论。

**博士生进阶思考**：
1.  在数字化时代，如何整合传统概率抽样与基于大数据的网络招募，进行混合模式调查？
2.  如何评估和校正由于使用多个抽样框或自抽样框带来的覆盖误差？
3.  在罕见病研究中，如何设计高效的概率抽样方案（如序贯抽样、网状抽样）？

掌握Survey Design的原理，不仅是进行高质量研究的技能，更是批判性评价现有证据（如阅读一篇[[横断面调查]]论文时，快速评估其抽样方法是否合理）的必备素养。
