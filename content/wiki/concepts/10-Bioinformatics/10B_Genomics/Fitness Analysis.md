# Fitness Analysis (适应度分析)

> [!info] 定义
> **适应度分析** 是通过量化基因突变对细菌生存和繁殖能力的影响，鉴定基因功能和重要性的方法。在 [[Tn-seq]] 中，适应度通过 Fold Change (FC) 衡量。

---

## 1. 概述

[[Fitness Analysis|适应度分析]]是功能基因组学的核心方法，用于鉴定细菌在特定条件下的必需基因和适应度基因。

### 1.1 适应度定义

| 指标 | 定义 | 生物学意义 |
|-----|------|-----------|
| **Fitness (Fit)** | FC < 0 (负值) | 基因**必需**或**适应** — 敲除后适应度降低 |
| **Unfitness (Unfit)** | FC > 0 (正值) | 基因**不适应** — 敲除后适应度增加 |
| **Neutral** | FC ≈ 0 | 基因非必需 |

### 1.2 计算方法

**Fold Change (FC)** = log₂(实验组丰度 / 对照组丰度)

- **实验组**: 感染/选择条件下的突变体丰度
- **对照组**: 初始文库/非选择条件下的突变体丰度

---

## 2. 适应度分析方法

### 2.1 Tn-seq 方法

**原理**: 通过转座子插入和测序，量化每个基因的适应度贡献。

**步骤**:
1. 构建饱和转座子突变体库
2. 在选择条件下培养/感染
3. 测序并量化插入位点丰度
4. 计算适应度 (FC)
5. 统计检验

**详细**: [[Tn-seq]]

### 2.2 CRISPRi 方法

**原理**: 利用 CRISPR 干扰抑制基因表达，观察适应度变化。

**步骤**:
1. 构建 CRISPRi 文库
2. 诱导 dCas9 表达
3. 观察生长缺陷
4. 量化适应度

**详细**: [[CRISPRi]]

### 2.3 基因敲除方法

**原理**: 通过同源重组敲除基因，观察适应度变化。

**步骤**:
1. 构建敲除质粒
2. 同源重组
3. 筛选转化子
4. 验证适应度

**详细**: [[基因敲除]]

## 3. 统计方法

### 3.1 标准化方法

| 方法 | 原理 | 优点 | 缺点 |
|-----|------|------|------|
| **TMM** | 加权修剪均值 | 考虑文库大小 | 假设多数基因不变 |
| **DESeq2** | 负二项分布 | 考虑离散度 | 计算复杂 |
| **RPKM/FPKM** | 考虑长度和测序深度 | 简单 | 不考虑组成偏差 |

### 3.2 差异分析方法

| 方法 | 原理 | 适用场景 |
|-----|------|---------|
| **负二项分布** | 考虑生物学变异 | 多重复 |
| **t-检验** | 正态分布假设 | 2组比较 |
| **Wilcoxon** | 非参数检验 | 非正态数据 |
| **Gumbel** | 极值分布 | 必需基因鉴定 |

### 3.3 多重检验校正

| 方法 | 控制目标 | 严格度 |
|-----|---------|-------|
| **FDR** | 错误发现率 | 较宽松 |
| **FWER** | 家族错误率 | 较严格 |
| **Bonferroni** | FWER | 最严格 |
| **Benjamini-Hochberg** | FDR | 常用 |

**详细**: [[Tn-seq 统计方法]]

## 4. 适应度分析软件

### 4.1 主要软件

| 软件 | 功能 | 特点 |
|-----|------|------|
| [[TRANSIT]] | 全流程分析 | 用户友好，多种统计方法 |
| [[TSAS]] | 插入位点鉴定 | 高灵敏度 |
| [[Tn-seq Tools]] | 基础分析 | 简单易用 |
| [[Bio-Tradis]] | TraDIS 分析 | 专门用于 TraDIS |

### 4.2 TRANSIT 使用

**TRANSIT** 是最常用的 Tn-seq 分析软件：

**功能模块**:
- **hmm**: Hidden Markov Model 分析
- **griffin**: 基因水平分析
- **gumbel**: 必需基因鉴定
- **resampling**: 重抽样检验

**输出**:
- 基因水平 FC 值
- 统计显著性 (p-value, q-value)
- 必需基因列表

**详细**: [[TRANSIT 使用指南]]

## 5. 结果解读

### 5.1 FC 值解读

| FC 范围 | 含义 | 示例 |
|---------|------|------|
| FC < -2 | 强必需基因 | 核心代谢基因 |
| -2 < FC < -1 | 中度必需基因 | 条件必需基因 |
| -1 < FC < 0 | 弱必需基因 | 适应度基因 |
| FC ≈ 0 | 非必需基因 | 冗余基因 |
| FC > 0 | 不适应基因 | 有害基因 |

### 5.2 统计显著性

| 指标 | 含义 | 阈值 |
|-----|------|------|
| **p-value** | 原假设下观察到结果的概率 | < 0.05 |
| **q-value** | FDR 校正后的 p-value | < 0.05 |
| **FWER** | 家族错误率 | < 0.05 |

> [!warning] 重要
> 在 Tn-seq 中，n=1 时仅 FWER 有意义。p-value 和 q-value 需要多个重复。

### 5.3 生物学解释

| 模式 | 解释 | 验证方法 |
|-----|------|---------|
| **所有组织必需** | 核心必需基因 | 基因敲除验证 |
| **组织特异必需** | 条件必需基因 | 组织特异感染 |
| **时间特异必需** | 阶段特异基因 | 时间序列分析 |
| **不适应基因** | 有害基因 | 过表达验证 |

## 7. 实验设计

### 7.1 重复设计

| 设计 | 优点 | 缺点 |
|-----|------|------|
| **生物学重复** | 考虑生物变异 | 成本高 |
| **技术重复** | 考虑技术变异 | 不考虑生物变异 |
| **混合重复** | 平衡成本和变异 | 复杂 |

**建议**: 至少 3 个生物学重复

### 7.2 时间点设计

| 设计 | 应用 | 优点 |
|-----|------|------|
| **单时间点** | 必需基因鉴定 | 简单 |
| **多时间点** | 动态适应度 | 全面 |
| **时间序列** | 时序分析 | 高分辨率 |

### 7.3 对照设计

| 对照 | 目的 | 重要性 |
|-----|------|-------|
| **初始文库** | 基线丰度 | 必需 |
| **体外培养** | 体外适应度 | 参考 |
| **不同组织** | 组织特异性 | 比较 |
