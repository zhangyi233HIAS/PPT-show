**定义**：一款基于本地Markdown文件的知识管理工具
https://obsidian.md/
**核心特性**：
- **双链系统**：`[[概念]]` 语法创建知识网络
- **本地优先**：数据存储在本地，完全可控
- **插件生态**：丰富的社区插件支持
- **图谱视图**：可视化知识网络结构


Obsidian 的本质不是笔记软件，而是一个**基于本地 Markdown 文件、高度可扩展的 IDE（集成开发环境）**。

### 1. 核心高阶逻辑：从“文件夹分类”到“图谱网状拓扑”

- **MOC (Map of Content，内容地图) 架构**：抛弃传统的多层树状文件夹，采用统一的扁平存储（或仅区分附件、模板和日记）。通过主控笔记（MOC）动态汇聚同一主题的标签与双链，实现柔性分类。
    
- **数据解耦**：利用纯文本 Markdown，底层可通过脚本（Python/Shell）直接批量处理，完全规避了类似 Notion 等云端工具的供应商锁定（Vendor Lock-in）风险。
    

### 2. 高阶插件生态（Top 使用率与工业级工作流）

| **插件名称**              | **核心作用与专家级玩法**                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Dataview**          | **核心必装。** 将笔记视为数据库，利用类似于 SQL 的 DQL 语言（或 DataviewJS）动态检索、筛选和展示属性（Frontmatter）。例如，一行脚本自动生成“所有未完成且截止日期为本周的任务清单”。 |
| **Templater**         | 强大的模板引擎。支持执行任意 JavaScript 脚本。可在创建笔记时自动获取系统状态、调用 Web API（如天气、股票、热点新闻）并动态填充。                                    |
| **Omnisearch**        | 极其强大的本地文本搜索引擎。内置 OCR 功能，能够对笔记中插入的图片、PDF 内部文本进行全量索引和秒级搜索。                                                      |
| **Obsidian Git**      | 自动化版本控制（自动化异地备份）。利用 Git 引擎自动按设定的时间间隔（如每30分钟）将本地 Vault 隐式 commit 并 push 到私有云端仓库（如 GitHub）。                     |
| **Smart Connections** | **AI 协同代表。** 本地调用 OpenAI / Ollama 接口。将全库笔记向量化（Embeddings），在右侧实时显示与当前书写内容语义最相关的历史笔记，打破“知识孤岛”。                  |
