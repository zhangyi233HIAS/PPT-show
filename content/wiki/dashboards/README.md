# 📊 仪表盘 (Dashboards)

> 数据驱动的可视化面板，一目了然地掌握关键指标和项目状态。

## 仪表盘列表

| 仪表盘 | 说明 | 更新频率 |
|--------|------|----------|
| [[research-dashboard\|研究仪表盘]] | 项目进度、关键指标 | 每周 |
| [[skill-dashboard\|技能仪表盘]] | 技能覆盖率、学习进度 | 每两周 |

## 设计原则

1. **一屏可见** — 关键指标在单屏内完整展示
2. **数据驱动** — 基于实际数据而非主观判断
3. **趋势导向** — 关注变化趋势而非静态快照
4. **可操作性** — 每个指标都对应可执行的行动

## 指标体系

```
┌─────────────────────────────────────┐
│           知识库健康度                │
│  ┌──────────┐    ┌──────────┐       │
│  │ 完整性    │    │ 连通性    │       │
│  │ 指标      │    │ 指标      │       │
│  └──────────┘    └──────────┘       │
│  ┌──────────┐    ┌──────────┐       │
│  │ 时效性    │    │ 活跃度    │       │
│  │ 指标      │    │ 指标      │       │
│  └──────────┘    └──────────┘       │
└─────────────────────────────────────┘
```

## 数据来源

- **知识库文件**：文件数量、大小、修改时间
- **链接数据**：wikilink、反向链接
- **标签数据**：标签分布、覆盖率
- **项目数据**：任务状态、完成率
- **协议数据**：Curator 评分、进化日志
