# 📇 索引系统说明

> 索引是知识库的导航层，帮助快速定位和关联各类知识条目。

## 四种索引

| 索引 | 文件 | 用途 | 维护频率 |
|------|------|------|----------|
| 实体索引 | [[entity-index]] | 追踪人物、项目、工具等具体实体 | 每次新增实体时更新 |
| 概念索引 | [[concept-index]] | 追踪理论、模型、原则等抽象概念 | 每次新增概念时更新 |
| 方法索引 | [[method-index]] | 追踪流程、技术、框架等方法论 | 每次新增方法时更新 |
| 发现索引 | [[finding-index]] | 追踪研究发现、实验结果、洞察 | 每次产生新发现时更新 |

## 维护规则

1. **新增条目**：在对应索引表格中添加一行，链接到详细笔记
2. **更新条目**：修改状态、标签等字段，更新日期
3. **归档条目**：状态标记为 `归档`，保留历史记录
4. **定期审查**：每月底检查索引完整性和链接有效性

## 使用技巧

- 在 Obsidian 中使用 `Ctrl+O` 快速搜索索引文件
- 利用表格排序功能按需浏览
- 结合标签（`#tag`）和 Dataview 插件进行高级查询
