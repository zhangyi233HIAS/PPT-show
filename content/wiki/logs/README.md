# 📋 日志系统说明

> 日志记录知识库的演变过程，提供可追溯的操作历史。

## 日志类型

| 日志 | 文件 | 用途 |
|------|------|------|
| Curator日志 | [[curator-log]] | 记录知识库质量评估与维护操作 |
| Kanban日志 | [[kanban-log]] | 记录任务状态变更与进度 |
| 进化日志 | [[evolution-log]] | 记录知识库结构变更与架构演进 |

## 使用原则

1. **及时记录**：操作完成后立即记录
2. **简洁明了**：用最少文字传达关键信息
3. **可追溯**：包含日期、原因、影响等关键字段
4. **定期回顾**：每周回顾日志，提取模式和改进点

## 日志与索引的关系

- 日志记录**时间线上的事件**
- 索引记录**当前状态的快照**
- 两者互补，共同构建完整的知识库记忆
