# Methods

Protocols, techniques, and analytical methods used in research.

## Taxonomy

Methods are organized into subdirectories by domain:

| Directory | Domain | Examples |
|-----------|--------|----------|
| `methods-Tnseq/` | Transposon mutagenesis sequencing | Tn-seq library prep, essential gene analysis, saturation analysis |
| `methods-Genomics/` | General genomics | Assembly, annotation, variant calling, comparative genomics |
| `methods-Transcriptomics/` | Gene expression | RNA-seq, differential expression, co-expression networks |
| `methods-Statistics/` | Statistical & computational methods | Hypothesis testing, Bayesian inference, machine learning, normalization |

## What a Method Page Contains

- **Protocol overview** — what the method does and when to use it
- **Key parameters** — critical settings and their effects
- **Tools & software** — specific implementations
- **Troubleshooting** — common issues and solutions
- **References** — key papers and documentation

## Naming Convention

Descriptive slug within the appropriate subdirectory:
- `methods-Tnseq/tn-seq-library-prep.md`
- `methods-Statistics/bayesian-essentiality-testing.md`

## Cross-linking

Methods should link to:
- **Sources** that describe or benchmark the method
- **Queries** that used the method
- Related methods in other subdirectories
