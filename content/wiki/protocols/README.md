## 使用原则

1. **协议优先** — 重复性任务遵循协议执行，减少决策偏差
2. **定期回顾** — 每月审视协议有效性，持续改进
3. **文档同步** — 协议变更时同步更新相关文档
4. **灵活适配** — 协议是指南而非教条，允许合理变通
