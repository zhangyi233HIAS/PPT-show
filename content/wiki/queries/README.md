# Queries

Research questions, query results, and analysis outputs.

## Purpose

Each page in this directory represents a **research question** and its answer — whether that answer comes from a database search, literature review, data analysis, or synthesis across sources.

## What a Query Page Contains

- **The question** — clearly stated
- **Method** — how the question was answered (search terms, databases queried, analysis performed)
- **Results** — findings, tables, figures, or summary text
- **Sources** — links to the raw evidence and source summaries that support the answer
- **Confidence** — how well-supported the answer is

## Naming Convention

Use a descriptive slug:
- `what-tnseq-essential-genes-b.subtilis.md`
- `transcriptomics-stress-response-conservation.md`

## Template

```markdown
---
type: query
status: open | answered | partial
date: YYYY-MM-DD
confidence: high | medium | low
tags: []
related: []
---

# <Question>

## Question
## Method
## Results
## Sources
## Open Follow-ups
```
