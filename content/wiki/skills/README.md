# 🧠 技能知识库

## 概述

技能知识库记录和组织与研究工作相关的所有技能与知识，采用三级分类体系，便于检索和积累。

## 三级分类体系

```
skills/
├── core/        ← 核心技能：基础研究能力
├── domain/      ← 领域技能：专业领域知识
└── extended/    ← 扩展技能：辅助工作能力
```

| 层级 | 说明 | 示例 |
|------|------|------|
| **[[core/README\|核心技能]]** | 研究工作的基础能力，通用性强 | 生物信息学、统计分析、实验设计 |
| **[[domain/README\|领域技能]]** | 特定研究领域的专业知识 | 沙门氏菌研究、鸽子基因组学 |
| **[[extended/README\|扩展技能]]** | 提升效率与质量的辅助能力 | 学术写作、同行审稿、演示汇报 |

## 设计理念

- **核心技能** 是根基，支撑所有研究工作
- **领域技能** 是专长，体现研究深度
- **扩展技能** 是助力，提升综合竞争力

三者相互关联、互为补充，共同构成完整的知识体系。
