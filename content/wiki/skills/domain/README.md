# 🎯 领域技能（Domain Skills）

## 概述

领域技能是特定研究方向的专业知识，体现研究的深度与特色。这些技能通常需要长期积累，具有较高的专业壁垒。

## 研究领域

| 血清分型 | 沙门氏菌血清型鉴定与分类 | |
| 毒力因子 | 致病机制与毒力岛分析 | |
| 耐药性 | 抗性基因检测与耐药机制 | |
