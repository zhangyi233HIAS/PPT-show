# 📊 摘要系统

## 概述

摘要系统用于定期记录和回顾项目进展，帮助跟踪里程碑、积累成果、规划未来。

## 摘要类型

| 类型 | 频率 | 模板 | 说明 |
|------|------|------|------|
| 周摘要 | 每周 | [[weekly-summary]] | 记录一周主要进展与下周计划 |
| 月摘要 | 每月 | [[monthly-summary]] | 汇总里程碑、数据统计与下月目标 |

## 使用指南

1. **周摘要** — 每周五或周日填写，回顾本周完成的任务、遇到的问题、下周计划
2. **月摘要** — 每月末填写，汇总本月里程碑、关键数据、经验教训

## 文件命名规范

- 周摘要：`周摘要-YYYY-WXX.md`（如 `周摘要-2026-W23.md`）
- 月摘要：`月摘要-YYYY-MM.md`（如 `月摘要-2026-06.md`）
