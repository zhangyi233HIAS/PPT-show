## 概述

工作流文档记录标准化的研究工作流程，确保每一步骤清晰可重复，提高工作效率和产出质量。

## 工作流设计原则

1. **标准化** — 每个流程有明确的步骤和检查清单
2. **可重复** — 记录详细参数，确保结果可复现
3. **可迭代** — 根据经验不断优化流程
4. **模块化** — 子流程可灵活组合
