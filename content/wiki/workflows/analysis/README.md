# 🔬 分析流程

## 概述

生物信息分析的标准化流程，从原始数据到分析报告的完整路径，确保分析可重复、结果可靠。

## 流程总览

```
数据获取 → 质控 → 分析 → 验证 → 报告
```

## 详细步骤

### 第1步：数据获取与准备

- [ ] 确认数据来源和格式
- [ ] 检查数据完整性
- [ ] 建立项目目录结构
- [ ] 记录数据元信息（来源、时间、版本）

#### 推荐目录结构

```
project_name/
├── raw_data/          # 原始数据（只读）
├── clean_data/        # 质控后数据
├── scripts/           # 分析脚本
├── results/           # 分析结果
├── figures/           # 图表
├── logs/              # 运行日志
└── README.md          # 项目说明
```

### 第2步：数据质控

- [ ] 原始数据质量评估（FastQC / NanoStat）
- [ ] 质量过滤与修剪（Trimmomatic / fastp）
- [ ] 去除接头和污染序列
- [ ] 质控前后数据统计对比
- [ ] 记录质控参数和结果

> [!warning] 重要
> 质控是分析质量的基础，不要跳过或草率处理。

### 第3步：核心分析

根据项目类型选择相应分析流程：

#### 基因组组装

| 步骤 | 工具 | 说明 |
|------|------|------|
| 组装 | SPAdes / Flye / Canu | 根据数据类型选择 |
| 质量评估 | QUAST / CheckM | N50、完整性、污染率 |
| 注释 | Prokka / Bakta | 基因预测与功能注释 |

#### 系统发育分析

| 步骤 | 工具 | 说明 |
|------|------|------|
| 序列比对 | MAFFT / MUSCLE | 多序列比对 |
| 建树 | IQ-TREE / RAxML | 最大似然法 |
| 可视化 | iTOL / FigTree | 树形展示 |

#### 变异检测

| 步骤 | 工具 | 说明 |
|------|------|------|
| 比对 | BWA / Minimap2 | 比对到参考基因组 |
| 变异调用 | GATK / Snippy | SNP/InDel检测 |
| 过滤 | VCFtools / BCFtools | 质量过滤 |

#### 比较基因组学

| 步骤 | 工具 | 说明 |
|------|------|------|
| 核心/泛基因组 | Roary / Panaroo | 基因组比较 |
| MLST分型 | MLST / chewBBACA | 分子分型 |
| 耐药基因 | AMRFinderPlus / CARD | 抗性基因检测 |

### 第4步：结果验证

- [ ] 关键结果的生物学合理性检查
- [ ] 使用不同方法/工具交叉验证
- [ ] 检查异常值和离群点
- [ ] 统计显著性评估
- [ ] 结果可重复性确认

### 第5步：分析报告

- [ ] 整理关键结果和图表
- [ ] 记录分析参数和版本信息
- [ ] 编写分析报告
- [ ] 归档脚本和中间文件
- [ ] 更新项目状态

## 环境管理

> [!tip] Conda 环境
> 为每个项目或分析类型创建独立的 Conda 环境，记录环境配置文件。
>
> ```bash
> conda env create -f environment.yml
> conda env export > environment.yml
> ```

## 日志记录

- 记录每一步的命令、参数、运行时间
- 保存标准输出和错误日志
- 使用 Git 跟踪脚本变更
