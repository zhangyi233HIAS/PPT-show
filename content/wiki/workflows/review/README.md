# 📝 审稿流程

## 概述

标准化的同行评审流程，确保评审意见全面、专业、建设性。

## 流程总览

```
收到邀请 → 初步评估 → 详细评审 → 撰写意见 → 提交
```

## 详细步骤

### 第1步：收到审稿邀请

- [ ] 确认是否在自己专业范围内
- [ ] 检查是否存在利益冲突
- [ ] 确认审稿截止日期
- [ ] 决定是否接受邀请

> [!warning] 时间管理
> 通常审稿周期为 2-4 周，需合理安排时间。

### 第2步：初步评估（通读）

- [ ] 快速阅读全文，了解研究主题和主要发现
- [ ] 评估论文的创新性和重要性
- [ ] 初步判断实验设计是否合理
- [ ] 记录整体印象和主要疑问

### 第3步：详细评审

#### 标题与摘要
- [ ] 标题是否准确反映研究内容
- [ ] 摘要是否包含关键信息（目的、方法、结果、结论）

#### 引言
- [ ] 研究背景是否充分
- [ ] 研究问题是否明确
- [ ] 文献引用是否全面、准确

#### 方法
- [ ] 实验设计是否合理
- [ ] 方法描述是否足够详细（可重复性）
- [ ] 统计方法是否恰当
- [ ] 样本量是否充足

#### 结果
- [ ] 数据展示是否清晰
- [ ] 图表是否规范、易读
- [ ] 统计分析是否正确
- [ ] 结果是否支持结论

#### 讨论
- [ ] 结果解释是否合理
- [ ] 局限性是否充分讨论
- [ ] 与现有文献的比较是否准确
- [ ] 未来方向是否合理

#### 其他
- [ ] 英文写作质量
- [ ] 参考文献格式
- [ ] 数据可用性声明

### 第4步：撰写评审意见

#### 结构模板

```markdown
**总体评价：**
[1-2句总体评价]

**主要问题：**
1. [问题描述及建议]
2. [问题描述及建议]

**次要问题：**
1. [问题描述及建议]
2. [问题描述及建议]

**语言与格式：**
- [语言问题]
- [格式建议]

**推荐决定：**
[接受 / 小修 / 大修 / 拒稿]
```

### 第5步：提交评审

- [ ] 再次检查评审意见的完整性和准确性
- [ ] 确保语气专业、建设性
- [ ] 按时提交

## 审稿检查清单

> [!check] 完整检查清单
> - 科学问题是否重要
> - 方法是否适当
> - 数据是否可靠
> - 结论是否被数据支持
> - 写作是否清晰
