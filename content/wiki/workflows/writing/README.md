# ✍️ 写作流程

## 概述

学术论文写作的标准化流程，从数据准备到论文发表的完整路径。

## 流程总览

```
数据准备 → 结构规划 → 初稿撰写 → 图表制作 → 反复修改 → 投稿
```

## 详细步骤

### 第1步：数据准备与分析

- [ ] 确认所有分析已完成并经过验证
- [ ] 整理关键结果和数据表
- [ ] 确定主要发现和亮点
- [ ] 选择最能支持结论的图表

### 第2步：结构规划

- [ ] 确定目标期刊
- [ ] 阅读期刊投稿指南
- [ ] 列出论文大纲
- [ ] 确定各部分核心信息

#### 标准结构（IMRaD）

| 部分 | 核心内容 | 建议字数 |
|------|----------|----------|
| **Title** | 简洁、准确、有吸引力 | 15-20词 |
| **Abstract** | 背景、方法、结果、结论 | 200-300词 |
| **Introduction** | 背景→缺口→目的 | 500-800词 |
| **Methods** | 详细、可重复 | 800-1500词 |
| **Results** | 客观呈现数据 | 1000-2000词 |
| **Discussion** | 解释→比较→局限→展望 | 1000-1500词 |

### 第3步：初稿撰写

> [!tip] 写作顺序建议
> Methods → Results → Introduction → Discussion → Abstract → Title

- [ ] **Methods** — 描述实验和分析方法
- [ ] **Results** — 呈现关键发现
- [ ] **Introduction** — 建立研究背景和动机
- [ ] **Discussion** — 解释结果、讨论意义
- [ ] **Abstract** — 凝练全文精华
- [ ] **Title** — 最终确定标题

### 第4步：图表制作

- [ ] 设计清晰的图表布局
- [ ] 确保分辨率符合期刊要求（通常 ≥300 DPI）
- [ ] 统一字体、颜色、标注风格
- [ ] 制作图注（Figure legends）
- [ ] 补充表格（Tables）

#### 图表设计原则
- 简洁明了，避免冗余信息
- 颜色选择考虑色盲友好
- 标注清晰，单位完整

### 第5步：反复修改

#### 修改轮次清单

| 轮次 | 重点 | 检查项 |
|------|------|--------|
| 第1轮 | 内容完整性 | 逻辑、数据、结论 |
| 第2轮 | 结构与流畅性 | 段落衔接、论证逻辑 |
| 第3轮 | 语言质量 | 语法、用词、表达 |
| 第4轮 | 格式与细节 | 引用格式、图表编号 |

### 第6步：投稿准备

- [ ] 准备 Cover Letter
- [ ] 检查投稿系统要求
- [ ] 准备利益冲突声明
- [ ] 确认作者贡献声明
- [ ] 补充材料整理
- [ ] 最终检查并提交

## 投稿后流程

```
提交 → 初审 → 同行评审 → 修回 → 再审 → 接收/拒稿
```

- 收到审稿意见 → 参见 [[../review/README|审稿流程]]（审稿人视角）
- 撰写修回信 → Response to Reviewers
